Variable shadowing allows you to declare a new variable with the same name as a previously declared variable by using the `let` keyword again. The new declaration "shadows" the old one, making the original variable inaccessible from that point forward.

This is fundamentally different from making a variable mutable with `mut`.

- **Mutability (`let mut`)**: Allows you to change a variable's **value**, but its **type cannot change**.
    
- **Shadowing (`let`)**: Creates an entirely **new** variable. Both its **value and type can be different** from the original.
    

---

### The Main Advantage: Changing a Variable's Type

The most powerful feature of shadowing is the ability to transform a value and change its type while reusing the same logical name. This is ideal when converting data, such as user input that arrives as a string.

Rust

```Rust
fn main() {
    // 1. The variable is first declared as a string.
    let grams_of_protein = "100.345";

    // 2. It's shadowed to become a new variable of type f64 (a decimal number).
    // The original string variable is now inaccessible.
    let grams_of_protein = 100.345;

    // 3. It's shadowed again to become a new variable of type i32 (a whole number).
    // The f64 variable is now inaccessible.
    let grams_of_protein = 100;

    println!("The final value is: {}", grams_of_protein);
}
```

In this example, the name `grams_of_protein` logically represents the same concept throughout, but its underlying type changes from a string to a float, and finally to an integer. This would be impossible using `mut`.

---

### Combining Shadowing and Mutability

You can make the _final_ shadowed version of a variable mutable. This allows you to perform a series of type transformations and then have a final variable whose value can be changed.

Rust

```Rust
fn main() {
    let grams_of_protein = "100.345"; // A string
    let grams_of_protein = 100.345;   // A float

    // The final shadowed version is an integer and is made mutable.
    let mut grams_of_protein = 100;
    println!("Initial integer value: {}", grams_of_protein);

    // Now that `grams_of_protein` is a mutable integer, we can change its value.
    grams_of_protein = 105;
    println!("Updated integer value: {}", grams_of_protein);

    // ERROR: You still cannot change its type.
    // grams_of_protein = 110.5;
}
```
