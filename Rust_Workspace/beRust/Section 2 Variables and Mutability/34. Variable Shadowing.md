### Variable Shadowing in Rust 👥

Variable shadowing allows you to declare a new variable with the same name as a previously declared variable. This is done by using the `let` keyword again for a name that is already in scope. When you shadow a variable, the new declaration "overshadows" the old one, making the original variable inaccessible from that point forward.

This is fundamentally different from marking a variable as mutable (`mut`).

- **Mutability (`let mut`)**: Allows you to change a variable's **value**, but its **type cannot change**.
    
- **Shadowing (`let`)**: Creates an entirely **new** variable with the same name. Both its **value and type can be different** from the original.
    

---

### The Main Advantage: Changing a Variable's Type

The most powerful feature of shadowing is the ability to transform a value and change its type while reusing the same logical name. This is especially common when converting data, like user input that arrives as a string.

Rust

```Rust
// 1. A value is first stored as a string.
let value = "  150  ";
println!("Initial value (as text): '{}'", value);

// 2. Shadow `value` to trim whitespace. The type is still a string slice.
let value = value.trim();
println!("Trimmed value (as text): '{}'", value);

// 3. Shadow `value` again to convert it to a number. The type now changes to an integer.
let value = value.parse::<i32>().unwrap();
println!("Final value (as number): {}", value);
```

In this example, the name `value` logically represents the same concept throughout, but its underlying type changes from a string to an integer, which would be impossible with `mut`.

---

### Combining Shadowing and Mutability

You can make the _final_ shadowed version of a variable mutable. This allows you to perform a series of type transformations and then have a final variable whose value can be changed.

Rust

```Rust
let config_setting = "true"; // A string

// Shadow the setting to a boolean type and make it mutable
let mut config_setting = config_setting.parse::<bool>().unwrap();
println!("Initial setting: {}", config_setting);

// Now that `config_setting` is a mutable boolean, we can change its value.
config_setting = false;
println!("Updated setting: {}", config_setting);
```

Here, the final `config_setting` is a mutable boolean. Its value can be changed from `true` to `false`, but it cannot be changed to a different type, like a number or a string.
