### Positional Arguments in `println!`

A fundamental concept in Rust and many other programming languages is **0-indexed counting**. This means that when we count items in a sequence, we start from `0`, not `1`. The first item is at position `0`, the second is at `1`, the third is at `2`, and so on.

This concept applies directly to the `println!` macro. When you pass values (arguments) after the initial format string, Rust assigns each one an index starting from `0`.

---

#### Syntax and Usage

You can explicitly reference these arguments by placing their index number inside the curly brace placeholders `{}`.

- `{0}` refers to the **first** argument after the string.
    
- `{1}` refers to the **second** argument after the string.
    

Rust

```Rust
let item = "Coffee Beans";
let quantity = 2; // This is the first argument (index 0)
let unit = "kg";      // This is the second argument (index 1)

// Explicitly referencing arguments by their position
println!("Order: {0} {1} of {2}.", quantity, unit, item);
```

**Output:** `Order: 2 kg of Coffee Beans.`

---

### The Advantage of Reusability

The primary benefit of using positional arguments is the ability to **reuse** a value multiple times in the output string without passing it again. This makes your code more efficient and less repetitive.

Rust

```Rust
let product_code = "A-113";
let status = "In Transit";

// Here, we reuse the product_code (index 0) multiple times.
println!("Status for {0}: The package is now '{1}'. Tracking number for item {0} is active.", product_code, status);
```

**Output:** `Status for A-113: The package is now 'In Transit'. Tracking number for item A-113 is active.`

In this example, we only passed `product_code` once, but by referencing its index `{0}`, we could inject its value into the string in two different places.
