```Rust
// A constant declared at the file level.
const TOUCHDOWN_POINTS: i32 = 6;

fn main() {
    // A variable with an explicit type annotation.
    let season: &str = "Fall";

    // A mutable variable that is declared and then reassigned.
    let mut points_scored: i32 = 28;
    points_scored = 35;

    // A variable that is shadowed to change its type.
    let event_time = "06:00"; // `event_time` is a &str here.
    let event_time = 6;      // `event_time` is now an i32.

    // A println! call using interpolation to display all values.
    println!(
        "My favorite season is {}. The team scored {} points. The event started at {}. A touchdown is worth {} points.",
        season, points_scored, event_time, TOUCHDOWN_POINTS
    );

    // A variable with a compiler directive to suppress the "unused" warning.
    #[allow(unused_variables)]
    let favorite_beverage = "Snapple Apple";
}
```

---

### Key Concepts in This Solution

- **Mutability (`mut`):** The `points_scored` variable is declared with `let mut` to allow its value to be changed from `28` to `35` on a subsequent line.
    
- **Constants (`const`):** `TOUCHDOWN_POINTS` is declared as a constant. Its name is in `UPPER_SNAKE_CASE`, its type (`i32`) is explicitly required, and it's placed at the file level to be accessible by any function.
    
- **Variable Shadowing:** `event_time` is first declared as a string (`&str`) and then "shadowed" by a new declaration using `let`. This allows its type to change to an integer (`i32`) while keeping the same name.
    
- **String Interpolation:** The `println!` macro uses curly braces `{}` to seamlessly embed the values of variables and constants into the final output string.
    
- **Compiler Directives:** The `#[allow(unused_variables)]` directive is placed directly above `favorite_beverage` to instruct the compiler to ignore the warning about it being unused.
