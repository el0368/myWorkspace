### Notes on `println!` and String Interpolation

The **`println!`** macro is the standard way to print text to the console. Its key feature is that it automatically appends a **line break** after the output, so subsequent prints start on a new line.

Rust

```Rust
// Prints text with a newline
println!("System check complete."); 
// This will appear on the next line
println!("All services are running."); 
```

---

### String Interpolation: Making Strings Dynamic

**Interpolation** is the process of injecting dynamic values (like variables or the results of expressions) directly into a string. This avoids having to print many separate parts. Rust offers two main ways to do this.

#### Method 1: Positional Arguments

This is the classic method where you use empty curly braces **`{}`** as placeholders in the string. You then provide the values to be inserted as additional, comma-separated arguments to `println!`. The values are matched to the placeholders in order.

Rust

```Rust
let user = "Alex";
let level = 12;

// The value of `user` goes into the first {}, `level` into the second.
println!("Welcome, {}. You are level {}.", user, level);

// You can also use expressions directly.
println!("In two levels, you will be level {}.", level + 2);
```

#### Method 2: Direct Variable Capture (Modern Syntax)

Introduced in Rust 1.58, this more modern syntax allows you to place the variable name directly inside the curly braces. This is often more readable as the value and its placeholder are in the same spot.

Rust

```Rust
let user = "Alex";
let level = 12;

// The variable names inside {} are replaced with their values.
println!("Welcome, {user}. You are level {level}.");
```

### Important Rules and Common Errors

1. **Curly Braces are Essential**: Without the braces, Rust treats the text as a hard-coded string, not a variable to be interpolated.
    
    - `println!("user");` -> Prints the literal word "user".
        
    - `println!("{user}");` -> Prints the value of the `user` variable (e.g., "Alex").
        
2. **Variable Must Exist**: Referencing a variable that doesn't exist or has a typo will cause a compile-time error. Rust will not build your program.
    
    Rust
    
    ```Rust
    let product_id = "X-789";
    // ERROR: `producy_id` is a typo and does not exist.
    // println!("Shipping item: {producy_id}"); 
    ```
    
3. **Case Sensitivity Matters**: Variable names are case-sensitive. `user` and `User` are two different variables.
    
    Rust
    
    ```Rust
    let user = "Alex";
    // ERROR: `User` with a capital 'U' is not the same variable.
    // println!("User login: {User}");
    ```
