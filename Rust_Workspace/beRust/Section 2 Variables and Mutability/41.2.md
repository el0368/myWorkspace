### Variables


```Rust
fn main() {
    // Variable declaration and type inference
    let age = 30;

    // Explicit type annotation
    let price: f64 = 19.99;

    // Type alias
    type Meters = i32;
    let distance: Meters = 1000;
}
```

### Interpolation


```Rust
fn main() {
    let name = "Alice";
    let city = "New York";

    // Basic interpolation
    println!("Hello, {}!", name);

    // Multiple arguments
    println!("{} lives in {}.", name, city);

    // Positional arguments
    println!("{1} lives in {0}. {1} is happy.", name, city);
}
```

### Mutability


```Rust
fn main() {
    // Immutable variable (default)
    let immutable_value = 10;
    // immutable_value = 20; // This would cause a compile-time error

    // Mutable variable
    let mut mutable_value = 5;
    mutable_value = 15; // This is allowed
    println!("Mutable value: {}", mutable_value);

    // mutable_value = "hello"; // This would cause a compile-time error (cannot change type)
}
```

### Constants

```Rust
// Constants declared at the file level
const MAX_USERS: u32 = 1000;
const PI: f64 = 3.14159;

fn main() {
    println!("Maximum users: {}", MAX_USERS);
    println!("Value of PI: {}", PI);

```

### Variable Shadowing


```Rust
fn main() {
    let x = 5;
    println!("Initial x: {}", x);

    // Shadowing the variable x with a new value
    let x = x + 1;
    println!("Shadowed x (value changed): {}", x);

    // Shadowing the variable x with a different type
    let x = "six";
    println!("Shadowed x (type changed): {}", x);
}
```

### Scopes


```Rust
fn main() {
    let outer_variable = 10;
    println!("Outer variable: {}", outer_variable);

    { // Start of a new block and scope
        let inner_variable = 20;
        println!("Inner variable: {}", inner_variable);
        let outer_variable = 100; // This shadows the outer_variable within this scope
        println!("Outer variable inside inner scope: {}", outer_variable);
    } // End of the inner block and scope

    // println!("Inner variable after scope: {}", inner_variable); // This would cause a compile-time error
    println!("Outer variable after inner scope: {}", outer_variable); // outer_variable reverts to its original value
}
```

### Compiler Directives


```Rust
// Apply to the entire file
#![allow(unused_variables)]

fn main() {
    #[allow(unused_variables)] // Apply to this line
    let unused_single_line = 1;

    let a = 10; // This would normally cause a warning because 'a' is unused
}

#[allow(unused_variables)] // Apply to this function
fn some_function() {
    let b = 20; // This would normally cause a warning because 'b' is unused
}
```

### Unused Variable Warning Solution (Underscore Prefix)


```Rust
fn main() {
    let _unused_variable = 10; // No warning because of the underscore prefix
    let _another_unused = "hello";
}
```
