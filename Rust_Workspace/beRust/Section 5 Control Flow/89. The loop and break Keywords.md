## Rust Control Flow: `loop` and `break` Keywords (Unconditional & Conditional Iteration)

This study guide introduces the fundamental concepts of iteration (repetition) in Rust using the `loop` keyword, and how to control its execution with the `break` keyword.

### I. Understanding Iteration

What is iteration?

Iteration (or repetition) is a core programming concept that means "to repeat, to do something over and over again." It's essential for automating processes that would otherwise be manual or tedious.

What is the simplest way to iterate in Rust?

The simplest way to create a repetitive block of code in Rust is by using the loop keyword.

---

### II. The `loop` Keyword

What does the loop keyword do?

The loop keyword declares a block of code that Rust will execute repeatedly and continuously.

- **Syntax:**
    
    Rust
    
    ```Rust
    loop {
        // Code to be repeated indefinitely
    }
    ```
    
- **Default Behavior:** By default, a `loop` creates an **infinite loop**. This means the code within its block will run **forever** (indefinitely) unless explicitly told to stop.
    
- **Warning:** Running an infinite loop without a termination condition will cause your program to consume increasing amounts of memory and CPU, eventually leading to a crash or hanging your system.

### III. The `break` Keyword

How do you stop an infinite loop?

To terminate a loop and prevent it from running indefinitely, you use the break keyword.

- **Definition:** The `break` keyword immediately **terminates the innermost loop** it is contained within. It causes the program's execution to jump out of the loop and continue with the code immediately following the loop's block.
    
- **Purpose:** `break` is almost always combined with a **conditional statement (an `if` statement)** to specify _when_ the loop should stop based on a condition being met.
    

**Syntax for `break` with `if`:**

Rust

```Rust
loop {
    if some_condition_is_met {
        // Optional: code to run just before breaking
        break; // Stop the loop
    }
    // Code that continues to run if the condition is not met
}
```

**Example: Countdown Timer Program**

Let's use the `loop` and `break` to create a countdown from 10 to 0.

Rust

```Rust
fn main() {
    let mut seconds = 10; // Must be mutable to change its value inside the loop

    println!("Starting countdown...");

    loop { // Start of the loop block
        // 1. Check the termination condition
        if seconds == 0 {
            println!("Blastoff!"); // Action when condition is met
            break;               // Terminate the loop
        }

        // 2. Perform actions for the current iteration (if not breaking)
        println!("{} seconds to blastoff...", seconds);

        // 3. Update state for the next iteration (decrement seconds)
        seconds -= 1; // Shorthand for: seconds = seconds - 1; (requires 'mut')
    } // End of the loop block

    println!("Program finished."); // This runs after the loop breaks
}
```

**Tracing `seconds = 10`:**

1. **Loop 1 (seconds = 10):**
    
    - `if 10 == 0` is `false`.
        
    - `println!("10 seconds to blastoff...")` executes.
        
    - `seconds` becomes `9`.
        
2. **Loop 2 (seconds = 9):**
    
    - `if 9 == 0` is `false`.
        
    - `println!("9 seconds to blastoff...")` executes.
        
    - `seconds` becomes `8`.
        
3. ... (This continues for `seconds` = 8, 7, 6, 5, 4, 3, 2)
    
4. **Loop 9 (seconds = 2):**
    
    - `if 2 == 0` is `false`.
        
    - `println!("2 seconds to blastoff...")` executes.
        
    - `seconds` becomes `1`.
        
5. **Loop 10 (seconds = 1):**
    
    - `if 1 == 0` is `false`.
        
    - `println!("1 seconds to blastoff...")` executes.
        
    - `seconds` becomes `0`.
        
6. **Loop 11 (seconds = 0):**
    
    - `if 0 == 0` is `true`.
        
    - `println!("Blastoff!")` executes.
        
    - `break;` is encountered, which immediately **terminates the `loop`**.
        
7. Program flow jumps to `println!("Program finished.")` after the loop.

### IV. Key Takeaways

- **Iteration (Repetition):** A core programming concept for automating repeated tasks.
    
- **`loop` Keyword:** Creates a block of code that executes repeatedly. By default, it's an **infinite loop**.
    
- **`break` Keyword:** Used to **terminate a `loop`** prematurely.
    
- **Conditional Termination:** `break` is almost always paired with an `if` statement to stop the loop when a specific condition is met.
    
- **Mutable State:** Variables modified inside a `loop` (like our `seconds` counter) must be declared with `mut`.
    
- **Structure:** The `loop` keyword defines a regular code block with curly braces, similar to function bodies or `if` blocks.
