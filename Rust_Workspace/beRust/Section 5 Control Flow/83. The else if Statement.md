## Rust Control Flow: The `else if` Statement

This study guide explores how to chain multiple related conditional checks using `else if`, a fundamental construct for controlling program execution flow.

### I. Understanding `else if`

What is an else if statement?

An else if statement allows you to check for another condition if the preceding if or else if condition(s) evaluated to false. It provides an alternative path of execution within a sequence of related conditional checks.

When can an else if statement be used?

An else if statement cannot exist independently. It must always follow an initial if statement (or another else if statement). It's part of a conditional chain.

How does an if-else if chain work?

Rust evaluates the conditions in an if-else if chain sequentially from top to bottom:

1. It first checks the condition of the initial `if` statement.
    
2. **If the `if` condition is `true`:**
    
    - Its associated code block is executed.
        
    - Rust then **skips all subsequent `else if` statements** in the chain and continues execution after the entire `if-else if` block. Only one block in the entire chain will ever execute.
        
3. **If the `if` condition is `false`:**
    
    - Rust moves on to evaluate the condition of the first `else if` statement.
        
    - This process repeats: If an `else if` condition is `true`, its block runs, and all subsequent `else if`s are skipped.
        
    - If an `else if` condition is `false`, Rust proceeds to the next `else if` in the chain.
        

The goal is to find the **first conditional that evaluates to `true`** and execute its corresponding block.

**Example: Seasons Logic**

Rust

```Rust
fn main() {
    let season = "spring"; // This value can be changed to test different paths

    if season == "summer" {
        println!("School's out! Time for vacation.");
    } else if season == "winter" {
        println!("Brr, so cold! Time for hot cocoa.");
    } else if season == "fall" {
        println!("Leaves falling! Beautiful colors.");
    } else if season == "spring" {
        println!("Lots of rain, but flowers are blooming!");
    }
    // If none of the above are true, nothing in this chain will execute.
    println!("Seasonal check complete.");
}
```

**Tracing `season = "spring"`:**

1. `if season == "summer"` ( `"spring" == "summer"` is `false`) - **Skipped.**
    
2. `else if season == "winter"` ( `"spring" == "winter"` is `false`) - **Skipped.**
    
3. `else if season == "fall"` ( `"spring" == "fall"` is `false`) - **Skipped.**
    
4. `else if season == "spring"` ( `"spring" == "spring"` is `true`) - **Execute its block.**
    
    - Output: `Lots of rain, but flowers are blooming!`
        
5. All subsequent `else if`s (if any) are skipped. Execution continues after the entire `if-else if` chain.
    
    - Output: `Seasonal check complete.`

### II. `if-else if` vs. Separate `if` Statements

**What's the difference between an `if-else if` chain and multiple independent `if` statements?**

This is a crucial distinction based on program behavior:

|Feature|`if-else if` Chain (`if ... else if ...`)|Separate `if` Statements (`if ...`, `if ...`, `if ...`)|
|---|---|---|
|**Relationship**|Conditions are **related and mutually exclusive** (or you want to prioritize the first match).|Conditions are **independent**.|
|**Evaluation**|Rust evaluates conditions **sequentially** and **stops at the first `true`** condition.|Rust evaluates **all** `if` statements, regardless of previous outcomes.|
|**Execution**|**Only one block** (at most) in the entire chain will execute.|**Multiple blocks** can execute if their respective conditions are `true`.|
|**Purpose**|For "choose one of these options" logic.|For "check each of these conditions" logic.|

**Example: `if-else if` vs. Separate `if`s**

Rust

```Rust
fn main() {
    let score = 95;

    // --- Using an if-else if chain (Only ONE block will run) ---
    println!("--- Using if-else if (Related Checks) ---");
    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else { // 'else' will be covered in the next lesson, but conceptually it handles 'none of the above'
        println!("Grade: F");
    }
    // Output: Grade: A (because score >= 90 is true, others are skipped)

    println!("\n--- Using Separate if (Independent Checks) ---");
    // --- Using separate if statements (Multiple blocks MIGHT run) ---
    let has_license = true;
    let is_adult = true;
    let has_vehicle = false;

    if has_license {
        println!("User has a valid driver's license.");
    }
    if is_adult {
        println!("User is an adult.");
    }
    if has_vehicle {
        println!("User owns a vehicle.");
    }
    // Output:
    // User has a valid driver's license.
    // User is an adult.
    // (Both blocks ran because their conditions were independent and true)
}
```

**When to choose which?**

- **Use `if-else if` (chained conditionals):**
    
    - When your conditions are **related** and you want to find the **first matching condition** and then stop checking others.
        
    - When the outcomes are mutually exclusive (e.g., a number cannot be both greater than 90 and greater than 80 simultaneously _in the context of the chain_).
        
    - Best for "if this, else if that, else if another thing" scenarios.
        
- **Use separate `if` statements:**
    
    - When your conditions are **independent**, and you want to check each one regardless of whether previous conditions were met.
        
    - When it's possible (and desired) for **multiple blocks of code to execute**.
        
    - Best for scenarios like "If the user is logged in, show their profile. If the user has new messages, show notifications. If the user has unread emails, show email count." (These can all be true and lead to separate actions).
