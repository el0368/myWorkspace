Here are simple code examples for each concept from the section review:

### If Statement

```Rust
fn main() {
    let number = 10;

    if number > 5 {
        println!("The number is greater than 5.");
    }
}
```

### Else If Statement

```Rust
fn main() {
    let number = 7;

    if number > 10 {
        println!("The number is greater than 10.");
    } else if number > 5 {
        println!("The number is greater than 5 but not greater than 10.");
    }
}
```

### Else Statement

```Rust
fn main() {
    let number = 3;

    if number > 10 {
        println!("The number is greater than 10.");
    } else if number > 5 {
        println!("The number is greater than 5.");
    } else {
        println!("The number is 5 or less.");
    }
}
```

### If/Else Expression (Blocks Producing a Valu

```Rust
fn main() {
    let condition = true;
    let number = if condition {
        5
    } else {
        6
    }; // Semicolon is important here to assign the result

    println!("The value of number is: {}", number);
}
```

### Match Statement (Basic)

```Rust
fn main() {
    let number = 3;

    match number {
        1 => println!("One!"),
        2 => println!("Two!"),
        3 => println!("Three!"),
        _ => println!("Something else!"), // Catch-all pattern
    }
}
```

### Match Statement (Binding to a Variable and Producing a Value)

```Rust
fn main() {
    let boolean_value = false;

    let message = match boolean_value {
        true => "It's true!",
        false => "It's false!",
    }; // Semicolon here to assign the result

    println!("{}", message);
}
```

### Match Statement (Catch-all Underscore `_`)

```Rust
fn main() {
    let lucky_number = 7;

    match lucky_number {
        1 => println!("One!"),
        2 => println!("Two!"),
        _ => println!("It's not one or two, it's something else!"), // Always matches last
    }
}
```

### Loop Keyword (Infinite Loop)

```Rust
fn main() {
    let mut count = 0;
    loop {
        println!("Looping forever... (count: {})", count);
        count += 1;
        if count == 3 {
            break; // Prevents infinite loop
        }
    }
}
```

### `break` Keyword

```Rust
fn main() {
    let mut counter = 0;
    loop {
        counter += 1;
        if counter == 5 {
            break; // Exit the loop
        }
        println!("Counter: {}", counter);
    }
    println!("Loop finished.");
}
```

### `continue` Keyword

```Rust
fn main() {
    let mut number = 0;
    loop {
        number += 1;
        if number % 2 == 0 { // Skip even numbers
            continue;
        }
        println!("Odd number: {}", number);
        if number >= 5 {
            break;
        }
    }
}
```

### While Loop

```Rust
fn main() {
    let mut count = 0;
    while count < 5 {
        println!("Count: {}", count);
        count += 1; // Mutating state to ensure termination
    }
    println!("While loop finished.");
}
```

### Recursion (with Base Case)

```Rust
fn factorial(n: u64) -> u64 {
    // Base case: if n is 0 or 1, factorial is 1
    if n == 0 || n == 1 {
        return 1;
    }
    // Recursive step: n * factorial(n-1)
    n * factorial(n - 1)
}

fn main() {
    let num = 5;
    println!("Factorial of {}: {}", num, factorial(num)); // Expected: 120
}
```
