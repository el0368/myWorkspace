### **The `cargo run` Command 🏃**

The **`cargo run`** command is a convenient tool that combines two steps into one: it first **compiles** the entire project and then immediately **executes** the resulting program. This is the exact command used by the `rust-analyzer` "Run" button in VS Code.

By default, `cargo run` builds the project in **debug mode**.

---

### **Command Variations and Flags**

- **Standard Command:**
    
    Bash
    
    ```Bash
    cargo run
    ```
    
    This command shows the intermediate steps: "Compiling," "Finished," and "Running," followed by the program's output.
    
- **Quiet Mode:**
    
    Bash
    
    ```Bash
    cargo run --quiet
    ```
    
    The **`--quiet`** flag silences Cargo's own output. This means you will only see the actual output from your program, without the intermediate compilation and running messages.
    
- **Shortcut:**
    
    Bash
    
    ```Bash
    cargo r
    ```
    
    The shortcut for `cargo run` is **`cargo r`**. It can also be combined with flags, for example: `cargo r --quiet`.
