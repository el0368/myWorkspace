### **In-Depth Notes: Manually Compiling and Running a Rust Program**

This note details the two-step process of compilation and execution that the VS Code `Run` button automates.

#### **1. The Compilation Step**

Compilation is the process of translating human-readable source code into machine code that the computer's processor can directly execute.

- **The Tool:** The Rust compiler is a command-line program named **`rustc`** (`rust` + `c` for compiler).
    
- **The Command:** To compile a Rust file, you first navigate to its directory and then run the `rustc` command followed by the filename.
    
    Bash
    
    ```Bash
    # Navigate into the source directory
    cd src
    
    # Compile the main.rs file
    rustc main.rs
    ```
    
- **The Output (Executable File):** The compilation process creates a new file called a **binary executable**. This file contains the compiled machine code.
    
    - On **macOS and Linux**, the executable file will have the same name as the source file but with no extension (e.g., `main`).
        
    - On **Windows**, the executable file will have an **`.exe`** extension (e.g., `main.exe`). A `.pdb` file may also be generated for debugging purposes, which can be ignored.
        

#### **2. The Execution Step**

Execution is the separate step of running the compiled program.

- **The Command:** You must specify that you want to run a file in the current directory.
    
    - On **macOS and Linux**:
        
        Bash
        
        ```Bash
        ./main 
        ```
        
        The `./` prefix means "in the current directory."
        
    - On **Windows** (in PowerShell):
        
        Bash
        
        ```Bash
        .\main.exe
        ```
        
        The `.\` prefix serves the same purpose.
        
- **The Result:** Running this command executes the program, and its output (e.g., "Hello World! I am a Rust developer.") is printed to the terminal.
    

#### **3. Understanding the Executable File**

- **Target Architecture:**
    
    - By default, `rustc` compiles an executable for the **specific computer architecture** (CPU type and operating system) it is running on.
        
    - This means an executable compiled on a Mac **will not** run on a Windows computer, and vice-versa.
        
    - It's possible to configure `rustc` to compile for different systems (cross-compilation), but that is an advanced topic.
        
- **Portability and Decoupling from Rust:**
    
    - Once the executable is created, it is **completely independent of Rust**.
        
    - You can transfer the executable file to another computer with the **same architecture**, and it will run perfectly fine **even if Rust is not installed** on that machine. The machine code is self-contained.
        

---

In summary, the `Run` button in VS Code is a convenient shortcut that automates these two distinct steps: first compiling the `.rs` file with `rustc` to create an executable, and then immediately running that new executable.
