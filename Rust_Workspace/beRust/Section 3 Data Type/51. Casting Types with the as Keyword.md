### Study Guide: Type Casting in Rust (`as`) ⚙️

**Type casting** is the process of converting a value from one primitive type to another. In Rust, this is primarily done using the **`as`** keyword. Casting creates a new value of the new type; the original variable remains unchanged.

The basic syntax is: `let new_variable = old_variable as NewType;`

---

### Common Casting Scenarios

#### 1. Casting Between Numeric Types

You can cast between different integer sizes or different float sizes, as long as the value fits.

Rust

```Rust
fn main() {
    // Example from the transcript: Casting a larger integer to a smaller one.
    let miles_away_i32: i32 = 50;
    let miles_away_i8 = miles_away_i32 as i8; // Cast from i32 to i8
    println!("i32 value {} becomes i8 value {}", miles_away_i32, miles_away_i8);

    // Example from the transcript: Casting a larger float to a smaller one.
    let pi_f64: f64 = 3.1415926535;
    let pi_f32 = pi_f64 as f32; // Cast from f64 to f32 (loses precision)
    println!("f64 value {} becomes f32 value {}", pi_f64, pi_f32);
}
```

#### 2. Casting from Float to Integer (Truncation)

When you cast a float to an integer, the decimal part is **truncated** (cut off). **It is not rounded.**

Rust

```Rust
fn main() {
    let distance: f64 = 100.99;
    // The `.99` is truncated, not rounded up.
    let distance_as_int = distance as i32; // Becomes 100
    println!("Float {} becomes Integer {}", distance, distance_as_int);
}
```

#### 3. Casting from Integer to Float

Casting an integer to a float is generally safe and straightforward. However, for extremely large integers, you might lose some precision when casting to `f64`.

Rust

```Rust
fn main() {
    let score: i32 = 150;
    let score_as_float = score as f64; // Becomes 150.0
    println!("Integer {} becomes Float {}", score, score_as_float);
}
```

### The Risks of Casting: Data Loss and Unexpected Behavior ⚠️

The `as` keyword is a "brute force" conversion. You are telling the compiler you know what you're doing, and it will perform the conversion even if it leads to data loss or strange results.

- **Truncation:** As seen above, casting from a float to an integer truncates the decimal value.
    
- **Overflow (Wrapping):** Casting a large number to a smaller integer type that cannot hold it will cause the value to "wrap around" in release builds. This can be a source of subtle bugs.
    
    Rust
    
    ```Rust
    fn main() {
        let large_num: i32 = 300;
        // The maximum value for an i8 is 127.
        // The value wraps around: 300 % 256 = 44.
        let small_num = large_num as i8;
        println!("300 cast to i8 becomes: {}", small_num); // Prints 44
    }
    ```
    
- **Sign Changes:** Casting between signed and unsigned types can also produce surprising results if the value is out of the target type's range.
    
    Rust
    
    ```Rust
    fn main() {
        let negative_num: i8 = -5;
        // An unsigned u8 cannot be negative, so the value wraps.
        let unsigned_num = negative_num as u8;
        println!("-5 cast to u8 becomes: {}", unsigned_num); // Prints 251
    }
    ```
    

For these reasons, while `as` is useful, it should be used with caution. For safer conversions, Rust provides traits like `From`/`Into` and methods like `try_into()` which can return an error instead of producing an incorrect value.
