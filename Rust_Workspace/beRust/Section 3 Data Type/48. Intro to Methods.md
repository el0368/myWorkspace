### What is a Method? ⚙️

A **method** is a function that is associated with a specific data type. It's a behavior or a command that you can execute on a value of that type. You call a method using dot notation: `value.method_name()`.

The parentheses `()` are essential to **invoke** (run) the method. The value that a method produces or gives back is called its **return value**.

---

### Methods without Arguments

Some methods perform an action on the value itself and don't require any additional input.

#### Examples from the Transcript

- The `.abs()` method on an integer returns its absolute value (its distance from zero).
    
    Rust
    
    ```Rust
    let number: i32 = -15;
    let absolute_value = number.abs(); // The return value is 15
    println!("The absolute value of {} is {}.", number, absolute_value);
    ```
    
- The `.trim()` method on a string removes leading and trailing whitespace.
    
    Rust
    
    ```Rust
    let messy_string = "  my content  ";
    let trimmed_string = messy_string.trim(); // The return value is "my content"
    println!("'{}' becomes '{}' after trimming.", messy_string, trimmed_string);
    ```
    

---

### Methods with Arguments

Many methods require **arguments**—inputs you provide inside the parentheses to customize how the method works.

#### Examples from the Transcript and New Examples

- The `.pow()` method raises a number to a specified power. The power is provided as an argument.
    
    Rust
    
    ```Rust
    let base: i32 = -15;
    let squared = base.pow(2); // The argument `2` specifies the power
    println!("{} squared is {}.", base, squared); // Prints 225
    ```
    
- The `.replace()` method on a string takes two arguments: the pattern to find and the replacement text. Multiple arguments are separated by commas.
    
    Rust
    
    ```Rust
    let sentence = "I like Rust. Rust is great!";
    // This replaces all occurrences of "Rust" with "the new language".
    let new_sentence = sentence.replace("Rust", "the new language");
    println!("Replaced: {}", new_sentence);
    ```
