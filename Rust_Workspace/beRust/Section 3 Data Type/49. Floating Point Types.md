### Study Guide: Floating-Point Types in Rust 💧

A **floating-point** number (or **float**) is a number with a fractional component (a decimal number). In Rust, all floats are **signed**, meaning they can represent both positive and negative values.

---

### Rust's Float Types: `f32` vs. `f64`

Rust has two primary floating-point types. **`f64` is the default type** that Rust infers for any decimal number.

|Feature|`f32`|`f64`|
|---|---|---|
|**Size**|32 bits (4 bytes)|64 bits (8 bytes)|
|**Precision**|~6-7 decimal digits|~15-17 decimal digits|
|**Common Name**|Single-precision|Double-precision|
|**Default?**|No|**Yes**|

You should use `f64` unless you have a specific reason to conserve memory, as it offers greater precision. To use `f32`, you must explicitly annotate the type.

Rust

```Rust
fn main() {
    // f64 is the default, so no annotation is needed here.
    let gravity_on_earth = 9.81; // Inferred as f64

    // For f32, you MUST explicitly annotate the type.
    let pi_approx: f32 = 3.14;
}
```

---

### Precision and Rounding Errors

A crucial concept with floats is that they have **limited precision**. Because they use a finite number of bits to represent a potentially infinite number of decimal values, they can't always store a number with perfect accuracy. This can lead to rounding errors. This is a fundamental limitation of computer architecture, not just a Rust-specific issue.

#### Example: `f64` vs. `f32` Precision

Notice how `f32` loses more of the original number's detail compared to `f64`.

Rust

```Rust
fn main() {
    // A long decimal number
    let long_decimal = 1.234567890123456789;

    // As an f64, precision is higher.
    let num_f64: f64 = long_decimal;

    // As an f32, more information is lost due to less memory.
    let num_f32: f32 = long_decimal;

    println!("Original:  {}", long_decimal);
    println!("As f64:    {}", num_f64);    // Shows ~15-17 digits
    println!("As f32:    {}", num_f32);    // Shows only ~6-7 digits
}
```

---

### Common Methods on Floats

To use float-specific methods, you often need to ensure the variable has an explicit float type annotation.

- **`.floor()`**: Rounds **down** to the nearest whole number.
    
- **`.ceil()`**: Rounds **up** to the nearest whole number.
    
- **`.round()`**: Rounds to the **nearest** whole number (e.g., 3.5 rounds to 4.0, 3.4 rounds to 3.0).
    
- **`.trunc()`**: Removes the fractional part, leaving just the integer part (e.g., 3.8 becomes 3.0).
    
- **`.fract()`**: Returns only the fractional part (e.g., 3.8 returns 0.8).
    

#### Example

Rust

```Rust
fn main() {
    let my_float: f64 = 3.8;

    println!("Original Number: {}", my_float);
    println!("floor(): {}", my_float.floor());   // Rounds down -> 3.0
    println!("ceil(): {}", my_float.ceil());     // Rounds up -> 4.0
    println!("round(): {}", my_float.round());   // Rounds to nearest -> 4.0
    println!("trunc(): {}", my_float.trunc());   // Truncates decimal -> 3.0
    println!("fract(): {}", my_float.fract());   // Returns fractional part -> 0.8...
}
```

---

### Key Takeaways

- Floats represent decimal numbers and come in two sizes: `f32` and `f64`.
    
- **`f64` is the default** and should be used unless memory is a critical concern.
    
- All floating-point numbers can have rounding errors due to their finite precision.
    
- Common methods like `.floor()`, `.ceil()`, and `.round()` are available for rounding operations.
