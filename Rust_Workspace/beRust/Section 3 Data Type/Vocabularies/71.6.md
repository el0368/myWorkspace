### Part 6 Vocabularies: Booleans & Logical/Comparison Operators

1. **Boolean (`bool`)**:
    
    - **Definition**: A fundamental data type that can hold only one of two possible values: `true` or `false`.
        
    - **Purpose**: It models the concept of truth or falsehood in programming, representing a dichotomy (two opposing states).
        
    - **Real-world Analogy**: On/off, active/inactive, yes/no, present/absent.
        
    - **Example**: `let is_logged_in: bool = true;`, `let has_error: bool = false;`
        
2. **Equality Operator (`==`)**:
    
    - **Definition**: An operator consisting of two equal signs in a row (`==`).
        
    - **Purpose**: It compares its two operands to determine if they are equal (have the same value).
        
    - **Result**: Returns a `bool` value: `true` if the operands are equal, and `false` if they are not.
        
    - **Example**: `5 == 5` evaluates to `true`; `10 == 7` evaluates to `false`.
        
3. **Inequality Operator (`!=`)**:
    
    - **Definition**: An operator consisting of an exclamation point followed by an equal sign (`!=`).
        
    - **Purpose**: It compares its two operands to determine if they are _not_ equal (have different values).
        
    - **Result**: Returns a `bool` value: `true` if the operands are not equal, and `false` if they are equal.
        
    - **Example**: `5 != 5` evaluates to `false`; `10 != 7` evaluates to `true`.
        
4. **Greater Than Operator (`>`)**:
    
    - **Definition**: An operator used for numerical comparison (`>`).
        
    - **Purpose**: Checks if the left operand is strictly greater than the right operand.
        
    - **Result**: Returns a `bool` value.
        
    - **Example**: `10 > 5` evaluates to `true`; `3 > 7` evaluates to `false`.
        
5. **Less Than Operator (`<`)**:
    
    - **Definition**: An operator used for numerical comparison (`<`).
        
    - **Purpose**: Checks if the left operand is strictly less than the right operand.
        
    - **Result**: Returns a `bool` value.
        
    - **Example**: `5 < 10` evaluates to `true`; `8 < 2` evaluates to `false`.
        
6. **Greater Than or Equal To Operator (`>=`)**:
    
    - **Definition**: An operator used for numerical comparison (`>=`).
        
    - **Purpose**: Checks if the left operand is greater than or equal to the right operand.
        
    - **Result**: Returns a `bool` value.
        
    - **Example**: `10 >= 10` evaluates to `true`; `5 >= 8` evaluates to `false`.
        
7. **Less Than or Equal To Operator (`<=`)**:
    
    - **Definition**: An operator used for numerical comparison (`<=`).
        
    - **Purpose**: Checks if the left operand is less than or equal to the right operand.
        
    - **Result**: Returns a `bool` value.
        
    - **Example**: `5 <= 5` evaluates to `true`; `8 <= 3` evaluates to `false`.
        
8. **AND Operator (`&&`)**:
    
    - **Definition**: A logical operator consisting of two ampersands (`&&`).
        
    - **Purpose**: Combines two Boolean operands. It returns `true` only if **both** of its operands are `true`. If either or both are `false`, it returns `false`. It enforces that multiple independent conditions must _all_ be met.
        
    - **Short-circuiting**: If the left operand evaluates to `false`, the right operand is **not evaluated** because the overall result is already known to be `false`.
        
    - **Truth Table**:
        
        - `true && true` -> `true`
            
        - `true && false` -> `false`
            
        - `false && true` -> `false`
            
        - `false && false` -> `false`
            
    - **Example**: `(age >= 18 && has_license)` (both must be true).
        
9. **OR Operator (`||`)**:
    
    - **Definition**: A logical operator consisting of two vertical pipe symbols (`||`).
        
    - **Purpose**: Combines two Boolean operands. It returns `true` if **at least one** of its operands is `true` (i.e., if the left is true, or the right is true, or both are true). It returns `false` only if both operands are `false`. It enforces that _either/or_ (or both) of multiple conditions must be met.
        
    - **Short-circuiting**: If the left operand evaluates to `true`, the right operand is **not evaluated** because the overall result is already known to be `true`.
        
    - **Truth Table**:
        
        - `true || true` -> `true`
            
        - `true || false` -> `true`
            
        - `false || true` -> `true`
            
        - `false || false` -> `false`
            
    - **Example**: `(is_student || is_faculty)` (either being true is sufficient).
        
10. **Short-circuiting**:
    
    - **Definition**: An optimization technique used by logical AND (`&&`) and OR (`||`) operators. It means that the second operand is only evaluated if its evaluation is necessary to determine the final result of the entire expression.
        
    - **For `&&`**: If the first operand is `false`, the second is skipped.
        
    - **For `||`**: If the first operand is `true`, the second is skipped.
        
    - **Benefit**: Improves performance by avoiding unnecessary computations and prevents errors (e.g., trying to access a property on a `null` object after a `null` check).
