### Part 7 Vocabularies: Compound Types: Scalar vs. Compound, Arrays

1. **Scalar Type**:
    
    - **Definition**: A data type that holds a **single value**.
        
    - **Characteristic**: Variables of scalar types (like integers, floats, Booleans, characters) will contain only one distinct piece of data at any given time.
        
    - **Contrast**: Directly opposes "Compound Type."
        
    - **Example**: `let age = 30;` (`age` holds only the value `30`).
        
2. **Compound Type / Composite Type**:
    
    - **Definition**: A data type that is a **collection of one or more values**. The word "compound" literally means "made up of multiple existing parts."
        
    - **Characteristic**: A single variable of a compound type can store and manage several individual values together.
        
    - **Contrast**: Directly opposes "Scalar Type."
        
    - **Example**: Arrays and tuples are the first compound types introduced.
        
3. **Array**:
    
    - **Definition**: A fundamental **compound data type** in Rust that represents a **fixed-size collection of homogeneous data** (data of the same type).
        
    - **Declaration**: Created using a pair of **square brackets (`[]`)**, with elements listed inside, separated by commas.
        
    - **Characteristics**:
        
        - **Ordered Collection**: Elements are stored and maintained in a specific sequence (the order in which they are declared).
            
        - **Homogeneous Data**: All elements within an array _must_ be of the exact same data type (e.g., all integers, all floats, all string slices). You cannot mix types within a single array.
            
        - **Fixed Size**: Once an array is declared, its size (the number of elements it contains, also called its "length") is fixed at compile time and **cannot change** throughout the program's execution. It will not grow or shrink.
            
    - **Example**: `let numbers = [1, 2, 3, 4];` (an array of four `i32` integers). `let names: [&str; 2] = ["Alice", "Bob"];`
        
4. **Homogeneous Data**:
    
    - **Definition**: A characteristic of certain data collections (like arrays) where **all the data elements within the collection are of the same type**.
        
    - **Relevance to Arrays**: Arrays are defined as homogeneous, meaning `[1, 2, 3]` is valid, but `[1, "hello", true]` is not a valid array in Rust.
        
5. **Fixed Size**:
    
    - **Definition**: A property of a data type (like an array) meaning its **size (number of elements or memory footprint) is determined at compile time and remains constant** throughout the program's runtime. It cannot grow larger or shrink smaller.
        
    - **Relevance to Arrays**: This is a defining characteristic of Rust arrays. It enables them to be stored efficiently on the stack, as the compiler knows exactly how much memory to allocate.
        
6. **Index Position**:
    
    - **Definition**: A numerical value assigned to each element within an ordered collection (like an array or a tuple) that reflects its **order or position in line**.
        
    - **Counting**: In programming, index positions **start counting from `0`**. So, the first element has an index of `0`, the second has an index of `1`, and so on.
        
    - **Uniqueness**: Each element is assigned its own unique, non-duplicate index.
        
    - **Example**: In `let arr = ["A", "B", "C"];`, "A" is at index 0, "B" at index 1, and "C" at index 2.
        
7. **Length**:
    
    - **Definition**: The **count of the number of elements** within a collection (like an array).
        
    - **Counting**: Length starts counting from `1` (like human counting).
        
    - **Relationship to Index Position**: The final valid index position in an array (or tuple) will always be **one less than its length** because indexing starts from `0`. For an array of `length N`, the valid indices are `0` through `N-1`.
        
    - **Example**: `let arr = [10, 20, 30];` has a `length` of `3`, and its highest index position is `2`.
