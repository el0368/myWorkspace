## Rust's Basic Data Types

### What is a Data Type?

In Rust, every value has a **data type**, which tells the compiler what kind of data it is. Rust is a **statically typed** language, meaning the compiler must know the type of every variable at compile time. This allows the compiler to optimize the program by requesting the precise amount of memory needed to store each value. While the compiler can often infer a variable's type, developers can also explicitly annotate it.

---

### Scalar Types

A **scalar type** is a fundamental type that holds a single value. The numeric types we've seen, like integers and floats, are scalar. This is in contrast to **compound types**, which can hold multiple values, like a container or a box.

---

### Integer Types

Integers are whole numbers and fall into two main categories based on their ability to store negative numbers.

#### Signed vs. Unsigned Integers

- **Signed (`i` prefix):** These integers can be positive or negative. The `i` stands for "integer." Example: `i32`.
    
- **Unsigned (`u` prefix):** These integers can only be 0 or positive. They cannot store negative values. Example: `u8`.
    

The primary trade-off is the range of values. Because an **unsigned** integer doesn't need to use a bit to store a positive/negative sign, it can use that space to store larger positive numbers compared to its signed counterpart of the same size. For example, a `u8` can store values from 0 to 255, while an `i8` can store values from -128 to 127.

#### Understanding Bits

The number in an integer type (e.g., the `32` in `i32`) refers to the number of **bits** it occupies in memory. A **bit** is the smallest unit of computer memory, representing either a 0 or 1. More bits mean more memory usage but also the ability to store a much larger range of numbers.

---

### Floating-Point Types

Floating-point numbers are numbers with a decimal component. Rust has two primary float types:

- **`f32` (single-precision):** Accurate to about 6-9 decimal digits.
    
- **`f64` (double-precision):** Accurate to about 15-17 decimal digits.
    

The main difference is their **precision**. An `f64` uses twice as many bits as an `f32`, allowing it to store more digits after the decimal point with greater accuracy.

---

### Compiler Defaults and Optimization Advice

- **Defaults:** If you don't specify a type, the Rust compiler will infer a default. For integers, the default is **`i32`**, and for floating-point numbers, it's **`f64`**.
    
- **Optimization:** The instructor advises against "premature optimization" by trying to use the smallest possible data type for every variable. In the era of modern computers with abundant memory, using the default `i32` for a small number like `5` is perfectly acceptable and often leads to cleaner code. The priority should be to write a correct, working program first, and only focus on minimizing memory usage if it becomes a specific requirement.
