### Study Guide: Equality (`==`) and Inequality (`!=`) Operators

In Rust, you can compare two values to see if they are the same or different. These comparisons always produce a **boolean** (`true` or `false`) result.

|Operator|Name|Returns `true` if...|
|---|---|---|
|`==`|**Equality**|The two operands are equal.|
|`!=`|**Inequality**|The two operands are **not** equal.|

#### Crucial Distinction: Comparison (`==`) vs. Assignment (`=`)

It's critical not to confuse the two.

- **`=` (Single equals):** This is the **assignment** operator. It assigns a value to a variable.
    
- **`==` (Double equals):** This is the **comparison** operator. It checks if two values are equal and returns `true` or `false`.
    

Rust

```Rust
// ASSIGNMENT: Sets the value of `x` to 5.
let x = 5;

// COMPARISON: Checks if `x` is equal to 5, resulting in a boolean.
let is_five = (x == 5); // is_five is now `true`
```

### Rules of Comparison

#### 1. Operands Must Be of the Same Type

You can only compare values that share the exact same data type. Attempting to compare an integer to a float, for example, will result in a compile-time error.

Rust

```Rust
fn main() {
    // ERROR: This will not compile due to a type mismatch (i32 vs. f64).
    // let is_equal = 13 == 13.0;

    // FIX: Cast one of the types to match the other using the `as` keyword.
    let is_equal = 13 == (13.0 as i32); // The comparison is now (13 == 13), which is true.
    println!("Is 13 equal to 13.0 (after casting)? {}", is_equal);
}
```

#### 2. String Comparison is Exact

For strings to be equal, they must have the exact same characters in the exact same order. The comparison is **case-sensitive** and **whitespace-sensitive**.

Rust

```Rust
fn main() {
    // Example from transcript: Different values
    println!("'Coke' == 'Pepsi' -> {}", "Coke" == "Pepsi"); // false

    // Example from transcript: Case sensitivity matters
    println!("'Coke' == 'coke' -> {}", "Coke" == "coke"); // false

    // Example from transcript: Whitespace matters
    println!("'Coke' == 'Coke ' -> {}", "Coke" == "Coke "); // false

    // My Example: Inequality
    println!("'Rust' != 'Go' -> {}", "Rust" != "Go"); // true
}
```

#### 3. Numeric and Boolean Comparison

Comparison works as expected for numbers and booleans.

Rust

```Rust
fn main() {
    // Example from transcript: Integers
    println!("13 != 13 -> {}", 13 != 13); // false

    // My Example: Floats
    println!("3.14 == 3.1400 -> {}", 3.14 == 3.1400); // true

    // Example from transcript: Booleans
    println!("true != false -> {}", true != false); // true
}
```

### How It Works: The `PartialEq` Trait

Behind the scenes, the `==` and `!=` operators are made possible by a **trait** called `PartialEq` (Partial Equality). For a type to be comparable, it must implement this trait. All of Rust's primitive types, like integers, floats, booleans, and strings, have this trait implemented for you automatically.

When you create your own custom types (like `structs`) later on, you will often use `#[derive(PartialEq)]` to automatically make them comparable.
