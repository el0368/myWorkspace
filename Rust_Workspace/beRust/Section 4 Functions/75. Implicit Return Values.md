### Study Guide: Idiomatic Returns in Rust (Expressions) 🎯

In Rust, the most common and idiomatic way to return a value from a function is by using an **implicit return**. Instead of using the `return` keyword, you can make the last line of your function an **expression**, and its value will be automatically returned.

---

### Statements vs. Expressions (The Key Detail)

To understand implicit returns, you must know the difference between a statement and an expression in Rust.

- **Statement**: An instruction that performs an action but does **not** return a value. Statements end with a semicolon (`;`).
    
    Rust
    
    ```Rust
    // This is a statement. It performs an action (binding a value) but returns nothing.
    let x = 5;
    ```
    
- **Expression**: An instruction that **evaluates to a value**. When an expression is the last line of a function, it becomes the function's return value. Expressions do **not** have a semicolon at the end.
    
    Rust
    
    ```Rust
    // This is an expression. It evaluates to the value 15.
    5 + 10
    ```
    

The semicolon is what turns an expression into a statement.

---

### How to Write an Implicit Return

To convert a function to use an implicit return, follow these two critical steps:

1. Make sure the value you want to return is the **very last line** in the function.
    
2. **Remove the `return` keyword and the trailing semicolon (`;`)**.
    

#### Example from the Transcript (`square` function)

This shows the conversion from an explicit `return` to an idiomatic, expression-based return.

Rust

```Rust
// With the `return` keyword (explicit return)
fn square_explicit(number: i32) -> i32 {
    return number * number;
}

// With an implicit return (idiomatic Rust)
fn square_implicit(number: i32) -> i32 {
    number * number // No `return` keyword, no semicolon
}

fn main() {
    let result = square_implicit(5);
    println!("The result is {}", result); // Prints 25
}
```

#### My Example (using an `if/else` expression)

`if/else` blocks are also expressions in Rust, making them perfect for implicit returns.

Rust

```Rust
fn get_status(is_online: bool) -> &'static str {
    // The value of the executed block is returned.
    if is_online {
        "Online"
    } else {
        "Offline"
    }
}

fn main() {
    let status = get_status(true);
    println!("User status: {}", status); // Prints "User status: Online"
}
```

### Key Takeaways

- Rust functions can implicitly return the value of the last expression.
    
- To make the last line an expression that returns a value, **omit the semicolon**.
    
- This is the preferred and idi-omatic way to return values in Rust.
    
- A line ending with a semicolon is a statement and implicitly returns a "unit type" `()`, which is like nothing.
