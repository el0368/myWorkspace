### Study Guide: Function Parameters in Rust 📥

A **parameter** is a special variable declared in a function's signature that acts as a placeholder for an expected input. Parameters are what make functions powerful and flexible. Instead of performing the exact same task every time, a function can accept data and customize its behavior.

---

### Parameters vs. Arguments

These two terms are closely related but have distinct meanings.

- **Parameter**: The placeholder/variable name in the **function definition**.
    
- **Argument**: The concrete **value** you pass into the function when you **call (or invoke)** it.
    

Rust

```Rust
// In this function definition, `name` is the PARAMETER.
fn say_hello(name: &str) {
    println!("Hello, {}!", name);
}

fn main() {
    // When we call the function, "Alice" is the ARGUMENT.
    say_hello("Alice");
}
```

---

### Syntax for Defining Parameters

Parameters are defined inside the parentheses `()` of a function definition. Each parameter requires a name and an explicit type annotation, separated by a colon (`:`).

- Single Parameter:
    
    fn function_name(param_name: Type)
    
- Multiple Parameters: Separate multiple parameters with a comma.
    
    fn function_name(param1: Type1, param2: Type2)

This function is customized with both a quantity and a topping.


#### My Example (Calculating a Price)

This function takes two numbers to perform a calculation.

Rust

```Rust
fn calculate_total(price: f64, tax_rate: f64) {
    let total = price * (1.0 + tax_rate);
    println!("The total price is ${:.2}", total);
}

fn main() {
    calculate_total(49.99, 0.07); // The total price is $53.49
}
```

### Rust's Strict Type Checking

The Rust compiler is very strict about function calls, which is a key safety feature. It enforces two rules at compile time:

1. **Correct Number of Arguments:** You must pass exactly the number of arguments that the function defines as parameters.
    
2. **Correct Type of Arguments:** Each argument's type must match the type of its corresponding parameter.
    

Rust

```Rust
fn bake_pizzas(quantity: i32, topping: &str) { /* ... */ }

fn main() {
    // ERROR: missing the `topping` argument
    // bake_pizzas(10);

    // ERROR: "ten" is a &str, not an i32
    // bake_pizzas("ten", "veggie");
}
```
