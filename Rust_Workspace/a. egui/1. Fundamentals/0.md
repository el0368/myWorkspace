Here is a focused roadmap for **Fundamentals Only**. This path ignores complex topics like threading, custom painting, or mobile gestures. It focuses strictly on "How do I build a standard desktop tool?"

### 🗺️ Phase 1: The Skeleton (Days 1-2)

**Goal:** Get a window open and understand the "Loop".

1. **The Setup:**
    
    - Do not create a generic Rust project. Clone the official [eframe_template](https://github.com/emilk/eframe_template).
        
    - **Why:** It sets up the windowing system (eframe) for you.
        
    - **Task:** Run `cargo run` and see the default app.
        
2. **The `update` Function:**
    
    - Locate the `impl eframe::App for TemplateApp` block.
        
    - Find `fn update(...)`.
        
    - **Concept:** Understand that this specific function runs **60 times every second**.
        
    - **Task:** Add a `println!("Frame!");` inside `update` and watch your terminal flood. This proves the "Immediate Mode" concept.1
        

### 🗺️ Phase 2: State & Widgets (Days 3-4)

**Goal:** Connect variables to the screen.

1. **The Struct (Your Data):**
    
    - Go to your `struct TemplateApp`.
        
    - Add fields: `name: String`, `age: u32`, `is_happy: bool`.
        
    - **Task:** Initialize them in `impl Default for TemplateApp`.
        
2. **Read-Only Widgets (Output):**
    
    - Use `ui.label("text")` to show static text.
        
    - Use `ui.label(format!("My age is {}", self.age))` to show your data.2
        
3. **Interactive Widgets (Input):**
    
    - **Text:** `ui.text_edit_singleline(&mut self.name)`.
        
    - **Numbers:** `ui.add(egui::Slider::new(&mut self.age, 0..=100))`.
        
    - **Booleans:** `ui.checkbox(&mut self.is_happy, "I am happy")`.
        
    - **Concept:** Notice you pass `&mut`. You don't "get" the text later; the widget changes your variable _while_ the user types.3
        

### 🗺️ Phase 3: Control Flow (Day 5)

**Goal:** Make the UI react to logic.

1. **The "If" Statement UI:**
    
    - Immediate mode allows you to use standard Rust `if` statements to hide/show UI.
        
    - **Task:** Wrap a label in an `if`:
        
        Rust
        
        ```
        if self.is_happy {
            ui.label("Glad to hear it!");
        }
        ```
        
2. **The Button Action:**
    
    - Buttons return a "Response".
        
    - **Task:** Create a reset button:
        
        Rust
        
        ```
        if ui.button("Reset").clicked() {
            self.age = 0;
            self.name.clear();
        }
        ```
        

### 🗺️ Phase 4: Basic Layout (Days 6-7)

**Goal:** Stop the "Vertical List" look.

1. **Panels (The Container):**
    
    - **SidePanel:** Use `egui::SidePanel::left("my_side").show(...)` for a sidebar.
        
    - **CentralPanel:** Use `egui::CentralPanel::default().show(...)` for the main content.
        
    - **Rule:** `CentralPanel` must always be added **last** in the code.4
        
2. **Directions:**
    
    - **Horizontal:** Use `ui.horizontal(|ui| {... })` to put two buttons side-by-side.
        
    - **Vertical:** This is the default, but you can enforce it with `ui.vertical(...)`.
        
3. **Separation:**
    
    - Use `ui.separator()` to draw lines between sections.
        
    - Use `ui.add_space(10.0)` to add empty breathing room.
        

### ✅ The "Fundamental" Final Project

To graduate from fundamentals, build a **Character Creator**:

1. **Struct:** Define a `Character` with Name (String), Class (Enum), and Strength (u32).
    
2. **Layout:**
    
    - **Left Panel:** Controls. A text box for the name, radio buttons for the Class, and a slider for Strength.
        
    - **Central Panel:** The "Preview". Display the character's stats in big bold text (`ui.heading`).
        
    - **Logic:** Show a warning label in red (`ui.colored_label`) if Strength is too low (e.g., `< 5`).
        

Once you can build this without looking at the docs every 2 minutes, you have mastered the fundamentals.
