### Why we kill `target`?

1. **It is Regeneratable:** The `target` folder is just the output of the "Compiler Factory." As long as you have the "Blueprints" (source code), you can build the factory output again in seconds.
    
2. **It is Heavy:** As you saw, a single build can be **130MB+**. If you keep backing this up, your GitHub repository will become gigabytes in size for no reason.
    
3. **It is Machine-Specific:** The files inside `target` are built specifically for _your_ current computer (Windows). If you download them on a Mac or Linux machine, they won't work anyway. You _have_ to rebuild them on the new machine.
