This is a crucial concept. The short answer is: **No.**

You cannot put a `CentralPanel` inside another `CentralPanel`.

- **The Rule:** You get **one** `CentralPanel` per screen. It is the "End of the line." It fills all remaining space.
    

However, what you _actually_ want is to **divide** that `CentralPanel` into smaller sections (like a "Chart section" and a "Stock List section").

Here are the keywords you need to read in the docs to do this.

---

### 1. The Concept: "Cuts" vs. "Fills"

Since you are already inside the `CentralPanel`, you can't use "Panels" anymore. You must use **Layouts**.

- **`ui.vertical(...)`**: Lays out items from Top to Bottom.
    
- **`ui.horizontal(...)`**: Lays out items from Left to Right.
    
- **`ui.columns(...)`**: Splits the space into equal vertical strips.
    

---

### 2. How to Read "Layout" Docs

Search for `egui::Ui` again. Look for these methods:

**A. `horizontal`**

Rust

```
pub fn horizontal<R>(&mut self, add_contents: impl FnOnce(&mut Ui) -> R) -> InnerResponse<R>
```

- **Translation:** "Take the current space, and whatever you add inside `{ ... }`, place it side-by-side (Left to Right)."
    

**B. `vertical`**

Rust

```
pub fn vertical<R>(&mut self, add_contents: impl FnOnce(&mut Ui) -> R) -> InnerResponse<R>
```

- **Translation:** "Take the current space, and stack items (Top to Bottom)."
    

---

### 3. Practical Example: The "Trading Terminal" Layout

You want a classic setup:

- **Left:** A list of stocks.
    
- **Right:** The big chart.
    

You cannot use `SidePanel` inside `CentralPanel`. You must use `ui.horizontal`.

**The Code Structure:**

Rust

```
egui::CentralPanel::default().show(ctx, |ui| {
    // We are now inside the Main Window (The Void).
    
    // We want to split this Void into Left and Right.
    // KEYWORD: ui.horizontal
    ui.horizontal(|ui| {
        
        // --- COLUMN 1: The Stock List (Left) ---
        // We create a "Group" (a visible box) to make it look like a window.
        ui.group(|ui| {
            ui.heading("Watchlist");
            ui.button("AAPL");
            ui.button("TSLA");
            // This column grows as wide as these buttons need.
        });

        // --- COLUMN 2: The Chart (Right) ---
        // We create another Group for the chart.
        // We want this to take ALL remaining width.
        ui.group(|ui| {
             ui.heading("Chart Area");
             ui.label("Big Chart Goes Here");
        });
        
    }); // End of Horizontal split
});
```

### 4. Advanced Keyword: `Resizable`

For a trading app, you probably want to drag the line between the Watchlist and the Chart, right?

The keyword for a "box you can resize" is **`egui::Resize`**.

**How to read the docs for `Resize`:**

1. **Search:** `egui::Resize`
    
2. **Look for `default`**: `Resize::default()`
    
3. **Look for `show`**: `show(ui, ...)`
    

How it fits in:

Instead of a static group, you wrap your Watchlist in a Resize.

Rust

```
ui.horizontal(|ui| {
    // 1. Resizable Watchlist Area
    egui::Resize::default()
        .default_width(200.0) // Start with 200px width
        .show(ui, |ui| {
             ui.heading("Watchlist");
             ui.button("AAPL");
        });

    // 2. The Rest (The Chart)
    ui.group(|ui| {
        ui.heading("Chart");
    });
});
```

### Summary Checklist

- **Can I nest CentralPanels?** No.
    
- **How do I split the screen inside the CentralPanel?**
    
    - Keyword: `ui.horizontal` (for Left/Right split)
        
    - Keyword: `ui.vertical` (for Top/Bottom split)
        
    - Keyword: `ui.group` (to draw a border around that section)
        
    - Keyword: `egui::Resize` (if you want to drag the borders)
