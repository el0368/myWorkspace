### The "Save Game" Loop

Whenever you finish a feature or get code working, run these 4 commands in order:

1. **`git status`**
    
    - _Asks:_ "What did I change?" (Red files = changed, Green files = ready to save).
        
2. **`git add .`**
    
    - _Action:_ "Stage ALL changes." (Moves everything to the loading dock).
        
3. **`git commit -m "Describe what you did"`**
    
    - _Action:_ "Save Snapshot." (Wraps the files in a box and labels it. e.g., `"Feat: Add Dark Theme"`).
        
4. **`git push`**
    
    - _Action:_ "Upload." (Sends the box to GitHub for safekeeping).
