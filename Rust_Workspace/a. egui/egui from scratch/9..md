### Why Git Bash?

1. **It solves your Encoding Problem:** In PowerShell, creating files (like `.gitignore`) often defaults to a Windows-specific format (UTF-16) that Git can't read. In Git Bash, typing `echo "target/" > .gitignore` works perfectly and instantly.
    
2. **It is the Standard:** Most developer tutorials and commands (including Git) are written for Linux/Unix. Git Bash mimics Linux, so commands just work without translation.
    
3. **Better Git Integration:** It highlights branches and status automatically in the prompt.
