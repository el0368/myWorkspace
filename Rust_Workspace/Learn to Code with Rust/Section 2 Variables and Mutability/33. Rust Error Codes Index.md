### Investigating Rust Compiler Errors 🔎

The Rust compiler is designed to be helpful, and every error it produces comes with a unique **error code** (e.g., `E0384`). This code is your key to getting a detailed explanation of what went wrong and how to fix it. There are two primary ways to look up an error code.

---

#### 1. Using the Terminal (`--explain`)

When the compiler reports an error, it often suggests a command you can run directly in your terminal to learn more.

- **Command:** `rustc --explain <ERROR_CODE>`
    
- **Example:** If you encounter error `E0308` (a type mismatch), you would run:
    
    Bash
    
    ```
    rustc --explain E0308
    ```
    
- **Output:** This command prints a detailed explanation directly to your console, which typically includes:
    
    - A clear description of the error.
        
    - A code example that deliberately triggers the error.
        
    - A recommended solution or fix.
        

---

#### 2. The Online Rust Error Codes Index

All compiler error codes are documented online in the **Rust Error Codes Index**. You can easily find this page by searching for it.

- **Advantages:**
    
    - **Better Formatting:** The online documentation has proper syntax highlighting, making code examples easier to read.
        
    - **Interactive Examples:** Many error pages include runnable code snippets. You can click a "Run" button to see the incorrect code compile and fail live, allowing you to study the full compiler output.
        
    - **Centralized Resource:** It serves as a complete, searchable list of every possible compiler error.
        

The best way to use these resources is to look up an error **at the moment you encounter it**. This turns a frustrating bug into a valuable, targeted learning opportunity.
