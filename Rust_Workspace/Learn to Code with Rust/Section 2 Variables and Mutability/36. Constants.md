### Constants in Rust 🏛️

A **constant** is a name bound to a value that is permanently **immutable**. Its value is set when the code is compiled and can never be changed during the program's execution. The `mut` keyword cannot be used with constants.

---

### Constants vs. Immutable Variables

While both are immutable, constants have two key differences from regular variables declared with `let`.

|Feature|Immutable Variable (`let`)|Constant (`const`)|
|---|---|---|
|**Value Set**|At **Runtime** (when the program runs). Can hold results from function calls, user input, etc.|At **Compile Time** (when the code is built). Must be a hard-coded value known in advance.|
|**Scope**|Limited to the **scope** where it's declared (e.g., inside a function).|Can be declared in any scope, including the **global (file-level) scope**, making it accessible across multiple functions.|

---

### Declaration and Usage

To declare a constant, you must follow specific syntax rules.

- Use the **`const`** keyword.
    
- The naming convention is **`UPPER_SNAKE_CASE`** (all capital letters with underscores between words).
    
- An explicit **type annotation is mandatory**.
    

#### Example

Constants are ideal for hard-coded values that are known in advance and need to be used in multiple places.

Rust

```Rust
// A constant defined at the global scope.
// It's accessible by any function in this file.
const SECONDS_IN_MINUTE: u32 = 60;

fn main() {
    let minutes = 5;
    let total_seconds = minutes * SECONDS_IN_MINUTE;

    println!("{} minutes is {} seconds.", minutes, total_seconds);
    display_conversion_factor();
}

fn display_conversion_factor() {
    // The same constant can be used in another function.
    println!("There are {} seconds in a minute.", SECONDS_IN_MINUTE);
}
```
