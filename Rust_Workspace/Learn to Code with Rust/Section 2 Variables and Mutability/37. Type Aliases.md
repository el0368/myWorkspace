### Using Type Aliases in Rust 🏷️

A **type alias** in Rust allows you to create a new name, or a "nickname," for an existing type. Its primary purpose is to provide **semantic meaning** and improve code readability. It clarifies the _intent_ of the data without introducing a new, distinct type. For example, instead of just `u32`, you could have a `UserID` type, which makes the code more self-documenting.

---

### Declaration and Usage

You create a type alias using the `type` keyword, typically at the top level of a file or module so it can be reused. The convention is to name the alias using `PascalCase`.

The syntax is: `type AliasName = ExistingType;`

#### Example

In a program that handles e-commerce data, using aliases can make function signatures much clearer.

Rust

```Rust
// Create a type alias for a product ID, which is just a u64 number.
type ProductID = u64;

// Create a type alias for a price in cents to avoid floating-point issues.
type PriceInCents = u32;

fn main() {
    let book_id: ProductID = 101;
    let book_price: PriceInCents = 2599; // Represents $25.99

    display_product(book_id, book_price);
}

// This function signature is much more descriptive than `fn display_product(id: u64, price: u32)`
fn display_product(id: ProductID, price: PriceInCents) {
    println!("Product ID: {}", id);
    println!("Price: {} cents", price);
}
```

---

### Key Characteristics

A type alias is purely a compile-time convenience. It does **not** create a new, distinct type. The compiler treats the alias as being identical to the original type. This means any operation you can perform on the original type, you can also perform on the alias.

Rust

```Rust
type Age = u8;

let my_age: Age = 30;

// Mathematical operations work just like with a u8
let a_decade_ago = my_age - 10; 

println!("A decade ago, I was {}.", a_decade_ago);
```
