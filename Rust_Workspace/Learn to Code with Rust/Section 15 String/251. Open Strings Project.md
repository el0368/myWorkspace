This section focuses on Rust's string types and how to work with them. You'll be using the `strings` Cargo project and writing your code in `src/main.rs`.

### Topics Covered 📖

---

- **String Slices (`&str`)**: You'll learn about `&str`, a fixed-length, immutable reference to a string. It's the type of string literals you write with double quotes.
    
- **The String Type**: This is Rust's owned, growable, and mutable string type, used for dynamic text.
    
- **Concatenation**: You'll explore different ways to combine strings, including using the `+` operator and the mutable methods `push_str` (to append a slice) and `push` (to append a single character).
    
- **Indexing and Slicing**: You'll discover how to create a string slice (`&str`) from a larger string by specifying a range of byte indices, and you'll understand why direct character indexing isn't allowed in Rust.
    
- **`format!` Macro**: This macro is a versatile way to build strings from various values and is often a cleaner alternative to the `+` operator for concatenation.
    
- **Common String Methods**: You'll learn about other useful methods for manipulating and inspecting strings, such as `trim`, `len`, and `is_empty`.
    
- **Collecting User Input**: Finally, you'll learn how to handle user input from the console, which is a common use case for the mutable `String` type.
