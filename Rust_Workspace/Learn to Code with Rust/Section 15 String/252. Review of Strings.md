# 🦀 Rust Strings Study Guide

## 1. **String Types in Rust**

Rust has **two main string types**:

1. **`&str` (string slice)** – borrowed, immutable, fixed-length sequence of UTF-8 bytes.
    
2. **`String`** – owned, heap-allocated, growable string, mutable.
    

---

### 1.1 **String Slice `&str`**

- Reference to a string literal or a portion of a `String`.
    
- Immutable by nature.
    
- Example:
    

```rust
fn main() {
    let pirate: &str = "Bloodhook";  // string slice (borrow)
    println!("Pirate: {}", pirate);

    let slice: &str = &pirate[0..5]; // slice first 5 bytes
    println!("Slice: {}", slice);    // prints "Blood"
}
```

**Key points:**

- Cannot modify `&str`.
    
- Commonly comes from string literals.
    
- Safe slicing prevents invalid UTF-8 indexing.
    

---

### 1.2 **Owned `String`**

- Heap-allocated, mutable, supports dynamic changes.
    
- Example:
    

```rust
fn main() {
    let mut sailor = String::new();         // empty heap string
    let mut bad_guy = String::from("Bloodhook"); // from literal
    let mut pirate = "Captain".to_string();     // &str -> String

    // Modifying strings
    sailor.push_str("Jack");        // append string
    bad_guy.push('!');              // append single char
    pirate.push_str(" Sparrow");

    println!("Sailor: {}", sailor);
    println!("Bad Guy: {}", bad_guy);
    println!("Pirate: {}", pirate);
}
```

**Key points:**

- `String::new()` → creates empty string.
    
- `String::from("...")` → heap-allocated copy of literal.
    
- `to_string()` → converts `&str` to `String`.
    
- Mutable strings can grow, shrink, and change.
    

---

## 2. **Accessing Characters in Strings**

- **Rust strings cannot be indexed directly with `[i]`** because strings are UTF-8, and characters may be multiple bytes.
    

### 2.1 **Using Slices**

```rust
fn main() {
    let pirate = "Bloodhook";

    // Access first character safely using range
    let first_char = &pirate[0..1]; // slice first byte
    println!("First char: {}", first_char);
}
```

**Rules:**

- Range must align with **UTF-8 character boundaries**.
    
- Single character may require multiple bytes (e.g., emojis).
    

### 2.2 **Iterating Over Characters**

```rust
fn main() {
    let pirate = "Bloodhook";
    for c in pirate.chars() {
        println!("{}", c);
    }

    // Get first character
    let first_char = pirate.chars().next().unwrap();
    println!("First char via iterator: {}", first_char);
}
```

- `.chars()` → iterates over Unicode characters.
    
- `.bytes()` → iterates over raw bytes.
    
- `.graphemes()` (via `unicode-segmentation` crate) → iterates over visual characters (optional advanced).

## 3. **Converting Between `&str` and `String`**

### 3.1 `&str` → `String`

```rust
let slice: &str = "hello";
let owned: String = slice.to_string();
let owned2: String = String::from(slice);
```

### 3.2 `String` → `&str`

```rust
let owned: String = String::from("world");
let slice: &str = &owned; // borrow as &str
```

**Notes:**

- `.as_str()` is equivalent to `&owned`.

## 4. **Modifying Strings**

- Strings on the heap can be modified.
    

### 4.1 Append String or Char

```rust
fn main() {
    let mut s = String::from("Hello");
    s.push_str(" World"); // append &str
    s.push('!');          // append char
    println!("{}", s);
}
```

### 4.2 Remove Characters

```rust
let mut s = String::from("Hello");
s.pop(); // removes last character
println!("{}", s); // "Hell"
```

### 4.3 Replace Substrings

```rust
let s = String::from("I am a pirate");
let new_s = s.replace("pirate", "sailor");
println!("{}", new_s); // "I am a sailor"
```

---

## 5. **String Concatenation**

### 5.1 Using `+` operator

```rust
let a = String::from("Hello");
let b = " World";
let c = a + b; // a is moved, b is &str
println!("{}", c);
```

### 5.2 Using `format!` macro (preferred)

```rust
let a = String::from("Hello");
let b = String::from("World");
let c = format!("{} {}", a, b); // a, b not moved
println!("{}", c);
```

## 6. **Advanced: Unicode Awareness**

- Each Rust string is **UTF-8 encoded**.
    
- Some characters occupy more than one byte.
    

```rust
fn main() {
    let emoji = "😀";
    println!("Bytes: {}", emoji.len());        // 4 bytes
    println!("Chars: {}", emoji.chars().count()); // 1 character

    let first = &emoji[0..4]; // correct slice
    println!("{}", first);
}
```

**Takeaways:**

- Always be cautious when slicing strings.
    
- `.chars()` iterator is safe for Unicode.
