# 📘 Study Guide: Strings in Rust

---

## 🔹 String Types in Rust

### `&str` (string slice)

- Immutable reference to a sequence of UTF-8 bytes.
    
- Most commonly comes from **string literals** (e.g., `"hello"`).
    
- Stored in the program’s **binary/executable** at compile time.
    
- Characteristics:
    
    - Lightweight, fast access.
        
    - Immutable — cannot grow or shrink.
        
    - Borrowed type, so **ownership rules don’t apply**.
        

### `String` (heap-allocated string)

- A **growable, mutable** string stored on the heap.
    
- Useful when working with user input, dynamic text, or concatenation.
    
- Characteristics:
    
    - Can grow and shrink at runtime.
        
    - Requires `mut` if you want to modify it.
        
    - Owns its data (follows Rust’s ownership rules).
        

---

## 🔹 Deref Coercion

- Rust can **coerce `&String` into `&str`** automatically.
    
    - This is why functions expecting `&str` can also accept `&String`.
        
    - Example:
        
        ```rust
        fn greet(name: &str) {
            println!("Hello, {}", name);
        }
        
        let s = String::from("Alice");
        greet(&s); // &String → &str automatically
        ```
        
- **Reverse is not allowed**: you cannot coerce `&str` into `&String`.
    
    - Reason: a string slice may not come from a `String` at all (it might come from a literal).
        

👉 **Best practice**:

- Functions should take `&str` in parameters, because it works with both `String` and `&str`.

## 🔹 Concatenation

### 1. `push_str(&str)`

- Appends a string slice to a mutable `String`.
    
- Does **not** take ownership of the argument.
    
- Example:
    
    ```rust
    let mut s = String::from("Hello");
    let name = "World";
    s.push_str(name);
    println!("{}", s); // HelloWorld
    ```
    

### 2. `push(char)`

- Appends a single character (`char`) to a mutable `String`.
    
- Uses **single quotes** (`' '`).
    
- Example:
    
    ```rust
    let mut s = String::from("Hi");
    s.push('!');
    println!("{}", s); // Hi!
    ```
    

### 3. `+` operator

- Syntactic sugar for the `add` method:
    
    ```rust
    fn add(self, other: &str) -> String
    ```
    
- Rules:
    
    - Consumes (moves) the left operand (`String`).
        
    - Right operand must be `&str` (coerced from `&String` if needed).
        
    - Returns a new `String`.
        
- Example:
    
    ```rust
    let s1 = String::from("Hello");
    let s2 = String::from("World");
    let s3 = s1 + &s2; // s1 is moved
    println!("{}", s3); // HelloWorld
    ```
    
- If you still need the original:
    
    ```rust
    let s1 = String::from("Hello");
    let s2 = String::from("World");
    let s3 = s1.clone() + &s2; // s1 is preserved
    ```

## 🔹 Indexing & Slicing

- Strings in Rust are UTF-8 encoded, meaning characters may use multiple bytes.
    
- Example: `"a"` = 1 byte, `"é"` = 2 bytes, `"😊"` = 4 bytes.
    
- **Direct indexing** (e.g., `s[0]`) is not allowed, because it could cut through a multi-byte character → invalid UTF-8.
    
- **Slicing with ranges is allowed** (but must align with valid character boundaries):
    
    ```rust
    let s = String::from("Hello");
    let slice = &s[0..4]; // "Hell"
    ```
    
- ⚠️ Runtime panic occurs if slice cuts into the middle of a multi-byte character.

## 🔹 `format!` Macro

- Similar to `println!`, but returns a new `String` instead of printing.
    
- Useful for building complex strings:
    
    ```rust
    let name = "Alice";
    let greeting = format!("Hello, {}!", name);
    println!("{}", greeting);
    ```
    
- Supports positional arguments, formatting options, etc.

## 🔹 Common String Methods

- **Whitespace handling**
    
    - `trim()` → removes whitespace from both ends. Returns `&str`.
        
    - `trim_start()` and `trim_end()` → remove only from one side.
        
- **Case conversion**
    
    - `to_uppercase()` → returns a new `String`.
        
    - `to_lowercase()` → same.
        
- **Replace**
    
    - `replace("old", "new")` → returns new `String`.
        
- **Split**
    
    - Splits string into pieces based on delimiter.
        
    - Returns an iterator (`Split`). Usually collected into `Vec<&str>`.
        
    
    ```rust
    let data = "a,b,c";
    let parts: Vec<&str> = data.split(',').collect();
    println!("{:?}", parts); // ["a", "b", "c"]
    ```

## 🔹 User Input with `io`

- Using `stdin` to collect input:
    
    ```rust
    use std::io;
    
    fn main() {
        let mut input = String::new();
        io::stdin().read_line(&mut input)
            .expect("Failed to read line");
        println!("You typed: {}", input.trim());
    }
    ```
    
- Key points:
    
    - `read_line` expects a **mutable reference to a String**.
        
    - Returns a `Result` (`Ok` = number of bytes read, `Err` = failure).
        
    - The `String` is filled with input (including newline `\n`).
        
    - Call `trim()` to remove the newline.

# 🔑 Summary Checklist

- `&str` = immutable view into text (usually literals).
    
- `String` = owned, growable heap-allocated text.
    
- Prefer function parameters as `&str` for flexibility.
    
- Concatenation:
    
    - `push_str(&str)` → append slice.
        
    - `push(char)` → append single char.
        
    - `+` operator → consumes left string, appends right slice.
        
- No direct indexing; use slicing ranges carefully.
    
- Use `format!` for complex string construction.
    
- Common methods: `trim`, `to_uppercase`, `replace`, `split`.
    
- For user input: use `read_line` into `String` and handle `Result`.
