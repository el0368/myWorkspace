# 📘 Study Guide: Strings in Rust

---

## 🔹 String Types

### 1. `&str` (String Slice)

- Appears most often as `&str` (borrowed reference).
    
- Immutable view into string data (cannot grow/shrink).
    
- Commonly obtained from **string literals**:
    
    ```rust
    let greeting: &str = "Hello"; // stored in program binary
    ```
    
- Characteristics:
    
    - Hard-coded, unchanging content.
        
    - Stored directly in the compiled executable.
        
    - Lightweight, no heap allocation.
        
    - **Not mutable.**
        

---

### 2. `String` (Heap-Allocated String)

- Stored on the **heap**.
    
- Mutable (can grow or shrink).
    
- Suitable for dynamic text that changes at runtime:
    
    ```rust
    let mut name = String::from("Alice");
    name.push_str(" Smith");
    ```
    

---

## 🔹 Deref Coercion

- Automatic conversion from `&String` → `&str` when required.
    
- Works **one way only**:
    
    - ✅ `&String` → `&str` (safe, because any string reference can be seen as a string slice).
        
    - ❌ `&str` → `&String` (unsafe, because not all slices come from heap `String`s).
        

**Practical usage:**

- When defining function parameters, prefer `&str` because it works with both `String` and string literals.
    

---

## 🔹 Concatenation

### 1. `push_str(&str)`

- Appends a string slice to an existing `String`.
    
- Requires the `String` to be **mutable**.
    
- Example:
    
    ```rust
    let mut full_name = String::from("Sylvester");
    full_name.push_str(" Stallone");
    ```
    

### 2. `push(char)`

- Appends a single **character** to a `String`.
    
- Characters use single quotes (`' '`):
    
    ```rust
    let mut s = String::from("Hi");
    s.push('!'); 
    ```
    

### 3. `+` Operator (calls `add` method)

- Concatenates by **moving ownership** of the first string.
    
- Signature of `add`:
    
    ```rust
    fn add(self, other: &str) -> String
    ```
    
- Rules:
    
    - First string (`self`) is consumed (ownership lost).
        
    - Second operand must be `&str` (works via deref coercion if `&String` provided).
        
- Example:
    
    ```rust
    let first = String::from("Sylvester");
    let last = String::from("Stallone");
    let full = first + &last; // first is now invalid
    ```

## 🔹 Indexing Strings

- Rust prohibits direct indexing into strings (e.g., `s[0]`).
    
- Reason: Strings are UTF-8 encoded → characters may occupy multiple bytes.
    
    - English letters = 1 byte.
        
    - Emojis/non-English = multiple bytes.
        
- Direct indexing risks slicing invalid byte sequences.
    

### ✅ Allowed: Range Slicing

```rust
let s = String::from("Hello");
let slice = &s[0..4]; // "Hell"
```

⚠️ Still risky: slicing must align to valid UTF-8 boundaries or program will panic at runtime.

## 🔹 The `format!` Macro

- Similar to `println!`, but returns a new `String` instead of printing.
    
- Example:
    
    ```rust
    let name = "Alice";
    let greeting = format!("Hello, {}", name);
    ```
    
- Supports:
    
    - Dynamic placeholders (`{}` if type implements `Display`).
        
    - Positional/named arguments.
        
- Always produces a heap-allocated `String`.

## 🔹 Common String Methods

### 1. Trimming Whitespace

- **`trim()`** → removes leading & trailing whitespace. Returns `&str`.
    
- **`trim_start()`** → removes only from start.
    
- **`trim_end()`** → removes only from end.
    

### 2. Case Conversion

- **`to_uppercase()`** → returns a new `String` in uppercase.
    
- **`to_lowercase()`** → returns a new `String` in lowercase.
    

### 3. Replace

- **`replace(from, to)`** → replaces all occurrences of substring. Returns new `String`.
    
    ```rust
    let s = "Hello world";
    let new_s = s.replace("world", "Rust");
    ```
    

### 4. Split

- **`split(delimiter)`** → splits string into parts at delimiter.
    
- Produces an iterator of `&str`.
    
- Collect into vector:
    
    ```rust
    let items: Vec<&str> = "a,b,c".split(',').collect();
    ```

## 🔹 Collecting User Input

- Uses **`std::io`**:
    
    ```rust
    use std::io;
    
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("Failed to read");
    ```
    
- Notes:
    
    - Input written into mutable `String` reference.
        
    - Returns a `Result`:
        
        - `Ok(n)` → success, `n` = number of bytes read.
            
        - `Err(e)` → failure.
            
    - Use `match` for error handling.
        
    - Input includes newline (`\n`) → usually trimmed with `.trim()`.

## 🔹 Key Principles

1. **`&str` is lightweight and immutable** → best for parameters.
    
2. **`String` is heap-allocated, growable, and mutable.**
    
3. **Concatenation:**
    
    - `push_str` → add slice.
        
    - `push` → add char.
        
    - `+` → consumes first string, appends second.
        
4. **No direct indexing into strings** (UTF-8 safety).
    
5. **`format!` macro** builds heap strings cleanly.
    
6. **Efficiency:** Rust minimizes data duplication (e.g., `trim` returns slice, not copy).
    
7. **Input:** read into `String`, trim for clean results.
