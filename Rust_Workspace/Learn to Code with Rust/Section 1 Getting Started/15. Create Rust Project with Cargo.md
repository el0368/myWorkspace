### **Notes: Creating a Rust Project**

#### **1. The Cargo Tool**

- **What it is:** `cargo` is the official command-line tool and package manager for Rust, included with the standard installation.
    
- **Primary Functions:**
    
    - Creates new projects (`cargo new`).
        
    - Compiles source code into an executable.
        
    - Formats code.
        
    - Manages project dependencies.
        
- **Why use it:** It is the recommended standard for creating Rust projects, ensuring a consistent and predictable structure.
    

#### **2. Creating a Project: `cargo new`**

- **Command:** `cargo new <project_name>`
    
- **Example:** `cargo new hello_world`
    
- **Naming Convention:**
    
    - **`snake_case`** is a common format: all lowercase, with words separated by underscores.
        
    - Project names cannot contain spaces.
        
- **Terminology:** Rust projects are also referred to as **packages** or **crates**.
    

#### **3. Project Types: Binary vs. Library Crates**

- `cargo new` by default creates a **binary application package**.
    
- **Binary Crate:**
    
    - A standalone, executable application designed to be run on its own.
        
    - _Analogy:_ A complete car.
        
- **Library Crate:**
    
    - Not standalone. It's code meant to be included and used by other projects (binary or library crates).
        
    - _Analogy:_ A car engine or a tire—a component for a larger system.
        

#### **4. Standard Project File Structure**

Cargo generates a standard set of files and folders:

- **`src/` (Source Directory):**
    
    - This is the most important directory for the developer.
        
    - It contains all the Rust source code.
        
    - Rust files have the **`.rs`** extension.
        
    - A new binary project includes a starter `main.rs` file.
        
- **`target/`:**
    
    - This directory holds the final compiled output.
        
    - When you build your code, the resulting executable program is placed here.
        
- **`Cargo.toml`:**
    
    - The project's **manifest** or configuration file.
        
    - **TOML** stands for "Tom's Obvious Markup Language".
        
    - Contains metadata like `name` and `version` (e.g., `0.1.0`).
        
    - The `rust-analyzer` VS Code extension uses this file to recognize the directory as a Rust project.
        
- **`Cargo.lock`:**
    
    - **Automatically generated** by Cargo during compilation.
        
    - **Do not edit this file manually.**
        
    - Its primary purpose is to **lock down the exact versions of all project dependencies** to ensure consistent builds every time.
        
    - Should be committed to source control (like Git).
        
- **`.gitignore`:**
    
    - A file for the **Git version control system**.
        
    - It lists files and folders (like the `target/` directory) that Git should ignore and not track.
        

#### **5. Development Workflow & Key Takeaway**

- **Workflow Steps:**
    
    1. Create the project: `cargo new hello_world`
        
    2. Navigate into the directory: `cd hello_world`
        
    3. Open in your editor: `code .` (for VS Code)
        
- **Most Important Point:** All the developer-written code for the project will live inside the **`src/`** directory.
