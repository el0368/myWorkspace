A **comment** is a human-readable note added to source code that is **completely ignored by the Rust compiler**. This allows developers to leave explanations, links, diagrams, or other metadata directly within the code without causing compilation errors.

---

### **Types of Comments and Syntax**

Rust supports two main types of comments.

#### **Single-Line Comments (`//`)**

- **Syntax:** A single-line comment begins with two forward slashes (`//`). The compiler ignores everything on that line following the `//`.
    
- **Placement:** They can occupy an entire line or be placed at the end of a line of code.
    
    Rust
    
    ```Rust
    // This entire line is a comment.
    let x = 5; // This part is a comment, but the code before it runs.
    ```
    
- **Keyboard Shortcut:** You can quickly toggle comments on and off in VS Code using `Cmd + /` on a Mac or `Ctrl + /` on Windows. This shortcut works across many programming languages.
    

#### **Multi-Line (Block) Comments (`/* ... */`)**

- **Syntax:** A multi-line comment starts with `/*` and ends with `*/`. Everything between these markers, including line breaks, is considered part of the comment.
    
- **Purpose:** This syntax is ideal for larger blocks of text, such as detailed explanations or metadata blocks, without needing to start each line with `//`.
    
    Rust
    
    ```Rust
    /*
      This is a multi-line comment.
      It's useful for providing more detailed information.
      Author: Boris
      Copyright: 2024
    */
    ```
    

---

### **Common Use Cases 💡**

Comments have two primary uses in development:

1. **Documentation:** To explain what a piece of code is doing, making it easier for others (or your future self) to understand.
    
2. **Temporarily Disabling Code:** You can "comment out" a line of code to prevent it from running without having to delete it. This is useful for testing how the program behaves without certain parts.
    
    Rust
    
    ```Rust
    println!("This line will run.");
    // println!("This line is temporarily disabled."); 
    println!("This line will also run.");
    ```
