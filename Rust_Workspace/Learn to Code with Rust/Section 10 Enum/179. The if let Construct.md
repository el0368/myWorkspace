### Part 1: `if let` for a Unit Variant

This progressive example starts by introducing the `if let` construct as a concise way to match a single enum variant without the overhead of a full `match` statement.

- **The Problem with `match`:** The `match` keyword is exhaustive; it requires an arm for every possible variant. This can be verbose if you only care about one specific variant.
    
- **The Solution: `if let`:** The `if let` syntax combines an `if` condition with a `let` pattern match. It checks if a value matches a single, specified pattern and executes a block of code if it does.
    
- **The Code:** This part defines the `Milk` enum and shows how to use `if let` to check for the unit variant `Whole`.
    

Rust

```Rust
// Our enum with three different variant types.
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::Whole; // This is our dynamic value.
    
    // `if let` checks if `my_beverage` is the `Whole` variant.
    if let Milk::Whole = my_beverage {
        // This block only executes if the condition is true.
        println!("You have whole milk.");
    }
    
    // Change `my_beverage` to another variant to see the `if` block skipped.
    let my_beverage = Milk::Lowfat(2);
    if let Milk::Whole = my_beverage {
        // This block is not executed.
        println!("This line is not printed.");
    }
}
```

### Part 2: `if let` for a Tuple Variant (Binding Data)

This part shows how `if let` can also be used to declare a variable that binds to a tuple variant's associated data. This is where the "let" part of "if let" truly shines.

- **Binding Data:** The pattern in an `if let` statement can use parentheses `()` to bind the positional data of a tuple variant to a variable name of your choosing.
    
- **Conditional Variable:** This new variable (e.g., `percent`) is only declared and valid within the `if` block. If the `if let` check fails, the variable is never created.
    

Rust

```Rust
// The enum from Part 1.
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::Lowfat(2); // Our dynamic value
    
    // The pattern binds the `i32` data to the `percent` variable.
    if let Milk::Lowfat(percent) = my_beverage {
        // `percent` is a local variable available only in this block.
        println!("Your beverage is {}% milk.", percent);
    }
    
    // Change `my_beverage` to another variant to see the `if let` fail.
    let my_beverage = Milk::Whole;
    if let Milk::Lowfat(percent) = my_beverage {
        // This block is not executed, and `percent` is not created.
        println!("This line is not printed.");
    }
}
```

### Part 3: `if let` for a Struct Variant (Binding Named Data)

This part shows the syntax for using `if let` with a struct variant, where the data is bound to a variable using its field name.

- **Struct Variant Syntax:** The pattern uses curly braces `{}` and the field's name to bind the data to a local variable. You can use field init shorthand (`kind`) or an explicit binding (`kind: my_kind`) if the variable name needs to be different.
    
- **The Code:** This example shows how to use `if let` with the `NonDairy` variant.
    

Rust

```Rust
// The enum from Part 1.
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::NonDairy {
        kind: String::from("Oat"),
    };
    
    // The pattern uses curly braces to bind the `kind` field to a variable named `kind`.
    if let Milk::NonDairy { kind } = my_beverage {
        println!("Your beverage is {} milk.", kind);
    }
    
    // Change `my_beverage` to another variant.
    let my_beverage = Milk::Lowfat(1);
    if let Milk::NonDairy { kind } = my_beverage {
        // This block is not executed, and `kind` is not created.
        println!("This line is not printed.");
    }
}
```

### Part 4: Adding an `else` Clause to `if let`

This final part shows that `if let` can be used just like a regular `if` statement, including the addition of an optional `else` clause. This provides a fallback option if the single-variant check fails.

- **`if let...else`:** This construct provides a simple and clean way to handle a specific case and a "catch-all" for all other cases.
    
- **The Code:** This example shows how `if let` can be combined with `else` to provide a fallback message.
    

Rust

```Rust
// The enum from Part 1.
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::Whole;
    
    // We check for a `NonDairy` variant.
    if let Milk::NonDairy { kind } = my_beverage {
        println!("Your beverage is {} milk.", kind);
    } else {
        // This `else` block runs because `my_beverage` is not a `NonDairy` variant.
        println!("You have some other milk variant.");
    }
    
    // Output: You have some other milk variant.
}
```
