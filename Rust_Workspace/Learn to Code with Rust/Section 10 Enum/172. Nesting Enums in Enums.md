### Part 1: The Problem & Solution with Tuple Variants

This progressive example demonstrates how to associate one enum with another using a **tuple variant**. The goal is to add a `Meat` choice to a `Burrito` and `Bowl` from a `RestaurantItem` enum.

- **Nesting Enums:** An enum is a valid data type, so it can be stored as an associated value within another enum variant.
    
- **Tuple Variant Syntax:** The `Burrito` and `Bowl` variants are defined with parentheses `()` containing the `Meat` enum as the associated data type.
    
- **Instantiation:** To create an instance, you nest the variant constructors: `RestaurantItem::Burrito(Meat::Steak)`.
    

Rust

```Rust
// An enum to represent a choice of meat.
#[derive(Debug)]
enum Meat {
    Chicken,
    Steak,
}

// Our main enum for the restaurant items.
#[derive(Debug)]
enum RestaurantItem {
    // These variants now hold a `Meat` enum variant as associated data.
    Burrito(Meat),
    Bowl(Meat),
    VeganPlate, // This variant holds no data.
}

fn main() {
    // We instantiate a `Burrito` variant and provide a `Meat::Steak` variant as its data.
    let lunch = RestaurantItem::Burrito(Meat::Steak);

    // We instantiate a `Bowl` variant with `Meat::Chicken`.
    let dinner = RestaurantItem::Bowl(Meat::Chicken);
    
    // The `VeganPlate` variant is instantiated with no associated data.
    let abandoned_meal = RestaurantItem::VeganPlate;

    // Printing the enums shows the nested variants.
    println!("Lunch was {:?}.", lunch);
    println!("Dinner was {:?}.", dinner);
    println!("Nobody ate {:?}.", abandoned_meal);
}
```

### Part 2: The Solution with Struct Variants

This part shows a more structured way to nest enums, especially when a variant needs to hold multiple pieces of associated data. We refactor the `RestaurantItem` enum to use **struct variants**.

- **The Problem with Tuples:** If a variant needs more data, like a choice of beans, `Burrito(Meat, Beans)` becomes less readable.
    
- **Struct Variant Syntax:** The `Burrito` and `Bowl` variants are refactored to use curly braces `{}` and named fields, making the associated data self-documenting.
    
- **The Code:** This example introduces a new `Beans` enum and refactors the `RestaurantItem` enum to use struct variants, which is a good setup for Part 3.
    

Rust

```Rust
// An enum for a choice of meat.
#[derive(Debug)]
enum Meat {
    Chicken,
    Steak,
}

// A new enum for a choice of beans.
#[derive(Debug)]
enum Beans {
    Pinto,
    Black,
}

// Our main enum, refactored to use struct variants for clarity.
#[derive(Debug)]
enum RestaurantItem {
    // The Burrito variant now uses named fields for its associated data.
    Burrito { meat: Meat, beans: Beans },
    // The Bowl variant also uses named fields.
    Bowl { meat: Meat, beans: Beans },
    // The VeganPlate remains a unit variant.
    VeganPlate,
}

fn main() {
    // This part will be filled in by the next example.
}
```

### Part 3: Instantiation of Nested Struct Variants

This final part demonstrates the instantiation of the struct variants from Part 2. The syntax uses nested curly braces, with an inner set for the struct variant and an outer set for the enum variant.

- **Instantiation Syntax:** The syntax for a struct variant uses curly braces `{}`. Inside, you provide the named fields and their values, which in this case are instances of other enums.
    
- **The Result:** The final output clearly shows the hierarchical nature of the data, with the top-level enum, the struct variant, and the nested enum values all cleanly represented.
    

Rust

```Rust
// All enums from Part 2.
#[derive(Debug)]
enum Meat {
    Chicken,
    Steak,
}

#[derive(Debug)]
enum Beans {
    Pinto,
    Black,
}

#[derive(Debug)]
enum RestaurantItem {
    Burrito { meat: Meat, beans: Beans },
    Bowl { meat: Meat, beans: Beans },
    VeganPlate,
}

fn main() {
    // Instantiate the `Burrito` struct variant with named fields.
    let lunch = RestaurantItem::Burrito {
        meat: Meat::Steak,      // A `Meat` enum variant
        beans: Beans::Pinto,    // A `Beans` enum variant
    };

    // Instantiate the `Bowl` struct variant with different choices.
    let dinner = RestaurantItem::Bowl {
        meat: Meat::Chicken,
        beans: Beans::Black,
    };
    
    // Instantiate the unit variant.
    let abandoned_meal = RestaurantItem::VeganPlate;

    println!("Lunch: {:#?}", lunch);
    println!("Dinner: {:#?}", dinner);
    println!("Nobody ate: {:#?}", abandoned_meal);
}
```
