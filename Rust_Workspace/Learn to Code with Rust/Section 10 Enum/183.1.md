An **enum** (enumeration) in Rust is a custom data type that lets you define a type with a fixed set of named values called **variants**. This is useful for representing a limited set of possibilities, like the states of a traffic light.

Let's look at some examples of the different types of variants and how to use them.

### Declaring and Using Enums

Rust

```Rust
// An enum with three empty variants
enum TrafficLight {
    Red,
    Yellow,
    Green,
}

fn main() {
    // Instantiate an enum variant
    let light = TrafficLight::Red;

    // The 'match' keyword is used to handle each possible variant.
    // This is an exhaustive check, meaning all variants must be handled.
    match light {
        TrafficLight::Red => println!("Stop!"),
        TrafficLight::Yellow => println!("Slow down."),
        TrafficLight::Green => println!("Go!"),
    }
}
```

### Variants with Associated Data

Enums can store data inside their variants. There are two main ways to do this: **tuple variants** and **struct variants**.

#### Tuple Variants

Tuple variants hold data without named fields. You access the data by its position.

Rust

```Rust
// A tuple enum variant that stores an IP address as four u8 values.
enum IpAddrKind {
    V4(u8, u8, u8, u8),
    V6(String),
}

fn main() {
    let home = IpAddrKind::V4(127, 0, 0, 1);
    let loopback = IpAddrKind::V6(String::from("::1"));

    // Matching can destructure the associated data.
    match home {
        IpAddrKind::V4(a, b, c, d) => println!("This is an IPv4 address: {}.{}.{}.{}", a, b, c, d),
        IpAddrKind::V6(addr) => println!("This is an IPv6 address: {}", addr),
    }
}
```

#### Struct Variants

Struct variants are similar to structs; they hold data with named fields, making the data easier to understand and access.

Rust

```Rust
// A struct enum variant that stores data with named fields.
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
}

fn main() {
    let msg = Message::Move { x: 10, y: 5 };

    match msg {
        Message::Quit => println!("Quit message"),
        Message::Move { x, y } => println!("Move to x: {}, y: {}", x, y),
        Message::Write(text) => println!("Text message: {}", text),
    }
}
```

### Methods on Enums

You can define methods for enums using an **`impl`** block, just like with structs. The `self` parameter refers to the enum instance itself.

Rust

```Rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

impl Coin {
    // A method that returns the value of the coin.
    fn value_in_cents(&self) -> u8 {
        // We use a match expression on 'self' to determine the value.
        match self {
            Coin::Penny => 1,
            Coin::Nickel => 5,
            Coin::Dime => 10,
            Coin::Quarter => 25,
        }
    }
}

fn main() {
    let coin = Coin::Dime;
    println!("The coin is worth {} cents.", coin.value_in_cents());
}
```

### The `if let` Construct

When you only care about one specific variant and don't want to write a full `match` expression, `if let` is a more concise option.

Rust

```Rust
enum Action {
    Run,
    Jump { height: u32 },
    Slide,
}

fn main() {
    let action = Action::Jump { height: 10 };

    // This block of code will only run if 'action' is the 'Jump' variant.
    if let Action::Jump { height } = action {
        println!("We jumped {} feet high!", height);
    } else {
        println!("This is not a jump action.");
    }

    let other_action = Action::Run;

    // 'if let' handles a single variant, ignoring all others.
    if let Action::Jump { height } = other_action {
        println!("We jumped {} feet high!", height);
    } else {
        println!("This is not a jump action.");
    }
}
```
