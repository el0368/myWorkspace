### Part 2: Accessing Data for Unit and Tuple Variants

This part shows the syntax for the `match` arms that handle the `Cold` (unit) variant and the `Delicate` (tuple) variant. The syntax for accessing tuple variant data is a key focus.

- **Unit Variant (`Cold`):** Matching a unit variant is straightforward; you simply list the variant name. There is no associated data to access.
    
- **Tuple Variant (`Delicate(String)`):** You match a tuple variant using parentheses `()`. The value inside the parentheses is a pattern that binds the associated data to a temporary variable name of your choosing (`fabric_type` in this example). This name can then be used in the arm's code block.
    
- **The Code:** This example shows the `match` arms for these two variant types and their corresponding function calls.
    

Rust

```Rust
// The enum from Part 1
#[derive(Debug)]
enum LaundryCycle {
    Cold,
    Hot { temperature: u32 },
    Delicate(String),
}

fn wash_laundry(cycle: LaundryCycle) {
    match cycle {
        // Arm for the unit variant. No associated data to access.
        LaundryCycle::Cold => {
            println!("Running the laundry with cold temperature.");
        },
        // This is where the struct variant arm will go.
        // ...
        // Arm for the tuple variant. Binds the `String` to `fabric_type`.
        LaundryCycle::Delicate(fabric_type) => {
            println!("Running the laundry with a delicate cycle for {}.", fabric_type);
        },
    }
}

fn main() {
    // Invoking `wash_laundry` with a unit variant.
    wash_laundry(LaundryCycle::Cold);

    // Invoking `wash_laundry` with a tuple variant.
    wash_laundry(LaundryCycle::Delicate(String::from("silk")));
}
```

### Part 3: Accessing Data for a Struct Variant

This part shows the syntax for the `match` arm that handles the `Hot` (struct) variant. The syntax for accessing struct variant data is different from tuple variants.

- **Struct Variant (`Hot { temperature: u32 }`):** You match a struct variant using curly braces `{}`. Inside the braces, you specify the field names you want to access (`temperature` in this case). These names are fixed by the enum's definition and are used to bind the data to a local variable.
    
- **The Code:** This example adds the `Hot` variant's `match` arm and its corresponding function call.
    

Rust

```Rust
// The enum from Part 1
#[derive(Debug)]
enum LaundryCycle {
    Cold,
    Hot { temperature: u32 },
    Delicate(String),
}

fn wash_laundry(cycle: LaundryCycle) {
    match cycle {
        LaundryCycle::Cold => {
            println!("Running the laundry with cold temperature.");
        },
        // Arm for the struct variant. Binds the `temperature` field.
        LaundryCycle::Hot { temperature } => {
            println!("Running the laundry with a temperature of {}.", temperature);
        },
        LaundryCycle::Delicate(fabric_type) => {
            println!("Running the laundry with a delicate cycle for {}.", fabric_type);
        },
    }
}

fn main() {
    // Invoking `wash_laundry` with a unit variant.
    wash_laundry(LaundryCycle::Cold);

    // Invoking `wash_laundry` with a struct variant.
    wash_laundry(LaundryCycle::Hot { temperature: 100 });

    // Invoking `wash_laundry` with a tuple variant.
    wash_laundry(LaundryCycle::Delicate(String::from("silk")));
}
```

### Part 4: The Final Progressive Example (Complete Code)

This final part brings all the concepts together into a complete, working program. It shows the three `match` arms and all three `wash_laundry` calls.

- **Full `match`:** The `match` statement is now complete and exhaustive, with an arm for each of the three different variant types.
    
- **Complete Invocation:** The `main` function shows how to correctly instantiate and pass each of the three variants to the `wash_laundry` function, demonstrating the distinct syntax required for each.

```Rust
// Final enum definition

enum LaundryCycle {
    Cold,
    Hot { temperature: u32 },
    Delicate(String),
}

        },

fn main() {
    println!("--- Laundry Cycle Examples ---");

    // Invocation for Unit Variant
    wash_laundry(LaundryCycle::Cold);

    // Invocation for Struct Variant
    wash_laundry(LaundryCycle::Hot { temperature: 100 });

    // Invocation for Tuple Variant
    wash_laundry(LaundryCycle::Delicate(String::from("silk")));
```
