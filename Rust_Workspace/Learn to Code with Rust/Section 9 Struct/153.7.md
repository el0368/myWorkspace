### Part 7: Associated Functions and Other Struct Types

This study guide reviews the concepts of **associated functions** and the two less common but still important struct types: **tuple-like structs** and **unit-like structs**. These features complete the overview of structs in Rust.

#### 1. Associated Functions

An **associated function** is a function that belongs to a struct's namespace but is **not a method**.

- **Key Difference from a Method:** A method always takes `self` (or a variation of it) as its first parameter and is called on a specific _instance_. An associated function **does not take `self`** and is called on the _struct type itself_.
    
- **Invocation Syntax:** `StructName::function_name()`. The double-colon `::` is the access syntax for items within a struct's namespace.
    
- **Common Use Case:** The most frequent use for an associated function is a **constructor**, which is a function that creates and returns a new instance of the struct type. It's a best practice to name these functions `new()` to follow standard library conventions, but it's not a technical requirement.
    

#### 2. Tuple-Like Structs

A **tuple-like struct** is a struct that orders its fields by **position (index)** rather than by name.

- **Declaration Syntax:** `struct StructName(Type1, Type2, ...);` (uses parentheses `()` instead of curly braces `{}`).
    
- **Instantiation Syntax:** `let instance = StructName(value1, value2, ...);`
    
- **Accessing Fields:** You access the field values using dot notation with their zero-based index: `instance.0`, `instance.1`, etc.
    
- **Purpose:** Tuple-like structs are useful for creating new, distinct types from existing data that would otherwise be indistinguishable (e.g., `struct Color(u8, u8, u8);` is a different type from `struct Point(u8, u8, u8);`, even though they hold the same data types).
    

#### 3. Unit-Like Structs

A **unit-like struct** is a struct that has **no fields**.

- **Declaration Syntax:** `struct StructName;` (ends with a semicolon `;`).
    
- **Instantiation Syntax:** `let instance = StructName;`
    
- **Purpose:** Unit-like structs are used when you need to define a new type to which you can add behaviors (methods) and traits, but which doesn't need to hold any data of its own. They are similar in concept to the unit type `()`.
    

#### Example: Associated Functions and Other Struct Types in Code

Rust

```Rust
// Named-field struct (for context)
#[derive(Debug)]
struct Coffee {
    name: String,
}

// Associated function to act as a constructor for Coffee.
impl Coffee {
    // This is an associated function because it does not have a `self` parameter.
    // It returns a new instance of the Coffee struct.
    fn new(name: &str) -> Self { // The `Self` alias refers to the `Coffee` type.
        Self {
            name: name.to_string(),
        }
    }
}

// A tuple-like struct. Fields are accessed by position.
struct Color(u8, u8, u8);

// A unit-like struct. It has no data.
struct BrewState;

impl BrewState {
    // A method on a unit-like struct.
    fn get_status(&self) {
        println!("Brewing is active.");
    }
}

fn main() {
    // Using a named-field struct with its associated function.
    let my_coffee = Coffee::new("Latte"); // The `::` syntax calls the associated function `new`.
    println!("My coffee is: {:#?}", my_coffee);

    // Using a tuple-like struct.
    let red = Color(255, 0, 0); // Instance is created with parentheses.
    println!("Red is R:{} G:{} B:{}", red.0, red.1, red.2); // Fields are accessed by index.

    // Using a unit-like struct.
    let status = BrewState; // No parentheses or curly braces for instantiation.
    status.get_status(); // You can still call methods on it.
}
```
