### 10. Methods on Structs

**Explanation in the Scope of the Transcript:**

The transcript describes **methods on structs** as functions attached to a struct instance, enabling the struct to perform specific behaviors or actions. These methods are defined within an `impl` block for the struct, using the `impl` keyword followed by the struct’s name and curly braces. Methods always take `self` as their first parameter, representing the struct instance, and can accept additional parameters for further inputs. They can produce a return value, similar to regular functions, and are invoked using dot notation (`instance.method()`). Methods enhance structs by adding functionality, making them more than just data containers, and create consistency across instances of the same struct type by providing a uniform interface for operations, as emphasized in the transcript.

**Rust Code Example:**

Below is a minimal code example demonstrating methods on structs, aligned with the transcript’s description.
```rust
struct Book {
    title: String,
    pages: u32,
}

impl Book {
    // Method to get a description
    fn description(&self) -> String {
        format!("{} has {} pages", self.title, self.pages)
    }
}

fn main() {
    let book = Book {
        title: String::from("Rust Guide"),
        pages: 300,
    };
    // Invoke method on struct instance
    println!("Book: {}", book.description());
}
```

**Code Explanation:**

1. **Struct Declaration**:
   - The `Book` struct is defined with fields `title: String` and `pages: u32`, providing the data structure for the method to operate on.

2. **Method Definition**:
   - Within the `impl Book` block, the `description` method is defined, taking `&self` (an immutable reference to the struct instance) as its first parameter, as per the transcript’s note that methods always receive `self`.
   - The method returns a `String` describing the book, using the fields `self.title` and `self.pages`.

3. **Method Invocation**:
   - The method is invoked on the `book` instance using dot notation (`book.description()`), as described in the transcript, producing a formatted string output.

4. **Minimal Usage**:
   - The example is kept minimal, focusing on defining and invoking a method to demonstrate its attachment to the struct instance and its role in adding behavior.

**Key Takeaways**:
- Methods are functions defined in an `impl` block for a struct, taking `self` as the first parameter to operate on the instance.
- They are invoked with dot notation, providing consistent behavior across struct instances.
- The example is minimal, showcasing a single method’s definition and invocation as per the transcript.
