# Using Struct and Impl Together - Complete Guide

## The Basic Relationship

**Struct** = Data structure (what you store) **Impl** = Behavior (what you can do with that data)

Think of it like:

- **Struct** = A car with engine, wheels, fuel tank
- **Impl** = Methods to start, drive, refuel the car

## 1. Basic Pattern: Data + Behavior

```rust
// STRUCT: Define what data we store
struct Car {
    make: String,
    model: String,
    year: u32,
    fuel_level: f64,  // 0.0 to 100.0
    is_running: bool,
}

// IMPL: Define what we can do with that data
impl Car {
    // Constructor - create new cars
    fn new(make: String, model: String, year: u32) -> Car {
        Car {
            make,
            model,
            year,
            fuel_level: 100.0,  // Start with full tank
            is_running: false,  // Start turned off
        }
    }
    
    // Read-only methods (getters)
    fn info(&self) -> String {
        format!("{} {} {}", self.year, self.make, self.model)
    }
    
    fn fuel_level(&self) -> f64 {
        self.fuel_level
    }
    
    fn is_running(&self) -> bool {
        self.is_running
    }
    
    // Action methods (change the car's state)
    fn start(&mut self) -> Result<(), String> {
        if self.fuel_level <= 0.0 {
            return Err("Cannot start: no fuel".to_string());
        }
        if self.is_running {
            return Err("Car is already running".to_string());
        }
        
        self.is_running = true;
        println!("{} started!", self.info());
        Ok(())
    }
    
    fn stop(&mut self) {
        self.is_running = false;
        println!("{} stopped.", self.info());
    }
    
    fn drive(&mut self, miles: f64) -> Result<(), String> {
        if !self.is_running {
            return Err("Cannot drive: car is not running".to_string());
        }
        
        let fuel_needed = miles * 0.1; // 10 miles per gallon equivalent
        if fuel_needed > self.fuel_level {
            return Err("Not enough fuel for this trip".to_string());
        }
        
        self.fuel_level -= fuel_needed;
        println!("Drove {} miles. Fuel remaining: {:.1}%", miles, self.fuel_level);
        Ok(())
    }
    
    fn refuel(&mut self) {
        self.fuel_level = 100.0;
        println!("{} refueled to 100%", self.info());
    }
}

// Usage example
fn main() {
    let mut my_car = Car::new("Toyota".to_string(), "Camry".to_string(), 2020);
    
    println!("Car info: {}", my_car.info());
    println!("Fuel level: {}%", my_car.fuel_level());
    
    my_car.start().unwrap();
    my_car.drive(50.0).unwrap();
    my_car.drive(200.0).unwrap();
    my_car.refuel();
    my_car.stop();
}
```

## 2. Real-World Example: Bank Account

```rust
use std::fmt;

// STRUCT: Store account data
#[derive(Debug, Clone)]
struct BankAccount {
    account_number: String,
    owner: String,
    balance: f64,
    is_frozen: bool,
    transaction_history: Vec<Transaction>,
}

#[derive(Debug, Clone)]
struct Transaction {
    description: String,
    amount: f64,  // Positive for deposits, negative for withdrawals
    balance_after: f64,
}

// IMPL: Define account behaviors
impl BankAccount {
    // Constructor
    fn new(account_number: String, owner: String) -> BankAccount {
        BankAccount {
            account_number,
            owner,
            balance: 0.0,
            is_frozen: false,
            transaction_history: Vec::new(),
        }
    }
    
    // Another constructor with initial deposit
    fn with_initial_deposit(account_number: String, owner: String, initial_amount: f64) -> Result<BankAccount, String> {
        if initial_amount < 0.0 {
            return Err("Initial deposit cannot be negative".to_string());
        }
        
        let mut account = BankAccount::new(account_number, owner);
        account.balance = initial_amount;
        account.add_transaction("Initial deposit".to_string(), initial_amount);
        Ok(account)
    }
    
    // Getters
    fn balance(&self) -> f64 {
        self.balance
    }
    
    fn account_number(&self) -> &str {
        &self.account_number
    }
    
    fn owner(&self) -> &str {
        &self.owner
    }
    
    fn is_frozen(&self) -> bool {
        self.is_frozen
    }
    
    // Account actions
    fn deposit(&mut self, amount: f64) -> Result<(), String> {
        if amount <= 0.0 {
            return Err("Deposit amount must be positive".to_string());
        }
        if self.is_frozen {
            return Err("Cannot deposit: account is frozen".to_string());
        }
        
        self.balance += amount;
        self.add_transaction(format!("Deposit"), amount);
        Ok(())
    }
    
    fn withdraw(&mut self, amount: f64) -> Result<(), String> {
        if amount <= 0.0 {
            return Err("Withdrawal amount must be positive".to_string());
        }
        if self.is_frozen {
            return Err("Cannot withdraw: account is frozen".to_string());
        }
        if amount > self.balance {
            return Err("Insufficient funds".to_string());
        }
        
        self.balance -= amount;
        self.add_transaction("Withdrawal".to_string(), -amount);
        Ok(())
    }
    
    fn transfer_to(&mut self, other_account: &mut BankAccount, amount: f64) -> Result<(), String> {
        // Withdraw from this account
        self.withdraw(amount)?;
        
        // Deposit to other account
        match other_account.deposit(amount) {
            Ok(()) => {
                // Update transaction descriptions to be more specific
                if let Some(last_transaction) = self.transaction_history.last_mut() {
                    last_transaction.description = format!("Transfer to {}", other_account.account_number);
                }
                if let Some(last_transaction) = other_account.transaction_history.last_mut() {
                    last_transaction.description = format!("Transfer from {}", self.account_number);
                }
                Ok(())
            }
            Err(e) => {
                // If deposit fails, reverse the withdrawal
                self.deposit(amount).unwrap(); // This should not fail
                Err(format!("Transfer failed: {}", e))
            }
        }
    }
    
    fn freeze(&mut self) {
        self.is_frozen = true;
        println!("Account {} has been frozen", self.account_number);
    }
    
    fn unfreeze(&mut self) {
        self.is_frozen = false;
        println!("Account {} has been unfrozen", self.account_number);
    }
    
    // Private helper method
    fn add_transaction(&mut self, description: String, amount: f64) {
        let transaction = Transaction {
            description,
            amount,
            balance_after: self.balance,
        };
        self.transaction_history.push(transaction);
    }
    
    // Transaction history
    fn get_transaction_history(&self) -> &Vec<Transaction> {
        &self.transaction_history
    }
    
    fn print_statement(&self) {
        println!("\n=== ACCOUNT STATEMENT ===");
        println!("Account: {}", self.account_number);
        println!("Owner: {}", self.owner);
        println!("Current Balance: ${:.2}", self.balance);
        println!("Status: {}", if self.is_frozen { "FROZEN" } else { "Active" });
        println!("\nTransaction History:");
        
        for (i, transaction) in self.transaction_history.iter().enumerate() {
            println!("{}. {} | Amount: ${:.2} | Balance: ${:.2}", 
                     i + 1, 
                     transaction.description,
                     transaction.amount,
                     transaction.balance_after);
        }
        println!("========================\n");
    }
}

// Implement Display trait for pretty printing
impl fmt::Display for BankAccount {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "Account {}: {} (Balance: ${:.2})", 
               self.account_number, self.owner, self.balance)
    }
}

// Usage example
fn main() {
    // Create accounts
    let mut alice_account = BankAccount::with_initial_deposit(
        "ACC001".to_string(), 
        "Alice Johnson".to_string(), 
        1000.0
    ).unwrap();
    
    let mut bob_account = BankAccount::new(
        "ACC002".to_string(), 
        "Bob Smith".to_string()
    );
    
    // Perform transactions
    alice_account.deposit(500.0).unwrap();
    alice_account.withdraw(200.0).unwrap();
    
    bob_account.deposit(100.0).unwrap();
    
    // Transfer money
    alice_account.transfer_to(&mut bob_account, 300.0).unwrap();
    
    // Print statements
    alice_account.print_statement();
    bob_account.print_statement();
    
    // Demonstrate freezing
    alice_account.freeze();
    match alice_account.withdraw(100.0) {
        Ok(()) => println!("Withdrawal successful"),
        Err(e) => println!("Withdrawal failed: {}", e),
    }
    
    alice_account.unfreeze();
    alice_account.withdraw(100.0).unwrap();
}
```

## 3. Advanced Pattern: Multiple Impl Blocks

```rust
// STRUCT: User data
struct User {
    id: u32,
    username: String,
    email: String,
    created_at: std::time::SystemTime,
    is_active: bool,
    login_count: u32,
}

// IMPL Block 1: Constructors
impl User {
    fn new(id: u32, username: String, email: String) -> User {
        User {
            id,
            username,
            email,
            created_at: std::time::SystemTime::now(),
            is_active: true,
            login_count: 0,
        }
    }
    
    fn inactive_user(id: u32, username: String, email: String) -> User {
        let mut user = User::new(id, username, email);
        user.is_active = false;
        user
    }
}

// IMPL Block 2: Getters/Info
impl User {
    fn id(&self) -> u32 {
        self.id
    }
    
    fn username(&self) -> &str {
        &self.username
    }
    
    fn email(&self) -> &str {
        &self.email
    }
    
    fn is_active(&self) -> bool {
        self.is_active
    }
    
    fn login_count(&self) -> u32 {
        self.login_count
    }
    
    fn account_age_days(&self) -> u64 {
        self.created_at.elapsed()
            .unwrap_or_default()
            .as_secs() / (24 * 60 * 60)
    }
}

// IMPL Block 3: Actions
impl User {
    fn activate(&mut self) {
        self.is_active = true;
        println!("User {} activated", self.username);
    }
    
    fn deactivate(&mut self) {
        self.is_active = false;
        println!("User {} deactivated", self.username);
    }
    
    fn login(&mut self) -> Result<(), String> {
        if !self.is_active {
            return Err("Cannot login: account is inactive".to_string());
        }
        
        self.login_count += 1;
        println!("User {} logged in (total logins: {})", self.username, self.login_count);
        Ok(())
    }
    
    fn change_email(&mut self, new_email: String) -> Result<(), String> {
        if !new_email.contains('@') {
            return Err("Invalid email format".to_string());
        }
        
        let old_email = self.email.clone();
        self.email = new_email;
        println!("Email changed from {} to {}", old_email, self.email);
        Ok(())
    }
}

// IMPL Block 4: Display/Debug
impl User {
    fn summary(&self) -> String {
        format!("User {} (ID: {}, Email: {}, Active: {}, Logins: {})", 
                self.username, self.id, self.email, self.is_active, self.login_count)
    }
    
    fn detailed_info(&self) -> String {
        format!("User Details:\n  ID: {}\n  Username: {}\n  Email: {}\n  Active: {}\n  Login Count: {}\n  Account Age: {} days",
                self.id, self.username, self.email, self.is_active, self.login_count, self.account_age_days())
    }
}
```

## 4. Pattern: Struct with Associated Constants and Functions

```rust
struct Circle {
    radius: f64,
}

impl Circle {
    // Associated constant
    const PI: f64 = 3.14159265359;
    
    // Associated function (like static method)
    fn unit_circle() -> Circle {
        Circle { radius: 1.0 }
    }
    
    fn from_diameter(diameter: f64) -> Circle {
        Circle { radius: diameter / 2.0 }
    }
    
    // Instance methods
    fn radius(&self) -> f64 {
        self.radius
    }
    
    fn diameter(&self) -> f64 {
        self.radius * 2.0
    }
    
    fn area(&self) -> f64 {
        Self::PI * self.radius * self.radius  // Using associated constant
    }
    
    fn circumference(&self) -> f64 {
        2.0 * Self::PI * self.radius
    }
    
    fn scale(&mut self, factor: f64) {
        self.radius *= factor;
    }
    
    fn scaled(self, factor: f64) -> Circle {  // Consumes self, returns new Circle
        Circle { radius: self.radius * factor }
    }
}

// Usage
fn main() {
    let circle1 = Circle::unit_circle();  // Associated function
    let circle2 = Circle::from_diameter(10.0);  // Associated function
    
    println!("Circle 1 area: {:.2}", circle1.area());
    println!("Circle 2 circumference: {:.2}", circle2.circumference());
    
    let circle3 = circle1.scaled(2.0);  // circle1 is consumed
    println!("Scaled circle area: {:.2}", circle3.area());
}
```

## 5. Common Patterns & Best Practices

### Pattern 1: Validation in Constructor

```rust
struct Email {
    address: String,
}

impl Email {
    fn new(address: String) -> Result<Email, String> {
        if !address.contains('@') {
            return Err("Invalid email: missing @".to_string());
        }
        if !address.contains('.') {
            return Err("Invalid email: missing domain".to_string());
        }
        
        Ok(Email { address })
    }
    
    fn address(&self) -> &str {
        &self.address
    }
}

// Usage
fn main() {
    match Email::new("user@example.com".to_string()) {
        Ok(email) => println!("Valid email: {}", email.address()),
        Err(e) => println!("Error: {}", e),
    }
}
```

### Pattern 2: Builder Pattern

```rust
#[derive(Debug)]
struct Pizza {
    size: String,
    crust: String,
    toppings: Vec<String>,
}

struct PizzaBuilder {
    size: Option<String>,
    crust: Option<String>,
    toppings: Vec<String>,
}

impl Pizza {
    fn builder() -> PizzaBuilder {
        PizzaBuilder {
            size: None,
            crust: None,
            toppings: Vec::new(),
        }
    }
}

impl PizzaBuilder {
    fn size(mut self, size: &str) -> Self {
        self.size = Some(size.to_string());
        self
    }
    
    fn crust(mut self, crust: &str) -> Self {
        self.crust = Some(crust.to_string());
        self
    }
    
    fn topping(mut self, topping: &str) -> Self {
        self.toppings.push(topping.to_string());
        self
    }
    
    fn build(self) -> Result<Pizza, String> {
        let size = self.size.ok_or("Size is required")?;
        let crust = self.crust.ok_or("Crust is required")?;
        
        Ok(Pizza {
            size,
            crust,
            toppings: self.toppings,
        })
    }
}

// Usage
fn main() {
    let pizza = Pizza::builder()
        .size("Large")
        .crust("Thin")
        .topping("Pepperoni")
        .topping("Mushrooms")
        .topping("Extra Cheese")
        .build()
        .unwrap();
    
    println!("{:#?}", pizza);
}
```

## Key Takeaways

1. **Struct** defines your data structure - what you store
2. **Impl** defines behavior - what you can do with that data
3. **Multiple impl blocks** help organize related functionality
4. **Use constructors** (`fn new()`) to create valid instances
5. **Method types**:
    - `&self` - read-only access
    - `&mut self` - can modify the instance
    - `self` - consumes the instance
6. **Associated functions** (no self parameter) are like "static" methods
7. **Validation** should happen in constructors, not after creation
8. **Builder pattern** for complex objects with many optional fields

The struct-impl combination is the foundation of object-oriented-like programming in Rust!
