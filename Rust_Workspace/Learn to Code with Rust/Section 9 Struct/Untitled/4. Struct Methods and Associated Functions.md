### Rust Structs: Methods and Associated Functions (In-Depth)

In Rust, a `struct` by itself is just a container for data. To define the actions and behaviors that a struct can perform, you use **methods** and **associated functions**. While both are functions that belong to a type, they serve different purposes and have distinct syntax.

### I. Methods: Behavior for a Specific Instance

A method is a function that is attached to and operates on a specific **instance** of a `struct`. They define the behaviors of that instance.

- **Key Characteristic:** Methods always have a special first parameter, which is a variant of the keyword `self`. This parameter represents the instance the method is being called on.1
    
- **Definition:** Methods are defined inside an `impl` block (short for "implementation").2 A single `struct` can have multiple `impl` blocks.3
    
- **Invocation:** You call a method using **dot notation** (`.`) on a struct instance.
    

#### The Four `self` Parameter Options

The `self` parameter is the bridge between a method and the instance it is called on.4 The syntax you choose for `self` determines the method's ownership and mutability permissions.

1. **Immutable Reference (`&self`):**
    
    - **Syntax:** `fn my_method(&self) { ... }`
        
    - **Ownership:** The method **borrows** an immutable reference to the instance. The original variable remains the owner and stays valid.
        
    - **Permissions:** The method can **read** the struct's fields but cannot modify them.
        
    - **Use Case:** This is the most common and idiomatic signature for methods that perform a read-only operation (e.g., `get_info`, `calculate_value`).
        
2. **Mutable Reference (`&mut self`):**
    
    - **Syntax:** `fn my_method(&mut self) { ... }`
        
    - **Ownership:** The method **borrows** an exclusive, mutable reference to the instance. The original variable remains the owner but must be `mut` and cannot be used while the borrow is active.
        
    - **Permissions:** The method can **read and write** to the struct's fields.
        
    - **Use Case:** This is the most common and idiomatic signature for methods that modify the struct's state in place (e.g., `set_value`, `increment_counter`).
        
3. **Immutable Ownership (`self`):**
    
    - **Syntax:** `fn my_method(self) { ... }`
        
    - **Ownership:** The method takes **full ownership** of the instance (a move).
        
    - **Permissions:** The method can **read** the struct's fields but cannot modify them. The instance is consumed.
        
    - **Use Case:** For methods that logically consume the struct, making it unusable afterward (e.g., `to_string`, `into_iterator`).
        
4. **Mutable Ownership (`mut self`):**
    
    - **Syntax:** `fn my_method(mut self) { ... }`
        
    - **Ownership:** The method takes **full ownership** and can modify the struct.
        
    - **Permissions:** The method can **read and write** to the struct's fields. The instance is consumed.
        
    - **Use Case:** Less common, but used for consuming a struct after a final modification.
        

### II. Associated Functions: Logic for the Type

An associated function is a function that belongs to a struct type but does not operate on an instance of that struct.

- **Key Characteristic:** Associated functions **do not take `self` as their first parameter**.
    
- **Definition:** Like methods, they are defined inside an `impl` block.5
    
- **Invocation:** You call an associated function using the struct's name and the **double-colon syntax (`::`)**.
    
- **Use Case:** The most common use is as a **constructor** function to create a new instance of the struct.
    

#### The `Self` Alias

Within an `impl` block, the keyword `Self` (capital 'S') is a type alias for the name of the struct itself. It's a best practice to use `Self` for type annotations in methods and associated functions to make the code more flexible if the struct's name ever changes.

### III. Side-by-Side Comparison

|Feature|Associated Function|Method|
|---|---|---|
|**First Parameter**|**None (`self` is absent)**|**`self`** (or `&self`, `&mut self`)|
|**Called On**|The **type itself** (`StructName`)|An **instance** of the type (`instance`)|
|**Invocation Syntax**|`StructName::function_name(args)`|`instance.method_name(args)`|
|**Common Use Case**|Constructors (e.g., `new()`), factory functions.|Defining behaviors and actions that operate on a piece of data.|
|**Code Example**|`let s = String::from("hello");`|`s.len();`|

### IV. Full Code Example: Methods & Associated Functions

This example demonstrates the definition and invocation of both methods and associated functions for a `Rectangle` struct.

Rust

```
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // --- Associated Function (Constructor) ---
    // Does not take `self`. Called on the type `Rectangle`.
    // Returns a new `Rectangle` instance (using the `Self` alias).
    fn new(width: u32, height: u32) -> Self {
        Self { width, height }
    }

    // --- Method (Immutable Borrow) ---
    // Takes an immutable reference `&self`.
    // Can read the data but not modify it.
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // --- Method (Mutable Borrow) ---
    // Takes a mutable reference `&mut self`.
    // Can read and write to the data.
    fn set_size(&mut self, new_width: u32, new_height: u32) {
        self.width = new_width;
        self.height = new_height;
    }
}

fn main() {
    // 1. Calling an Associated Function (Constructor)
    //    We call `new()` on the type `Rectangle` using `::`.
    let mut rect = Rectangle::new(10, 20);
    println!("Initial rect: {:?}", rect); // Output: Initial rect: Rectangle { width: 10, height: 20 }

    // 2. Calling an Immutable Method
    //    We call `area()` on the `rect` instance using `.`.
    let area = rect.area();
    println!("Area: {}", area); // Output: Area: 200

    // 3. Calling a Mutable Method
    //    We call `set_size()` on the `mut rect` instance using `.`
    rect.set_size(15, 25);
    println!("After size change: {:?}", rect); // Output: After size change: Rectangle { width: 15, height: 25 }
}
```
