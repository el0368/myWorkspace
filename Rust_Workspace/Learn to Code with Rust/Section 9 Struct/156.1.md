### Explanation of Methods with Multiple Parameters in Rust

In Rust, methods defined in an `impl` block for a struct can take **multiple parameters** in addition to the `self` parameter. These parameters allow methods to accept external data to interact with or modify the struct instance. Let’s explain this concisely in my own words.

#### Key Concepts
1. **Method Definition**:
   - Methods are defined inside an `impl StructName` block and typically use `self` (or `&self`, `&mut self`) to refer to the struct instance.
   - You can add **additional parameters** to a method, just like any regular function, to pass in extra data.

2. **Parameter Types**:
   - Additional parameters can be of any type (e.g., `String`, `u32`, references, structs, etc.).
   - Parameters can be passed by value (taking ownership), by immutable reference (`&`), or by mutable reference (`&mut`), depending on the method’s needs.

3. **Usage**:
   - Use multiple parameters to:
     - Provide data to update the struct’s fields.
     - Perform computations involving the struct and external values.
     - Interact with other structs or data.
   - The `self` parameter determines whether the method takes ownership (`self`), borrows immutably (`&self`), or borrows mutably (`&mut self`).

4. **Ownership and Borrowing**:
   - Parameters passed by value (e.g., `String`) transfer ownership to the method.
   - Parameters passed by reference (e.g., `&String`) borrow the data, allowing it to remain usable outside the method.
   - Rust’s borrowing rules apply (e.g., only one mutable borrow at a time).

#### Example Code
```rust
struct TaylorSwiftSong {
    title: String,
    duration: u32,
}

impl TaylorSwiftSong {
    // Immutable method with multiple parameters
    fn describe(&self, prefix: &str, suffix: &str) {
        println!("{}{} ({}s){}", prefix, self.title, self.duration, suffix);
    }

    // Mutable method with multiple parameters
    fn update(&mut self, new_title: String, new_duration: u32) {
        self.title = new_title;
        self.duration = new_duration;
        println!("Updated to: {} ({}s)", self.title, self.duration);
    }

    // Method with another struct as a parameter
    fn compare_duration(&self, other: &TaylorSwiftSong) -> bool {
        self.duration > other.duration
    }
}

fn main() {
    let mut song = TaylorSwiftSong {
        title: String::from("Blank Space"),
        duration: 231,
    };

    let other_song = TaylorSwiftSong {
        title: String::from("Shake It Off"),
        duration: 219,
    };

    // Call method with multiple parameters (immutable borrow)
    song.describe("Song: ", " is awesome!");
    // Prints: Song: Blank Space (231s) is awesome!

    // Call method with multiple parameters (mutable borrow)
    song.update(String::from("Lover"), 234);
    // Prints: Updated to: Lover (234s)

    // Call method with another struct
    let is_longer = song.compare_duration(&other_song);
    println!("Is {} longer than {}? {}", song.title, other_song.title, is_longer);
    // Prints: Is Lover longer than Shake It Off? true
}
```

#### Explanation of Code
- **`describe(&self, prefix: &str, suffix: &str)`**:
  - Takes `&self` (immutable borrow) to read the struct’s fields.
  - Accepts two additional parameters (`prefix` and `suffix` as string slices) to customize output.
  - `song` remains usable after the call.

- **`update(&mut self, new_title: String, new_duration: u32)`**:
  - Takes `&mut self` (mutable borrow) to modify the struct’s fields.
  - Accepts `new_title` (takes ownership of a `String`) and `new_duration` (a `u32`, copied).
  - Updates `title` and `duration`; `song` remains usable (requires `mut` in `let mut song`).

- **`compare_duration(&self, other: &TaylorSwiftSong)`**:
  - Takes `&self` and a reference to another `TaylorSwiftSong` instance.
  - Compares durations and returns a boolean.
  - Both `song` and `other_song` remain usable.

#### Key Takeaways
- Methods can take multiple parameters beyond `self` to work with external data.
- Use `&self` for read-only access, `&mut self` for modifications, and choose parameter types (value or reference) based on ownership needs.
- Parameters follow Rust’s ownership and borrowing rules, ensuring memory safety.
- Combine `self` with other parameters to perform complex operations like updates, comparisons, or formatted output.
