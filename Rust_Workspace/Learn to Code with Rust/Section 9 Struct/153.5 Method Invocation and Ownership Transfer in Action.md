### Part 5: Method Invocation and Ownership Transfer in Action

This study guide demonstrates how to invoke a method on a struct instance and illustrates the critical ownership transfer that occurs when the method's `self` parameter takes ownership.

#### 1. Method Invocation Syntax

To run a method, you use dot notation on a struct instance.

- **Syntax:** `instance_variable.method_name(arguments)`
    
- **Distinction:**
    
    - `instance.field_name` is used to **access data** (a field).
        
    - `instance.method_name()` is used to **invoke a behavior** (a method).
        
- **Implicit `self`:** When you invoke a method, you do not need to explicitly provide the `self` parameter as an argument. Rust automatically handles this for you, passing the struct instance (or a reference to it) as the first argument to the method.
    

#### 2. Ownership Transfer in Action (The `self` Ownership Example)

When a method's `self` parameter is defined to take ownership (e.g., `fn method(self)`), the method call itself acts as a **move operation**.

**Step-by-Step Execution:**

1. A `song` instance is created in the `main` function. `song` is the owner.
    
2. The `song.display_song_info()` method is called.
    
3. Because `display_song_info`'s signature is `fn display_song_info(self)`, Rust performs a **move of ownership**.
    
4. The ownership of the `TaylorSwiftSong` instance is transferred from the `song` variable to the `self` parameter of the method.
    
5. The `display_song_info` method runs, using its now-owned `self` parameter to access the struct's fields.
    
6. The method ends. The `self` parameter goes out of scope and, as the owner, is responsible for deallocating the struct's memory.
    
7. Control returns to `main`. The original `song` variable is now **invalidated** because its ownership was moved. Any attempt to use `song` will result in a compile-time error.
    

#### Example: `self` Ownership Transfer

Rust

```Rust
// The struct blueprint
#[derive(Debug)]
struct TaylorSwiftSong {
    title: String,
    release_year: u32,
    duration_secs: u32,
}

impl TaylorSwiftSong {
    // This `self` signature takes IMMUTABLE OWNERSHIP.
    fn display_song_info(self) {
        println!("Title: {}", self.title);
        println!("Release Year: {}", self.release_year);
        println!("Duration: {} seconds", self.duration_secs);
        // The `self` parameter and the struct it owns are deallocated here.
    }
}

fn main() {
    let song = TaylorSwiftSong {
        title: String::from("Blank Space"),
        release_year: 2014,
        duration_secs: 231,
    };

    // Invoking the method on `song`. Ownership of the instance MOVES here.
    // The `self` parameter in the method (lowercase) becomes the owner.
    song.display_song_info();

    // This line would cause a compile-time error!
    // `song` is no longer the owner, as ownership was moved into the method.
    // The compiler error would be E0382: "borrow of moved value: `song`"
    // println!("The song's title is: {}", song.title);
}
```
