### Part 4: Verifying Mutation and Printing from Within the Method

This study guide focuses on how to confirm that a method with a `mut self` parameter has successfully modified a struct's internal state. Since the original variable is invalidated after the method call, the only way to inspect the changes is to print the struct from within the method itself.

#### 1. The Method for Verification

To verify that a mutation operation (such as `self.duration_secs = self.duration_secs * 2;`) has worked, you can use the `println!` macro to print the entire struct after the modification has occurred.

- **Target:** You use the `self` parameter as the value to print, as `self` represents the struct instance that has just been modified.
    
- **Timing:** The `println!` call must be placed after the mutation and before the method concludes.
    
- **Purpose:** This allows you to see the state of the struct at a particular point in time, which is essential for debugging.
    

#### 2. Printing a Struct with the `Debug` Trait

As a reminder, structs do not implement the `Display` trait, so you cannot use `println!("{}")`. You must use the `Debug` trait, which is automatically enabled by the `#[derive(Debug)]` attribute.

- **Format Specifier:** The `Debug` trait uses the format specifier `{:?}`.
    
- **Pretty-Print:** For a more readable, aesthetically pleasing output (especially with many fields), you can use the pretty-print format specifier `{:#?}`.
    

The output will be a technical, programmer-friendly string representation of the struct, including its name, fields, and their corresponding values.

#### 3. Code Example: `double_length` Method with Verification

Rust

```rust
// The struct blueprint
#[derive(Debug)] // This attribute is essential for printing the struct.
struct TaylorSwiftSong {
    title: String,
    release_year: u32,
    duration_secs: u32,
}

impl TaylorSwiftSong {
    // This `mut self` signature takes MUTABLE OWNERSHIP.
    fn double_length(mut self) {
        println!("Original duration (inside method): {}", self.duration_secs);
        
        // Mutate the struct's field. This is a valid operation.
        self.duration_secs = self.duration_secs * 2;
        
        // Use the Debug trait from within the method to verify the change.
        println!("\nUpdated struct from within method: {:#?}", self);

        // Ownership of the struct is consumed here, and it is deallocated.
    }
}

fn main() {
    let song = TaylorSwiftSong {
        title: String::from("Blank Space"),
        release_year: 2014,
        duration_secs: 231,
    };
    
    // We can print the original struct before the method call, as it is still valid.
    println!("Original song from main: {:#?}", song);
    
    // Invoking the method on `song`. Ownership of the instance is MOVED here.
    song.double_length();
    
    // The `song` variable in `main` is now invalid.
}
```

**Output of the `double_length` method call:**

```rust
Original song from main: TaylorSwiftSong {
    title: "Blank Space",
    release_year: 2014,
    duration_secs: 231,
}
Original duration (inside method): 231

Updated struct from within method: TaylorSwiftSong {
    title: "Blank Space",
    release_year: 2014,
    duration_secs: 462,
}
```
