```rust
use std::collections::HashMap;

// -------------------------
// 1) Define the trait
// -------------------------
trait Accommodation {
    // Default (fallback) implementation:
    fn get_description(&self) -> String {
        String::from("A wonderful place to stay.")
    }

    // Must be implemented by each type:
    fn book(&mut self, guest: &str, nights: u32);
}

// -------------------------
// 2) Define a concrete type
// -------------------------
#[derive(Debug)]
struct Hotel {
    name: String,
    reservations: HashMap<String, u32>,
}

// Inherent impl: methods that belong directly to Hotel
impl Hotel {
    fn new(name: &str) -> Self {
        Self {
            name: name.to_string(),
            reservations: HashMap::new(),
        }
    }

    /// Regular method (not part of any trait).
    /// Calls a trait-mandated method internally.
    fn summarize(&self) -> String {
        format!("{}: {}", self.name, self.get_description())
    }

    /// Regular method that calls a *mutating* trait method.
    fn book_and_summarize(&mut self, guest: &str, nights: u32) -> String {
        self.book(guest, nights); // calls the trait method
        self.summarize()          // calls another inherent method
    }
}

// -------------------------
// 3) Implement the trait for Hotel
// -------------------------
impl Accommodation for Hotel {
    // Override the trait's default method
    fn get_description(&self) -> String {
        format!("{} is the pinnacle of luxury.", self.name)
    }

    fn book(&mut self, guest: &str, nights: u32) {
        self.reservations.insert(guest.to_string(), nights);
    }
}

// -------------------------
// 4) Main demonstration
// -------------------------
fn main() {
    let mut hotel = Hotel::new("The Luxe");

    // Inherent method calling a trait method internally
    println!("{}", hotel.summarize());

    // Call mutating trait method directly
    hotel.book("Alice", 2);
    println!("{:#?}", hotel);

    // Inherent method that calls both book() and summarize()
    println!("{}", hotel.book_and_summarize("Bob", 3));
    println!("{:#?}", hotel);

    // (Exercise: comment out get_description override above
    // to see the default version used here.)
}
```

This one file shows:

- A trait with a default method and a required method.
    
- A concrete type (`Hotel`) with its own inherent methods.
    
- Trait implementation that overrides the default method.
    
- Inherent methods (`summarize`, `book_and_summarize`) calling trait methods internally.
    
- Demonstration in `main`.
