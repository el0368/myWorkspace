### **Traits for Function Parameter Constraints**

1. **Problem: Functions that work with multiple types**  
    Sometimes you want a function that can work with **different types**, but only if those types have certain abilities.
    
    Example: You have `Hotel` and `Airbnb` structs, and both can `book()` a guest. You want a function that can **book any accommodation**, without hardcoding the type.
    
2. **Solution: Use a trait**  
    A **trait** defines a set of methods that a type **must implement**.
    
    ```rust
    trait Accommodation {
        fn book(&mut self, guest: &str);
        fn get_description(&self) -> String;
    }
    ```
    
    Any type that implements `Accommodation` **guarantees** it has these methods.
    
3. **Using a trait in a function parameter**  
    Instead of writing a function for a specific type, you can say:
    
    ```rust
    fn book_for_one_night(entity: &mut impl Accommodation, guest: &str) {
        println!("Booking: {}", entity.get_description());
        entity.book(guest);
    }
    ```
    
    - `&mut impl Accommodation` means: _any mutable reference to a type that implements the `Accommodation` trait_.
        
    - Rust ensures that `entity` **has the required methods**, so you can safely call `get_description()` and `book()`.
        
4. **Why this is useful**
    
    - **Flexibility:** The function works with any type that implements the trait (`Hotel`, `Airbnb`, future types).
        
    - **Safety:** Rust checks at compile time that the type really implements the trait.
        
    - **Code reuse:** One function can operate on many types, no duplicate code needed.
        
5. **Example in action**
    

```rust
struct Hotel { name: String }
struct Airbnb { name: String }

impl Accommodation for Hotel {
    fn book(&mut self, guest: &str) { println!("Hotel booked for {}", guest); }
    fn get_description(&self) -> String { self.name.clone() }
}

impl Accommodation for Airbnb {
    fn book(&mut self, guest: &str) { println!("Airbnb booked for {}", guest); }
    fn get_description(&self) -> String { self.name.clone() }
}

fn book_for_one_night(entity: &mut impl Accommodation, guest: &str) {
    println!("Booking at {}", entity.get_description());
    entity.book(guest);
}

fn main() {
    let mut hotel = Hotel { name: "The Luxe".to_string() };
    let mut airbnb = Airbnb { name: "Cozy Stay".to_string() };

    book_for_one_night(&mut hotel, "Alice");
    book_for_one_night(&mut airbnb, "Bob");
}
```

**Output:**

```
Booking at The Luxe
Hotel booked for Alice
Booking at Cozy Stay
Airbnb booked for Bob
```

✅ One function, multiple types, all safe.
