### Part 3 Vocabularies: Strings & Characters

1. **String**:
    
    - **Definition**: A general term referring to a sequence of text, essentially a collection of characters. In Rust, string literals are typically defined using double quotes.
        
    - **Characteristic**: Can contain any number of characters, including alphabetic, numeric, and symbolic.
        
    - **Example**: `"Hello Rust"`, `"123 abc!"`
        
2. **String Literal (`&str`)**:
    
    - **Definition**: A specific type of string in Rust that is **hard-coded directly into your program's source code**. It's a fundamental way to represent fixed, immutable text.
        
    - **Declaration**: Always defined using **double quotes (`"`)**.
        
    - **Technical Type**: The exact type inferred by Rust for such hard-coded strings is `&str`. The `&` symbol indicates it's a "reference" to a string "slice," a memory management concept that will be explained in greater detail later in the course.
        
    - **Synonyms**: The transcript notes that "string," "string literal," and "string slice" are often used interchangeably in introductory contexts to refer to this concept.
        
    - **Example**: `let greeting: &str = "Welcome!";`
        
3. **Character (`char`)**:
    
    - **Definition**: A scalar data type in Rust that represents a **single Unicode character**. It's designed to handle individual text components from any language.
        
    - **Declaration**: Always defined using **single quotes (`'`)**.
        
    - **Memory Footprint**: Occupies **4 bytes (32 bits)** in memory. This larger size ensures that it can store _any_ valid Unicode character, including those that require multiple bytes in UTF-8 encoding (like many emojis or characters from complex writing systems).
        
    - **Example**: `let first_letter: char = 'A';`, `let smiley_face: char = '😀';`, `let currency_symbol: char = '€';`
        
4. **Unicode**:
    
    - **Definition**: A comprehensive **computing industry standard** for the consistent encoding, representation, and handling of text expressed in most of the world's writing systems.
        
    - **Scope**: It assigns a unique numerical value (called a code point) to virtually every character used in modern and historical languages, as well as symbols, punctuation, and emojis (over 140,000 characters covering 150 languages).
        
    - **Relevance to `char`**: Rust's `char` type is built on the Unicode standard, ensuring that a single `char` variable can represent any character defined by Unicode.
        
5. **Special Characters (Escape Sequences)**:
    
    - **Definition**: Within a string literal, these are specific character combinations that begin with a **backslash (`\`)** and are interpreted by the compiler not as literal characters, but as instructions to produce a special, non-printable, or otherwise difficult-to-represent output.
        
    - **Purpose**: They allow you to embed specific formatting commands or characters that would otherwise cause syntax errors or be invisible.
        
    - **Common Examples Mentioned**:
        
        - `\n`: Represents a **newline** character, causing text to break to the next line.
            
        - `\t`: Represents a **tab** character, inserting horizontal spacing.
            
        - `\"`: **Escapes a double quote**. This is necessary when you want to include a literal double quote _inside_ a string that is already delimited by double quotes, preventing the compiler from interpreting it as the end of the string.
            
        - `\\`: **Escapes a backslash**. This allows you to include a literal backslash character in your string, as a single backslash normally signals the start of an escape sequence.
            
    - **Example**:
        
        Rust
        
        ```
        println!("Greeting:\n\tHello, \"World\"! This is a backslash: \\");
        /* Output:
        Greeting:
            Hello, "World"! This is a backslash: \
        */
        ```
