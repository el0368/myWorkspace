### Part 2 Vocabularies: Floating-Point Numbers & Formatting

1. **Floating Point Value / Float**:
    
    - **Definition**: A numerical data type that represents numbers with a **decimal component** (i.e., numbers that are not whole numbers).
        
    - **Characteristic**: Can represent fractional values.
        
    - **Example**: `3.14`, `-0.5`, `123.456`, `0.0`.
        
2. **`f32`**:
    
    - **Definition**: A **32-bit single-precision floating-point type** in Rust.
        
    - **Characteristics**:
        
        - Occupies 32 bits (4 bytes) in memory.
            
        - Offers a lower level of **precision** (typically 6 to 9 significant decimal digits) compared to `f64`.
            
        - Uses less memory than `f64`.
            
    - **Example**: `let small_pi: f32 = 3.14159f32;` (the `f32` suffix explicitly assigns the type).
        
3. **`f64`**:
    
    - **Definition**: A **64-bit double-precision floating-point type** in Rust. It is the **default floating-point type** in Rust if you don't explicitly specify `f32`.
        
    - **Characteristics**:
        
        - Occupies 64 bits (8 bytes) in memory.
            
        - Offers a higher level of **precision** (typically 15 to 17 significant decimal digits) compared to `f32`.
            
        - Uses more memory than `f32`.
            
    - **Example**: `let accurate_calculation: f64 = 1.234567890123456;` (often inferred as `f64`).
        
4. **Precision**:
    
    - **Definition**: In the context of floating-point numbers, precision refers to the **number of accurate digits** that a floating-point type can reliably store and represent, particularly those after the decimal point.
        
    - **Relevance**: `f64` has higher precision than `f32`, meaning it can represent fractional numbers with more accurate decimal places.
        
5. **Format Specifier (`:`)**:
    
    - **Definition**: A special symbol, the colon (`:`), placed within the curly braces (`{}`) of Rust's formatting macros (like `println!`, `format!`).
        
    - **Purpose**: It signals to the macro that the interpolated value should be printed with **customized formatting options** that follow the colon. These options alter the _appearance_ of the value in the output string, but do not change the underlying value itself.
        
    - **Example**: In `println!("{:.2}", my_float);`, the `:` indicates that `.2` is a format specifier.
        
6. **Dot Syntax (`.N`) (for float precision)**:
    
    - **Definition**: A specific type of format specifier, composed of a dot followed by a number (e.g., `.2`, `.4`), used _after_ the colon in `println!` when formatting floating-point numbers.
        
    - **Purpose**: It instructs Rust to round or pad the floating-point number so that it is displayed with exactly `N` digits after the decimal point.
        
    - **Impact**: This only affects the **printed string representation** that the user sees; the actual value stored in the computer's memory at its full precision remains unchanged.
        
    - **Example**: `println!("Price: {:.2}", 123.456);` would output "Price: 123.46".
