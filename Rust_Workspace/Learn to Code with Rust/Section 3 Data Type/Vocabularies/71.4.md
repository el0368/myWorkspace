### Part 4 Vocabularies: Methods

1. **Method**:
    
    - **Definition**: A **function that is associated with a specific value or a variable** (which holds a value). It represents an action, behavior, or a command that the value itself can perform or that can be performed _on_ that value.
        
    - **Syntax**: In Rust, methods are called using the **dot operator (`.`)** followed by the method's name and a pair of parentheses (`()`).
        
    - **Purpose**: Methods encapsulate operations relevant to the data type they belong to, making code more organized and readable.
        
    - **Example**: `my_string.len()` (the `len()` method operates on `my_string` to return its length); `my_char.is_alphabetic()` (the `is_alphabetic()` method checks a character's property).
        
2. **Invoke**:
    
    - **Definition**: To **run, execute, or call** a method (or a function or macro).
        
    - **Mechanism**: In Rust, the act of invoking a method is indicated by the presence of a pair of **parentheses (`()`)** immediately after the method's name. These parentheses are required even if the method does not accept any input values.
        
    - **Example**: In `println!("Length: {}", my_text.len());`, the `()` after `len` causes the `len` method to be invoked.
        
3. **Argument (to Method)**:
    
    - **Definition**: An **input value** that is passed to a method (or a function or macro) when it is invoked. Arguments provide the method with the necessary data or customization it needs to perform its operation.
        
    - **Placement**: Arguments are written directly _inside_ the parentheses `()` when the method is called.
        
    - **Multiple Arguments**: If a method requires more than one argument, they are separated by commas (`,`) and often followed by a space for better readability.
        
    - **Example**: If you had a method `user.set_age(30);`, then `30` is the argument being passed to the `set_age` method. In `println!("{:.2}", my_float);`, `my_float` is an argument passed to the `println!` macro.
