## Rust Core Data Types & Fundamentals: Section Review Study Guide

This section introduced foundational concepts in Rust, from basic data types to more complex structures and programming paradigms like traits and generics.

### 1. Scalar Types

Scalar types hold a single value.

#### a. Integers

Whole numbers.

- **Signed Integers (`i` family: `i8`, `i16`, `i32`, `i64`, `i128`)**
    
    - Support both **negative and positive** values, including zero.
        
    - The prefix `i` stands for "integer."
        
    - The number (e.g., `8`, `16`, `32`) indicates the **number of bits** the integer occupies in memory.
        
    - **Memory vs. Range:** More bits mean more memory consumption but a larger range of values that can be represented.
        
    - **Example:** `let temperature: i32 = -5;`
        
- **Unsigned Integers (`u` family: `u8`, `u16`, `u32`, `u64`, `u128`)**
    
    - Support only **zero and positive** values.
        
    - The prefix `u` stands for "unsigned."
        
    - They can represent positive values **twice as large** as their signed counterparts for the same number of bits, because they don't need to allocate a bit for the sign.
        
    - **Example:** `let age: u8 = 25;`
        

#### b. Floating-Point Numbers (`f32`, `f64`)

Numbers with a decimal component.

- **`f32` (32-bit float)**
    
    - Lower memory requirement.
        
    - Supports 6 to 9 digits of precision after the decimal point.
        
    - **Example:** `let pi: f32 = 3.14159f32;` (explicit type suffix `f32` can be added)
        
- **`f64` (64-bit float)**
    
    - Higher memory requirement.
        
    - Supports 15 to 17 digits of precision after the decimal point. This is the default float type in Rust.
        
    - **Example:** `let price: f64 = 99.99;` (inferred as `f64`)
        
- **Format Specifier for Precision (`:.N`)**
    
    - Used within `println!`'s curly braces (`{}`) to control the number of digits printed after the decimal point.
        
    - **Syntax:** `:.N` where `N` is the desired number of decimal places.
        
    - **Important:** This **only changes the _printed string representation_**; it does not alter the underlying float's value or precision in memory.
        
    - **Example:**
        
        Rust
        
        ```Rust
        let value = 123.456789;
        println!("Value (2 decimal places): {:.2}", value); // Output: Value (2 decimal places): 123.46
        println!("Value (4 decimal places): {:.4}", value); // Output: Value (4 decimal places): 123.4568
        ```
        

#### c. `usize` and `isize`

These are **aliases (nicknames)** for existing integer types, whose _actual size_ depends on the architecture of the computer running the program.

- **`usize`**: Alias for an unsigned integer.
    
    - On a 32-bit system: `u32`
        
    - On a 64-bit system: `u64`
        
- **`isize`**: Alias for a signed integer.
    
    - On a 32-bit system: `i32`
        
    - On a 64-bit system: `i64`
        
- **Advantage (Versatility):** They allow your code to remain the same while automatically adapting to the appropriate integer size for memory addressing and indexing on different systems.
    
- **Common Use:** Primarily used for indexing collections (like arrays and vectors) and for sizes, as they directly correspond to the size of memory addresses on the target system.
    
- **Example:** `let index: usize = 0;`
    

#### d. Booleans (`bool`)

Represent truth values.

- Can only be one of two values: `true` or `false`.
    
- Models binary states (on/off, active/inactive, yes/no).
    
- **Example:** `let is_admin: bool = true;`
    

#### e. Characters (`char`)

Represent a single Unicode character.

- **Definition:** A single Unicode character. Unicode is a standard for representing text from most of the world's writing systems (over 140,000 characters, including alphabets, digits, symbols, and emojis).
    
- **Declaration:** Declared using **single quotes (`'`)**.
    
- **Memory:** Occupies **4 bytes (32 bits)** in memory to support the entire Unicode range (including multi-byte UTF-8 characters like emojis).
    
- **`str` vs. `char`:** A `char` is a single character (`'A'`), while a `&str` (string slice) is a sequence of characters (`"Hello"`). Even `"A"` is a string, not a `char`.
    
- **Example:**
    
    Rust
    
    ```Rust
    let initial: char = 'J';
    let emoji_char: char = '🚀';
    let digit_char: char = '7';
    ```
    
- **`char` Methods:** `char` values have methods like:
    
    - `is_alphabetic()`: Checks if it's an alphabetic character.
        
    - `is_uppercase()`: Checks if it's an uppercase character.
        
    - `is_lowercase()`: Checks if it's a lowercase character.
        
    - `is_digit(radix)`: Checks if it's a digit in a given base (e.g., `c.is_digit(10)`).
        
    - `is_whitespace()`: Checks if it's a whitespace character.
        
    - **Example:**
        
        Rust
        
        ```Rust
        let my_char = 'A';
        println!("Is alphabetic: {}", my_char.is_alphabetic()); // true
        println!("Is uppercase: {}", my_char.is_uppercase());   // true
        ```
        

### 2. Strings and Special Characters

#### a. String Literals (`&str`)

- **Definition:** A fixed-size, hard-coded piece of text (sequence of characters) in your source code.
    
- **Declaration:** Declared using **double quotes (`"`)**.
    
- **Terminology:** Also referred to as "string slices" or simply "strings" in basic contexts. The `&` in `&str` indicates it's a "reference to a string slice," a concept covered later.
    
- **Example:** `let greeting: &str = "Hello, Rust!";`
    

#### b. Special Characters (Escape Sequences)

Characters that have a special meaning when prefixed with a backslash (`\`) inside a string literal. They don't print literally but produce specific formatting.

- **`\n`**: Newline (line break).
    
- **`\t`**: Tab.
    
- **`\"`**: Escapes a double quote (allows you to embed `"` within a `"`-delimited string without prematurely ending it).
    
- **`\\`**: Escapes a backslash (allows you to print a literal `\`).
    
- **Example:**
    
    Rust
    
    ```Rust
    println!("First line\nSecond line");
    println!("Indented text:\tThis is tabbed.");
    println!("He said, \"Hello!\"");
    println!("This is a backslash: \\");
    ```
    

### 3. Methods

- **Definition:** A function that is "attached" to a value (or a variable referring to a value).
    
- **Purpose:** Represents an action, behavior, or command that the value can perform or that can be performed _on_ the value.
    
- **Syntax:** `value.method_name(arguments)`
    
    - `value` or `variable`: The data on which the method operates.
        
    - `.`: The dot operator, used to call a method on a value.
        
    - `method_name`: The name of the behavior.
        
    - `()`: **Parentheses are mandatory** to invoke (run/execute) the method, even if it takes no arguments.
        
    - `arguments`: Inputs passed inside the parentheses, separated by commas (`,`) and spaces (for readability). Arguments customize the method's operation.
        
- **Example:**
    
    Rust
    
    ```Rust
    let sentence = "Rust is fun";
    println!("Length of sentence: {}", sentence.len()); // .len() is a method on string slices
    ```
    

### 4. Mathematical Operations

Rust supports standard arithmetic operations.

- **Addition:** `+` (e.g., `5 + 3`)
    
- **Subtraction:** `-` (e.g., `10 - 4`)
    
- **Multiplication:** `*` (e.g., `2 * 6`)
    
- **Division:** `/` (e.g., `10 / 3`)
    
    - **Integer Division (Floor Division):** If both operands are integers, Rust performs floor division (truncates the decimal part). `10 / 3` results in `3`.
        
    - **Floating-Point Division:** To get a decimal result, at least one operand (and typically both) must be a float. `10.0 / 3.0` results in `3.333...`.
        
- **Modulo:** `%` (e.g., `10 % 3`)
    
    - Returns the **remainder** of a division. `10 % 3` results in `1` (because `10 = 3*3 + 1`).
        

#### Augmented Assignment Operators

Combine an arithmetic operation with assignment. The variable on the left must be mutable (`mut`).

- `+=` (add and assign): `x += 5;` is equivalent to `x = x + 5;`
    
- `-=` (subtract and assign): `x -= 2;` is equivalent to `x = x - 2;`
    
- `*=` (multiply and assign): `x *= 3;` is equivalent to `x = x * 3;`
    
- `/=` (divide and assign): `x /= 2;` is equivalent to `x = x / 2;`
    
- `%=` (modulo and assign): `x %= 3;` is equivalent to `x = x % 3;`
    
- **Example:**
    
    Rust
    
    ```
    let mut counter = 10;
    counter += 5; // counter is now 15
    counter *= 2; // counter is now 30
    println!("Counter: {}", counter);
    ```
    

### 5. Logical and Comparison Operators (Produce Booleans)

These operators compare values or combine Boolean expressions, always resulting in a `bool` (`true` or `false`).

- **Equality:** `==` (Checks if two operands are equal).
    
    - `5 == 5` -> `true`
        
    - `5 == 10` -> `false`
        
- **Inequality:** `!=` (Checks if two operands are not equal).
    
    - `5 != 5` -> `false`
        
    - `5 != 10` -> `true`
        
- **Greater Than:** `>`
    
- **Less Than:** `<`
    
- **Greater Than or Equal To:** `>=`
    
- **Less Than or Equal To:** `<=`
    
- **AND Operator:** `&&` (Logical AND).
    
    - Returns `true` if **both** operands are `true`. Otherwise, `false`.
        
    - **Short-circuiting:** If the left operand is `false`, the right operand is not evaluated.
        
    - `true && true` -> `true`
        
    - `true && false` -> `false`
        
- **OR Operator:** `||` (Logical OR).
    
    - Returns `true` if **at least one** operand is `true`.
        
    - **Short-circuiting:** If the left operand is `true`, the right operand is not evaluated.
        
    - `true || false` -> `true`
        
    - `false || false` -> `false`
        
- **Example:**
    
    Rust
    
    ```Rust
    let score = 85;
    let has_bonus = true;
    
    println!("Is passing (>= 70)? {}", score >= 70); // true
    println!("Eligible for reward? {}", score >= 90 && has_bonus); // false
    println!("Can retake or passed? {}", score < 60 || score >= 70); // true
    ```
    

### 6. Compound Types

Compound types can store multiple values within a single variable.

#### a. Arrays (`[T; N]`)

- **Ordered Collection:** Stores elements in a specific sequence.
    
- **Homogeneous Data:** All elements **must be of the same type**.
    
- **Fixed Size:** The number of elements (its length) is fixed at compile time and **cannot change** during runtime.
    
- **Declaration:** Uses square brackets `[]` with elements separated by commas.
    
- **Type Annotation:** `[ElementType; Length]` (e.g., `[i32; 5]`, `[&str; 3]`).
    
- **Initialization:** Can be initialized with a list of values or a single value repeated: `[value; count]`.
    
- **Indexing:** Elements are accessed by their **zero-based index** using square brackets (e.g., `my_array[0]`).
    
- **Mutability:** If declared with `mut`, individual elements can be _replaced_, but not added or removed.
    
- **`len()` Method:** Returns the number of elements in the array.
    
- **`Debug` Trait:** Arrays do not implement `Display` but implement `Debug` (printable with `{:?}` or `{:#?}`).
    
- **Example:**
    
    Rust
    
    ```Rust
    let numbers = [10, 20, 30, 40]; // Inferred as [i32; 4]
    let mut colors: [&str; 3] = ["red", "green", "blue"]; // Explicit type
    println!("First color: {}", colors[0]); // red
    colors[1] = "yellow"; // Valid: changing an element in a mutable array
    // println!("Numbers: {}", numbers); // ERROR: does not implement Display
    println!("Numbers (Debug): {:?}", numbers); // Works
    println!("Colors (Length): {}", colors.len()); // 3
    ```
    

#### b. Tuples (`(T1, T2, T3, ...)`)

- **Ordered Collection:** Stores elements in a specific sequence.
    
- **Heterogeneous Data:** Elements **can be of different types**.
    
- **Fixed Size:** The number of elements is fixed at compile time and cannot change.
    
- **Declaration:** Uses parentheses `()` with elements separated by commas.
    
- **Type Annotation:** `(Type1, Type2, Type3, ...)` (e.g., `(&str, i32, bool)`).
    
- **Indexing:** Elements are accessed by their **zero-based index** using dot notation (e.g., `my_tuple.0`).
    
- **Destructuring:** A convenient way to extract elements into separate variables: `let (name, age) = my_tuple;`.
    
- **`Debug` Trait:** Tuples do not implement `Display` but implement `Debug` (printable with `{:?}` or `{:#?}`).
    
- **Unit Type (`()`):** An empty tuple represents the absence of a value (e.g., the implicit return type of a function that doesn't explicitly return anything).
    
- **Example:**
    
    Rust
    
    ```Rust
    let user_profile = ("Alice", 30, 1.75, true); // Inferred as (&str, i32, f64, bool)
    println!("User name: {}", user_profile.0); // Alice
    
    // Destructuring
    let (name, age, height, active) = user_profile;
    println!("Age: {}, Active: {}", age, active);
    
    // println!("Profile: {}", user_profile); // ERROR: does not implement Display
    println!("Profile (Debug): {:?}", user_profile); // Works
    ```
    

### 7. Traits

- **Definition:** A trait is a **contract** that defines a set of behaviors (method signatures) that a type _must_ implement if it chooses to "honor" that trait.
    
- **Purpose:**
    
    - **Consistency:** Ensures that different types that perform similar actions have consistent method names and signatures.
        
    - **Polymorphism (future topic):** Allows writing generic code that can operate on any type that implements a certain trait.
        
- **Implementation:** When a type fulfills a trait's requirements, it is said to **implement** that trait.
    
- **Choice:** A type can implement zero, one, or many traits. A single trait can be implemented by many types.
    
- **Analogy:** A legal contract for software.
    
- **Other Languages:** Similar to "interfaces" (Java, C#) or "protocols" (Swift).
    

#### a. `Display` Trait

- **Purpose:** To format a type into a **user-friendly, human-readable string**. Intended for displaying output to the end-user.
    
- **Mechanism:** Requires the type to implement a specific `fmt` method that writes to a formatter.
    
- **Usage:** Used implicitly with the standard curly braces `{}` in `println!`, `format!`, etc.
    
- **Implementation:** Implemented by basic types (integers, floats, booleans, characters, string slices) where the string representation is obvious.
    
- **Not Implemented For:** More complex types like arrays and tuples (because their "user-friendly" representation is not universally obvious).
    
- **Example:**
    
    Rust
    
    ```
    let num = 100;
    println!("The number is: {}", num); // Works (i32 implements Display)
    ```
    

#### b. `Debug` Trait

- **Purpose:** To format a type into a **programmer-facing string** for debugging purposes. Intended for developers to inspect the state of values.
    
- **Mechanism:** Also requires a `fmt` method, but specifically for `Debug` formatting.
    
- **Usage:** Used with format specifiers:
    
    - `{:?}`: Standard Debug format (compact).
        
    - `{:#?}`: "Pretty-print" Debug format (indented, multi-line for complex types).
        
- **Implementation:** Implemented by most types in Rust, including arrays and tuples. Can often be automatically derived for custom structs and enums using `#[derive(Debug)]`.
    
- **Example:**
    
    Rust
    
    ```Rust
    let numbers = [1, 2, 3];
    println!("Numbers (Debug): {:?}", numbers);    // [1, 2, 3]
    println!("Numbers (Pretty Debug):\n{:#?}", numbers);
    /* Output:
    [
        1,
        2,
        3,
    ]
    */
    ```
    

### 8. `dbg!` Macro

- **Syntax:** `dbg!(expression)`
    
- **Purpose:** A utility macro for **quick and dirty debugging**. It prints the value of an expression to standard error (`stderr`) along with meta-information (file, line number, column, and the source code of the expression itself), and then **returns the value of the expression**.
    
- **Requirement:** The expression passed to `dbg!` **must implement the `Debug` trait**.
    
- **Automatic Pretty-Printing:** `dbg!` often defaults to a pretty-printed `Debug` format for complex types.
    
- **Developer Tool:** Strictly for development and typically removed from production code.
    
- **Example:**
    
    Rust
    
    ```Rust
    fn calculate_area(length: f64, width: f64) -> f64 {
        let area = dbg!(length * width); // Prints the calculation and result of length * width
        area
    }
    
    fn main() {
        let result = calculate_area(5.0, 8.0);
        println!("The area is: {}", result);
        // Output from dbg! will appear before "The area is:"
        // [src/main.rs:3:18] length * width = 40.0
        // The area is: 40
    }
    ```
    

### 9. Ranges (`std::ops::Range<T>`)

- **Definition:** A type that represents a sequence or interval of **consecutive values**.
    
- **Advantage:** Allows representing a large sequence (e.g., 1 to 1000) without explicitly listing all values.
    
- **Syntax:**
    
    - **Exclusive Range (`..`):** `start..end` (goes up to `end`, but does not include `end`).
        
        - Example: `1..5` generates `1, 2, 3, 4`.
            
    - **Inclusive Range (`..=`):** `start..=end` (includes both `start` and `end`).
        
        - Example: `1..=5` generates `1, 2, 3, 4, 5`.
            
- **Homogeneous:** The values within a range must be of the same type (e.g., `Range<i32>`, `Range<char>`).
    
- **`Debug` Trait:** Implements `Debug` (printable with `{:?}` or `{:#?}`).
    
- **Example:**
    
    Rust
    
    ```Rust
    let num_range = 10..=15; // Inclusive range of integers
    let char_range = 'A'..'D'; // Exclusive range of characters: 'A', 'B', 'C'
    println!("Numeric Range: {:?}", num_range);
    println!("Character Range: {:?}", char_range);
    ```
    

#### Iteration with `for` Loops

- **Iteration:** The process of visiting each element in a collection, one by one.
    
- **Iterable:** A type that can be iterated over (e.g., `Range`, `Array`, `Vector`).
    
- **`for` Loop Syntax:**
    
    Rust
    
    ```Rust
    for element_variable in iterable_collection {
        // code to execute for each element
    }
    ```
    
    - `element_variable`: A temporary variable that holds the current element in each iteration.
        
- **Example:**
    
    Rust
    
    ```Rust
    let numbers = 1..=5;
    println!("Counting:");
    for n in numbers {
        println!("{}", n); // Prints 1, 2, 3, 4, 5 on separate lines
    }
    
    let fruits = ["Apple", "Banana", "Cherry"];
    println!("\nFruits:");
    for fruit in fruits {
        println!("I like {}", fruit);
    }
    ```
    

### 10. Generics

- **Definition:** A programming concept that allows you to write code that works with **multiple types** without explicitly duplicating the code for each type. It's about writing flexible, reusable components.
    
- **Type Argument:** Generics use "type arguments" (e.g., `i32` or `char`) to specify the concrete type that a generic placeholder will represent.
    
- **Placeholder:** A generic type parameter (often denoted by `T`, `U`, `V`, or descriptive names) acts as a placeholder for a future concrete type.
    
- **Angle Brackets (`< >`):** Used to enclose generic type arguments (e.g., `Range<i32>`, `Vec<String>`).
    
- **Reusability:** The primary benefit is allowing a single definition (e.g., of the `Range` type) to work for `Range<i32>`, `Range<char>`, `Range<f64>`, etc., without the need for separate `RangeI32`, `RangeChar`, `RangeF64` types.
    
- **Module Path for Types:** Some types, like `Range`, are nested within modules (`std::ops::Range`). This organization prevents naming conflicts and keeps the global namespace clean.
    
- **Example (Conceptual):** The Rust developer designed `Range<T>` to hold any type `T` that can be ordered. When you write `1..10`, Rust instantiates `Range<i32>`. When you write `'a'..'z'`, it instantiates `Range<char>`. The core logic of the `Range` type remains the same, but it adapts to the specific type you provide.
