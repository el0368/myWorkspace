### Study Guide: The Character (`char`) Data Type in Rust 🔡

The **`char`** type in Rust represents a single **Unicode Scalar Value**. Unicode is a universal standard for encoding characters from most of the world's writing systems, including letters, symbols, and emojis.

#### Memory Size

A `char` in Rust occupies **4 bytes** (32 bits) of memory. This large, fixed size ensures it can represent _any_ character in the Unicode standard, from a simple English letter (which only needs 1 byte) to a complex emoji.

---

### Declaration and Syntax

You declare a `char` literal using **single quotes (`'`)**. It can hold any single Unicode character.

Rust

```Rust
fn main() {
    // A standard alphabetic character
    let first_initial = 'B'; // Type `char` is inferred

    // A symbol
    let symbol = '$';

    // An emoji (On Windows: Win + . | On macOS: Fn + E)
    let emoji: char = '🦀'; // Explicitly annotated

    println!("Initial: {}, Symbol: {}, Emoji: {}", first_initial, symbol, emoji);
}
```

---

### `char` vs. `String` of Length 1

This is a critical distinction. A `char` is fundamentally different from a string that contains only one character.

|Feature|`char`|`&str` or `String`|
|---|---|---|
|**Delimiter**|Single Quotes (`'`)|Double Quotes (`"`)|
|**Represents**|A single Unicode character|A sequence of characters|
|**Size in Memory**|Always 4 bytes|Variable size|
|**Example**|`'A'`|`"A"`|

Attempting to put more than one character inside single quotes will cause a compile-time error.

---

### Common Methods on `char`

`char` values have many useful built-in methods that return a `bool` to check their properties.

- **`.is_alphabetic()`**: Checks if the character is in the alphabet.
    
- **`.is_numeric()`**: Checks if the character is a digit from 0-9.
    
- **`.is_uppercase()`**: Checks if the character is an uppercase letter.
    
- **`.is_lowercase()`**: Checks if the character is a lowercase letter.
    
- **`.is_whitespace()`**: Checks for whitespace characters like space, tab, or newline.
    

#### Example

Rust

```Rust
fn main() {
    let c1 = 'A';
    let c2 = '5';
    let c3 = ' ';
    let c4 = '🦀';

    println!("'{}' is alphabetic: {}", c1, c1.is_alphabetic()); // true
    println!("'{}' is numeric: {}", c2, c2.is_numeric());   // true
    println!("'{}' is whitespace: {}", c3, c3.is_whitespace()); // true
    println!("'{}' is lowercase: {}", c4, c4.is_lowercase()); // false
}
```
