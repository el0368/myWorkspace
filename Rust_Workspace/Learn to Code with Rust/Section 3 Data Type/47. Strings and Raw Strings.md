### String Literals 📝

A **string literal** is a sequence of characters whose value is known when your code is compiled. You create one by enclosing text in double quotes (`"`). This is different from a dynamic string that might be created from user input at runtime.

Rust

```
println!("This is a string literal.");
```

---

### Special Characters and Escaping

Within a string literal, certain character combinations starting with a backslash (`\`) have special meanings instead of being printed literally. To print a character that _normally_ has a special meaning (like `"` or `\`), you must **escape** it by placing a backslash (`\`) before it.

|Sequence|Description|Example|
|---|---|---|
|`\n`|**Newline:** Moves the cursor to the beginning of the next line.|`println!("Line 1\nLine 2");`|
|`\t`|**Tab:** Inserts a horizontal tab space.|`println!("Item:\tMilk");`|
|`\"`|**Double Quote:** Inserts a literal double quote character.|`println!("She said, \"Hello, Rust!\"");`|
|`\\`|**Backslash:** Inserts a literal backslash character.|`println!("Path: C:\\Users\\Default");`|

---

### Raw Strings

A **raw string** is a special type of string literal that ignores all escape sequences and special characters. Every character is interpreted literally as it is written. This is extremely useful for text that contains many backslashes, like Windows file paths or regular expressions.

You create a raw string by prefixing the opening quote with a lowercase `r`.

#### Example: Escaping vs. Raw String

Using a raw string is often much cleaner than manually escaping every backslash.

Rust

```Rust
fn main() {
    // Using escaping for a Windows path
    let path_escaped = "C:\\Program Files\\My App\\data.bin";

    // Using a raw string is much simpler for the same path
    let path_raw = r"C:\Program Files\My App\data.bin";

    println!("Escaped: {}", path_escaped);
    println!("Raw:     {}", path_raw);
}
```
