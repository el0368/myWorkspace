### Study Guide: Defining and Calling Functions in Rust 🚀

A **function** is a named sequence of instructions—a reusable block of code that performs a specific task. They are the primary way to structure and organize code in a Rust program.

**Key Benefits:**

- **Reusability:** Define a piece of logic once and run it multiple times from different places in your program.
    
- **Organization:** Break down a complex program into smaller, manageable, single-responsibility chunks.
    

---

### The Anatomy of a Function Definition

All custom functions follow the same syntax as the `main` function.

Rust

```Rust
fn function_name() {
    // This is the function body
    // It contains the code that runs when the function is called.
}
```

- **`fn`**: The keyword that starts every function definition.
    
- **`function_name`**: The name you give your function. The convention is to use **`snake_case`** (all lowercase, with underscores between words).
    
- **`()`**: Parentheses are required after the name. They will later be used to define function inputs (parameters).
    
- **`{}` (The Body)**: The curly braces enclose the function's body, which contains the sequence of instructions.
    

---

### Defining vs. Calling a Function

This is a crucial distinction for beginners.

- **Defining a Function:** This is like writing down a recipe. You are creating the set of instructions, but nothing happens yet.
    
    Rust
    
    ```Rust
    fn say_hello() {
        println!("Hello, Rust!");
    }
    ```
    
- **Calling (or Invoking) a Function:** This is like actually cooking the recipe. You tell the program to execute the instructions inside the function's body. You do this by writing the function's name followed by parentheses `()`.
    
    Rust
    
    ```Rust
    say_hello(); // This runs the code inside say_hello
    ```
    

---

### The Role of the `main` Function

The `main` function is the special **entry point** of every Rust executable. When you run your program, Rust automatically calls `main` first. Any other custom function you write will only run if it is called from within `main`, or from another function that is eventually called by `main`.

### Practical Examples

#### Example from the Transcript (Pizza Store)

This shows how to break down a larger task into smaller, reusable functions.

Rust

```Rust
fn open_store() {
    println!("Opening my pizza store!");
}

fn bake_pizza() {
    println!("Baking a pizza...");
}

fn swim_in_profit() {
    println!("So much $$$, so little time!");
}

fn main() {
    open_store();
    bake_pizza();
    swim_in_profit();
    // Reusability: We can call a function multiple times.
    swim_in_profit();
    swim_in_profit();
}
```

#### My Example (Morning Routine)

This shows how functions create a clear, readable sequence of events.

Rust

```Rust
fn wake_up() {
    println!("Good morning! Time to get up.");
}

fn make_coffee() {
    println!("Brewing a fresh cup of coffee.");
}

fn main() {
    println!("--- Starting my day ---");
    wake_up();
    make_coffee();
    println!("--- Ready for the day! ---");
}
```
