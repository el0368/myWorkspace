### Study Guide: Function Return Values in Rust 📤

A **return value** is the output that a function produces and gives back to the code that called it. This allows functions to perform calculations or transformations and provide the result for use elsewhere in your program.

---

### The Two Requirements for Returning a Value

To make a function return a value, you must do two things:

1. **Declare the Return Type:** You must tell the compiler exactly what type of data the function will return.
    
2. **Return a Value:** The function's body must provide a value of that specified type to send back to the caller.
    

---

### 1. Declaring the Return Type (`->`)

In the function's **signature** (its definition line), you declare the return type after the parameter list using an arrow (`->`) followed by the type. The compiler uses this to enforce correctness and will issue an error if you try to return a value of a different type.

Rust

```Rust
// This function takes an i32 and promises to RETURN an i32.
fn square(number: i32) -> i32 {
    // ... function body ...
    number * number
}

// This function takes a string slice and promises to RETURN a bool.
fn is_long(s: &str) -> bool {
    s.len() > 10
}
```

---

### 2. Returning a Value (Two Methods)

Rust provides two ways to return a value from a function.

#### Method A: The `return` Keyword

The `return` keyword explicitly sends a value back and **immediately exits the function**. Any code written after a `return` statement within the same block will never be executed.

Rust

```Rust
fn square(number: i32) -> i32 {
    return number * number;
    // println!("This will never run!"); // This is unreachable code
}
```

#### Method B: Expression-Based Returns (Idiomatic Rust)

**This is the most common and idiomatic way to return values in Rust.** Rust is an expression-based language, which means the last expression in a function's body is automatically used as its return value.

To do this, you simply write the value you want to return as the last line and **omit the semicolon**. A line without a semicolon is an expression; a line with one is a statement.

Rust

```Rust
// Idiomatic version of the square function
fn square(number: i32) -> i32 {
    number * number // No `return` keyword, no semicolon
}
```

---

### Capturing and Using a Return Value

When you call a function that returns a value, you can capture that result in a variable.

#### Example from the Transcript

Rust

```Rust
fn square(number: i32) -> i32 {
    number * number
}

fn main() {
    // The return value from `square(5)` is assigned to `five_squared`.
    let five_squared = square(5);
    println!("The square of 5 is {}", five_squared); // Prints 25

    // The return value from `square(13)` is assigned to `thirteen_squared`.
    let thirteen_squared = square(13);
    println!("The square of 13 is {}", thirteen_squared); // Prints 169
}
```

#### My Example

Rust

```Rust
fn create_greeting(name: &str) -> String {
    format!("Hello, {}!", name) // The `format!` macro returns a String
}

fn main() {
    let greeting = create_greeting("Alice");
    println!("{}", greeting); // Prints "Hello, Alice!"
}
```
