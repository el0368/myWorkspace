## Rust Control Flow: The `continue` Keyword (Skipping Loop Iterations)

This study guide focuses on the `continue` keyword, which allows you to skip the remainder of the current loop iteration and move directly to the next iteration.

### I. Understanding the `continue` Keyword

What does the continue keyword do?

The continue keyword forces a loop to immediately skip the rest of the current iteration's code and jump directly to the beginning of the next iteration.

- **Purpose:** It's used when you want to bypass certain parts of the loop body for specific conditions, without stopping the entire loop.
    
- **Behavior:** Think of it as telling the loop, "Okay, I'm done with this particular cycle; let's start the next one now."
    

**How does `continue` differ from `break`?**

|Feature|`continue`|`break`|
|---|---|---|
|**Action**|Skips to the **next iteration** of the loop.|**Terminates the entire loop**.|
|**Scope**|Affects only the **current iteration**.|Exits the **entire loop** permanently.|
|**Result**|The loop keeps running, just skipping some code.|The loop stops, and execution continues after the loop.|

**Example: Countdown Timer with `continue`**

Let's adapt the countdown timer to demonstrate `continue` when the `seconds` value is even.

Rust

```Rust
fn main() {
    let mut seconds = 21; // Initialize with 21 seconds

    println!("Initiating Launch Sequence Countdown (with continue logic):");

    loop { // Start of the `loop` block
        // --- Loop Control Checks (often at the top) ---

        // 1. Break condition (safer: less than or equal to 0)
        if seconds <= 0 {
            println!("Blastoff!");
            break; // Terminates the entire loop
        }

        // 2. Continue condition (for even numbers)
        if seconds % 2 == 0 { // Check if `seconds` is an even number
            println!("{} seconds (even number): Skipping 3 seconds.", seconds);
            seconds -= 3; // Decrement by 3 for even numbers
            continue;    // Skip the rest of this iteration and jump to the next `loop` cycle
        }

        // --- Normal Iteration Logic (only runs if 'continue' was NOT hit) ---
        println!("{} seconds to blastoff...", seconds);
        seconds -= 1; // Decrement by 1 for odd numbers
    } // End of the `loop` block

    println!("Launch sequence complete. Have a great flight!");
}
```

**Understanding the Flow (Tracing `seconds = 21`):**

1. **Iteration 1 (`seconds = 21`):**
    
    - `seconds <= 0` is `false`.
        
    - `seconds % 2 == 0` (`21 % 2 == 0`) is `false` (21 is odd).
        
    - Normal logic runs: `println!("21 seconds to blastoff...")`.
        
    - `seconds` becomes `20` (`21 - 1`).
        
    - Loop continues.
        
2. **Iteration 2 (`seconds = 20`):**
    
    - `seconds <= 0` is `false`.
        
    - `seconds % 2 == 0` (`20 % 2 == 0`) is `true` (20 is even).
        
    - `println!("20 seconds (even number): Skipping 3 seconds.")` runs.
        
    - `seconds` becomes `17` (`20 - 3`).
        
    - `continue;` is hit. This immediately **skips** `println!("{} seconds to blastoff...")` and `seconds -= 1;` for _this specific iteration_, and jumps to the top of the `loop` for the next cycle.
        
3. **Iteration 3 (`seconds = 17`):**
    
    - `seconds <= 0` is `false`.
        
    - `seconds % 2 == 0` (`17 % 2 == 0`) is `false` (17 is odd).
        
    - Normal logic runs: `println!("17 seconds to blastoff...")`.
        
    - `seconds` becomes `16` (`17 - 1`).
        
    - Loop continues.
        
4. **Iteration 4 (`seconds = 16`):**
    
    - `seconds <= 0` is `false`.
        
    - `seconds % 2 == 0` (`16 % 2 == 0`) is `true` (16 is even).
        
    - `println!("16 seconds (even number): Skipping 3 seconds.")` runs.
        
    - `seconds` becomes `13` (`16 - 3`).
        
    - `continue;` is hit. (Skips to next iteration).
        

... This pattern continues until `seconds` becomes `0` or less, at which point the `break` condition is met.

### II. Common Use Cases for `continue`

`continue` is useful when you want to:

- **Filter items:** Process most items in a loop but skip specific ones based on a condition.
    
- **Handle errors/exceptions within an iteration:** If an error occurs for a particular item, you might log it and `continue` to the next item instead of stopping the whole loop.
    
- **Optimize:** Skip expensive computations for iterations where they aren't needed.
    

**Example: Processing Only Positive Numbers**

Rust

```Rust
fn main() {
    let numbers = [-1, 0, 5, -3, 10, 2];

    println!("\n--- Processing Positive Numbers ---");
    for num in numbers { // Using a `for` loop, but `continue` works similarly in `loop`
        if num <= 0 { // If the number is zero or negative
            println!("Skipping non-positive number: {}", num);
            continue; // Skip the rest of this loop's body for this `num`
        }
        // This code only runs for positive numbers
        println!("Processing positive number: {} (doubled: {})", num, num * 2);
    }
    println!("--- Done processing. ---");
}
```

**Example Output:**

```Rust

Skipping non-positive number: 0
Processing positive number: 5 (doubled: 10)
Skipping non-positive number: -3

Processing positive number: 2 (doubled: 4)
--- Done processing. ---
```

### III. Key Takeaways

- **`continue` Keyword:** Skips the rest of the current loop iteration and moves directly to the beginning of the next iteration.
    
- **Contrast with `break`:** `break` exits the _entire loop_; `continue` skips only the _current cycle_.
    
- **Conditional Use:** `continue` is almost always used within an `if` statement to conditionally skip parts of the loop body.
    
- **Flow Control:** It provides fine-grained control over which parts of the loop body execute for each iteration.
