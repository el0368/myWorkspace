# HashMap Overview

## Introduction

This document summarizes key concepts about hash maps, a collection type used to store unordered key-value pairs, as covered in the course section.

## Key Concepts

- **Definition**: A hash map is a collection of unordered key-value pairs where keys are unique identifiers, and values can contain duplicates.
- **Purpose**: Hash maps establish mappings or connections between two pieces of data (e.g., restaurant menu item to price, company name to stock price), focusing on associations rather than order.
- **Length**: The number of key-value pairs in a hash map.

## Creating a HashMap

- **Library**: Use the `HashMap` type from the `collections` submodule in the standard library.
- **Initialization**: Create an empty hash map using the `new` constructor function.
- **Type Declaration**: If no key-value pairs are inserted, explicit type declarations for keys (`K`) and values (`V`) are required, as the compiler cannot infer types. Both keys and values must be of consistent types.

## Modifying a HashMap

- **Mutability**: The hash map variable must be declared with the `mut` keyword for modifications.
- **Insert Method**: The `insert` method adds a new key-value pair. If the key exists, it replaces the existing pair with the new value.
- **Remove Method**: The `remove` method deletes a key-value pair by key, returning an `Option` (`Some` with the value if the key exists, `None` if it does not).
- **Entry Method**: The `entry` method with `or_insert` adds a key-value pair only if the key is not present, avoiding overwrites.

## Accessing Values

- **Square Brackets**: Use square brackets with a key to access a value, but this panics if the key does not exist.
- **Get Method**: The `get` method is safer, returning an `Option` (`Some` with a reference to the value if the key exists, `None` if it does not), preventing runtime panics and requiring safe handling (e.g., via a `match` statement).

## Conclusion

Hash maps are a critical data structure for managing associations between data, offering efficient ways to store, modify, and access key-value pairs in Rust.

```rust
use std::collections::HashMap;

fn main() {
    // Create a new, empty HashMap
    let mut map: HashMap<String, i32> = HashMap::new();

    // Insert key-value pairs
    map.insert(String::from("Apple"), 10);
    map.insert(String::from("Banana"), 20);

    // Replace value for existing key
    map.insert(String::from("Apple"), 15);

    // Remove a key-value pair
    let removed = map.remove("Banana"); // Returns Option<i32>

    // Access value with square brackets (panics if key doesn't exist)
    let apple_price = map["Apple"];

    // Access value with get method (returns Option<&i32>)
    if let Some(value) = map.get("Apple") {
        println!("Apple price: {}", value);
    } else {
        println!("Key not found");
    }

    // Use entry and or_insert to add key-value pair if key doesn't exist
    map.entry(String::from("Orange")).or_insert(30);
}
```
