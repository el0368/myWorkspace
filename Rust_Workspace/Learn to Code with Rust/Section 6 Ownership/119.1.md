Here are simple code examples for each concept from the section review:

### Ownership (Basic) and Moves

```Rust
fn main() {
    // String is on the heap and does not implement Copy
    let s1 = String::from("hello"); // s1 owns "hello"
    println!("s1: {}", s1);

    let s2 = s1; // Ownership of "hello" moves from s1 to s2
                 // s1 is no longer valid here
    println!("s2: {}", s2);
    // println!("s1: {}", s1); // This line would cause a compile-time error
}
```

### Stack vs. Heap (Implicit)

```Rust
fn main() {
    // i32 is a fixed-size type, stored on the stack (and implements Copy)
    let x = 5; // x owns 5 (on the stack)
    let y = x; // y gets a copy of 5, x is still valid
    println!("x: {}, y: {}", x, y);

    // String is a dynamic-size type, stored on the heap
    let s1 = String::from("Rust programming"); // s1 owns the heap data
    println!("s1: {}", s1);
    // The actual data "Rust programming" is on the heap,
    // while the pointer, length, and capacity for s1 are on the stack.
}
```

### Scopes and Ownership (Drop)

```Rust
fn create_string() {
    let s = String::from("inside function"); // s comes into scope, owns the String
    println!("String inside function: {}", s);
} // s goes out of scope here, `drop` is called, memory is deallocated

fn main() {
    let outside_string = String::from("outside main"); // outside_string owns the String
    println!("String outside main: {}", outside_string);

    create_string(); // Calls a function that creates and drops a String

} // outside_string goes out of scope here, `drop` is called, memory is deallocated
```

### Copy Trait (for Stack Data)

```Rust
fn main() {
    let a = 10; // `a` owns the value 10 (on stack)
    let b = a;  // `b` gets a copy of 10, `a` is still valid (i32 implements Copy)

    println!("a: {}, b: {}", a, b);
}
```

### String Literal (`&str`) vs. `String` (Heap)

```Rust
fn main() {
    // String literal (&str) - fixed size, embedded in binary, on stack
    let s_literal: &str = "hello world";
    println!("String literal: {}", s_literal);

    // String (heap allocated) - dynamic size
    let s_dynamic: String = String::from("hello dynamic world");
    println!("Dynamic String: {}", s_dynamic);
}
```

### `clone()` Method

```Rust
fn main() {
    let s1 = String::from("original data"); // s1 owns the data
    println!("s1 (before clone): {}", s1);

    let s2 = s1.clone(); // s2 gets a *new, independent copy* of the data
                         // s1 remains valid
    println!("s1 (after clone): {}", s1);
    println!("s2 (after clone): {}", s2);
}
```

### `drop()` Function (Implicit Call)

```Rust
// `drop` is called automatically when a variable goes out of scope.
// We usually don't call it explicitly.
// This example demonstrates when it *would* be called implicitly.
struct MyDroppableStruct {
    id: i32,
}

impl Drop for MyDroppableStruct {
    fn drop(&mut self) {
        println!("Dropping MyDroppableStruct with ID: {}", self.id);
    }
}

fn main() {
    let _item1 = MyDroppableStruct { id: 1 }; // _item1 comes into scope
    { // New inner scope
        let _item2 = MyDroppableStruct { id: 2 }; // _item2 comes into scope
        println!("Inside inner scope.");
    } // _item2 goes out of scope, its `drop` method is called
    println!("Outside inner scope.");
} // _item1 goes out of scope, its `drop` method is called
```

### References (Borrowing `&`)

```Rust
fn calculate_length(s: &String) -> usize { // s is a reference (borrows)
    s.len()
}

fn main() {
    let s1 = String::from("hello"); // s1 owns the String
    println!("s1 (before borrow): {}", s1);

    let len = calculate_length(&s1); // Pass a reference to s1
    println!("s1 (after borrow): {}", s1); // s1 is still valid
    println!("The length of '{}' is {}.", s1, len);
}
```

### Dereference Operator (`*`)

```Rust
fn main() {
    let x = 5;
    let y = &x; // y is a reference to x

    println!("Value of x: {}", x);
    println!("Value of y (reference): {}", y); // Rust automatically dereferences for println!

    // Explicit dereference to get the value
    println!("Value at address of y: {}", *y);

    let mut s = String::from("hello");
    let r = &mut s; // r is a mutable reference
    *r = String::from("world"); // Dereference r to modify the original String
    println!("Modified string via reference: {}", s);
}
```

### Immutable References Implement Copy

```Rust
fn main() {
    let original_value = 100;
    let ref1 = &original_value; // ref1 is an immutable reference
    let ref2 = ref1; // ref2 gets a copy of the reference (ref1 is still valid)

    println!("Original value: {}", original_value);
    println!("Reference 1: {}", ref1);
    println!("Reference 2: {}", ref2);
}
```

### Ownership and Function Parameters (Copy vs. Move)

```Rust
// Function for types that implement Copy (like i32)
fn takes_copy(some_integer: i32) {
    println!("Inside takes_copy: {}", some_integer);
} // some_integer goes out of scope, but the original value is unaffected

// Function for types that do NOT implement Copy (like String)
fn takes_ownership(some_string: String) { // some_string takes ownership of the passed String
    println!("Inside takes_ownership: {}", some_string);
} // some_string goes out of scope, `drop` is called, and the memory is deallocated

fn main() {
    let my_int = 50;
    takes_copy(my_int); // my_int is copied, original is still valid
    println!("Original int after function call: {}", my_int);

    let my_string = String::from("Rust");
    takes_ownership(my_string); // my_string is MOVED, original is no longer valid
    // println!("Original string after function call: {}", my_string); // This would cause a compile-time error
}
```
