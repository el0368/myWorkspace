### Topics Covered in this Section

- **What is a Slice?**:
    
    - A slice is a **reference** to a contiguous portion of a collection type (like a `String` or an array).
        
    - It's a way to borrow a part of the data without taking ownership.
        
- **String Slices (`&str`)**:
    
    - A reference to a portion of text.
        
    - A **string literal** is a string slice (`&'static str`).
        
    - Creating a string slice from a `String` or another string slice.
        
    - The length of a string slice is measured in **bytes**, not characters.
        
- **Range Extraction Syntax**:
    
    - Using the **`&` operator** and **square brackets (`[]`)** with a range.
        
    - Syntax: `start..end`. The `end` bound is **exclusive**.
        
    - **Shorthand syntax**: Omitting the start bound (`..end`) or the end bound (`start..`).
        
- **Array Slices (`&[T]`)**:
    
    - A reference to a portion of an array.
        
    - Accessed by **index position**, not by bytes.
        
- **Mutable Slices**:
    
    - Slices can be made mutable using the **`&mut`** operator, allowing for modification of the borrowed data.
        
- **Slices as Function Parameters**:
    
    - Using a slice (`&[T]`) as a parameter type is **flexible** because it can accept both a slice and a full reference to a collection.
        
    - This is a key part of **deref coercion**, where a `&String` can be coerced into a `&str`, but not vice versa.
