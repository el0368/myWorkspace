# 🦀 The `crate` Prefix in Rust

## 1. **What is `crate`?**

- `crate` is a **keyword that refers to the root of your current crate**.
    
- Think of it as: “start from the top-level of my library or binary.”
    
- It is useful for **absolute paths inside your crate** instead of relative paths.
    

---

## 2. **Example Without `crate`**

Suppose project structure:

```
src/
 ├── main.rs
 ├── math.rs
 └── math/
     └── add.rs
```

`math.rs`:

```rust
pub mod add;

pub fn double(x: i32) -> i32 {
    x * 2
}
```

`math/add.rs`:

```rust
pub fn sum(a: i32, b: i32) -> i32 {
    a + b
}

// calling double function from math.rs
pub fn double_from_add(x: i32) -> i32 {
    super::double(x) // relative path: go up one module
}
```

This works, but `super` is relative, which can get confusing in **deep module trees**.

---

## 3. **Using `crate` (absolute path)**

Instead of `super`, you can write:

```rust
pub fn double_from_add(x: i32) -> i32 {
    crate::math::double(x) // absolute path from crate root
}
```

- `crate::math` → starts at the **root of your crate**, then accesses `math`.
    
- Absolute paths are more **robust**, especially when modules are nested deeply.
    

---

## 4. **When to Use `crate`**

- **Accessing items from anywhere in the crate** without worrying about relative path depth.
    
- When building **library crates** that may be used by other crates.
    
- Often used in **tests** or **nested modules**.
    

Example nested project:

```
src/
 ├── lib.rs
 ├── math/
 │   ├── mod.rs
 │   └── advanced/
 │       └── trig.rs
```

`trig.rs`:

```rust
pub fn sin(x: f64) -> f64 {
    x.sin()
}

pub fn double_sin(x: f64) -> f64 {
    crate::math::advanced::trig::sin(x) * 2.0
}
```

✅ Using `crate::` ensures you are **always starting from the root**, no matter how deeply nested.

---

## 5. **Difference Between `super` and `crate`**

|Keyword|Path starts from|When to use|
|---|---|---|
|`super`|parent module|Relative path, go up one level|
|`crate`|root of crate|Absolute path, robust for deep/nested modules|

---

## 6. **Summary**

- `crate` = root of **current crate**
    
- Used for **absolute module paths**
    
- Avoids confusion in **deeply nested modules**
    
- `super` = relative path (go up one module)
    
- `self` = relative path (current module)
    

---

⚡ Analogy:

- `crate` = “from the main entrance of my house”
    
- `super` = “from the room above”
    
- `self` = “from the current room”
