# 🦀 Root File Requirement in Rust Modules

## 1. **Why a root file is needed**

- Rust does **not automatically scan folders** for code.
    
- A **module must declare its children** so the compiler knows what exists.
    
- The root file (like `math.rs` or `mod.rs`) acts as the **entry point for that module**.
    
- Without it, Rust cannot “see” the submodules inside the folder.
    

---

## 2. **Example Without Root File**

Folder structure:

```
src/
 └── math/
     ├── add.rs
     └── mul.rs
```

Attempting to do this in `main.rs`:

```rust
mod math;

fn main() {
    println!("{}", math::add::sum(2,3));
}
```

❌ This **won’t compile** because Rust doesn’t know `math` exists as a module — there’s **no root file** telling Rust to load the folder.

---

## 3. **Adding a Root File (Required)**

Two options:

### Option A: `math.rs` (modern Rust 2018+)

```
src/
 ├── main.rs
 ├── math.rs     <-- root file
 └── math/
     ├── add.rs
     └── mul.rs
```

`math.rs`:

```rust
pub mod add;
pub mod mul;
```

Now in `main.rs`:

```rust
mod math;

fn main() {
    println!("{}", math::add::sum(2,3));
}
```

✅ Works perfectly.

---

### Option B: `math/mod.rs` (old style)

```
src/
 ├── main.rs
 └── math/
     ├── mod.rs   <-- root file
     ├── add.rs
     └── mul.rs
```

`mod.rs`:

```rust
pub mod add;
pub mod mul;
```

Same result. Rust now knows **“math module exists and has submodules add and mul.”**

---

## 4. **Key Takeaways**

- **Root file is mandatory** to access a folder as a module.
    
- It can be:
    
    - `math.rs` (modern, recommended)
        
    - `math/mod.rs` (old style, still supported)
        
- Submodules inside the folder **must be declared with `pub mod ...;`** in the root file.
    
- The folder itself without a root file is invisible to Rust.
    

---

⚡ Analogy:

- Folder = a room with doors inside
    
- Root file (`math.rs`) = the **room’s doorway** — if no doorway exists, no one can enter, no matter what’s inside.
