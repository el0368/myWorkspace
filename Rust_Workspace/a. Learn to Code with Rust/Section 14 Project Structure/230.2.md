# 🦀 Folder-Only Module Without `math.rs`

### Old Style (pre-2018)

```
src/
 ├── main.rs
 └── math/
     ├── mod.rs
     └── add.rs
```

- **`mod.rs`** is required **if you want `math` to be a module**.
    
- In this style:
    
    - `math/mod.rs` acts as the **root of the `math` module**
        
    - `add.rs` is a **submodule**, declared inside `mod.rs`:
        
        ```rust
        pub mod add;
        ```
        
- In `main.rs`:
    
    ```rust
    mod math;
    fn main() {
        println!("{}", math::add::sum(2,3));
    }
    ```
    

✅ Works fine. **No `math.rs` needed**.

---

### New Style (Rust 2018+)

```
src/
 ├── main.rs
 ├── math.rs        <-- optional but recommended
 └── math/
     └── add.rs
```

- You can have **`math.rs`** as the root of the module and then a folder `math/` for submodules.
    
- In `math.rs`:
    
    ```rust
    pub mod add;
    ```
    
- In `main.rs`:
    
    ```rust
    mod math;
    println!("{}", math::add::sum(2,3));
    ```
    
- You **don’t need `math.rs`** if you want to stick with the old `mod.rs` style.
    
- But the **modern, recommended way** is to use `math.rs` at the root and keep the folder for submodules.
    

---

### ✅ Key Rule

- **Every module must have a root file**:
    
    - Either `math.rs` in `src/`
        
    - Or `mod.rs` inside `math/`
        
- The folder alone is **not enough** — Rust needs a file to declare the module and its submodules.
    

---

### 🔑 Analogy

- Folder = room
    
- `mod.rs` or `math.rs` = the doorway to the room
    
- Without the doorway, Rust cannot enter the room, no matter what files are inside.
    

---

So your example here:

```
src/
 ├── main.rs
 └── math/
     ├── mod.rs
     └── add.rs
```

- ✅ Works fine. `mod.rs` is the root.
    
- `math.rs` **is not required** in this layout.
