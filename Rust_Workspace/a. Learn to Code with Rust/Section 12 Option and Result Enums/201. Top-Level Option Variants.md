### Part 1: The Rust Prelude & The Verbose `Option` Syntax

This progressive example introduces the **Rust prelude**, which is a collection of essential items (types, traits, functions, etc.) that are automatically available in every Rust program without needing an explicit `use` statement. The `Option` enum is a prime example.

- **The Prelude:** Rust makes frequently used items like the `Option` enum available by default, which is why we can use it directly.
    
- **The Verbose Syntax:** While `Option` is in the prelude, its variants (`Some` and `None`) technically exist within its namespace. The standard, verbose way to refer to them is by prefixing them with `Option::`.
    
- **The Code:** This part shows the `is_item_in_stock` function and a simple `main` function using this verbose syntax, which is the starting point for our refactoring.
    

Rust

```Rust
// The Option enum is in the prelude, so it's available.
fn is_item_in_stock(item_is_in_system: bool, item_is_in_stock: bool) -> Option<bool> {
    if item_is_in_system && item_is_in_stock {
        return Option::Some(true); // Verbose syntax for a variant
    } else if item_is_in_system {
        return Option::Some(false); // Verbose syntax for a variant
    } else {
        return Option::None; // Verbose syntax for a variant
    }
}

fn main() {
    let availability = is_item_in_stock(true, true);
    
    // The match statement also uses the verbose syntax
    match availability {
        Option::Some(value) => println!("Item is available: {}", value),
        Option::None => println!("Item is not in system."),
    }
    // Output: Item is available: true
}
```

### Part 2: The Shortcut - Omitting `Option::`

This part introduces the key shortcut. Because the `Option` enum's variants, `Some` and `None`, are also very common, they are also automatically available in the prelude. This allows us to omit the `Option::` prefix, making the code more concise.

- **The Shortcut:** You can replace `Option::Some` with just `Some`, and `Option::None` with just `None`.
    
- **No Functional Change:** This is a purely syntactic improvement. The code's behavior and the underlying types remain exactly the same.
    
- **The Code:** This part shows the refactored `is_item_in_stock` function, which is now cleaner and more concise.
    

Rust

```Rust
// The `Some` and `None` variants are also in the prelude, allowing for a shortcut.
fn is_item_in_stock(item_is_in_system: bool, item_is_in_stock: bool) -> Option<bool> {
    if item_is_in_system && item_is_in_stock {
        return Some(true); // Shortcut syntax
    } else if item_is_in_system {
        return Some(false); // Shortcut syntax
    } else {
        return None; // Shortcut syntax
    }
}

    // This part will be completed in the next example.
}
```

### Part 3: The Final Code (Shorthand in Action)

This final part presents a complete, working program using the concise shorthand syntax. It demonstrates how to use the simplified syntax in both the function body and the `match` statement.

- **Rule of Thumb:** The `Option` keyword is still required when you are specifying the **full type** (e.g., in a function's return type or a variable's explicit type annotation), but its prefix is optional when you are referring to a specific **variant**.
    
- **The Code:** This is the final, idiomatic Rust code that uses the prelude's shorthand for `Option`'s variants.
    

Rust

```Rust
// The final, concise version of our function.
fn is_item_in_stock(item_is_in_system: bool, item_is_in_stock: bool) -> Option<bool> {
    if item_is_in_system && item_is_in_stock {
        return Some(true);
    } else if item_is_in_system {
        return Some(false);
    } else {
        return None;
    }
}

fn main() {
    // We call the function and use the shorthand in the `match` statement.
    let availability = is_item_in_stock(true, true);
    
    match availability {
        Some(value) => println!("Item is available: {}", value), // Shorthand
        None => println!("Item is not in system."),             // Shorthand
    }
    // Output: Item is available: true
    
    let unavailable = is_item_in_stock(false, false);
    
    match unavailable {
        Some(value) => println!("Item is available: {}", value),
        None => println!("Item is not in system."),
    }
    // Output: Item is not in system.
}
```
