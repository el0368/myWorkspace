### 13. Associated Functions

**Explanation in the Scope of the Transcript:**

The transcript describes **associated functions** as functions defined within a struct’s `impl` block that are not methods because they do not take a `self` parameter. Unlike methods, which are called on a struct instance using dot notation (`instance.method()`), associated functions are invoked on the struct type itself using the double colon syntax (`StructName::function()`). They reside in the struct’s namespace, meaning they cannot be called at the top level of a program. The transcript highlights that the most common use case for associated functions is as **constructor functions**, typically named `new`, which create and return a new instance of the struct. This naming convention follows Rust’s standard practice (e.g., `String::new`), though it’s not mandatory, to maintain consistency with other Rust code.

**Rust Code Example:**

Below is a minimal code example demonstrating associated functions, aligned with the transcript’s description.

```rust
struct Book {
    title: String,
    pages: u32,
}

impl Book {
    // Associated function (constructor)
    fn new(title: String, pages: u32) -> Book {
        Book { title, pages }
    }
}

fn main() {
    // Invoke associated function using :: syntax
    let book = Book::new(String::from("Rust Guide"), 300);
    println!("Book: {} with {} pages", book.title, book.pages);
}
```

**Code Explanation:**

1. **Struct Declaration**:
   - The `Book` struct is defined with `title: String` and `pages: u32`, providing the context for the associated function.

2. **Associated Function Definition**:
   - Within the `impl Book` block, the `new` function is defined without a `self` parameter, making it an associated function, as per the transcript.
   - It takes `title` and `pages` as parameters and returns a new `Book` instance, serving as a constructor, which aligns with the transcript’s emphasis on constructor functions.

3. **Invocation with `::` Syntax**:
   - The function is invoked using `Book::new(...)`, not dot notation, as the transcript specifies that associated functions are called on the struct type with `::`.
   - The call creates a `Book` instance with the provided values.

4. **Minimal Usage**:
   - The `println!` macro displays the instance’s fields to confirm the constructor’s effect, keeping the example minimal while focusing on the associated function.

**Key Takeaways**:
- Associated functions are defined in an `impl` block without `self`, invoked on the struct type using `::` syntax.
- They are commonly used as constructors (e.g., `new`) to create struct instances, following Rust’s naming conventions.
- The example is minimal, showcasing the definition and invocation of an associated function as described in the transcript.
