### 12. Method Invocation and Automatic Dereferencing

**Explanation in the Scope of the Transcript:**

The transcript explains that **method invocation** on structs in Rust is done using dot notation (`instance.method()`), where the method is called on a specific struct instance. Methods are defined within an `impl` block and always include a `self` parameter, but Rust automatically provides the correct `self` value (the instance itself) during invocation, so it’s not included in the method call. Additionally, Rust supports **automatic dereferencing**, meaning methods can be invoked on both a struct instance and a reference to that instance (e.g., `&Book` or `&mut Book`) without changing the method’s code. When a method is called on a reference, Rust automatically follows the reference to the underlying struct value, ensuring the method works consistently regardless of whether `self` is defined as `self`, `&self`, or `&mut self`. This reduces complexity and promotes code consistency, as the transcript notes.

**Rust Code Example:**

Below is a minimal code example demonstrating method invocation and automatic dereferencing, aligned with the transcript’s description.

```rust
struct Book {
    title: String,
    pages: u32,
}

impl Book {
    // Method with immutable reference
    fn description(&self) -> String {
        format!("{} has {} pages", self.title, self.pages)
    }
}

fn main() {
    let book = Book {
        title: String::from("Rust Guide"),
        pages: 300,
    };

    // Invoke method on instance
    println!("Instance: {}", book.description());

    // Invoke method on immutable reference (automatic dereferencing)
    let book_ref = &book;
    println!("Reference: {}", book_ref.description());
}
```

**Code Explanation:**

1. **Struct and Method Definition**:
   - The `Book` struct is defined with `title: String` and `pages: u32`.
   - The `description` method, defined in an `impl Book` block, takes `&self` (immutable reference) and returns a formatted `String`, aligning with the transcript’s description of methods attached to instances.

2. **Method Invocation**:
   - The method is invoked on the `book` instance using dot notation (`book.description()`), as per the transcript’s note that methods are called with `instance.method()`.
   - Rust automatically provides the `self` parameter, so it’s not included in the call.

3. **Automatic Dereferencing**:
   - The method is also invoked on `book_ref`, an immutable reference (`&book`), using the same dot notation (`book_ref.description()`).
   - Rust automatically dereferences `book_ref` to access the underlying `Book` instance, as described in the transcript, ensuring the method works without modification.

4. **Minimal Usage**:
   - The example is minimal, focusing on invoking the method on both an instance and a reference to demonstrate automatic dereferencing, with `println!` showing the output.

**Key Takeaways**:
- Methods are invoked using dot notation (`instance.method()`), with Rust automatically supplying the `self` parameter.
- Automatic dereferencing allows methods to be called on references (`&Book` or `&mut Book`) without changing the method’s code, as Rust follows the reference to the instance.
