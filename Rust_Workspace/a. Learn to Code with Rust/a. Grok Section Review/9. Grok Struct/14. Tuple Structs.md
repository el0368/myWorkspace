### 14. Tuple Structs

**Explanation in the Scope of the Transcript:**

The transcript describes **tuple structs** as a type of struct in Rust where fields are identified by their position (index) rather than by names, similar to a tuple but defined as a distinct type. Unlike named field structs, tuple structs use parentheses `()` instead of curly braces `{}` for both declaration and instantiation. Fields are accessed using dot notation with their index (e.g., `struct_instance.0`), and the transcript emphasizes that tuple structs are not interchangeable with regular tuples or other tuple structs, even if they have the same field types and order. This distinctness allows tuple structs to represent specific types with ordered data, useful for lightweight, position-based data structures that need to be distinguished from other similar types in a program.

**Rust Code Example:**

Below is a minimal code example demonstrating tuple structs, aligned with the transcript’s description.

```rust
// Declaring a tuple struct
struct Point(i32, i32);

fn main() {
    // Instantiating a tuple struct
    let point = Point(3, 4);
    // Accessing fields by index
    println!("Point: ({}, {})", point.0, point.1);
}
```

2. **Instantiation**:
   - The `point` instance is created with `Point(3, 4)`, using parentheses to provide values in order, matching the transcript’s description of instantiation syntax for tuple structs.

3. **Field Access**:
   - Fields are accessed using dot notation with indices (`point.0`, `point.1`), as specified in the transcript, to retrieve the `x` and `y` coordinates.

4. **Minimal Usage**:
