### 1. Definition and Purpose of Enums

**Explanation in the Scope of a Typical Rust Course Transcript:**

In Rust, an **enum** (short for enumeration) is a custom data type that defines a set of possible variants, each representing a distinct value or state. Enums are used to model data that can be one of several predefined options, making them ideal for scenarios where a value must belong to a fixed set of possibilities. Each variant can optionally hold associated data, which can differ in type and structure, allowing enums to represent complex, heterogeneous data. The purpose of enums is to provide a way to express mutually exclusive states or choices in a type-safe manner, enhancing code clarity and safety by ensuring that only valid variants are used. They are particularly powerful in Rust for tasks like error handling (e.g., `Result`, `Option`) or modeling state machines, as they allow the compiler to enforce exhaustive handling of all possible cases.

**Rust Code Example:**

Below is a minimal code example demonstrating the definition and purpose of enums, styled to match the educational tone of the provided transcript.

    Quit,             // Variant with no data
}

    let num_msg = Message::Number(42);
    let quit_msg = Message::Quit;
