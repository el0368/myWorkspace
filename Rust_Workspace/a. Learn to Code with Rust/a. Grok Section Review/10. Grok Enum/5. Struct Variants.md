### 5. Struct Variants

**Explanation in the Scope of a Typical Rust Course Transcript:**

In Rust, **struct variants** are enum variants that hold associated data in a struct-like format, defined using curly braces `{}` with named fields, similar to a named field struct. Unlike tuple variants (which use positional data) or simple variants (with no data), struct variants allow each variant to store data with explicitly named fields, providing clarity and structure for complex data associated with a specific state. This makes them ideal for modeling scenarios where a variant needs to represent detailed, labeled information, such as an event with specific attributes. The transcript’s educational style would emphasize that struct variants are accessed via pattern matching (e.g., in a `match` expression), with the compiler ensuring all variants are handled, promoting type safety and expressiveness.

**Rust Code Example:**

Below is a minimal code example demonstrating struct variants in an enum, styled to match the educational tone of the provided transcript.

// Enum with struct variants
enum Command {
    Save { filename: String, data: String }, // Struct variant with named fields
    Delete { id: u32 },                     // Struct variant with one named field
}

fn main() {
    // Instantiate a struct variant
    let cmd = Command::Save {
        filename: String::from("doc.txt"),

    }
}
