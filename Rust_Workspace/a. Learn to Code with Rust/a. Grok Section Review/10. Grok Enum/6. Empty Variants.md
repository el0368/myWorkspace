### 6. Empty Variants

**Explanation in the Scope of a Typical Rust Course Transcript:**

In Rust, **empty variants** (also called unit variants) are enum variants that do not hold any associated data. They are defined simply by their name within the enum’s curly braces `{}`, without parentheses `()` or curly braces `{}` for data. Empty variants represent specific states or options where no additional information is needed, serving as markers or flags within the enum. They are useful for modeling scenarios where a type can be in one of several distinct states, some of which require no extra data, such as signaling an event like “Quit” or “None.” The transcript’s educational style would emphasize that empty variants, like all enum variants, must be handled in pattern matching (e.g., `match` expressions) to ensure type safety, making them a lightweight way to define discrete states in a program.

enum Status {
