### 2. Enum Declaration Syntax

**Explanation in the Scope of a Typical Rust Course Transcript:**

In Rust, an **enum** is declared using the `enum` keyword followed by a name in PascalCase (capitalizing the first letter of each word). The declaration is enclosed in curly braces `{}`, where each variant is listed, separated by commas. Each variant can optionally include associated data with specified types, defined in parentheses `()` for tuple-like variants, curly braces `{}` for struct-like variants, or no data at all for simple variants. The syntax creates a blueprint for the enum type, defining all possible states or values it can represent. This allows enums to model mutually exclusive options, with the compiler ensuring that all variants are handled in operations like `match` expressions, promoting type safety and clarity.

**Rust Code Example:**

Below is a minimal code example demonstrating the enum declaration syntax, styled to match the educational tone of the provided transcript.

```rust
// Enum declaration with various variant types
enum Operation {
    Add(i32, i32),           // Tuple-like variant with two i32s
    Result { value: i32 },   // Struct-like variant with named field
    Cancel,                  // Simple variant with no data
}

fn main() {
    // Example instantiation of a variant
    let op = Operation::Add(5, 10);
    match op {
        Operation::Add(a, b) => println!("Addition: {} + {} = {}", a, b, a + b),
        Operation::Result { value } => println!("Result: {}", value),
        Operation::Cancel => println!("Operation cancelled"),
    }
}
```
