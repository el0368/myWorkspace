## Specific Data Matching in match

The `match` keyword can extract and match against specific pieces of associated data from enum variants, allowing for very granular pattern matching.

### Extracting Data from Variants

**Tuple Variants:**

```rust
enum Message {
    Move(i32, i32),
    Write(String),
    ChangeColor(i32, i32, i32),
}

let msg = Message::Move(10, 20);

match msg {
    Message::Move(x, y) => println!("Move to x: {}, y: {}", x, y),
    Message::Write(text) => println!("Text message: {}", text),
    Message::ChangeColor(r, g, b) => println!("Change color to RGB({}, {}, {})", r, g, b),
}
```

**Struct Variants:**

```rust
enum Request {
    Get { url: String, timeout: u32 },
    Post { url: String, body: String, headers: Vec<String> },
}

let request = Request::Get { 
    url: "https://api.example.com".to_string(), 
    timeout: 30 
};

match request {
    Request::Get { url, timeout } => {
        println!("GET request to {} with timeout {}", url, timeout);
    },
    Request::Post { url, body, headers } => {
        println!("POST to {} with body: {} and {} headers", url, body, headers.len());
    },
}
```

### Matching Against Specific Values

You can match against variants that contain specific pieces of data:

```rust
enum Status {
    Code(i32),
    Message(String),
    Data { id: u32, value: String },
}

let status = Status::Code(404);

match status {
    Status::Code(200) => println!("Success!"),
    Status::Code(404) => println!("Not found!"),
    Status::Code(code) => println!("Other status code: {}", code),
    Status::Message(ref msg) if msg == "error" => println!("Error message received"),
    Status::Message(msg) => println!("Message: {}", msg),
    Status::Data { id: 1, value } => println!("Special case for ID 1: {}", value),
    Status::Data { id, value } => println!("ID: {}, Value: {}", id, value),
}
```

### Partial Matching and Wildcards

**Ignoring Some Fields:**

```rust
enum Event {
    Click { x: i32, y: i32, button: String },
    Scroll { direction: String, amount: i32 },
}

let event = Event::Click { x: 100, y: 200, button: "left".to_string() };

match event {
    Event::Click { x, y, .. } => println!("Click at ({}, {})", x, y), // Ignore button
    Event::Scroll { direction, .. } => println!("Scroll {}", direction), // Ignore amount
}
```

**Using Underscore for Unused Data:**

```rust
match event {
    Event::Click { x: _, y: _, button } => println!("Button clicked: {}", button),
    Event::Scroll { direction: _, amount } => println!("Scroll amount: {}", amount),
}
```

### Guard Conditions

Combine pattern matching with additional conditions:

```rust
enum Temperature {
    Celsius(f64),
    Fahrenheit(f64),
}

let temp = Temperature::Celsius(25.0);

match temp {
    Temperature::Celsius(c) if c > 30.0 => println!("Hot day: {}°C", c),
    Temperature::Celsius(c) if c < 0.0 => println!("Freezing: {}°C", c),
    Temperature::Celsius(c) => println!("Moderate: {}°C", c),
    Temperature::Fahrenheit(f) if f > 86.0 => println!("Hot day: {}°F", f),
    Temperature::Fahrenheit(f) => println!("Temperature: {}°F", f),
}
```

### Nested Matching

Match against nested enum structures:

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}

enum Error {
    Network(String),
    Parse(i32),
}

let result: Result<String, Error> = Result::Err(Error::Network("Connection failed".to_string()));

match result {
    Result::Ok(value) => println!("Success: {}", value),
    Result::Err(Error::Network(msg)) => println!("Network error: {}", msg),
    Result::Err(Error::Parse(code)) => println!("Parse error with code: {}", code),
}
```

### Exhaustive Matching Requirement

The compiler ensures every possible variant and data combination is handled:

```rust
enum Operation {
    Add(i32, i32),
    Subtract(i32, i32),
    Multiply(i32, i32),
}

let op = Operation::Add(5, 3);

match op {
    Operation::Add(a, b) => println!("{} + {} = {}", a, b, a + b),
    Operation::Subtract(a, b) => println!("{} - {} = {}", a, b, a - b),
    // Missing Multiply variant would cause compilation error
    Operation::Multiply(a, b) => println!("{} × {} = {}", a, b, a * b),
}
```

### Catchall Patterns

Use underscore for remaining cases:

```rust
enum Priority {
    Low,
    Medium,
    High(u8),
    Critical { level: u8, message: String },
}

let priority = Priority::High(5);

match priority {
    Priority::Critical { level: 10, message } => println!("Max critical: {}", message),
    Priority::High(level) if level > 7 => println!("Very high priority: {}", level),
    _ => println!("Standard priority handling"),
}
```

This granular matching capability allows you to handle complex data structures with precise control over which patterns trigger which code blocks, while the compiler ensures all possible cases are covered.
