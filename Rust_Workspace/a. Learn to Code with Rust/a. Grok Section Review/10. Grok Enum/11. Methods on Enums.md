## Methods on Enums

Enums can define their own methods using the exact same syntax as structs. Methods are functions that live on an instance - they're commands or actions that the enum can take based on its data.

### Method Definition Syntax

Use the `impl` keyword followed by the enum name, then a block that stores all methods:

```rust
enum Status {
    Active,
    Inactive,
    Pending,
}

impl Status {
    fn is_running(&self) -> bool {
        match self {
            Status::Active => true,
            Status::Inactive => false,
            Status::Pending => false,
        }
    }
}
```

### The self Parameter

Methods are declared like plain functions, except they accept `self` as the first parameter. The `self` parameter represents either the owned enum value or a reference to it:

```rust
enum Temperature {
    Celsius(f64),
    Fahrenheit(f64),
}

impl Temperature {
    // Takes a reference to avoid ownership issues
    fn to_celsius(&self) -> f64 {
        match self {
            Temperature::Celsius(c) => *c,
            Temperature::Fahrenheit(f) => (f - 32.0) * 5.0 / 9.0,
        }
    }
    
    // Takes ownership of the enum
    fn consume(self) -> String {
        match self {
            Temperature::Celsius(c) => format!("{}°C consumed", c),
            Temperature::Fahrenheit(f) => format!("{}°F consumed", f),
        }
    }
}
```

### Borrowing to Avoid Ownership Issues

Using `&self` allows you to avoid ownership by borrowing, which is essential for methods that don't need to consume the enum:

```rust
enum Shape {
    Circle(f64),
    Rectangle(f64, f64),
}

impl Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Circle(radius) => 3.14159 * radius * radius,
            Shape::Rectangle(width, height) => width * height,
        }
    }
    
    fn perimeter(&self) -> f64 {
        match self {
            Shape::Circle(radius) => 2.0 * 3.14159 * radius,
            Shape::Rectangle(width, height) => 2.0 * (width + height),
        }
    }
}

let shape = Shape::Circle(5.0);
println!("Area: {}", shape.area());      // Can still use shape after this
println!("Perimeter: {}", shape.perimeter()); // Because we borrowed, not moved
```

### Methods with Additional Parameters

Methods can define additional parameters after `self`, and you pass those in during invocation:

```rust
enum Counter {
    Simple(i32),
    WithStep(i32, i32),
}

impl Counter {
    fn increment(&mut self, amount: i32) {
        match self {
            Counter::Simple(value) => *value += amount,
            Counter::WithStep(value, step) => *value += amount * step,
        }
    }
    
    fn set_value(&mut self, new_value: i32) {
        match self {
            Counter::Simple(value) => *value = new_value,
            Counter::WithStep(value, _) => *value = new_value,
        }
    }
}

let mut counter = Counter::Simple(0);
counter.increment(5);        // Pass the amount parameter
counter.set_value(10);       // Pass the new_value parameter
```

### Automatic self Parameter Handling

You never have to pass in the argument for `self` because that is done automatically by Rust:

```rust
enum Message {
    Text(String),
    Number(i32),
}

impl Message {
    fn display(&self) -> String {
        match self {
            Message::Text(content) => format!("Text: {}", content),
            Message::Number(num) => format!("Number: {}", num),
        }
    }
    
    fn is_text(&self) -> bool {
        match self {
            Message::Text(_) => true,
            Message::Number(_) => false,
        }
    }
}

let msg = Message::Text("Hello".to_string());
// Rust automatically passes msg as &self
println!("{}", msg.display());    // No need to pass msg explicitly
println!("{}", msg.is_text());    // Rust handles the self parameter
```

### Working with Associated Data

Methods can access and manipulate the data stored within enum variants:

```rust
enum Account {
    Checking { balance: f64 },
    Savings { balance: f64, interest_rate: f64 },
}

impl Account {
    fn get_balance(&self) -> f64 {
        match self {
            Account::Checking { balance } => *balance,
            Account::Savings { balance, .. } => *balance,
        }
    }
    
    fn deposit(&mut self, amount: f64) {
        match self {
            Account::Checking { balance } => *balance += amount,
            Account::Savings { balance, .. } => *balance += amount,
        }
    }
    
    fn apply_interest(&mut self) {
        match self {
            Account::Checking { .. } => {}, // No interest for checking
            Account::Savings { balance, interest_rate } => {
                *balance += *balance * *interest_rate;
            }
        }
    }
}

let mut account = Account::Savings { 
    balance: 1000.0, 
    interest_rate: 0.05 
};
account.deposit(500.0);           // Additional parameter after self
account.apply_interest();         // Only self parameter needed
println!("{}", account.get_balance()); // Returns 1575.0
```

### Consistency with Structs

Rust strives for consistency between structs and enums regarding method definition. Both use the same `impl` syntax, both use `self` as the first parameter, and both automatically handle the `self` argument during method calls:

```rust
// Struct method syntax
struct Point { x: i32, y: i32 }
impl Point {
    fn distance(&self) -> f64 { /* implementation */ }
}

// Enum method syntax - identical pattern
enum Shape { Circle(f64), Square(f64) }
impl Shape {
    fn area(&self) -> f64 { /* implementation */ }
}
```

This consistency makes it easier to learn and use both types, as the method definition and invocation patterns are identical between structs and enums.
