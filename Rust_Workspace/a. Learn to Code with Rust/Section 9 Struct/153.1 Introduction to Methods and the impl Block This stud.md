### Part 1: Introduction to Methods and the `impl` Block

This study guide explains the fundamental concepts of methods in Rust, their purpose, and the syntax used to define them within an `impl` (implementation) block.

#### 1. What is a Method?

A method in Rust is a **function that belongs to a specific type** and is designed to operate on an instance of that type.

- **Data vs. Behavior:** A `struct`'s **fields** represent its data or state (e.g., a song's `title`, `release_year`). A `struct`'s **methods** represent its behavior or actions (e.g., a command to "play" or "display" a song).
    
- **Invocation:** Methods are called using the dot operator (`.`) on a variable or value that holds an instance of the type: `value.method_name()`. This is in contrast to a regular function which is called globally: `function_name()`.
    
- **Function-like:** Methods have the same features as regular functions: they can accept parameters (inputs) and can return a value (output).
    

#### 2. The Purpose of Methods

Methods are a powerful tool for code organization and reusability.

- **Organization:** They allow you to define all the common functionality for a given type in a single, dedicated place in your code (the `impl` block). This keeps the data (`struct` definition) and the behaviors (`impl` block) conceptually linked but syntactically separate.
    
- **Reusability:** You define a method once, and then every instance of that `struct` type automatically has access to and can use that method.
    
- **Consistency:** Methods create a consistent and reliable interface. All instances of a `TaylorSwiftSong` struct, for example, will share the same set of behaviors.
    

#### 3. Defining Methods with the `impl` Block

The `impl` keyword is used to define an implementation block, which is the container for all of a struct's methods.

- **Syntax:** `impl` is followed by the name of the `struct` you are implementing methods for, then a pair of curly braces.
    
    Rust
    
    ```Rust
    impl StructName {
        // All methods for StructName are defined here.
    }
    ```
    
- **Association:** The compiler automatically associates all code within this block with the `StructName` type.
    

#### 4. Method Definition Syntax

A method's definition looks just like a regular function's, but it has one key difference: it will always have a special first parameter.

- **Basic Syntax:** `fn method_name(first_parameter, other_parameters) { ... }`
    
- **First Parameter (`self`):** The first parameter of a method is always the keyword `self` (or a variation of it). `self` represents the specific instance of the struct that the method is being called on. This parameter is automatically passed by Rust, so you do not need to provide it during invocation.
    

#### Example: `TaylorSwiftSong` Struct and `impl` Block

Rust

```Rust
// Our struct definition (the data/blueprint).
// `derive(Debug)` is an attribute to enable easy printing.
#[derive(Debug)]
struct TaylorSwiftSong {
    title: String,
    release_year: u32,
    duration_secs: u32,
}

// Our implementation block (the behavior/methods).
// This block defines all the methods that belong to `TaylorSwiftSong`.
impl TaylorSwiftSong {
    // A method definition that belongs to `TaylorSwiftSong`.
    // It is named `display_song_info`.
    // It has a first parameter `self` which represents the song instance.
    fn display_song_info(self) {
        // The body of the method would be defined here.
        // It has access to the struct's fields via `self.field_name`.
    }
}
```
