A `struct` (short for "structure") is a custom data type in Rust that acts as a container for related data. Its purpose is to model complex, real-world concepts by bundling multiple pieces of information (called **fields**) together under a single, meaningful name.

Rust has three different types of structs, each with its own syntax and use case.

### 1. Named-Field Structs

This is the most common type of struct. Each field is assigned a specific name and a data type, providing excellent clarity and readability.

- Declaration Syntax:
    
    You use the struct keyword, followed by the struct's name (in PascalCase), and a pair of curly braces {}. Inside the braces, you define each field with its name, a colon, and its type, separating fields with commas.
    
- Example:
    
    This User struct models a user with a name, email, and a numeric id.
    
    Rust
    
    ```Rust
    // The blueprint for a named-field struct
    struct User {
        name: String,
        email: String,
        is_active: bool,
        sign_in_count: u64,
    }
    
    fn main() {
        // We can create an instance of the `User` struct.
        let user1 = User {
            name: String::from("Alice"),
            email: String::from("alice@example.com"),
            is_active: true,
            sign_in_count: 1,
        };
    
        // We can access the fields by name using dot notation.
        println!("User name: {}", user1.name); // Output: User name: Alice
    }
    ```
    

### 2. Tuple-Like Structs

Tuple-like structs are similar to regular tuples but are given a specific name to define them as a new, distinct type. Their fields are ordered by position rather than having names.

- Declaration Syntax:
    
    You use the struct keyword, followed by the struct's name (in PascalCase), and a pair of parentheses () with the types of the fields inside, separated by commas.
    
- Example:
    
    This Color struct models an RGB color. Its fields are accessed by their index (.0, .1, .2). This is a different type from a regular (u8, u8, u8) tuple.
    
    Rust
    
    ```Rust
    // The blueprint for a tuple-like struct
    struct Color(u8, u8, u8);
    
    // Another tuple-like struct with the same data types, but a different type name.
    struct Point(u8, u8, u8);
    
    fn main() {
        // We can create an instance of the `Color` struct.
        let red = Color(255, 0, 0);
    
        // We can access the fields by their index position.
        println!("The red component is: {}", red.0); // Output: The red component is: 255
    
        // A `Color` is not a `Point`, even though they hold the same types of data.
        // let my_point: Point = red; // This would cause a compile-time type mismatch error.
    }
    ```
    

### 3. Unit-Like Structs

Unit-like structs are the simplest type of struct. They have no fields and no data.

- Declaration Syntax:
    
    You use the struct keyword, followed by the struct's name (in PascalCase), and a semicolon ;.
    
- Example:
    
    This ApplicationStatus struct can be used as a marker type. Its primary purpose is to implement traits or methods when there's no data to store.
    
    Rust
    
    ```Rust
    // The blueprint for a unit-like struct
    struct ApplicationStatus;
    
    // You can define methods on a unit-like struct.
    impl ApplicationStatus {
        fn display_status(&self) {
            println!("The application is running.");
        }
    }
    
    fn main() {
        // We can create an instance of the `ApplicationStatus` struct.
        let status = ApplicationStatus;
    
        // We can still call methods on it.
        status.display_status(); // Output: The application is running.
    }
    ```
