The **Copy trait** makes types behave like "simple values" that get **copied** instead of **moved**.## **Key Points:**

**Copy Types** (get duplicated):

- All primitives: `i32`, `f64`, `bool`, `char`
- Arrays/tuples of Copy types
- Structs with only Copy fields (must `#[derive(Copy, Clone)]`)

**Non-Copy Types** (get moved):

- `String`, `Vec`, heap-allocated data
- Structs containing non-Copy fields

## **Behavior Difference:**

```rust
// Copy type
let x = 5;
let y = x;  // x is copied, both x and y are usable

// Non-Copy type  
let s1 = String::from("hello");
let s2 = s1;  // s1 is moved, only s2 is usable
```

## **Rules:**

- **Copy**: Cheap to duplicate (stack-only data)
- **Move**: Expensive to duplicate or has heap data
- **Copy requires Clone**: Must implement both traits
- **All Copy types are automatically copied** in assignments/function calls

Copy makes code simpler - no ownership transfer, just duplication!

---
```rust
fn main() {
    println!("=== COPY TYPES (primitives) ===");
    
    // i32 implements Copy - gets copied, not moved
    let x = 5;
    let y = x;  // x is COPIED to y
    
    println!("x: {}, y: {}", x, y); // Both x and y are still usable!
    
    // More Copy types
    let a = 10.5;     // f64 - Copy
    let b = true;     // bool - Copy  
    let c = 'A';      // char - Copy
    
    let a2 = a; // All get copied
    let b2 = b;
    let c2 = c;
    
    println!("Originals still work: {}, {}, {}", a, b, c);
    
    println!("\n=== NON-COPY TYPES (move instead) ===");
    
    // String does NOT implement Copy - gets moved
    let s1 = String::from("Hello");
    let s2 = s1;  // s1 is MOVED to s2
    
    // println!("{}", s1); // ERROR! s1 no longer valid
    println!("s2: {}", s2); // Only s2 works
    
    println!("\n=== STRUCTS WITH COPY ===");
    
    // Struct with only Copy fields can derive Copy
    #[derive(Copy, Clone, Debug)]
    struct Point {
        x: i32,  // Copy
        y: i32,  // Copy
    }
    
    let p1 = Point { x: 10, y: 20 };
    let p2 = p1;  // p1 is COPIED to p2
    
    println!("p1: {:?}, p2: {:?}", p1, p2); // Both work!
    
    // Can pass to functions multiple times
    print_point(p1);
    print_point(p1); // Still works because p1 was copied, not moved
    
    println!("\n=== STRUCTS WITHOUT COPY ===");
    
    // Struct with non-Copy field cannot be Copy
    #[derive(Debug)]
    struct Person {
        name: String,  // String is NOT Copy
        age: i32,      // i32 is Copy, but doesn't matter
    }
    
    let person1 = Person {
        name: String::from("Alice"),
        age: 30,
    };
    
    let person2 = person1;  // person1 is MOVED to person2
    
    // println!("{:?}", person1); // ERROR! person1 no longer valid
    println!("person2: {:?}", person2);
    
    println!("\n=== WHEN COPY HAPPENS ===");
    
    let num = 42;
    
    // Copy happens in these situations:
    let copied1 = num;           // Assignment
    some_function(num);          // Function call
    let copied2 = num;           // Multiple assignments work
    
    println!("Original num still works: {}", num);
    
    // Arrays of Copy types are also Copy
    let arr1 = [1, 2, 3];        // [i32; 3] implements Copy
    let arr2 = arr1;             // arr1 is copied
    println!("arr1: {:?}, arr2: {:?}", arr1, arr2);
}

fn print_point(p: Point) {
    println!("Point in function: {:?}", p);
    // p is dropped here, but original wasn't moved, so it's still usable
}

fn some_function(n: i32) {
    println!("Function received copy: {}", n);
}

#[derive(Copy, Clone, Debug)]
struct Point {
    x: i32,
    y: i32,
}
```
