## Rust Control Flow: `if-else` as an Expression

This study guide explores a powerful feature in Rust where `if-else` (and `if-else if-else`) constructs can return values, allowing their results to be assigned directly to variables. This concept replaces the traditional ternary operator found in many other languages.

### I. `if-else` as an Expression

What does it mean for if-else to be an "expression"?

In Rust, an expression is something that evaluates to a value. Just like 5 + 3 is an expression that evaluates to 8, an entire if-else block can also evaluate to a single value. This value can then be assigned to a variable.

How does if-else return a value?

For an if-else block to return a value, the last line in each of its associated code blocks (if block and else block, and any else if blocks) must be an expression (without a semicolon). The value of this final expression is the value that the entire if-else construct evaluates to.

- **Crucial Rule:** All branches (the `if` block, all `else if` blocks, and the `else` block) **must return a value of the same type**. The compiler will enforce this to ensure type safety.
    

**Example: Determining Even or Odd (from transcript)**

Rust

```Rust
// Define the function outside of main
fn even_or_odd(number: i32) -> String { // Function now returns a String
    // The entire if-else construct evaluates to a String
    let result = if number % 2 == 0 { // Condition: is remainder when divided by 2 equal to 0?
        "even".to_string() // Expression 1 (no semicolon), evaluates to String "even"
    } else {
        "odd".to_string() // Expression 2 (no semicolon), evaluates to String "odd"
    }; // Semicolon needed here because it's part of a `let` statement

    // The 'result' variable (a String) is the last expression in the function, so it's returned implicitly
    result
}

fn main() {
    let num1 = 17;
    let num2 = 100;

    let parity1 = even_or_odd(num1); // Call the function, assign its String result
    println!("The number {} is {}.", num1, parity1); // Output: The number 17 is odd.

    let parity2 = even_or_odd(num2);
    println!("The number {} is {}.", num2, parity2); // Output: The number 100 is even.
}
```

Explanation:

In the even_or_odd function:

1. The `if number % 2 == 0` condition is evaluated.
    
2. If `true`, the `if` block is entered. The expression `"even".to_string()` is evaluated, and its `String` result is the value returned by the `if` branch.
    
3. If `false`, the `else` block is entered. The expression `"odd".to_string()` is evaluated, and its `String` result is the value returned by the `else` branch.
    
4. Whichever branch executes, its `String` value is then assigned to the `result` variable.
    
5. Finally, `result` itself is the last expression in the `even_or_odd` function, so its value is returned by the function.

### II. Rust's Equivalent of the Ternary Operator

What is the ternary operator?

The ternary operator (often condition ? value_if_true : value_if_false) is a common shorthand in many programming languages (like C++, Java, JavaScript, Python) for an if-else expression that returns one of two values based on a condition, all on a single line.

- **Example (C-style):** `int result = (num % 2 == 0) ? "even" : "odd";`
    

Does Rust have a ternary operator?

No. Rust does not have a dedicated ternary operator symbol (? :).

What is Rust's equivalent of the ternary operator?

Rust achieves the exact same functionality (returning one of two values based on a boolean condition) by using the standard if-else construct as an expression.

- **Syntax:**
    
    Rust
    
    ```Rust
    let result = if condition {
        value_if_true // No semicolon
    } else {
        value_if_false // No semicolon
    }; // Semicolon here to end the `let` statement
    ```
    
- This is considered Rust's idiomatic way to express a conditional assignment that would be handled by a ternary operator in other languages. It benefits from being more readable for multi-line expressions and consistent with Rust's general expression-oriented nature.
    

**Example: Ternary Equivalent in Rust**

Rust

```Rust
fn main() {
    let is_logged_in = true;

    // Rust's "ternary operator" equivalent
    let greeting = if is_logged_in {
        "Welcome back!" // No semicolon
    } else {
        "Please log in." // No semicolon
    }; // Semicolon for the `let` statement

    println!("{}", greeting); // Output: Welcome back!

    let age = 15;
    let status = if age >= 18 {
        "Adult"
    } else {
        "Minor"
    };
    println!("Person is a: {}", status); // Output: Person is a: Minor
}
```

### III. Key Takeaways

- **`if-else` as Expression:** The entire `if-else` (or `if-else if-else`) block can evaluate to a single value that can be assigned to a variable.
    
- **No Semicolons in Returning Branches:** The last line of each `if`, `else if`, or `else` block that produces a value _must not_ have a semicolon for that value to be implicitly returned.
    
- **Type Consistency:** All branches of an `if-else` expression **must return the same data type**. The compiler will enforce this strict type safety.
    
- **Rust's Ternary Equivalent:** The `if-else` expression provides the same functionality as the ternary operator in other languages, aligning with Rust's preference for blocks as expressions. This leads to more readable and idiomatic code.
    
- **Flexibility:** This feature allows for very concise and readable conditional assignments, especially when combined with complex logic within the blocks.
