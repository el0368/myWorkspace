## Rust Control Flow: `loop` and `break` Keywords (Unconditional & Conditional Iteration)

This study guide introduces the fundamental concepts of iteration (repetition) in Rust using the `loop` keyword, and how to control its execution with the `break` keyword.

### I. Understanding Iteration

What is iteration?

Iteration, also known as repetition or looping, is a core programming concept that means "to repeat a block of code multiple times." It's essential for automating processes that would otherwise be manual, tedious, or impossible to complete efficiently.

What is the simplest way to iterate in Rust?

The simplest way to create a repeating block of code in Rust is by using the loop keyword.

---

### II. The `loop` Keyword

What does the loop keyword do?

The loop keyword declares a block of code that Rust will execute repeatedly and continuously without any built-in condition to stop.

- **Syntax:**
    
    Rust
    
    ```Rust
    loop {
        // Code to be repeated indefinitely
    }
    ```
    
- **Default Behavior:** By default, a `loop` creates an **infinite loop**. This means the code within its block will run **forever** (indefinitely) until the program is manually stopped or runs out of resources.
    
- **Caution:** Running an infinite loop without a proper termination mechanism will cause your program to consume increasing amounts of CPU and memory, leading to a system freeze or program crash.

### III. The `break` Keyword

How do you stop an infinite loop?

To terminate a loop and prevent it from running indefinitely, you must explicitly use the break keyword.

- **Definition:** The `break` keyword immediately **exits (terminates)** the innermost loop it is contained within. When `break` is encountered, the program's execution jumps out of the loop and continues with the first line of code located immediately after the loop's closing curly brace.
    
- **Purpose:** `break` is almost universally combined with a **conditional statement (an `if` statement)**. This pairing allows you to specify _when_ the loop should stop based on a specific condition being met.
    

**Syntax for `break` with `if` (Conditional Termination):**

Rust

```Rust
loop {
    // Check if the condition to stop the loop is met
    if some_condition_is_met {
        // Optional: Perform any final actions before exiting the loop
        println!("Condition met, breaking loop!");
        break; // This keyword terminates the loop
    }
    // Code that executes if the loop continues (i.e., condition not met yet)
    println!("Loop is still running...");
}
```

**Example: Countdown Timer Program (from transcript)**

This example demonstrates a practical use of `loop` with `break` for a countdown.

Rust

```Rust
fn main() {
    let mut seconds = 10; // Declared as 'mut' because its value will change

    println!("Starting countdown...");

    loop { // Outer `loop` block
        // 1. Check for the termination condition at the beginning of each iteration
        if seconds == 0 {
            println!("Blastoff!"); // Message when countdown finishes
            break;               // Exit the `loop`
        }

        // 2. Actions to perform during each regular countdown step
        println!("{} seconds to blastoff...", seconds);

        // 3. Update the loop's state for the next iteration (decrement the counter)
        seconds -= 1; // Uses the augmented assignment operator (equivalent to `seconds = seconds - 1;`)
    } // End of `loop` block

    println!("Program finished."); // This line executes only after the loop has broken
}
```

**Example: Simulating a Login Attempt**

This expanded example shows `loop` and `break` in a different context.

Rust

```Rust
fn main() {
    let max_attempts = 3;
    let mut attempts_made = 0;
    let correct_password = "password123";
    let mut user_input = String::new();

    println!("Please log in. You have {} attempts.", max_attempts);

    loop {
        attempts_made += 1; // Increment attempt counter
        println!("Attempt {}/{}.", attempts_made, max_attempts);
        println!("Enter password:");

        user_input.clear(); // Clear previous input
        std::io::stdin()
            .read_line(&mut user_input)
            .expect("Failed to read line");
        let entered_password = user_input.trim(); // Get trimmed password as &str

        if entered_password == correct_password {
            println!("Login successful! Welcome.");
            break; // Exit loop on success
        } else {
            println!("Incorrect password.");
        }

        if attempts_made >= max_attempts {
            println!("Maximum attempts reached. Account locked.");
            break; // Exit loop on too many failed attempts
        }
    }

    println!("Session concluded.");
}
```

### IV. Key Takeaways

- **Iteration (Repetition):** A fundamental concept for automating tasks by repeating code execution.
    
- **`loop` Keyword:** Creates a basic, unconditional loop that executes its block of code repeatedly. By default, it results in an **infinite loop**.
    
- **`break` Keyword:** The mechanism to **explicitly terminate a `loop`**. When encountered, control immediately transfers to the statement following the loop.
    
- **Conditional Termination:** The `break` keyword is almost always used in conjunction with an **`if` statement** inside the loop to define the condition under which the loop should stop.
    
- **Mutable State:** Variables that are intended to change their values across loop iterations (e.g., counters, flags) must be declared with the `mut` keyword.
    
- **Structure:** The `loop` keyword defines a standard code block enclosed in curly braces, just like function bodies or `if` statements.
