Open Vectors Project

The project/directory for this section is called `vectors`.

To open the Cargo project in VSCode, go to `File > Open Folder...`. Locate and select the `vectors` directory in the `learn-to-code-with-rust` course folder.

Alternatively, navigate to the project directory in Terminal/PowerShell and execute `code .`

Write your code in the `src/main.rs`.
