### Part 1: Adding Elements to a Vector (`push` and `insert`)

This progressive example demonstrates how to add new elements to a vector using the `push` and `insert` methods. These methods showcase a vector's ability to grow in size.

- **Mutability:** Any method that modifies the vector (adds, removes, or changes elements) requires the vector to be marked as **mutable (`mut`)**.
    
- **`.push(value)`:** Appends a single new element to the end of the vector. This operation is always successful and very efficient.
    
- **`.insert(index, value)`:** Inserts a new element at a specific index. This pushes all subsequent elements down by one position. This operation can be less efficient for large vectors because it requires shifting all the elements.
    

Rust

```Rust
fn main() {
    // We must declare the vector as mutable to add elements.
    let mut pizza_diameters = vec![8, 10, 12, 14];
    println!("Initial vector: {:?}", pizza_diameters);

    // Use `.push()` to add 16 to the end.
    pizza_diameters.push(16);
    println!("After push(16): {:?}", pizza_diameters); // Output: [8, 10, 12, 14, 16]

    // Use `.insert()` to add 4 at the beginning (index 0).
    pizza_diameters.insert(0, 4);
    println!("After insert(0, 4): {:?}", pizza_diameters); // Output: [4, 8, 10, 12, 14, 16]

    // Use `.insert()` to add an element in the middle.
    // Insert `11` at index 3.
    pizza_diameters.insert(3, 11);
    println!("After insert(3, 11): {:?}", pizza_diameters); // Output: [4, 8, 10, 11, 12, 14, 16]
}
```

### Part 2: Removing Elements from a Vector (`pop` and `remove`)

This part demonstrates how to remove elements from a vector. It highlights the difference between a method that can fail gracefully (`pop`) and a method that can cause a panic (`remove`).

- **`.pop()`:** Removes and returns the **last** element of the vector. This method returns an `Option<T>`, where `Some(T)` is returned if an element was successfully removed, and `None` is returned if the vector was empty. This is a safe, non-panicking operation.
    
- **`.remove(index)`:** Removes and returns the element at a specified `index`. This method **panics!** if the index is out of bounds. It is a more direct but risky operation.
    

Rust

```Rust
fn main() {
    let mut numbers = vec![1, 2, 3, 4, 5, 6];
    println!("Initial vector: {:?}", numbers);

    // Use `.pop()` to remove the last element (`6`).
    let last_number_option = numbers.pop();
    println!("Popped: {:?}", last_number_option); // Output: Popped: Some(6)
    println!("Vector after pop: {:?}", numbers); // Output: Vector after pop: [1, 2, 3, 4, 5]

    // If the vector is empty, `pop()` returns `None`.
    let mut empty_vec: Vec<i32> = Vec::new();
    let empty_pop_result = empty_vec.pop();
    println!("Pop on empty vector: {:?}", empty_pop_result); // Output: Pop on empty vector: None

    // Use `.remove()` to remove the element at a specific index.
    // Index 2 is the value `3` from our current vector.
    let removed_number = numbers.remove(2);
    println!("Removed at index 2: {}", removed_number); // Output: Removed at index 2: 3
    println!("Vector after remove: {:?}", numbers); // Output: Vector after remove: [1, 2, 4, 5]

    // This line would cause a runtime panic! because index 50 does not exist.
    // let risky_remove = numbers.remove(50); // PANIC!
}
```

### Part 3: The Final Progressive Example (Combining Operations)

This final part brings all the concepts together into a single, comprehensive program. It shows a vector being created, modified by adding elements, and then having elements removed. This demonstrates the vector's primary advantage over a fixed-size array: its dynamic size.

- **Vector's Advantage:** The ability to grow and shrink is a key feature of a vector. This flexibility is what makes it a suitable solution for scenarios where the number of elements is unpredictable (e.g., user input, data from a file).
    
- **The Code:** This is the final, complete program that showcases the vector's dynamic nature.
    

Rust

```Rust
fn main() {
    // 1. Initial vector creation with `vec!` macro.
    let mut pizza_diameters = vec![8, 10, 12, 14];
    println!("Initial vector: {:?}", pizza_diameters);

    // 2. Adding elements to the vector.
    // Use `push` to add an element to the end.
    pizza_diameters.push(16);
    // Use `insert` to add an element at the start.
    pizza_diameters.insert(0, 4);
    println!("After adding elements: {:?}", pizza_diameters);
    // Output: [4, 8, 10, 12, 14, 16]

    // 3. Removing elements from the vector.
    // Use `pop` to remove the last element (`16`).
    let last_element = pizza_diameters.pop();
    println!("Popped last element: {:?}", last_element);
    // Output: Popped last element: Some(16)

    // Use `remove` to remove the element at index 2 (`10`).
    let middle_element = pizza_diameters.remove(2);
    println!("Removed element from middle: {}", middle_element);
    // Output: Removed element from middle: 10

    // 4. Final state of the vector.
    println!("Final vector after all operations: {:?}", pizza_diameters);
    // Output: [4, 8, 12, 14]
}
```
