# 📘 Rust String Methods — Practical, In-Scope Guide

## 1) `trim`, `trim_start`, `trim_end`

**Goal:** remove whitespace at the start/end of a string **without allocating** when possible.

```rust
fn main() {
    // Extra spaces on both ends, comma+space between items
    let mut music_genres: &str = "   Rock, Metal, Country, Rap   ";

    // Borrow-only cleanup (returns &str slice of the original)
    let trimmed: &str = music_genres.trim();       // both ends
    let left:   &str = music_genres.trim_start();  // leading only
    let right:  &str = music_genres.trim_end();    // trailing only

    // Reassign (same type: &str → &str), no allocation
    music_genres = trimmed;

    // Debug preview
    println!("left=[{:?}]", left);
    println!("right=[{:?}]", right);
    println!("trimmed=[{:?}]", music_genres);
}
```

**Key points**

- All three return a **`&str`** (a slice of the original), so **no new `String`** is created.
    
- Works perfectly when your original binding is a `&str`.
    
- If you _need ownership_ (e.g., to store or modify later), convert explicitly:
    
    ```rust
    let owned_clean = music_genres.trim().to_string(); // allocates a new String
    ```

## 2) Case Conversion: `to_uppercase`, `to_lowercase`

**Goal:** produce an all-uppercase or all-lowercase version of a string.

```rust
fn main() {
    let music_genres: &str = "Rock, Metal, Country, Rap";

    // These create NEW heap-allocated Strings (because content changes)
    let shout: String = music_genres.to_uppercase();
    let soft:  String = music_genres.to_lowercase();

    println!("{}", shout); // "ROCK, METAL, COUNTRY, RAP"
    println!("{}", soft);  // "rock, metal, country, rap"
}
```

**Key points**

- Both methods **allocate and return `String`**, since they create a transformed copy.
    
- Original `&str` remains unchanged.

## 3) Find & Replace: `replace`

**Goal:** replace **all** occurrences of a pattern (substring) with another substring.

```rust
fn main() {
    let music_genres: &str = "Rock, Metal, Country, Rap";

    // Replace all lowercase 'a' with '@' (example)
    let noisy: String = music_genres.replace("a", "@");

    println!("{}", noisy); // "Rock, Met@l, Country, R@p"
}
```

**Key points**

- Signature conceptually: `fn replace(&self, from: &str, to: &str) -> String`.
    
- Returns a **new `String`** (allocates) because content differs from the source.
    
- Operates on substring matches (not regex; plain substring pattern).

## 4) Splitting: `split` → `collect`

**Goal:** split a delimited string into pieces and collect them.

```rust
fn main() {
    // Assume we've cleaned surrounding spaces
    let music_genres: &str = "Rock, Metal, Country, Rap";

    // Split on comma+space as the delimiter
    let parts_iter = music_genres.split(", ");

    // Collect into a vector of &str (borrowed views into the original slice)
    let genres: Vec<&str> = parts_iter.collect();

    // Vectors implement Debug (use {:?})
    println!("{:?}", genres); // ["Rock", "Metal", "Country", "Rap"]
}
```

**Key points**

- `split` returns an **iterator** (`Split`), not a vector.
    
- Use `.collect()` to gather into a container; annotate the target type as needed.
    
- When splitting a `&str`, collecting into `Vec<&str>` **does not allocate substring data**; it borrows slices from the original.
    
- If you want **owned** pieces:
    
    ```rust
    let genres_owned: Vec<String> =
        music_genres.split(", ").map(|s| s.to_string()).collect();
    ```

## 5) Putting It Together (progressive example)

Start with messy input → normalize whitespace → inspect variants → replace → split.

```rust
fn main() {
    // 1) Messy input (pretend read from a file)
    let mut music_genres: &str = "    Rock, Metal, Country, Rap    ";

    // 2) Normalize edges without allocating
    music_genres = music_genres.trim();

    // 3) Make case variants (allocating, returns String)
    let upper = music_genres.to_uppercase();
    let lower = music_genres.to_lowercase();

    println!("upper: {}", upper);
    println!("lower: {}", lower);

    // 4) Replace a character across the entire string (allocates)
    let replaced = music_genres.replace("a", "@");
    println!("replaced: {}", replaced);

    // 5) Split on ", " and collect borrowed slices (no per-piece clones)
    let genres: Vec<&str> = music_genres.split(", ").collect();
    println!("genres: {:?}", genres);
}
```

## 6) Mutability, Shadowing, and Ownership Notes

- `trim*` methods return `&str` — you can **reassign** a `&str` binding after trimming:
    
    ```rust
    let mut s: &str = "  data  ";
    s = s.trim(); // still &str → no allocation
    ```
    
- If your variable is a `String` and you want to _overwrite it_ with a trimmed version, you must produce a new `String`:
    
    ```rust
    let mut s = String::from("  data  ");
    s = s.trim().to_string(); // allocate a new owned String
    ```
    
- Printing collections: vectors **do not** implement `Display` but **do** implement `Debug`. Use `{:?}`:
    
    ```rust
    let v = vec!["Rock", "Metal"];
    println!("{:?}", v);
    ```

## 8) Minimal “from messy to structured” pattern

```rust
fn parse_genres(input: &str) -> Vec<&str> {
    input.trim().split(", ").collect()
}
```

- Clean edges (`trim`) → split on delimiter → collect borrowed slices.
    

This set of methods gives you a compact toolkit to **clean**, **transform**, **replace**, and **slice** strings efficiently, choosing between **borrowed views** (`&str`) and **owned data** (`String`) only when you truly need allocation.
