# 📘 Study Guide: `format!` Macro in Rust

---

## 🔹 Purpose of `format!`

The `format!` macro is designed to construct **heap-allocated `String` values** that include interpolated content. Unlike `println!`, which outputs text directly to the console, `format!` returns a new `String`. This makes it useful when:

- You need to **build a string dynamically**.
    
- You want to **concatenate values** in a clean, readable way.
    
- You plan to **assign the result to a variable** or **return it from a function**.
    

Because it returns a `String`, the result can be stored, manipulated, or passed around just like any other owned string value.

---

## 🔹 Basic Usage

Syntax is nearly identical to `println!`. The only difference is that the output goes into a `String` instead of standard output.

```rust
let first_name = "Sylvester";
let last_name = "Stallone";

// Using format! to create a new heap-allocated String
let icon = format!("{} {}", first_name, last_name);

println!("{}", icon); // "Sylvester Stallone"
```

Here:

- `first_name` and `last_name` are borrowed implicitly.
    
- The resulting value (`icon`) is a `String` stored on the heap.
    
- No ownership is transferred from `first_name` or `last_name`.
    

---

## 🔹 Ownership and Borrowing

A critical feature: **the `format!` macro does not consume its arguments**. Instead, it borrows values behind the scenes.

Example:

```rust
let first_name = String::from("Sylvester");
let last_name = String::from("Stallone");

let icon = format!("{} {}", first_name, last_name);

println!("{}", first_name); // Still valid
println!("{}", last_name);  // Still valid
```

This behavior makes `format!` very convenient because you don’t lose access to the variables you interpolate into the new string.

---

## 🔹 Interpolation Options

Anything that works inside `println!` also works inside `format!`.

### 1. Positional Arguments

```rust
let first_name = "Sylvester";
let last_name = "Stallone";

let msg = format!("{0} {1} - Icon: {0}", first_name, last_name);
println!("{}", msg); 
// "Sylvester Stallone - Icon: Sylvester"
```

- `{0}` refers to the first argument.
    
- `{1}` refers to the second argument.
    
- You can reuse values multiple times without repeating them in the argument list.
    

---

### 2. Named Arguments

```rust
let msg = format!(
    "{first} {last} is famous",
    first = "Sylvester",
    last = "Stallone"
);
println!("{}", msg);
// "Sylvester Stallone is famous"
```

Named arguments improve readability, especially when multiple interpolations occur.

---

### 3. Standard Placeholder `{}`

By default, `{}` inserts the `Display` representation of a value.

```rust
let year = 2025;
let msg = format!("Year: {}", year);
println!("{}", msg);
// "Year: 2025"
```

Any type that implements the `Display` trait can be interpolated. This includes:

- Strings and string slices (`String`, `&str`)
    
- Numbers (integers, floats)
    
- Booleans
    
- User-defined types that implement `Display`
    

---

## 🔹 Concatenation vs. `format!`

Before `format!`, string building often used:

- `push_str` or `push`
    
- `+` operator
    

Both approaches work but become less readable with multiple values.

Example with `+`:

```rust
let first_name = "Sylvester".to_string();
let last_name = "Stallone".to_string();

let full = first_name + " " + &last_name;
```

Limitations:

- `+` moves the left operand, consuming it.
    
- Requires explicit borrowing for the right operand (`&last_name`).
    
- Less elegant when interpolating more than two or three values.
    

With `format!`:

```rust
let full = format!("{} {}", "Sylvester", "Stallone");
```

- No ownership issues.
    
- Cleaner syntax.
    
- Scales well when interpolating many values.
    

---

## 🔹 Integration with Functions

Since `format!` returns a `String`, it can directly serve as a function return value:

```rust
fn make_icon(first: &str, last: &str) -> String {
    format!("{} {}", first, last)
}

fn main() {
    let icon = make_icon("Sylvester", "Stallone");
    println!("{}", icon);
}
```

This pattern is powerful for generating dynamic messages or formatted text in libraries and applications.

---

## 🔹 Advanced Formatting Options

Everything supported by `println!` formatting applies here:

- **Width and Alignment**
    
    ```rust
    let msg = format!("{:>10}", "Rust"); // Right align in 10 chars
    println!("{}", msg); // "      Rust"
    ```
    
- **Padding**
    
    ```rust
    let msg = format!("{:-^10}", "Rust"); 
    println!("{}", msg); // "---Rust---"
    ```
    
- **Number Formatting**
    
    ```rust
    let pi = 3.14159;
    let msg = format!("{:.2}", pi); 
    println!("{}", msg); // "3.14"
    ```
    
- **Debug Output**
    
    ```rust
    let arr = [1, 2, 3];
    let msg = format!("{:?}", arr); 
    println!("{}", msg); // "[1, 2, 3]"
    ```
    

---

## 🔹 Key Takeaways

1. `format!` builds a new **heap-allocated `String`** instead of printing.
    
2. Syntax is the same as `println!`, but the result can be stored or returned.
    
3. Interpolated values are **borrowed, not moved**, so ownership is preserved.
    
4. Supports positional, named, and reused arguments.
    
5. Cleaner and safer alternative to `+` or `push_str` for complex string concatenation.
    
6. Fully supports advanced formatting (alignment, precision, padding, debug, etc.).
