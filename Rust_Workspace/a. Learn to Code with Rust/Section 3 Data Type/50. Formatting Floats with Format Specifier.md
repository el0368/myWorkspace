### Study Guide: Formatting Output with `println!` 🎨

A **format specifier** is a special syntax used inside the curly braces `{}` of a `println!` macro to customize how a value is printed. It gives you fine-grained control over the output's appearance.

**Key Principles:**

- You create a format specifier by adding a colon (`:`) after the variable or positional index.
    
- Formatting **only changes the visual representation** of the value for that specific `println!` call; it does **not** alter the underlying variable itself.
    

You can use format specifiers with both direct interpolation and positional arguments:

Rust

```Rust
let pi = 3.14159;
// Direct interpolation with a format specifier
println!("Value: {pi:.2}");

// Positional argument with a format specifier
println!("Value: {:.2}", pi);
```

---

### Controlling Floating-Point Precision

This is one of the most common uses for format specifiers. The syntax `:.N` lets you specify the number of decimal places to display. Rust will automatically handle rounding.

Rust

```Rust
fn main() {
    let pi = 3.14159265;
    println!("Default:      {}", pi);
    println!("Precision 2:  {:.2}", pi); // Prints 3.14
    println!("Precision 4:  {:.4}", pi); // Prints 3.1416 (note the rounding)
    println!("Precision 0:  {:.0}", pi); // Prints 3
}
```

### Formatting with Different Number Systems

You can easily display integers in binary, octal, or hexadecimal format.

|Specifier|Description|
|---|---|
|`:b`|**Binary** (base 2)|
|`:o`|**Octal** (base 8)|
|`:x`|**Hexadecimal** (base 16, lowercase `a-f`)|
|`:X`|**Hexadecimal** (base 16, uppercase `A-F`)|

Rust

```Rust
fn main() {
    let number = 255;
    println!("Number:      {}", number);     // Default (Display)
    println!("Binary:      {:b}", number);    // Prints 11111111
    println!("Octal:       {:o}", number);     // Prints 377
    println!("Hex (lower): {:x}", number); // Prints ff
    println!("Hex (upper): {:X}", number); // Prints FF
}
```

### Padding and Alignment

You can specify a minimum width for the output and control its alignment. If the value is shorter than the specified width, it will be padded with a fill character (the default is a space).

|Specifier|Description|
|---|---|
|`N`|Pad to a width of `N` characters.|
|`>`|Right-align the text (default).|
|`<`|Left-align the text.|
|`^`|Center-align the text.|
|`fill`|A character placed before the alignment specifier to use for padding instead of a space.|

Rust

```Rust
fn main() {
    let item = "Shield";
    let quantity = 5;
    println!("Item: {:<10} | Quantity: {}", item, quantity); // Left-aligns "Shield" in a 10-char space
    println!("Item: {:^10} | Quantity: {}", item, quantity); // Center-aligns "Shield"
    println!("ID:   {:0>5}", 42); // Pads with leading zeros to a width of 5 -> "00042"
}
```

---

### Key Takeaways

- Use a colon (`:`) inside `{}` to start a format specifier.
    
- `:.N` controls the number of decimal places for floats.
    
- Specifiers like `:b`, `:o`, and `:x` can display numbers in different bases.
    
- You can control width and alignment with characters like `<` and `^`, and even specify the fill character.
