### Study Guide: Compound Assignment Operators in Rust ✍️

In Rust, **compound assignment operators** (also called augmented assignment operators) provide a convenient shorthand for modifying a variable by performing a mathematical operation on it and then assigning the result back to the original variable.

They combine an operation and an assignment into a single operator.

- **Long Form:** `variable = variable + value;`
    
- **Short Form:** `variable += value;`
    

---

### The Prerequisite: Mutability

These operators modify a variable in place, so the variable **must** be declared as **mutable** using the `let mut` keywords. Attempting to use a compound assignment operator on an immutable variable will result in a compile-time error.

Rust

```Rust
fn main() {
    let x = 10;
    // x += 5; // This would cause a compile error because x is not mutable.
}
```

---

### Common Operators and Examples

The following table shows the common compound assignment operators and their equivalents.

|Operator|Long-Form Equivalent|Example (from transcript)|My Example (`let mut score = 100;`)|
|---|---|---|---|
|`+=`|`var = var + val;`|`year += 1;`|`score += 20; // score is now 120`|
|`-=`|`var = var - val;`|`year -= 5;`|`score -= 10; // score is now 90`|
|`*=`|`var = var * val;`|`year *= 2;`|`score *= 3; // score is now 300`|
|`/=`|`var = var / val;`|`year /= 4;`|`score /= 5; // score is now 20`|
|`%=`|`var = var % val;`|_(Not in transcript)_|`score %= 3; // score is now 1 (100 % 3)`|

#### Full Example

Rust

```Rust
fn main() {
    let mut year = 2025;
    println!("Original year: {}", year);

    // Add 1 and assign
    year += 1; // year is now 2026
    println!("After += 1: {}", year);

    // Subtract 5 and assign
    year -= 5; // year is now 2021
    println!("After -= 5: {}", year);

    // Multiply by 2 and assign
    year *= 2; // year is now 4042
    println!("After *= 2: {}", year);

    // Divide by 4 and assign (integer division)
    year /= 4; // year is now 1010
    println!("After /= 4: {}", year);
}
```

### Important Note for Developers from Other Languages

Unlike many other C-style languages (like C++, Java, or JavaScript), Rust **does not** have the `++` (increment) and `--` (decrement) operators.

The idiomatic way to increment or decrement a value by one is to use `+= 1` or `-= 1`.

Rust

```Rust
fn main() {
    let mut count = 0;
    count += 1; // Correct way to increment in Rust. `count++` is not valid.
    println!("Count: {}", count);
}
```
