### Study Guide: Mathematical Operations in Rust 🧮

Rust supports all common mathematical operations using standard symbols called **operators**. The values that an operator acts on are called **operands**.

#### Basic Arithmetic Operators

| Operation      | Operator | Example (from transcript) | My Example                       |
| -------------- | -------- | ------------------------- | -------------------------------- |
| Addition       | `+`      | `5 + 4`                   | `let total = 20 + 8;`            |

### Integer vs. Floating-Point Division

This is a crucial concept to understand in Rust.

- **Integer Division (Floor Division):** When you divide two integers, Rust performs **floor division**, and the result is always an integer. The decimal part is **truncated** (cut off), not rounded.
    
    Rust
    
    ```Rust
    // 5 divided by 3 is 1 with a remainder of 2. The result is truncated to 1.
    let floor_division = 5 / 3;
    println!("5 / 3 = {}", floor_division); // Prints 1
    ```
    
- **Floating-Point Division:** To get a precise decimal result, you must perform the division with **floating-point numbers** (e.g., `f64`).
    
    Rust
    
    ```Rust
    // 5.0 divided by 3.0 gives a precise decimal result.
    let decimal_division = 5.0 / 3.0;
    println!("5.0 / 3.0 = {}", decimal_division); // Prints 1.666...
    ```

### The Modulo (Remainder) Operator (`%`)

The modulo operator (`%`) returns the **remainder** left over after a division. A common use case is to check if a number is even or odd.

Rust

```Rust
fn main() {
    // Example from transcript: 7 divided by 2 is 3 with a remainder of 1.
    let remainder = 7 % 2;
    println!("7 % 2 = {}", remainder); // Prints 1

    // My Example: Check if a number is even
    let number = 16;
    if number % 2 == 0 {
        println!("{} is an even number.", number);
    } else {
        println!("{} is an odd number.", number);
    }
}
```

### Operator Precedence

Rust follows the standard mathematical order of operations (similar to PEMDAS/BODMAS). Multiplication, division, and remainder have higher precedence than addition and subtraction. You can use parentheses `()` to explicitly control the order of operations.

Rust

```Rust
fn main() {
    // Multiplication is done first because it has higher precedence.
    let result1 = 5 + 2 * 10; // 5 + 20 = 25
    println!("Result 1: {}", result1);

    // Parentheses force the addition to be done first.
    let result2 = (5 + 2) * 10; // 7 * 10 = 70
    println!("Result 2: {}", result2);
}
```

### Compound Assignment Operators

Rust provides convenient shorthand operators to modify a variable in place.

|Operator|Example|Equivalent To|
|---|---|---|
|`+=`|`x += 5;`|`x = x + 5;`|
|`-=`|`x -= 5;`|`x = x - 5;`|
|`*=`|`x *= 5;`|`x = x * 5;`|
|`/=`|`x /= 5;`|`x = x / 5;`|
|`%=`|`x %= 5;`|`x = x % 5;`|

Rust

```Rust
fn main() {
    let mut score = 100;
    score += 50; // `score` is now 150
    println!("Final Score: {}", score);
}
```
