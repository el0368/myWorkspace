### Study Guide: The Boolean (`bool`) Data Type in Rust ✅

The **Boolean** data type, named after mathematician George Boole, represents a value of **truth**. It is fundamental to programming for controlling logic and flow.

A Boolean can only be one of two values:

- `true`
    
- `false`
    

They are used to model binary states like yes/no, on/off, or active/inactive.

---

### Declaration and Memory

In Rust, the Boolean type is called **`bool`**. You can declare a boolean variable and either let Rust infer the type or annotate it explicitly.

Rust

```Rust
fn main() {
    // Explicitly annotating the type
    let is_active: bool = true;

    // Letting Rust infer the type
    let is_on_vacation = false;

    println!("Active: {}, On Vacation: {}", is_active, is_on_vacation);
}
```

A `bool` occupies **1 byte** (8 bits) in memory. Although 1 bit is technically enough to store `true` or `false`, a full byte is used for performance reasons, as modern CPUs are optimized to work with byte-sized chunks of data.

---

### Generating Booleans: Comparisons

Booleans are most often generated as the result of a **comparison**. Rust uses standard mathematical symbols for this.

|Operator|Meaning|Example|Result|
|---|---|---|---|
|`==`|Equal to|`5 == 5`|`true`|
|`!=`|Not equal to|`5 != 4`|`true`|
|`>`|Greater than|`10 > 5`|`true`|
|`<`|Less than|`10 < 5`|`false`|
|`>=`|Greater than or equal to|`5 >= 5`|`true`|
|`<=`|Less than or equal to|`5 <= 10`|`true`|

#### Example from Transcript

Rust

```Rust
fn main() {
    let age: i32 = 21;
    let is_young = age < 35; // This expression evaluates to `true`
    println!("Is the person young? {}", is_young);
}
```

---

### Generating Booleans: Methods

Many built-in types have methods that return a `bool` to check their state.

#### Examples

Rust

```Rust
fn main() {
    let number: i32 = -40;
    println!("Is the number positive? {}", number.is_positive()); // false
    println!("Is the number negative? {}", number.is_negative()); // true

    let username = "";
    println!("Is the username empty? {}", username.is_empty()); // true
}
```

---

### Combining Booleans: Logical Operators

You can combine or modify boolean values using **logical operators** to create more complex conditions.

|Operator|Name|Meaning|
|---|---|---|
|`&&`|**AND**|`true` only if _both_ sides are `true`.|
|`||`|
|`!`|**NOT**|Inverts a boolean value (`true` becomes `false`).|

#### Example

Rust

```Rust
fn main() {
    let has_permission = true;
    let is_logged_in = false;

    let can_access_admin_panel = has_permission && is_logged_in; // false
    let can_see_content = has_permission || is_logged_in;      // true
    let is_guest = !is_logged_in;                         // true
}
```
