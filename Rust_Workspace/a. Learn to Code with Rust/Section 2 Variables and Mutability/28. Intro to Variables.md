## Variables in Rust

### What is a Variable?

A **variable** is a name assigned to a value in a program, acting as a placeholder or stand-in. Using variables provides two main benefits:

1. **Context:** A well-chosen name (e.g., `apples_in_garden`) provides context for what the value represents.
    
2. **Reuse:** It allows you to refer to the same value multiple times throughout your code without rewriting it.
    

---

### Declaring Variables

In Rust, you declare variables using a specific syntax:

- **`let` keyword:** All variable declarations start with the `let` keyword.
    
- **Variable Name:** The name you choose should follow **snake_case** formatting (all lowercase, with words separated by underscores, e.g., `apples_in_garden`).
    
- **Assignment (`=`):** The value is assigned to the variable using a single equals sign.
    
- **Semicolon (`;`):** The statement must end with a semicolon, which signals the end of a command, much like a period at the end of a sentence.
    

Rust

```Rust
fn main() {
    // A variable 'apples' is declared and assigned the value 50.
    let apples = 50;
}
```

---

### Type Inference

Rust is a **statically typed** language, meaning the compiler must know the type of every variable at compile time. However, you don't always have to write the type yourself.

When you assign an initial value, the Rust compiler **infers** (deduces) the data type. In the example `let apples = 50;`, Rust infers the type as `i32` (a 32-bit signed integer). This information is often shown by editor tools like `rust-analyzer` to help developers.

---

### Compiler Warnings and Errors

The Rust compiler provides feedback to help you write better code:

- **Warning:** A suggestion for improvement or a note about inefficient code (like an "unused variable"). A warning will not prevent the program from compiling.
    
- **Error:** A more serious issue that violates Rust's rules. An error will prevent the program from compiling until it is fixed.
    

---

### How Variables are Evaluated

Rust always evaluates the **right-hand side** of the equals sign _first_ before assigning the final result to the variable on the left-hand side.

Variables can be used in expressions just like regular values. Rust will substitute the variable names with their corresponding values before performing the calculation.

### Complete Code Example

This code demonstrates all the concepts discussed: declaration, evaluation, and using variables in expressions.

Rust

```Rust
fn main() {
    // 'apples' is assigned the value 50. Rust infers the type as i32.
    let apples = 50;

    // The right side (14 + 6) is evaluated first to 20.
    // 'oranges' is then assigned the value 20.
    let oranges = 14 + 6;

    // The variables 'apples' and 'oranges' are replaced with their values (50 and 20).
    // The sum (70) is calculated, and then assigned to the 'fruits' variable.
    let fruits = apples + oranges;
}
```
