### Part 1: The `let else` Concept & Tuple Variant

This progressive example introduces the **`let else`** construct, which is a variation of `if let`. Its primary purpose is to execute a block of code when a pattern _does not_ match, while still binding associated data if the pattern _does_ match.

- **The Inverse of `if let`:** While `if let` executes a block on a successful match, `let else` executes a block on a failed match.
    
- **Binding Scope:** A key feature is that the variable declared in the `let` pattern is available for the rest of the function's scope **only if the pattern is a match**.
    
- **Compiler Requirement:** The `else` block _must_ contain a terminating expression (e.g., `return;`) because if the pattern doesn't match, the variable is never defined, and the compiler must prevent the code from proceeding.
    

Rust

```Rust
// The enum from our previous lessons
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::Whole; // Test value 1: a non-matching variant.

    // This `let else` checks if `my_beverage` is a `Lowfat` variant.
    // If it is NOT, the `else` block runs.
    let Milk::Lowfat(percent) = my_beverage else {
        // This `else` block runs if the pattern fails.
        // It must contain a terminating expression (like `return;`)
        // to satisfy the compiler.
        println!("You do not have the lowfat milk.");
        return; // Terminates the function early.
    }; // Semicolon needed here to end the `let else` statement.

    // This code only runs if `my_beverage` IS a `Lowfat` variant.
    // The `percent` variable is available from here on out.
    println!("{}% milk is available here.", percent);
}
```

### Part 2: `let else` with a Struct Variant

This part demonstrates the `let else` construct with a **struct variant**. The syntax for the pattern changes from parentheses `()` to curly braces `{}` to match the variant's definition. The core logic and compiler requirements remain the same.

- **Struct Variant Syntax:** The pattern uses curly braces `{}` and the field name (`kind`) to bind the data.
    
- **The Code:** This example shows `let else` being used with the `NonDairy` variant.
    

Rust

```Rust
// The enum from our previous lessons
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let my_beverage = Milk::Lowfat(2); // Test value 1: a non-matching variant.

    // This `let else` checks if `my_beverage` is a `NonDairy` variant.
    let Milk::NonDairy { kind } = my_beverage else {
        println!("You do not have the nondairy milk.");
        return;
    }; // Semicolon needed here to end the `let else` statement.

    // This code only runs if `my_beverage` IS a `NonDairy` variant.
    // The `kind` variable is available from here on out.
    println!("{} milk is available here.", kind);
}
```

### Part 3: The Final Progressive Example

This final part ties both concepts together in a complete program. It uses a mutable variable to demonstrate both the "match succeeds" and "match fails" scenarios within a single function, showcasing the full power of the `let else` construct.

- **`let else` Flow:** The code either executes the `else` block and terminates, or it skips the block, binds the variable, and continues with the rest of the function's code.
    

Rust

```Rust
// The enum from our previous lessons
#[derive(Debug)]
enum Milk {
    Whole,
    Lowfat(i32),
    NonDairy { kind: String },
}

fn main() {
    let mut my_beverage = Milk::NonDairy { kind: String::from("Oat") };
    
    // First scenario: The pattern matches.
    let Milk::NonDairy { kind } = my_beverage else {
        println!("You do not have the nondairy milk.");
        return;
    };
    
    // The pattern matched, so this code runs and the `kind` variable is available.
    println!("The kind of milk is {}.", kind);
    
    // --- Second scenario: The pattern does not match. ---
    
    // Reassign the mutable variable to a non-matching variant.
    my_beverage = Milk::Lowfat(1);
    
    // This `let else` will fail to match.
    let Milk::NonDairy { kind } = my_beverage else {
        println!("\nSwitching to non-nondairy logic.");
        println!("You do not have the nondairy milk.");
        return; // Terminates the function here.
    };
    
    // This line is never reached because the function terminates in the `else` block above.
    println!("The kind of milk is {}.", kind);
}
```

**Final Output:**

```Rust
The kind of milk is Oat.

Switching to non-nondairy logic.
You do not have the nondairy milk.
```
