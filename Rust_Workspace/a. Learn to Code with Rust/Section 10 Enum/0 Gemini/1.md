Variants are the specific, named options that make up an **enum**.1 An enum, short for enumeration, is a data type you define to represent a set of fixed possibilities. Each of these possibilities is called a variant.

### What Variants Mean

Think of an enum as a category, and its variants as the individual items within that category. For example, if the category is `Weekday`, the variants would be `Monday`, `Tuesday`, `Wednesday`, and so on. A variable of type `Weekday` can only hold one of these specific variant values.2

Variants can also hold data, either as a simple tuple or as a named struct.3 This allows a single enum type to represent not just different states, but also different types and amounts of data associated with each state.4

---

### Examples of Variants

In the `TrafficLight` enum below, `Red`, `Yellow`, and `Green` are the variants. A variable named `my_light` can be assigned one of these three values.

Rust

```Rust
// The enum type
enum TrafficLight {
    // The variants
    Red,
    Yellow,
    Green,
}

fn main() {
    // `current_light` is a variable of type `TrafficLight`.
    // Its value is the `Red` variant.
    let current_light = TrafficLight::Red; 
}
```

In this next example, `Message` is an enum with three variants. Each variant holds different data:5

- `Quit` is a simple variant with no data.6
    
- `Move` holds two `i32` values.7
    
- `Write` holds a `String`.8
    

Rust

```Rust
// The enum with its variants
enum Message {
    Quit,
    Move(i32, i32),
    Write(String),
}

fn main() {
    // `my_message` is a variable of type `Message`.
    // Its value is the `Write` variant, holding a String.
    let my_message = Message::Write(String::from("hello"));

    // `quit_message` is a different variant, holding no data.
    let quit_message = Message::Quit;
}
```
