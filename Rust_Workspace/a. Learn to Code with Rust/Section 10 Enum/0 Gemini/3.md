You use **enum struct variants** when you want to give a descriptive name to each piece of data associated with a variant. You use **enum tuple variants** when the meaning of the data is clear from its order and type alone.

---

### Enum Struct Variants 🧱

Use struct variants when the associated data fields are more complex or their purpose isn't immediately obvious. Naming the fields makes your code more readable and self-documenting. This is similar to why you'd use a regular `struct` over a `tuple`.

- **Syntax:** `Variant { name: Type, another_name: Type }`
    
- **When to use:** When you need to add clarity to the data. This is especially helpful if the variant holds multiple values of the same type.
    

#### Example: `UserEvent`

In this example, the `Click` variant's data is more clear with named fields, distinguishing the `x` and `y` coordinates. The `Login` variant's fields are also self-explanatory.

Rust

```Rust
enum UserEvent {
    Click { x: i32, y: i32 },
    Login { username: String, password: String },
    Logout,
}

let click = UserEvent::Click { x: 100, y: 200 };
let login = UserEvent::Login { 
    username: String::from("alice"), 
    password: String::from("secret"),
};
```

---

### Enum Tuple Variants 📦

Use tuple variants for simple, straightforward data where the meaning of each value is obvious from its position. This syntax is more concise than a struct variant.

- **Syntax:** `Variant(Type, Type)`
    
- **When to use:** When the variant holds a single value, or when the data is a simple pair of values that's easily understood, like dimensions or coordinates.
    

#### Example: `Command`

Here, the `Write` variant holds a single string, so a tuple variant is perfect.1 For `Move`, the data is a standard coordinate pair, so `(i32, i32)` is concise and clear.

Rust

```Rust
enum Command {
    Quit,
    Move(i32, i32),
    Write(String),
    ChangeColor(i32, i32, i32),
}

let move_cmd = Command::Move(50, -30);
let write_cmd = Command::Write(String::from("hello"));
let color_cmd = Command::ChangeColor(255, 128, 0);
```

### Quick Reference

|Feature|Struct Variant (`{}`)|Tuple Variant (`()`)|
|---|---|---|
|**Clarity**|High (data is named)|Low (data is positional)|
|**Conciseness**|Lower (more verbose)|Higher (more compact)|
|**Best For**|Complex data, multiple values of the same type, self-documentation.|Simple data, single values, standard coordinate pairs.|
