### 1. What is a Hash Map?

A **hash map** is a collection type that stores pairs of data: a **key** and a corresponding **value**. In other programming languages, this data structure is also known as a dictionary, a hash, an associative array, or a map.

- **Key-Value Pairs:** Each entry in a hash map is a unique key linked to a value.
    
- **Unique Keys:** The key must be unique, as it serves as the identifier for searching for and retrieving its associated value.
    
- **Duplicate Values:** The values can contain duplicates.
    
- **No Inherent Order:** Unlike arrays or vectors, a hash map does not maintain any specific order. Its purpose is to provide a fast lookup from a key to its value, not to store a sequenced collection.
    
- **Memory:** Hash maps are stored on the heap because their size is dynamic and unpredictable at compile time.
    

### 2. Hash Map Syntax and Creation

To use a hash map, you first need to bring it into scope from the standard library. The type name is `HashMap`.

- **Import:** You must import `HashMap` from the `std::collections` module.
    
    Rust
    
    ```Rust
    use std::collections::HashMap;
    ```
    
- **Generics:** A `HashMap` is a generic type that requires two concrete types: one for the keys and one for the values.
    
    - `HashMap<K, V>`: `K` is the type for the keys, and `V` is the type for the values.
        
- **Creation:** The most common way to create an empty hash map is with the `new()` constructor function.
    

#### Code Example: Creating an Empty HashMap

Rust

```Rust
use std::collections::HashMap;

fn main() {
    // Creating an empty hash map with an explicit type annotation.
    // The keys are `String`s and the values are `f64`s.
    let mut menu: HashMap<String, f64> = HashMap::new();

    // The turbofish operator can also be used for explicit type annotation.
    let mut country_capitals = HashMap::<&str, &str>::new();
}
```

### 3. Adding Key-Value Pairs

To add data to a hash map, you use the `insert()` method. The hash map must be mutable to allow new entries.

- **`insert(key, value)`:** This method takes two arguments: the key and the value. The types of these arguments must match the generic types defined for the hash map.
    
- **Mutability:** The hash map variable must be declared with `mut` to allow for the `insert()` method to be called on it.
    

#### Code Example: Inserting Values

Rust

```Rust
use std::collections::HashMap;

fn main() {
    let mut menu: HashMap<String, f64> = HashMap::new();
    menu.insert(String::from("Steak"), 29.99);
    menu.insert(String::from("Tuna"), 29.99); // Values can be duplicates.
    menu.insert(String::from("Burger"), 14.99); // Keys must be unique.

    let mut country_capitals = HashMap::<&str, &str>::new();
    country_capitals.insert("France", "Paris");
    country_capitals.insert("Germany", "Berlin");

    // Hash maps do not implement `Display`, but do implement `Debug`.
    println!("Restaurant Menu: {:?}", menu);
    println!("Country Capitals: {:?}", country_capitals);
}
```

### 4. Type Inference with Hash Maps

When you create a hash map with the `new()` constructor, Rust cannot infer the types of the keys and values if the map is empty. However, as soon as you insert the first key-value pair, the compiler can deduce the types and make the type annotation optional.

#### Code Example: Type Inference

Rust

```Rust
use std::collections::HashMap;

fn main() {
    let mut country_capitals = HashMap::new(); // Type is initially unknown.
    
    // Rust now infers the type of the hash map from the first insertion.
    // The keys are inferred as `&str`, and the values are inferred as `&str`.
    country_capitals.insert("France", "Paris");
    
    // The compiler now knows the types, so subsequent insertions must match.
    country_capitals.insert("Germany", "Berlin");
    
    println!("{:?}", country_capitals);
}
```

### 5. Summary

- A hash map is a collection of key-value pairs used for establishing **relationships** and **associations**.
    
- The `HashMap` type is generic over its key type (`K`) and value type (`V`).
    
- The `new()` constructor creates an empty hash map, which typically requires a type annotation if it is not immediately populated.
    
- The `insert()` method adds a new key-value pair. Keys must be unique, while values can contain duplicates.
    
- Hash maps are ideal for fast lookups and are a core tool for modeling relationships in your programs.
