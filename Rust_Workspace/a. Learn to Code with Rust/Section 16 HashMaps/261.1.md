# Rust HashMap Guide

## What is a HashMap?

A HashMap is a collection type that stores pairs of keys and values, establishing connections between two values in your program. In other languages, this data structure is also called a dictionary, hash, associative array, or map.

## Key Characteristics

- **Keys must be unique** - Each key can only appear once
- **Values can have duplicates** - Multiple keys can map to the same value
- **No guaranteed order** - Don't assume any ordering of elements
- **Heap allocated** - Size can change during program execution
- **Fast lookups** - Uses hashing for efficient key-to-value retrieval

## When to Use HashMap

Use a HashMap when you need to establish relationships between values, like:

- Restaurant menu items to prices
- Country names to capitals
- User IDs to user data

Use vectors/arrays when you need ordered data.

## Creating a HashMap

### Import the HashMap type:

```rust
use std::collections::HashMap;
```

### Basic creation with type annotation:

```rust
let mut menu: HashMap<String, f64> = HashMap::new();
```

### Alternative syntax with turbofish operator:

```rust
let mut menu = HashMap::<String, f64>::new();
```

### Type inference (after inserting data):

```rust
let mut menu = HashMap::new();
menu.insert("Steak".to_string(), 29.99); // Rust infers types
```

## Adding Data

Use the `insert()` method to add key-value pairs:

```rust
let mut menu: HashMap<String, f64> = HashMap::new();

menu.insert("Steak".to_string(), 29.99);
menu.insert("Tuna".to_string(), 29.99);   // Same value, different key
menu.insert("Burger".to_string(), 14.99);
```

## Example with Different Types

```rust
let mut country_capitals: HashMap<&str, &str> = HashMap::new();

country_capitals.insert("France", "Paris");
country_capitals.insert("Germany", "Berlin");
```

## Displaying HashMap Contents

HashMaps implement the Debug trait but not Display:

```rust
println!("{:?}", menu);
// Output: {"Steak": 29.99, "Tuna": 29.99, "Burger": 14.99}
```

## Key Points

- HashMap is found in `std::collections::HashMap`
- Must be declared as `mut` if you plan to modify it
- Keys are used as search points to retrieve corresponding values
- Very fast for key-based lookups due to hashing algorithm
- Perfect for establishing associations and mappings between data
