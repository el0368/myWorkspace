# Comparing HashSets in Rust

This document outlines key methods for comparing two `HashSet`s in Rust, focusing on mathematical set operations as described in the provided transcript.

## Setup

- **HashSets**: Two mutable `HashSet<&str>` instances are used:
    - `concert_queue`: Contains `"Boris"` and `"Melissa"`.
    - `movie_queue`: Contains `"Boris"` and `"Phil"`.
- **Common Element**: `"Boris"` is present in both sets.

## Comparison Methods

### 1. Union (`union`)

- **Purpose**: Returns a `Union` struct containing all unique elements from both `HashSet`s (no duplicates).
- **Syntax**: `concert_queue.union(&movie_queue)`.
- **Output**: Includes elements from both sets, e.g., `["Boris", "Melissa", "Phil"]`.
- **Notes**:
    - Order is not guaranteed.
    - Returns a `Union` struct, not a `HashSet`, but supports `Debug` formatting for printing.
- **Example**:
    
    ```rust
    println!("{:?}", concert_queue.union(&movie_queue)); // Outputs: ["Boris", "Melissa", "Phil"]
    println!("{:?}", movie_queue.union(&concert_queue)); // Same output, order may vary
    ```
    

### 2. Difference (`difference`)

- **Purpose**: Returns a `Difference` struct with elements in the first `HashSet` that are not in the second.
- **Syntax**: `concert_queue.difference(&movie_queue)`.
- **Output**:
    - `concert_queue.difference(&movie_queue)`: `["Melissa"]` (in `concert_queue`, not in `movie_queue`).
    - `movie_queue.difference(&concert_queue)`: `["Phil"]` (in `movie_queue`, not in `concert_queue`).
- **Example**:
    
    ```rust
    println!("{:?}", concert_queue.difference(&movie_queue)); // Outputs: ["Melissa"]
    println!("{:?}", movie_queue.difference(&concert_queue)); // Outputs: ["Phil"]
    ```
    

### 3. Symmetric Difference (`symmetric_difference`)

- **Purpose**: Returns a `SymmetricDifference` struct with elements in either `HashSet` but not in both.
- **Syntax**: `concert_queue.symmetric_difference(&movie_queue)`.
- **Output**: `["Melissa", "Phil"]` (elements exclusive to one set).
- **Example**:
    
    ```rust
    println!("{:?}", concert_queue.symmetric_difference(&movie_queue)); // Outputs: ["Melissa", "Phil"]
    ```
    

### 4. Disjoint Check (`is_disjoint`)

- **Purpose**: Returns `true` if the two `HashSet`s have no elements in common, `false` otherwise.
- **Syntax**: `concert_queue.is_disjoint(&movie_queue)`.
- **Output**: `false` (because `"Boris"` is in both sets).
- **Example**:
    
    ```rust
    println!("{}", concert_queue.is_disjoint(&movie_queue)); // Outputs: false
    ```
    

### 5. Subset Check (`is_subset`)

- **Purpose**: Returns `true` if all elements in the first `HashSet` are in the second.
- **Syntax**: `concert_queue.is_subset(&movie_queue)`.
- **Output**: `false` (because `"Melissa"` is not in `movie_queue`).
- **Example with Subset**:
    
    ```rust
    let mut attendees: HashSet<&str> = HashSet::new();
    attendees.insert("Boris");
    println!("{}", attendees.is_subset(&concert_queue)); // Outputs: true ("Boris" is in concert_queue)
    ```
    

### 6. Superset Check (`is_superset`)

- **Purpose**: Returns `true` if the first `HashSet` contains all elements of the second.
- **Syntax**: `concert_queue.is_superset(&attendees)`.
- **Output**: `true` (because `concert_queue` contains `"Boris"`, all elements of `attendees`).
- **Example**:
    
    ```rust
    println!("{}", concert_queue.is_superset(&attendees)); // Outputs: true
    ```
    

## Key Takeaways

- **Mathematical Set Operations**: Methods like `union`, `difference`, `symmetric_difference`, `is_disjoint`, `is_subset`, and `is_superset` enable common set comparisons.
- **Return Types**: These methods return special structs (e.g., `Union`, `Difference`) that support `Debug` formatting, not `HashSet`s.
- **No Order Guarantee**: Results do not maintain a specific order, as `HashSet`s prioritize uniqueness over order.
- **Safety and Flexibility**: These methods allow safe comparison of `HashSet`s, identifying commonalities or differences without modifying the original sets.
- **References**: Methods take a reference to the second `HashSet` (e.g., `&movie_queue`) to avoid ownership issues.

These operations make `HashSet` a powerful tool for comparing collections of unique elements in Rust.
