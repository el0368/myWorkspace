### 2. The Logic Stack (The "Partners")

_Emil does not make these. You cannot build the platform without them._

To make the UI work, you **must** add these three standard Rust crates. They are the industry standard partners to `egui`.

1. **`tokio`** (The Engine)
    
    - **Why:** `egui` is single-threaded (it runs on the UI thread). If you fetch stock prices on the UI thread, your window freezes.
        
    - **Usage:** You spawn a background task (`tokio::spawn`) to listen for price updates.
        
2. **`reqwest`** (The Fetcher)
    
    - **Why:** To connect to the API (Binance, Alpaca, etc.) and download the Scanner data.
        
    - **Usage:** `reqwest::get("https://api.market/stocks")`.
        
3. **`serde`** (The Translator)
    
    - **Why:** The API sends text (JSON). Rust needs Structs.
        
    - **Usage:** It converts incoming data into your `Stock` struct automatically.
