Here is how to calculate a factorial in Rust using recursion.

Rust

```Rust
fn factorial(n: u64) -> u64 {
    // Base case: 0! is defined as 1. This stops the recursion.
    if n == 0 {
        1
    } else {
        // Recursive step: n! = n * (n-1)!
        n * factorial(n - 1)
    }
}
```

---

### How It Works 🔢

The function relies on two key components:

1. **Base Case**: The `if n == 0` condition is the **base case**. It provides a direct answer for the smallest input (`0! = 1`) and prevents the function from calling itself infinitely.
    
2. **Recursive Step**: The `else` block is the **recursive step**. It breaks the problem down into a smaller version of itself by calculating the factorial of `n - 1` and then multiplying the result by `n`.
    

For example, factorial(4) unwinds like this:

4 * factorial(3) → 4 * (3 * factorial(2)) → 4 * (3 * (2 * factorial(1))) → 4 * (3 * (2 * (1 * factorial(0))))

Once it hits the base case factorial(0), which returns 1, the chain of multiplications resolves:

4 * 3 * 2 * 1 * 1 = 24

### Example Usage

Here is a complete, runnable example.

Rust

```Rust
// The recursive factorial function
fn factorial(n: u64) -> u64 {
    if n == 0 {
        1
    } else {
        n * factorial(n - 1)
    }
}

fn main() {
    let num = 5;
    let result = factorial(num);
    // The factorial of 5 is 120
    println!("The factorial of {} is {}", num, result);

    let num = 10;
    let result = factorial(num);
    // The factorial of 10 is 3628800
    println!("The factorial of {} is {}", num, result);
}
```
