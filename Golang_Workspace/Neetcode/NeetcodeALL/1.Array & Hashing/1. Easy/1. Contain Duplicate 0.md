Of course! The problem "Contains Duplicate" is a classic and very useful programming puzzle.

The goal is to write a function that checks if a list of numbers has any duplicates in it. If it finds a number more than once, it should return `true`. If all the numbers are unique, it should return `false`.

Let's solve this using the clever **map** data structure we just learned about!

---

## The Plan (Our Algorithm)

The most efficient way to solve this is to keep track of the numbers we've already seen. A map is the perfect tool for this.

Analogy: The Party Guest List 📋

Imagine you are a security guard at a party. Your job is to check guests in and make sure nobody with the same name enters twice.

1. You start with a **blank clipboard** (this will be our empty `map`).
    
2. For each **guest** (each `number` in our slice) that arrives:
    
3. You first check your clipboard: **"Is this name already on my list?"**
    
4. If **YES**, you've found a duplicate! You can stop immediately and raise an alarm (`return true`).
    
5. If **NO**, you write their name on the clipboard to remember you've seen them, and then you let them pass.
    
6. If you get through the entire line of guests and never find a duplicate, you can report that everything is fine (`return false`).
    

---

## The Go Code

This Go code follows our "Guest List" plan exactly.

Go

```Go
package main

import "fmt"

// containsDuplicate takes a slice of integers.
// It returns 'true' if any number appears more than once, and 'false' otherwise.
func containsDuplicate(numbers []int) bool {
    // 1. We create our "clipboard", which is an empty map.
    // The key will be the number we've seen (int).
    // The value will just be 'true' (bool) to mark that we've seen it.
    seen := make(map[int]bool)

    // 2. We loop through each number in the slice.
    for _, number := range numbers {

        // 3. We check our "clipboard" (the map).
        // This is a special two-part check in Go.
        // The 'ok' variable will be 'true' if the number was already in the map.
        if _, ok := seen[number]; ok {
            // 4. If 'ok' is true, we have found a duplicate! We can stop.
            return true
        }

        // 5. If the number was not in the map, we add it to our "clipboard"
        // so we can remember we've seen it for next time.
        seen[number] = true
    }

    // 6. If the loop finishes without ever finding a duplicate, we can report false.
    return false
}

func main() {
    listWithDuplicates := []int{8, 2, 0, 1, 5, 2} // Contains '2' twice
    listWithoutDuplicates := []int{8, 2, 0, 1, 5}

    fmt.Println("Does the first list contain a duplicate?", containsDuplicate(listWithDuplicates))
    fmt.Println("Does the second list contain a duplicate?", containsDuplicate(listWithoutDuplicates))
}
```

### The Output

```
Does the first list contain a duplicate? true
Does the second list contain a duplicate? false
```

## Big O Rating

This solution is very fast! Its "slowness rating" is `[[O(n) - Slow (Linear)]]`.

This is because we only have to loop through the list of `n` numbers one single time. Each check and addition to the map is, on average, an `[[O(1) - Instant]]` action. This makes it a very efficient solution.
