While slices are dynamic, you cannot add a new element by trying to assign a value to an index that doesn't exist yet. Doing so will cause your program to crash.

The correct way to add elements to a slice is by using Go's built-in **`append`** function.

---

### How `append` Works

The most crucial concept to understand is that `append` does **not** modify the slice you pass to it. Instead, it **returns a new, updated slice** that includes the added element(s).

The reason for this is that the original slice's underlying array might not have enough capacity for the new elements. In that case, `append` will create a brand new, larger array and return a slice that points to it.

---

### The Correct Pattern: Reassigning the Result

Because `append` returns a new slice, the correct and necessary pattern is to reassign the result back to your original slice variable.

Go

```Go
slice = append(slice, elementToAdd)
```

This updates your variable to point to the new slice (and potentially the new underlying array) that `append` created.

Go

```Go
package main

import "fmt"

func main() {
    prices := []float64{10.99, 8.99}
    fmt.Println("Original slice:", prices)

    // Append a new value.
    // The result is reassigned back to the 'prices' variable.
    prices = append(prices, 5.99)
    prices = append(prices, 2.99, 1.99) // You can append multiple elements at once.

    fmt.Println("Updated slice:", prices)
}
```

**Output:**

```
Original slice: [10.99 8.99]
Updated slice: [10.99 8.99 5.99 2.99 1.99]
```

Forgetting to reassign the result (`append(prices, 5.99)` without the `prices =`) is a common mistake. If you do that, the original `prices` slice will remain unchanged, and the new element will be lost.
