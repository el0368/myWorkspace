Every slice in Go has two properties that describe its relationship with its underlying array: **length** and **capacity**. Understanding the difference between them is key to using slices effectively.

---

### Definitions

- **Length**: The number of elements the slice currently contains. You get this using the built-in `len()` function.
    
- **Capacity**: The number of elements in the underlying array, counting from the first element of the slice to the end of the array. You get this using the built-in `cap()` function.
    

Capacity tells you how much the slice can grow by "reslicing" before it needs to be reallocated in memory.

---

### When Length and Capacity Differ

The difference between length and capacity becomes clear when you create a slice from another slice.

Go

```Go
package main

import "fmt"

func main() {
    // Start with an array of 5 elements.
    prices := [5]float64{10.99, 9.99, 45.99, 20.0, 50.0}
    // Indices:             0      1      2       3      4

    // Create a slice that views elements from index 1 to the end.
    featuredPrices := prices[1:4] // Views [9.99, 45.99, 20.0]

    fmt.Printf("featuredPrices: Length=%d, Capacity=%d\n", len(featuredPrices), cap(featuredPrices))
}
```

**Output:**

```Go
featuredPrices: Length=3, Capacity=4
```

**Explanation:**

- **Length is 3**: Because `featuredPrices` contains three elements (`9.99`, `45.99`, `20.0`).
    
- **Capacity is 4**: Because the underlying array, starting from the first element of the slice (`9.99`), has four available slots until its end (`9.99`, `45.99`, `20.0`, `50.0`). The capacity doesn't include the `10.99` because it's "to the left" of the slice's starting point.
    

---

### The Power of Capacity: Reslicing

The capacity tells you how much a slice can expand without needing new memory. Because Go knows `featuredPrices` has a capacity of 4, you can reslice it to include more elements from the underlying array.

Go

```Go
func main() {
    prices := [5]float64{10.99, 9.99, 45.99, 20.0, 50.0}
    featuredPrices := prices[1:4] // len=3, cap=4

    fmt.Println("Original slice:", featuredPrices)

    // Reslice to include all elements up to its full capacity.
    featuredPrices = featuredPrices[:cap(featuredPrices)]

    fmt.Println("Resliced to full capacity:", featuredPrices)
    fmt.Printf("New Length: %d, New Capacity: %d\n", len(featuredPrices), cap(featuredPrices))
}
```

**Output:**

```Go
Original slice: [9.99 45.99 20]
Resliced to full capacity: [9.99 45.99 20 50]
New Length: 4, New Capacity: 4
```

Even though `featuredPrices` originally had only 3 elements, its capacity of 4 allowed it to be expanded to reveal the `50.0` from the underlying array. This is a powerful and efficient feature, but remember you can only expand a slice to the right, not to the left.
