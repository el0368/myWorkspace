A **slice** is a powerful feature in Go that lets you work with a **subset**, or a "part," of an array.1 While you can access the entire array or a single element, a slice gives you the flexibility to select a continuous portion of it.2

Think of a slice as a **view** or a **window** into a section of an array.

---

### The Slicing Syntax `[start:end]`

You create a slice from an existing array using square bracket notation with a colon.3 The syntax is `array[start:end]`.

This expression creates a new slice that includes elements from the `start` index up to, but **not including**, the `end` index.4

- **`start`**: The index of the first element to be included (**inclusive**).
    
- **`end`**: The index of the first element to be excluded (**exclusive**).5
    

Go

```Go
package main

import "fmt"

func main() {
    prices := [4]float64{10.99, 9.99, 45.99, 20.0}
    // Indices:          0      1      2       3

    // Create a slice that includes elements from index 1 up to (but not including) index 3.
    // This will include elements at index 1 and 2.
    featuredPrices := prices[1:3]

    fmt.Println(featuredPrices) // Output: [9.99 45.99]
}
```

---

### Slicing Shortcuts

Go provides two convenient shortcuts for slicing from the beginning or to the end of an array.

#### 1. Omitting the Start Index

If you omit the `start` index (`[:end]`), the slice will automatically start from the beginning of the array (index 0).

Go

```Go
// Get the first two elements.
// prices[:2] is a shortcut for prices[0:2].
firstTwoPrices := prices[:2]
fmt.Println(firstTwoPrices) // Output: [10.99 9.99]
```

#### 2. Omitting the End Index

If you omit the `end` index (`[start:]`), the slice will include all elements from the `start` index all the way to the end of the array.

Go

```Go
// Get all elements except the first one.
allButFirst := prices[1:]
fmt.Println(allButFirst) // Output: [9.99 45.99 20]
```
