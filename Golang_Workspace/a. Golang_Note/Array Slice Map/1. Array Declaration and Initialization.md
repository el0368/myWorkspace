An array in Go is a **fixed-size** collection of elements that are all of the **same type**.1 You must define its size when you create it, and that size cannot be changed later.2

---

### Declaring an Array

The primary way to declare an array is using the `var` keyword, followed by the variable name and the type.3 The type consists of the length in square brackets and the data type of its elements.4


```Go
var productNames [4]string // Declares an array that holds 4 strings
```

### Zero-Value Initialization

If you declare an array without assigning any values, Go automatically initializes it for you. Each element is set to the **"zero value"** for its type.5

- For `string`, the zero value is an empty string (`""`).
    
- For numbers like int or float64, the zero value is 0.
    
- For bool, the zero value is false.
    

This ensures that the array has a valid, non-null value from the start, preventing crashes from uninitialized variables.



```Go
// This will print: [  ] (an array of four empty strings)
fmt.Println(productNames)
```

---

### Initialization with Literals

You can also declare and initialize an array in one step using an array literal.6



```Go
prices := [4]float64{10.99, 9.99, 45.99, 20.0}
```

You don't have to provide all the values. If you provide fewer values than the array's length, the remaining elements are automatically set to their zero value.7



```Go
// This creates an array of 4 elements: [A Book, "", "", ""]
productNames := [4]string{"A Book"}
```
