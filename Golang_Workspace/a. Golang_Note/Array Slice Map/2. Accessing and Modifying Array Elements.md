To work with individual values within an array, you use their **index**. An index is a number that represents an element's position in the array.

---

### The Core Concept: Zero-Based Indexing

The most important rule to remember is that Go arrays (like those in most programming languages) use **zero-based indexing**.

- The **first** element is at index **0**.
    
- The **second** element is at index **1**.
    
- The **third** element is at index **2**.
    
- ...and so on.
    

For an array of length 4, the valid indexes are 0, 1, 2, and 3. Forgetting this and trying to access the "fourth" element at index 4 will result in an error.

---

### Accessing (Reading) an Element

To read a single value from an array, you use **square bracket notation** after the variable name, placing the index inside the brackets.

Go

```Go

package main

import "fmt"

func main() {
    prices := [4]float64{10.99, 9.99, 45.99, 20.0}

    // To access the third price (45.99), we use index 2.
    thirdPrice := prices[2]

    fmt.Println("The third price in the list is:", thirdPrice) // Output: 45.99
}
```

This is different from a `struct`, where you use dot notation (e.g., `user.name`). For arrays, you must use square brackets and the element's numerical position.

---

### Modifying (Writing) an Element

You use the exact same square bracket notation to change or set the value of an element. You specify the index you want to change and assign it a new value.

Go

```Go

package main

import "fmt"

func main() {
    // Declare an array with some zero-value slots.
    productNames := [4]string{"A Book"}
    fmt.Println("Initial array:", productNames) // Output: [A Book   ]

    // Set the value of the third element (at index 2).
    productNames[2] = "A Carpet"

    fmt.Println("Modified array:", productNames) // Output: [A Book  A Carpet ]
}
```

This shows how you can target specific slots in the array to either set an initial value or update an existing one, without affecting the other elements.
