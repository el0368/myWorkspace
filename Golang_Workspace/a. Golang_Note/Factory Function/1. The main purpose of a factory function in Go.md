The main purpose of a **factory function** in Go is to ensure a **struct** is always created in a valid and consistent state. It acts as a controlled entry point for creating objects.1

Key purposes include:

- **Validation ✅**: It prevents the creation of a struct with invalid or missing data.
    
- **Encapsulation 💊**: It hides complex setup logic from the user.2
    
- **Consistency 🤝**: It guarantees that every instance is initialized the same way.
    

---

### ## Components of a Factory Function

A well-structured factory function in Go is made of these components:

1. **Function Signature**: The function is conventionally named **`New<TypeName>`**. It accepts the data needed to create the struct and returns two values: a pointer to the newly created struct (`*<TypeName>`) and an **`error`**.
    
2. **Validation Logic**: Inside the function, you first check if the input parameters are valid. If not, you return `nil` and a descriptive error.
    
3. **Instance Creation**: If validation passes, you create an instance of the struct using a struct literal (`&TypeName{...}`).
    
4. **Successful Return**: You return a pointer to the new instance and a `nil` error to signal that the creation was successful.
    

### Example

Here is a full example showing all the components.

Go

```Go
package main

import (
	"fmt"
)

type User struct {
	ID    string
	Email string
}

// The Factory Function
func NewUser(id, email string) (*User, error) { // 1. Function Signature
	// 2. Validation Logic
	if id == "" || email == "" {
		return nil, fmt.Errorf("id and email cannot be empty")
	}

	// 3. Instance Creation
	user := &User{
		ID:    id,
		Email: email,
	}

	// 4. Successful Return
	return user, nil
}
```
