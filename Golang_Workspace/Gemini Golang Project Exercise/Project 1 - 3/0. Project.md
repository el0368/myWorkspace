## Project 1: E-commerce Product Catalog

We need a simple tool to manage our product catalog. The program should allow us to add new products and then display all the products we've added.

**Requirements:**

- We need a function that allows us to add a new product to our list.

## Project 2: Employee Directory

We're looking to create a basic employee directory. The main goal is to store employee information and be able to look up an employee by their ID.

**Requirements:**

- An **employee** record must contain an **Employee ID** (string), **First Name**, **Last Name**, **Position**, and their **contact information**.
    
- The **contact information** should be its own unit, containing the employee's **email** and **phone number**. This should be part of the employee record.
    
- The system needs to be able to add a new employee to the directory.
    
- Crucially, we need a function that can find and display a single employee's full details when we search by their **Employee ID**.
