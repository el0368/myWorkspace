## 🛠️ Key Technical Concepts

To succeed in today’s lab, keep these three "pillars" in mind:

1. **Orchestration:** This isn't just about calling an API; it's about building a system that can send a coding task to Claude, a summarization task to GPT-4o mini, and a high-speed check to Groq, all within one workflow.
    
2. **Inference & Runtime:** You'll be distinguishing between the _model_ (like Llama 3) and the _provider_ (like Groq or Ollama) that runs it.
    
3. **Distillation:** This is why "smaller" models like DeepSeek-R1-Distill-Llama are so smart—they were "taught" by much larger, more expensive models.
