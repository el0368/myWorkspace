### 3. The "Next" Core Idea: Handoffs (Transfer of Control)

The speaker mentions that there are two ways for agents to collaborate. You just finished **"Agents as Tools"** (which is a **Manager/Worker** relationship). The next big concept is **"Handoffs."**

**The difference is crucial:**

- **Agents as Tools (Delegation):** Agent A calls Agent B. Agent B does the work and returns the result to Agent A. Agent A stays in control the whole time.
    
- **Handoffs (Transfer):** Agent A decides it is no longer the right person for the job and "hands the baton" to Agent B. Agent B is now in charge of the conversation with the user.
    

|**Feature**|**Agents as Tools**|**Handoffs**|
|---|---|---|
|**Control**|Stays with the original Manager.|Passes to the new Agent.|
|**History**|Result is appended to Manager's context.|The entire conversation "moves" to the new Agent.|
|**Analogy**|A boss asking an employee for a report.|A receptionist transferring your call to a specialist.|
