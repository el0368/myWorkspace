# Week 2 Day 3: Mastering the Agentic Toolkit

This document breaks down the advanced features of the OpenAI Agents SDK by focusing on the "Tooling Workflow." We look at the **Concept**, how to **Input** data into the tool, the **Process** it performs, and the final **Output** it produces.

## 1. Multi-Model Integration (The Universal Connector)

**The Concept:** Using a single "remote control" (the SDK) to drive different "engines" (Gemini, DeepSeek, Groq). You don't change your logic; you just swap the engine.

### How to use the Tool:

- **Input (Defining the Engine):** You provide a `base_url` (the provider's address) and an `api_key`.
    
- **The Process (Wrapping):** Use the `OpenAIChatCompletionsModel` tool to "translate" the raw API into a format the SDK understands.
    
- **Output (The Brain):** A `model` object assigned to an Agent.
    

Example Implementation:

Shows how to define different model "engines" for specific purposes.

```python
from openai import AsyncOpenAI
from agents import Agent, OpenAIChatCompletionsModel

# Define the DeepSeek "Engine" - Great for cost-effective reasoning
# base_url is the key here; it tells the client to go to DeepSeek instead of OpenAI
deepseek_client = AsyncOpenAI(base_url="[https://api.deepseek.com](https://api.deepseek.com)", api_key="YOUR_KEY")
deepseek_model = OpenAIChatCompletionsModel(model="deepseek-chat", openai_client=deepseek_client)

# Define the Gemini "Engine" - Great for large context and creative tasks
gemini_client = AsyncOpenAI(
    base_url="[https://generativelanguage.googleapis.com/v1beta/openai/](https://generativelanguage.googleapis.com/v1beta/openai/)", 
    api_key="YOUR_KEY"
)
gemini_model = OpenAIChatCompletionsModel(model="gemini-1.5-flash", openai_client=gemini_client)

# Define the Groq "Engine" - Using Llama 3.3 for high-speed inference
groq_client = AsyncOpenAI(base_url="[https://api.groq.com/openai/v1](https://api.groq.com/openai/v1)", api_key="YOUR_KEY")
groq_model = OpenAIChatCompletionsModel(model="llama-3.3-70b-versatile", openai_client=groq_client)

# Assign engines to specific agents to specialize their intelligence
agent_ds = Agent(name="DeepSeek Expert", model=deepseek_model)
agent_gm = Agent(name="Gemini Creative", model=gemini_model)
agent_l3 = Agent(name="Llama 3 Speedy", model=groq_model)
```

## 2. Structured Outputs (The Data Sculptor)

**The Concept:** Forcing an AI to fill out a digital form instead of writing text. This turns "chatting" into "data processing."

### How to use the Tool:

- **Input (The Blueprint):** Define a Pydantic `BaseModel` with your required fields.
    
- **The Process (Enforcement):** Pass this blueprint into the Agent using `output_type`.
    
- **Output (The Object):** `Runner.run()` returns a Python **Object** instead of a string.
    

Example Implementation:

Shows how to turn an agent's research into a usable, reliable Python object.

```
from pydantic import BaseModel

# 1. Input: The Blueprint (Schema)
# We define exactly what fields we want the AI to capture
class NameCheckOutput(BaseModel):
    is_name_in_message: bool # True/False check
    name: str | None # Captures the specific name found

# 2. Process: Assign the schema to a guardrail agent
guardrail_agent = Agent(
    name="NameCheck",
    instructions="Check if the user is including someone's personal name.",
    output_type=NameCheckOutput, # Forces JSON response
    model="gpt-4o-mini"
)

# 3. Output: Accessing the structured object
result = await Runner.run(guardrail_agent, "Email Alice at Acme.")
# The result is already a Python object. No string parsing required.
if result.final_output.is_name_in_message:
    print(f"Found name: {result.final_output.name}")
```

## 3. Guardrails (The Execution Gatekeeper)

**The Concept:** Automated "tripwires" that monitor data. If data is unsafe, the tool "breaks" the circuit and stops execution immediately.

### How to use the Tool:

- **Input (The Decorator):** Mark an async function with `@input_guardrail` or `@output_guardrail`.
    
- **The Process (Validation):** Inside the function, run a check (logic or another agent).
    
- **Output (The Tripwire):** Return a `GuardrailFunctionOutput`. If `trip_wire_triggered=True`, the SDK raises an **Exception**.
    

Example Implementation:

Uses an agent inside a guardrail to enforce privacy rules.

```
from agents import input_guardrail, GuardrailFunctionOutput

# run_in_parallel=False ensures we don't start the main agent until this passes
@input_guardrail(run_in_parallel=False) 
async def guardrail_against_name(context, agent, message):
    # Run our structured output agent from section 2
    check = await Runner.run(guardrail_agent, message)
    
    # Logic: Trip the wire if a name was detected
    triggered = check.final_output.is_name_in_message
    
    # Return output_info for the Trace log and the trip status
    return GuardrailFunctionOutput(
        output_info={"reason": "PII Name detected", "found": check.final_output.name},
        trip_wire_triggered=triggered
    )

# The Sales Manager is now protected by the guardrail
careful_manager = Agent(
    name="Careful Manager",
    input_guardrails=[guardrail_against_name],
    model="gpt-4o-mini"
)
```

## 4. The Runner (The Orchestrator)

**The Concept:** If the Agent is the "brain," the **Runner** is the "body." It is the engine that actually executes the logic and manages the "Agentic Loop."

### How to use the Tool:

- **Input:** `Runner.run(agent, input)`.
    
- **Process:** Handles Tool Calls, Handoffs, and parallel executions.
    
- **Jupyter Note:** In notebooks, you must use `await` directly and ensure `nest_asyncio.apply()` is run at the top.
    

**Example Process:**

```
# In Jupyter/Cursor Notebooks
import nest_asyncio
nest_asyncio.apply() # Fixes event loop errors in notebooks

# We can now 'await' the runner directly
result = await Runner.run(careful_manager, "Send email to CEO from Alice")

# If the guardrail trips, it raises an Exception, stopping the code right here.
```

## 5. Tracing (The Flight Recorder)

**The Concept:** A visual map of every step. Essential for seeing when agents go into "infinite loops" or parallel paths.

**Example Trace Hierarchy:**

- **Trace (The Folder)**
    
    - `guard_span`: Did the name check pass? -> NO (Tripwire!)
        
    - _Result:_ Process stopped. The main model never fired, saving tokens.
        

## 6. Review: Tools vs. Handoffs

|   |   |
|---|---|
|**Tool (Agent as Tool)**|**Handoff (Transfer)**|
|`agent.as_tool()`|`handoffs=[agent]`|
|Like a "sub-routine" or "function call."|Like "passing the baton" to a new expert.|
|**Sales Manager** calls **SubjectWriter** tool.|**Sales Manager** hands off to **EmailerAgent**.|
