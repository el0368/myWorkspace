สคริปต์นี้คือ **คู่มือการเซตอัปสภาพแวดล้อม (Environment Setup)** สำหรับผู้ใช้ Windows โดยเฉพาะครับ Ed Donner เน้นย้ำว่าขั้นตอนนี้สำคัญที่สุดเพื่อให้คุณรันโปรเจกต์ในคอร์สได้สำเร็จ

สรุปสิ่งที่ต้องเตรียมและขั้นตอน 5+1 อย่างละเอียดมีดังนี้ครับ:

---

### ⚠️ สิ่งที่ต้องระวังก่อนเริ่ม (Gotchas)

- **Long Paths:** Windows มักจำกัดชื่อไฟล์ไม่เกิน 260 ตัวอักษร ให้คุณปลดล็อคข้อจำกัดนี้ (LongPathsEnabled) เพื่อป้องกันการติดตั้ง Library พัง
    
- **Antivirus:** ระวังซอฟต์แวร์สแกนไวรัสบล็อกการติดตั้งในบางขั้นตอน
    

---

### 🛠️ 5 ขั้นตอนหลักในการเซตอัป

#### 1. ติดตั้ง Git และ Clone Repo

- เปิด **PowerShell** แล้วเช็ค Git ด้วยคำสั่ง `git --version` (ถ้าไม่มีให้ไปโหลดที่ git-scm.com)
    
- สร้างโฟลเดอร์เก็บโปรเจกต์: `mkdir projects` แล้ว `cd projects`
    
- ใช้คำสั่ง Clone:
    
    Bash
    
    ```
    git clone https://www.youtube.com/watch?v=HrBUDpSekbY
    ```
    
- เข้าไปที่โฟลเดอร์รูท: `cd agents`
    

#### 2. ติดตั้ง Cursor IDE

- โหลดและติดตั้ง **Cursor** จาก https://www.google.com/search?q=cursor.com (ตัวนี้เป็น AI Code Editor ที่ Ed แนะนำ)
    
- เปิดโปรเจกต์ใน Cursor โดยเลือกโฟลเดอร์ `agents` ที่คุณเพิ่ง Clone มา
    

#### 3. ติดตั้ง UV (Package Manager)

- ติดตั้งผ่าน PowerShell:
    
    PowerShell
    
    ```
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
    
- **สำคัญ:** ปิดและเปิด PowerShell ใหม่เพื่อให้คำสั่ง `uv` ทำงาน
    
- ใน Terminal ของ Cursor ให้พิมพ์คำสั่งเพื่อสร้างสภาพแวดล้อมและลง Library ทั้งหมด:
    
    Bash
    
    ```
    uv sync
    ```
    
    _(uv จะสร้างโฟลเดอร์ `.venv` ให้คุณโดยอัตโนมัติ ซึ่งเร็วมากครับ)_
    

#### 4. เตรียม OpenAI API Key

- ไปที่ [platform.openai.com](https://platform.openai.com/)
    
- **Billing:** เติมเงินขั้นต่ำ $5
    
- **API Keys:** สร้าง Secret Key ใหม่แล้วก๊อปปี้ไว้ (ระวังอย่าไปวางในโปรแกรม Word หรือ Notepad ที่อาจจะแก้ฟอร์แมตขีดกลางของคุณ)
    

#### 5. สร้างไฟล์ `.env` (ที่เก็บความลับ)

- ใน Cursor สร้างไฟล์ใหม่ชื่อว่า `.env` (ต้องมีจุดข้างหน้าเสมอ)
    
- พิมพ์ข้อความนี้ลงไป (ห้ามพิมพ์ผิดแม้แต่ตัวเดียว):
    
    Code snippet
    
    ```
    OPENAI_API_KEY=sk-proj-คีย์ของคุณ
    ```
