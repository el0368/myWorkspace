# Your First AI Agent: A Fun 2-Step Workflow

### Introduction: The Magic of Teamwork for AIs

Imagine you have a complex problem to solve. You could ask a single, brilliant expert for their opinion. That's like making a single call to an AI. But what if you could assemble a _team_ of experts? The first expert analyzes the problem and passes their findings to a second expert, who builds on that work to create a solution. This team-based approach is far more powerful.

This is the fundamental idea behind agentic AI. Instead of a single interaction, we create a workflow where multiple AI calls work together, passing information to each other to solve a bigger problem.

By the end of this walkthrough, you will build a simple two-step AI "agent" that first creates a challenging question and then, in a second step, solves it. This will reveal the fundamental pattern behind more complex Agentic AI.

The core idea of Agentic AI is orchestrating multiple AI interactions to accomplish a larger task that a single interaction could not.

--------------------------------------------------------------------------------

### 1. The Foundation: A Simple Conversation with an AI

Before we can build a team, we need to know how to talk to a single "expert." Let's start by making a basic, one-off call to an AI model.

### 1.1 Setting the Stage: The OpenAI Client

First, we need to import the necessary library and create a tool to communicate with the AI.

```python
# The all important import statement
from openai import OpenAI

# Create an instance of the OpenAI class, which is a lightweight library
# for connecting to OpenAI's cloud services.
openai = OpenAI()
```

This code doesn't run an AI on your computer. Instead, it creates a "client"—a lightweight library that acts as a tool for connecting to the powerful models running on OpenAI's servers.

### 1.2 Your First AI Call: "What is 2+2?"

Now, let's ask a simple question. We'll structure our conversation in a standard format and send it to the AI.

```python
# Conversations are represented as lists of dictionaries.
# This standard format has a 'role' (e.g., 'user') and 'content' (the prompt).
messages = [{"role": "user", "content": "What is 2+2?"}]

# Call the chat completions API endpoint
response = openai.chat.completions.create(
    model="gpt-4.1-nano", # An incredibly cheap and fast model, perfect for simple tasks.
    messages=messages
)

# Extract and print the text content from the response
print(response.choices[0].message.content)
```

Let's break down the three most important parts of this code:

- `**messages**` **list:** This is the standard way to structure a conversation. It's a list containing one or more dictionaries, each with a `role` (like `"user"`) and `content` (the actual text of the message).
- `**openai.chat.completions.create(...)**`**:** This is the primary function we use to send our request to the specified AI `model`.
- `**response.choices[0].message.content**`**:** The AI returns a complex response object. This specific path lets us extract the single thing we care about: the AI's text reply.

Expected Output:

```
2 plus 2 equals 4.
```

Now that we've successfully had a simple one-off conversation, let's orchestrate a sequence of conversations to build our first agentic pattern.

--------------------------------------------------------------------------------

### 2. The Agentic Pattern: A Two-Step Workflow

Now, we'll implement the "teamwork" concept by building our first agentic pattern. We'll create a simple, two-step workflow.

1. **AI Call #1:** We will ask the AI to act as a "Question Generator" and create a hard question.
2. **AI Call #2:** We will take the generated question and feed it to the AI to act as a "Problem Solver."

The key to this entire process is using the _output_ of the first call as the _input_ for the second.

### 2.1 Step 1: Generating a Challenging Question

Let's ask our first AI expert to come up with a challenging IQ-style question.

```python
# Define a prompt asking the AI to generate a challenging question.
# The instruction "Respond only with the question" is a simple form of prompt engineering.
user_prompt = "Please propose a hard, challenging question to assess someone's IQ. Respond only with the question."

messages = [{"role": "user", "content": user_prompt}]

# Make the API call
response = openai.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages
)

# Store the AI's output in a new variable called 'question'
question = response.choices[0].message.content

print("Generated Question:")
print(question)
```

The most important line here is `question = response.choices[0].message.content`. Instead of just printing the result, we are **capturing the output from our first AI expert so we can hand it off to our second expert.**

### 2.2 Step 2: Answering the Generated Question

Now we'll programmatically use the `question` variable from the previous step as the input for our second AI call.

```python
# Now, we use the 'question' variable from the previous step as our new content.
messages = [{"role": "user", "content": question}]

# Make the second API call to get the answer
response = openai.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages
)

# Store the new response in a variable called 'answer'
answer = response.choices[0].message.content

print("\nGenerated Answer:")
print(answer)
```

You've just created a workflow! Notice how we didn't copy-paste the question manually. We programmatically used the `question` variable as the input for our second call. This chaining of inputs and outputs is the essence of building AI agents.

Our agent is now working, but the answer it provided looks like a block of unformatted text. Let's add a finishing touch to make the output much easier to read.

--------------------------------------------------------------------------------

### 3. Making the Output Shine with Markdown

Large Language Models (LLMs) often communicate using **Markdown**, a simple text-formatting syntax that uses characters like `#` for headings and `*` for bold text. Our code can render this Markdown to produce beautifully formatted output.

### 3.1 Rendering the AI's Response

By importing a couple of special functions, we can tell our programming environment to display the AI's response as formatted text instead of plain text.

```python
# Import special functions from IPython.display to render formatted output in notebooks
from IPython.display import Markdown, display

# The 'display' function can render various types of content, including Markdown
display(Markdown(answer))
```

After running this code, you will see a nicely formatted response, with headings, bold text, and paragraphs, just as the AI intended.

2. **Identify a Pain Point:** Take the business area from step 1 and ask the LLM to "identify a specific pain point in that business sector."

Following the logic of the **Two-Step Workflow** you just learned, here is the complete Python code to solve the **Three-Step Business Challenge**.

This script programmatically chains three calls together, ensuring the output of one step becomes the context for the next.

Python

```python
from openai import OpenAI
from IPython.display import Markdown, display

# Initialize the client
openai = OpenAI()

# --------------------------------------------------------------------------------
# STEP 1: Find an Opportunity
# --------------------------------------------------------------------------------
print("Step 1: Finding a business opportunity...")

prompt_1 = "Pick a specific business area or industry that might be worth exploring for an AI opportunity. Respond only with the name of the industry."
messages_1 = [{"role": "user", "content": prompt_1}]

response_1 = openai.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages_1
)

# Capture the industry name
business_area = response_1.choices[0].message.content
print(f"Target Industry: {business_area}")

# --------------------------------------------------------------------------------
# STEP 2: Identify a Pain Point
# --------------------------------------------------------------------------------
print(f"Step 2: Identifying a pain point in {business_area}...")

# We use the variable 'business_area' from Step 1 to build the next prompt
prompt_2 = f"Identify a specific, high-impact pain point or operational challenge in the {business_area} sector that is ripe for an AI solution. Respond only with a description of the pain point."
messages_2 = [{"role": "user", "content": prompt_2}]

response_2 = openai.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages_2
)

# Capture the pain point description
pain_point = response_2.choices[0].message.content

# --------------------------------------------------------------------------------
# STEP 3: Propose a Solution
# --------------------------------------------------------------------------------
print("Step 3: Proposing an Agentic AI solution...")

# We use the 'pain_point' and 'business_area' variables to build the final prompt
prompt_3 = f"Given the pain point: '{pain_point}' in the {business_area} industry, propose a sophisticated Agentic AI solution. Explain how the agent would operate and what benefits it provides. Use Markdown formatting."
messages_3 = [{"role": "user", "content": prompt_3}]

response_3 = openai.chat.completions.create(
    model="gpt-4.1-mini",
    messages=messages_3
)

# Capture the final solution
final_solution = response_3.choices[0].message.content

# --------------------------------------------------------------------------------
# FINAL OUTPUT: Render beautifully with Markdown
# --------------------------------------------------------------------------------
display(Markdown(f"## AI Venture Architect Report\n\n**Industry:** {business_area}\n\n**The Pain Point:** {pain_point}\n\n---"))
display(Markdown(final_solution))
```

### Key Concepts Applied:

1. **Sequential Chaining:** Notice how `business_area` is used in Step 2, and `pain_point` is used in Step 3. This creates a logical thread where the AI's "thought process" builds upon its previous answers.
    
2. **Context Injection:** By placing the output of a previous call into a f-string (e.g., `f"Given the pain point: '{pain_point}'..."`), you are giving the AI the specific context it needs to stay on track.
    
3. **Autonomous Logic:** Even though we hard-coded the three steps, the _content_ is chosen by the LLM. This is the first step toward **Agency**—where the AI chooses the industry and the specific problem to solve.
