เนื้อหาในส่วนนี้ Edward Donner กำลังปูพื้นฐานเรื่อง **"การเตรียมตัวและทัศนคติ"** ก่อนเข้าสู่บทเรียนจริง ซึ่งมีประเด็นที่สำคัญมากสำหรับคุณ (ในฐานะคนที่กำลังรอเครื่อง Dell RAM 32GB และเริ่มลอง Ollama) ดังนี้ครับ:

### 1. ใครเรียนคอร์สนี้ได้บ้าง?

เขายืนยันว่าคอร์สนี้ออกแบบมาเพื่อคนทุกระดับ ตั้งแต่คนที่ไม่เคยเขียนโค้ดเลย (Extreme Beginner) ไปจนถึงระดับมืออาชีพ (Agent Engineer)

- **สำหรับคุณ:** คุณอยู่ในกลุ่มที่เขาเรียกว่า **"AI Engineer"** (หรือคนที่กำลังขยับจาก Python/LLM ไปสู่ Agent) ซึ่งเขาบอกว่าจะเป็นกลุ่มที่ **"สนุกและได้ประโยชน์ที่สุด"** เพราะพื้นฐานคุณพร้อมที่จะต่อยอดไปยังโปรเจกต์ที่ซับซ้อนได้ทันที
    

### 2. เครื่องมือที่จะใช้ (IDE & Package Manager)

นี่คือจุดที่สำคัญมากสำหรับการเซตอัปเครื่องใหม่ของคุณ:

- **Cursor IDE:** เขาเลือกใช้ Cursor แทน VS Code แบบดั้งเดิม เพราะมันถูกสร้างมาเพื่อการเขียนโค้ดร่วมกับ AI โดยเฉพาะ (มีพื้นฐานมาจาก VS Code ทำให้คุณไม่ต้องเรียนรู้ใหม่ แต่จะทำงานได้เร็วขึ้นมาก)
    
- **uv:** เขาจะพาคุณเปลี่ยนจาก Anaconda มาใช้ **uv** ซึ่งเป็น Package Manager ที่เขียนด้วยภาษา **Rust** ทำให้มันเร็วมากและเสถียรกว่าระบบเดิมๆ
    

### 3. เรื่องค่าใช้จ่าย API (ทางเลือกสำหรับคุณ)

Edward ให้ข้อมูลที่น่าสนใจเรื่องงบประมาณ:

- **API Key (OpenAI/DeepSeek):** การใช้โมเดลระดับ Frontier (ตัวท็อป) จะมีค่าใช้จ่าย แต่เขาบอกว่าตลอดทั้งคอร์สเขาใช้ไป **ไม่ถึง $5 (ประมาณ 180 บาท)** เท่านั้น
    
- **ทางเลือกฟรี (Gemini & Ollama):** เขาแนะนำว่าถ้าไม่อยากเสียเงิน สามารถใช้ **Gemini (Free Tier)** หรือรัน **Ollama** ในเครื่องตัวเองได้เลย
    
- **จุดที่ต้องระวัง:** เขาเตือนว่าถ้าใช้โมเดลเล็กในเครื่อง (เช่น Llama 3.2 ตัวเล็ก) มันอาจจะตอบไม่ฉลาดเท่าในวิดีโอที่เขาใช้โมเดลตัวใหญ่ แต่เครื่อง **RAM 32GB** ของคุณจะช่วยให้คุณรันโมเดลที่ "ใหญ่และฉลาด" ได้ในเครื่องตัวเอง ซึ่งจะได้ผลลัพธ์ใกล้เคียงกับที่เขาโชว์ครับ
    

### 4. ทัศนคติแบบวิศวกร (Patience is Key)

เขาย้ำเรื่องความ **"อดทน"**:

- การเซตอัปสภาพแวดล้อม (Environment) ในงาน AI ระดับสูงอาจจะมีความเจ็บปวดบ้าง (Painful process) แต่เขาขอให้มองว่าการเจอปัญหาคือ **"โอกาสในการเรียนรู้ที่ยอดเยี่ยม"**
