### Part 3: Adding Logic with Methods

This section introduces a way to run custom JavaScript functions within your Vue app to make the content more dynamic.

**Goal:** Create a method that randomly selects between two different course goals and display the result in the HTML.

**Step 1: The HTML (`index.html`)**

We will update the `<p>` tag to call a method named `outputGoal()` instead of just referencing a data property.

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vue Basics</title>
    <link
      href="https://fonts.googleapis.com/css2?family=Jost:wght@400;700&display=swap"
      rel="stylesheet"
    />
    <link rel="stylesheet" href="styles.css" />
    <script
      src="https://unpkg.com/vue@3.4.9/dist/vue.global.js"
      defer
    ></script>
    <script src="app.js" defer></script>
  </head>
  <body>
    <header>
      <h1>Vue Course Goals</h1>
    </header>
    <section id="user-goal">
      <h2>My Course Goal</h2>
      <p>{{ outputGoal() }}</p>
      <p>
        Learn more
        <a v-bind:href="vueLink">about Vue</a>
      </p>
    </section>
  </body>
</html>
```

**Step 2: The JavaScript (`app.js`)**

We will modify the `data` object to hold two different goal strings. We'll then add a new `methods` property to our app configuration.

JavaScript

```JavaScript
const app = Vue.createApp({
  data() {
    return {
      // We now have two distinct goals
      courseGoalA: "Master Vue and build amazing apps!",
      courseGoalB: "Learn the fundamentals of Vue.",
      vueLink: "https://vuejs.org",
    };
  },
  // The 'methods' property holds an object of functions
  methods: {
    // This is our custom method
    outputGoal() {
      const randomNumber = Math.random();
      if (randomNumber < 0.5) {
        // 'this' refers to the Vue app instance, giving us access to data
        return this.courseGoalA;
      } else {
        return this.courseGoalB;
      }
    },
  },
});

app.mount("#user-goal");
```

**How it Works:**

1. We've added a new `methods` property to the object passed to `createApp()`. This property holds all the functions (or "methods") for our app.
    
2. Inside the `methods` object, we define a function called `outputGoal()`. This function generates a random number and, based on the number, returns either `this.courseGoalA` or `this.courseGoalB`.
    
3. The `this` keyword inside the method is crucial; it allows the method to access the data properties (`courseGoalA` and `courseGoalB`) that belong to the same Vue app instance.
    
4. In the HTML, `{{ outputGoal() }}` tells Vue to **execute** the `outputGoal` method. Vue then displays whatever value the method returns. Each time the page is reloaded, `Math.random()` will generate a new number, and a different goal will be displayed, making the application dynamic.
