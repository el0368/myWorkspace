### Part 2: Dynamically Setting HTML Attributes

This section introduces a new directive for handling data that doesn't go between HTML tags.

**Goal:** Use Vue-managed data to dynamically set the value of an HTML attribute, like the `href` attribute of a link.

**Step 1: The HTML (`index.html`)**

We'll add a new paragraph with a link. Notice how we use a different syntax for the `href` attribute compared to the text inside the `<p>` tags.

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vue Basics</title>
    <link
      href="https://fonts.googleapis.com/css2?family=Jost:wght@400;700&display=swap"
      rel="stylesheet"
    />
    <link rel="stylesheet" href="styles.css" />
    <script
      src="https://unpkg.com/vue@3.4.9/dist/vue.global.js"
      defer
    ></script>
    <script src="app.js" defer></script>
  </head>
  <body>
    <header>
      <h1>Vue Course Goals</h1>
    </header>
    <section id="user-goal">
      <h2>My Course Goal</h2>
      <p>{{ courseGoal }}</p>
      <p>
        Learn more
        <a v-bind:href="vueLink">about Vue</a>
      </p>
    </section>
  </body>
</html>
```

**Step 2: The JavaScript (`app.js`)**

We'll add a new data property, `vueLink`, to hold the URL for the link.

JavaScript

```JavaScript
const app = Vue.createApp({
  data() {
    return {
      courseGoal: "Finish the course and learn Vue!",
      // 'vueLink' is a new property holding a URL string
      vueLink: "https://vuejs.org",
    };
  },
});

app.mount("#user-goal");
```

**How it Works:**

1. We've added a new property, `vueLink`, to our `data` object with the value `"https://vuejs.org"`.
    
2. In the HTML, we use the `v-bind` directive, which is a special instruction for Vue.
    
3. The syntax `v-bind:href="vueLink"` tells Vue to **bind** the value of the `href` attribute to the value of the `vueLink` data property.
    
4. Unlike the `{{ }}` interpolation, which only works for content between tags, `v-bind` is specifically designed for dynamic attributes. It ensures that the link's `href` attribute is correctly set to `"https://vuejs.org"`, allowing the link to work as expected.
