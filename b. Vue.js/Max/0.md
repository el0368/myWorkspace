### Part 1: Setting up a Vue App and Displaying Data

This section covers the absolute fundamentals: getting Vue running and outputting static data.

- **Connecting Vue to HTML:** Use `Vue.createApp()` and `app.mount()` to create a Vue application instance and tell it which part of your HTML (`#user-goal` in this case) it should control. This is the foundation for everything else.
    
- **Declaring Data:** In the `createApp` object, use the `data()` method to return an object. This object holds all the data your app will manage, such as `courseGoalA`, `courseGoalB`, and `vueLink`.
    
- **Outputting Content with Interpolation:** Use the **double curly brace syntax** (`{{ }}`) to display data from your `data()` object directly in your HTML. Vue replaces this syntax with the actual value of the data property. For example, `{{ courseGoal }}` would display the value of the `courseGoal` property.

### Part 2: Dynamically Setting HTML Attributes

This section introduces a new directive for handling data that doesn't go between HTML tags.

- **Binding Attributes with `v-bind`:** When you need to set the value of an HTML attribute (like `href`, `src`, or `class`) dynamically using Vue data, you cannot use the double curly brace syntax. Instead, you use the **`v-bind` directive**, followed by the attribute name (e.g., `v-bind:href`).
    
- **How it Works:** The value you provide to `v-bind:href="..."` is a JavaScript expression. Vue will evaluate this expression and set the `href` attribute to its result. This is how you can use a data property like `vueLink` to control where a link goes: `<a v-bind:href="vueLink">...</a>`.
    

---

### Part 3: Adding Logic with Methods

This section introduces a way to run custom JavaScript functions within your Vue app.

- **Declaring Methods:** In the `createApp` object, you can add a `methods` property. This property takes an object where each key is the name of a function you define. These functions are your custom methods.
    
- **Using `this`:** Inside a method, the `this` keyword refers to the Vue app instance itself. This gives you access to all the data and other methods within your app. For example, `this.courseGoalA` allows you to access the `courseGoalA` data property from within a method like `outputGoal()`.
    
- **Calling Methods in HTML:** You can call a method from your HTML template using the same double curly brace syntax (`{{ }}`) that you use for data. You must include parentheses (`()`) to execute the function, like `{{ outputGoal() }}`. Vue will run the code in the method and display whatever value the method returns.
