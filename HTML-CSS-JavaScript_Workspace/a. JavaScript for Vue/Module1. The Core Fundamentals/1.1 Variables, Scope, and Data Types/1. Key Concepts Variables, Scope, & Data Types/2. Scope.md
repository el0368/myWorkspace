Scope in JavaScript determines the accessibility of variables.1 It's a set of rules for where variables can be accessed.2 Understanding scope is crucial because it controls how your program manages memory and prevents conflicts between variable names.3

---

### Global Scope 🌍

When a variable is declared **outside** of any function or code block (`{...}`), it has **global scope**.4 A global variable can be accessed and modified from anywhere in your entire program.

While this might seem convenient, it's generally considered bad practice to create too many global variables. They can be accidentally overwritten by other parts of your code, leading to hard-to-find bugs.5

JavaScript

```JavaScript
// This variable has global scope
const appVersion = "2.1";

function displayVersion() {
  // Can be accessed inside a function
  console.log(`Version: ${appVersion}`);
}

displayVersion(); // Outputs: Version: 2.1
console.log(appVersion); // Outputs: 2.1
```

---

### Function Scope 

Variables declared with the `var` keyword are **function-scoped**.6 This means they are only visible and accessible within the **entire function** they are declared in, no matter which block they are inside.

If you declare a `var` outside a function, it becomes a global variable.7 This behavior, where `var` ignores blocks, is a key reason why it's been replaced by `let` and `const`.

JavaScript

```JavaScript
function calculateScore() {
  // 'totalScore' is function-scoped
  var totalScore = 100;

  if (totalScore > 50) {
    // 'message' is also function-scoped
    var message = "You Win!";
  }

  // Both variables are accessible anywhere inside the function
  console.log(`Score: ${totalScore}, Message: ${message}`); // Works fine
}

calculateScore();
// console.log(totalScore); // Error: totalScore is not defined out here
```

---

### Block Scope 🧱

This is the modern and most important scope to understand. Variables declared with **`let`** and **`const`** are **block-scoped**.8 This means the variable is confined to the **block** (`{...}`) in which it was declared. A "block" includes `if` statements, `for` loops, `while` loops, or even just a standalone pair of curly braces.9

This provides a more predictable and fine-grained level of control, reducing bugs by limiting where a variable can be accessed and modified.

JavaScript

```JavaScript
function processData(data) {
  // 'processed' is only visible inside this if block
  if (data.isValid) {
    const processed = true;
    let value = data.value * 2;
    console.log(value); // Outputs the doubled value
  }

  // Trying to access 'processed' or 'value' here would cause an error.
  // console.log(processed); // ReferenceError: processed is not defined
}

processData({ isValid: true, value: 50 });
```

In summary, scope answers the question, **"Where is this variable available?"**

- **Global**: Everywhere. (Use sparingly).
    
- **Function**: Inside the function it was created in (applies to `var`).
    
- **Block**: Inside the `{...}` block it was created in (applies to `let` and `const`).10
