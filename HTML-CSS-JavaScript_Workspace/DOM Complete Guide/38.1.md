### ## Accessing Groups of Elements: `getElementsByClassName`

So far, we've used `getElementById` to find one specific element—our "one-of-a-kind" book in the library. But what if we need to find _all_ the books that belong to the same genre?

This is where `getElementsByClassName` comes in. It's a method designed to find every element on the page that shares the same class name.

---

### The Key Difference: A Collection, Not a Single Item

When you use `getElementById`, the browser hands you **one single object**.

When you use `getElementsByClassName`, the browser hands you an **`HTMLCollection`**. Think of this as a special "shelf" or a "box" that holds all the matching elements.

This distinction is the most important concept to understand, and it's a common stumbling block.

### The Common Mistake (and Why It Happens)

Because you get back a collection (the shelf), you cannot apply a style directly to it.

JavaScript

```JavaScript
// Let's get all elements with the class 'book-report'
const reports = document.getElementsByClassName('book-report');

// This will NOT work and will cause an error!
reports.style.color = 'blue'; 
```

This fails because you're trying to paint the **shelf** blue, not the individual **books** on it. The collection object itself doesn't have a `.style` property.

---

### The Solution: The Loop

To work with a collection, you must loop through it and handle each item one by one. The most reliable way to do this with an `HTMLCollection` is a classic `for` loop.

#### The Simple 3-Step Process:

1. **Get the collection** (the "shelf").
    
2. **Loop through the collection** from the first item to the last.
    
3. **Inside the loop**, access each individual item and apply your changes.
    

#### Code Example:

Let's say you have this HTML:

HTML

```HTML
<p class="warning">Warning: The floor is wet.</p>
<p>This is a normal paragraph.</p>
<p class="warning">Warning: The coffee is hot.</p>
```

Here's how you would make all the warnings red:

JavaScript

```JavaScript
// 1. Get the collection of all elements with the 'warning' class.
const allWarnings = document.getElementsByClassName('warning');

// 2. Loop through the entire 'allWarnings' collection.
for (let i = 0; i < allWarnings.length; i++) {

  // 3. Inside the loop, grab the individual element at the current position...
  const singleWarning = allWarnings[i];
  
  // ...and apply the style to it.
  singleWarning.style.color = 'red';
  singleWarning.style.fontWeight = 'bold';
}
```

This code correctly takes each "book" off the "shelf," paints it, and puts it back, resulting in all your warning messages turning red and bold.
