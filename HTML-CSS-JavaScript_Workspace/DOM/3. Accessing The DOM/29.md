Here is a breakdown of those methods for accessing the DOM.

These methods can be grouped into two categories: the older, more specific `getElementsBy...` methods and the modern, flexible `querySelector` methods.

---

## The "Classic" Methods

These methods are fast and straightforward but less flexible than their modern counterparts.

### `document.getElementById()`

- **What it does:** Finds a single element by its unique `id`.
    
- **Analogy:** 📚 Knowing a book's unique ISBN number. It's the most direct way to find one specific book.
    
- **Returns:** A **single element object** or `null` if no match is found.
    

### `document.getElementsByClassName()`

- **What it does:** Finds all elements that have a given CSS class name.
    
- **Analogy:** Asking for all the books in the "Science Fiction" genre section.
    
- **Returns:** A **live `HTMLCollection`** (an array-like list) of all matching elements.
    

### `document.getElementsByTagName()`

- **What it does:** Finds all elements with a given HTML tag name (e.g., 'p', 'li', 'div').
    
- **Analogy:** Asking for all the "hardcover" books in the library, regardless of genre.
    
- **Returns:** A **live `HTMLCollection`**.
    

> What is a "Live" Collection?
> 
> An HTMLCollection is live. This means if you add or remove elements from the DOM that match the selector, the collection variable automatically updates itself without you having to run the query again.

---

## The "Modern" Methods

These methods are more powerful and flexible because they use CSS selectors, allowing for much more complex queries.

### `document.querySelector()`

- **What it does:** Finds the **first** element that matches a specified CSS selector.
    
- **Analogy:** Telling the librarian, "Just give me the first book you see that has a blue cover."
    
- **Returns:** A **single element object** (the first one found) or `null` if no match is found.
    

### `document.querySelectorAll()`

- **What it does:** Finds **all** elements that match a specified CSS selector.
    
- **Analogy:** Telling the librarian, "Please give me a list of all the books that have a blue cover."
    
- **Returns:** A **static `NodeList`** (an array-like list).
    

> What is a "Static" Collection?
> 
> A NodeList returned by querySelectorAll is static. It's a snapshot of the matching elements at the moment you run the query. If you add or remove elements from the DOM later, the NodeList variable will not automatically update.

---

## Summary Table

| Method                     | Selects By   | Returns          | Collection Type |
| -------------------------- | ------------ | ---------------- | --------------- |
| `getElementById()`         | Unique `id`  | Single Element   | N/A             |
| `getElementsByClassName()` | Class name   | `HTMLCollection` | **Live**        |
| `getElementsByTagName()`   | Tag name     | `HTMLCollection` | **Live**        |
| `querySelector()`          | CSS Selector | Single Element   | N/A             |
| `querySelectorAll()`       | CSS Selector | `NodeList`       | **Static**      |
