### ## Module 3 Study Guide: Making Changes (Manipulation & Traversal) 🔧

**Objective:** By the end of this module, you'll be able to dynamically create, modify, and place elements on a web page using JavaScript. You'll master changing content, styles, and attributes, and you'll be able to navigate the DOM tree with ease.

---

### **Lesson 1: Content & Attributes**

Once you've selected an element, this is how you change what it contains and how it's configured.

- **`textContent` vs. `innerHTML`**
    
    - **`element.textContent`**: Gets or sets the **raw text** of an element, automatically stripping out any HTML tags. It's fast and safe. Use this when you only need to work with plain text.
        
        JavaScript
        
        ```
        const heading = document.querySelector('h1');
        // GET: heading.textContent would return "Page Title"
        // SET:
        heading.textContent = 'A Brand New Title';
        ```
        
    - **`element.innerHTML`**: Gets or sets the full **HTML content** inside an element. It will render any HTML tags you provide.
        
        JavaScript
        
        ```
        const div = document.querySelector('.content');
        // SET:
        div.innerHTML = '<h2>Subtitle</h2><p>This is a paragraph.</p>';
        ```
        
    - **⚠️ Security Warning:** Never set `innerHTML` with content from an untrusted source (like user input). A malicious user could inject a `<script>` tag and execute code on your page, an attack known as Cross-Site Scripting (XSS).
        
- **Managing Attributes**
    
    - **`element.getAttribute('attributeName')`**: Reads the value of an HTML attribute.
        
    - **`element.setAttribute('attributeName', 'value')`**: Sets the value of an HTML attribute. It will create the attribute if it doesn't exist.
        
        JavaScript
        
        ```
        const link = document.querySelector('a');
        const url = link.getAttribute('href'); // Reads "./about.html"
        link.setAttribute('href', 'https://example.com'); // Changes the link's destination
        link.setAttribute('target', '_blank'); // Adds a new attribute
        ```

### **Lesson 2: Styling with JavaScript**

You have two ways to change an element's style. One is generally much better than the other.

- **The Direct Way: `element.style`**
    
    - **What it does:** Directly modifies the inline `style` attribute of an element. CSS properties are written in camelCase (e.g., `backgroundColor`, `fontSize`).
        
    - **When to use it:** Best for dynamic values that are calculated on the fly, like setting an element's position based on mouse coordinates.
        
    - **Example:**
        
        JavaScript
        
        ```
        const title = document.querySelector('h1');
        title.style.color = 'blue';
        title.style.fontSize = '24px';
        ```
        
    - **Why it's often not the best choice:** It mixes your styling rules into your JavaScript, which can become hard to manage. This is known as poor "separation of concerns."
        
- **The Best Practice: `element.classList`**
    
    - **What it does:** Manipulates the element's `class` attribute. The idea is to have your styles pre-defined in your CSS file and use JS to simply toggle the classes on or off.
        
    - **Why it's better:** It keeps your styles in your stylesheet and your logic in your script, which is much cleaner.
        
    - **Key Methods:**
        
        - `.add('className')`: Adds a class.
            
        - `.remove('className')`: Removes a class.
            
        - `.toggle('className')`: Adds the class if it's not there, removes it if it is.
            
        - `.contains('className')`: Checks if an element has a class, returns `true` or `false`.
            
    - **Example:**
        
        CSS
        
        ```
        /* In your styles.css */
        .active {
          color: blue;
          font-weight: bold;
        }
        ```
        
        JavaScript
        
        ```
        // In your script.js
        const element = document.querySelector('.item');
        element.classList.add('active'); // Makes the element blue and bold
        ```

### **Lesson 3: Creating & Removing Elements**

This is the core of building dynamic applications.

- **The Lifecycle of a New Element**
    
    1. **Create it (in memory):** Use `document.createElement('tagName')`. The element is created but isn't on the page yet.
        
    2. **Configure it:** Use `textContent`, `classList`, `setAttribute`, etc., to set it up.
        
    3. **Place it (on the page):** Use an insertion method to add it to the DOM.
        
- **Modern Insertion Methods**
    
    - `parentElement.append(newElement)`: Adds the new element at the **end** of the parent.
        
    - `parentElement.prepend(newElement)`: Adds the new element at the **beginning** of the parent.
        
- **Putting it all together:**
    
    JavaScript
    
    ```
    // 1. Select the parent
    const list = document.querySelector('ul');
    
    // 2. Create the new element
    const newItem = document.createElement('li');
    
    // 3. Configure it
    newItem.textContent = 'Item 4';
    newItem.classList.add('list-item');
    
    // 4. Place it on the page
    list.append(newItem);
    ```
    
- Removing an Element
    
    The modern way is simple: just call .remove() on the element you want to delete.
    
    JavaScript
    
    ```
    const elementToRemove = document.querySelector('#old-item');
    elementToRemove.remove();
    ```

### **Lesson 4: Navigating the Tree (Traversal)**

Traversal is moving from a selected element to its relatives.

- **Moving Up:**
    
    - `element.parentElement`: Selects the direct parent of an element.
        
- **Moving Down:**
    
    - `element.children`: Returns a live `HTMLCollection` of an element's direct children.
        
- **Moving Sideways:**
    
    - `element.nextElementSibling`: Selects the very next sibling **element**.
        
    - `element.previousElementSibling`: Selects the very previous sibling **element**.
        
    - **Note:** It's important to use the `...ElementSibling` versions. The older versions (`nextSibling`) can select invisible text nodes (like whitespace in your HTML), which is usually not what you want.
        
- **Example:**
    
    HTML
    
    ```
    <ul>
      <li>One</li>
      <li class="active">Two</li>
      <li>Three</li>
    </ul>
    ```
    
    JavaScript
    
    ```
    const activeItem = document.querySelector('.active'); // Selects <li>Two</li>
    
    const parentList = activeItem.parentElement; // The <ul>
    const nextItem = activeItem.nextElementSibling; // The <li>Three</li>
    const prevItem = activeItem.previousElementSibling; // The <li>One</li>
    ```
