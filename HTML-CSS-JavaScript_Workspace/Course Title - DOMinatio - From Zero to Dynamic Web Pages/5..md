### **Project 1: The To-Do List (Simple)**

**Project Goal:** Build an application where a user can add tasks to a list and remove them by clicking on them. This is the "Hello, World!" of DOM manipulation projects.

**Core Skills Practiced:**

- **Form Handling:** Listening for the `submit` event and using `e.preventDefault()`.
    
- **Element Creation:** Using `document.createElement()`.
    
- **Content & Placement:** Using `textContent` and `.append()`.
    
- **Event Delegation:** Using a single listener on the parent `<ul>` to efficiently handle removing items.
    

**Step-by-Step Guide:**

1. **HTML Structure:**
    
    - Create a `<form>` containing an `<input type="text">` and a `<button>Add</button>`.
        
    - Create an empty `<ul>` that will hold the list of tasks.
        
2. **Add a Task:**
    
    - Select the `form`, `input`, and `ul` elements in your JavaScript.
        
    - Add a `submit` event listener to the `form`.
        
    - Inside the listener function:
        
        - Call `e.preventDefault()` to stop the page from reloading.
            
        - Get the text from the input field (`input.value`). If it's empty, stop the function.
            
        - Create a new `<li>` element.
            
        - Set its `textContent` to the input's value.
            
        - `append()` the new `<li>` to your `<ul>`.
            
        - Clear the input field (`input.value = ''`).
            
3. **Remove a Task (Event Delegation):**
    
    - Add a `click` event listener to the parent `<ul>`.
        
    - Inside this listener function:
        
        - Check if the element that was clicked (`e.target`) is an `<li>` element. A good way is `if (e.target.tagName === 'LI')`.
            
        - If it is, remove that specific element: `e.target.remove()`.

### **Project 2: Image Carousel/Slider (Intermediate)**

**Project Goal:** Create a functional image slider with "next" and "previous" buttons to cycle through a set of images.

**Core Skills Practiced:**

- **State Management:** Using a variable (`currentIndex`) to keep track of which image is active.
    
- **Data Structures:** Using an array to hold the image URLs.
    
- **Attribute Manipulation:** Changing the `src` attribute of an `<img>` tag.
    
- **Event Handling:** Responding to `click` events on the control buttons.
    

**Step-by-Step Guide:**

1. **HTML Structure:**
    
    - An `<img>` tag to display the current image.
        
    - Two `<button>` elements, one for "Previous" and one for "Next".
        
2. **JavaScript Setup:**
    
    - Create an array containing the file paths to your images (e.g., `['img/image1.jpg', 'img/image2.jpg', ...]`).
        
    - Create a variable `currentIndex` and initialize it to `0`.
        
    - Select the `<img>` element and the two buttons.
        
3. **Core Functionality:**
    
    - Create a function `showImage(index)` that takes an index, and sets the image's `src` attribute to the URL at that position in your array.
        
    - Call `showImage(currentIndex)` once at the beginning to display the first image.
        
4. **Event Listeners:**
    
    - Add a `click` listener to the "Next" button. Inside, increment `currentIndex`. If `currentIndex` is now greater than the last index of the array, reset it to `0`. Then call `showImage(currentIndex)`.
        
    - Add a `click` listener to the "Previous" button. Inside, decrement `currentIndex`. If `currentIndex` is now less than `0`, set it to the last index of the array (`images.length - 1`). Then call `showImage(currentIndex)`.

### **Project 3: "Are You Sure?" Modal/Popup (Advanced)**

**Project Goal:** Create a modal window that appears when a button is clicked and can be closed in multiple ways (close button, clicking the background overlay, pressing the "Escape" key).

**Core Skills Practiced:**

- **CSS Class Manipulation:** Using `.classList.add()` and `.classList.remove()` to control visibility.
    
- **Complex Event Handling:** Listening for clicks on different elements and keyboard events on the document.
    
- **Logical Checks:** Checking the `e.target` to differentiate between a click on the modal background vs. its content.
    

**Step-by-Step Guide:**

1. **HTML Structure:**
    
    - A `<button>` to trigger the modal.
        
    - A main modal container `div` (e.g., `.modal-overlay`), which will cover the whole screen.
        
    - Inside the overlay, a `div` for the modal content itself (e.g., `.modal-content`).
        
    - Inside the content, a close button (e.g., `<span class="close-modal">&times;</span>`).
        
2. **CSS Setup:**
    
    - By default, hide the `.modal-overlay` (`display: none;`).
        
    - Create a class like `.is-visible` that changes the display property to `flex` or `block`.
        
3. **JavaScript Logic:**
    
    - Select the open button, the close button, and the modal overlay element.
        
    - Create two functions: `openModal()` which adds the `.is-visible` class to the overlay, and `closeModal()` which removes it.
        
4. **Event Listeners:**
    
    - Add a `click` listener to the **open button** that calls `openModal()`.
        
    - Add a `click` listener to the **close button** that calls `closeModal()`.
        
    - Add a `click` listener to the **modal overlay**. Inside, check `if (e.target === modalOverlay)`. If true, it means the user clicked the background and not the content, so call `closeModal()`.
        
    - Add a `keydown` listener to the `document`. Inside, check `if (e.key === 'Escape')` and call `closeModal()`.
