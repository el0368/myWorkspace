He was showing you **how to see the "invisible" whitespace and newline nodes** that the browser's developer tools normally hide for convenience.

His main point is that while the standard view is clean, a special property called **`.childNodes`** can be used to reveal the complete and unfiltered list of every single node inside an element.

---

## The Core Concept: A Special Tool to See Everything

Think of it like looking at a car engine 🚗:

- **The standard DevTools view** is like looking at the engine with its plastic cover on. You see the major, important parts. It's clean and easy to understand.
    
- **The `.childNodes` property** is like taking the cover off. Suddenly, you see _all_ the wires, tubes, bolts, and empty spaces in between. It's more cluttered, but it's the complete and true picture.
    

---

## Key Takeaways from His Demonstration

1. **DevTools Hides "Clutter":** He first proved that if you just select an element like `<head>` and log it to the console, you won't see the text nodes for the line breaks and spaces around it. The browser does this to make the output cleaner.
    
2. **`.childNodes` is the Key:** He introduced `.childNodes` as the specific property that gives you access to a `NodeList` containing **every single child**, including the "invisible" text nodes.
    
3. **You Must Use It on a Single Element:** He showed that you can't call `.childNodes` on the `HTMLCollection` you get back from `getElementsByTagName('head')`. You must first grab the single element _out of_ that collection (`head[0]`) and then access its `.childNodes`.
    

### The Simple Step-by-Step Process He Showed

This is the "trick" to revealing the hidden nodes:

JavaScript

```JavaScript
// 1. Get the collection of elements.
const headCollection = document.getElementsByTagName('head');

// 2. Access the single element you want to inspect from the collection.
const headElement = headCollection[0];

// 3. Access the .childNodes property on that single element.
const allNodesInsideHead = headElement.childNodes;

// This will show a NodeList with all children, including text nodes for whitespace.
console.log(allNodesInsideHead); 
```
