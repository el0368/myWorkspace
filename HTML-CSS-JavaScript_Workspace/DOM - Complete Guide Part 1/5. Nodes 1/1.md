## Module 1: Core Concepts - What is the DOM?

The goal of this module is to build the single most important mental model for understanding the web: what the DOM is and what its fundamental building blocks are.

### Lesson 1: What a Node Is - The DOM's Building Block

The first concept is that the DOM is a tree-like structure, and the most basic unit in that tree is called a **Node**.

- **Analogy:** Think of a complex LEGO model 🧱. A **Node** is the single, most fundamental LEGO brick. Every single piece of the final model, no matter its shape or size, is a type of brick.
    

In the DOM, "Node" is simply the generic name for any single object in the page's structure.

### Lesson 2: The "Everything is a Node" Rule

This is the most surprising but crucial rule: **every single thing** in your HTML file is represented in the DOM as a node. This includes not just the visible elements, but also the "invisible" parts.

- **HTML Tags** become **Element Nodes**.
    
- The **text you write** becomes **Text Nodes**.
    
- **HTML comments** become **Comment Nodes**.
    
- Even the **line breaks and spaces** you use for formatting become their own **Text Nodes**.
    

For example, in this code:

HTML

```HTML
<div>
  <p>Hello</p>
</div>
```

The `<div>` contains three child nodes: a comment node, a text node (for the newline and spaces), and the `<p>` element node.

### Lesson 3: The 4 Most Common Node Types

While there are many technical types of nodes, you only need to focus on these four for 99% of your work:

1. **Element Node**: The most common type. These are your HTML tags like `<div>`, `<h1>`, and `<span>`.
    
2. **Text Node**: The actual text content inside an element.
    
3. **Comment Node**: An HTML comment (``).
    
4. **Document Node**: The root of everything—the `document` object itself.
