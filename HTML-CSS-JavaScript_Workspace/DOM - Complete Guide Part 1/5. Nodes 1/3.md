## Module 3: Working with Groups of Nodes

Welcome to Module 3. We've learned how to find and identify individual nodes. But what happens when we need to work with multiple elements at once, like all the items in a list? This module covers the practical skills for handling collections of nodes.

### Lesson 3.1: Introduction to Node Collections (`HTMLCollection` & `NodeList`)

When you use a method that can find multiple elements (like `querySelectorAll` or `getElementsByClassName`), the browser doesn't return a standard JavaScript array. Instead, it gives you a special, array-like object called a **collection**.

- **Analogy:** Think of it like going to the library and asking for all the books on a specific shelf 📚. The librarian doesn't hand you a loose pile of books; they give you a **box** or a **cart** that contains all the books.
    

There are two main types of these "boxes":

1. **`HTMLCollection`**: The older type, returned by methods like `getElementsByClassName()`.
    
2. **`NodeList`**: The modern type, returned by `querySelectorAll()`.
    

The most important thing to remember is that you are dealing with the _collection_ (the box), not the individual items inside it just yet.

### Lesson 3.2: The Rule of Collections - You Must Loop

This is the single most important rule and the most common mistake beginners make. **You cannot apply a change directly to the collection itself.**

Using our analogy, you can't just paint the outside of the box and expect all the books inside to change color. You have to open the box, take out each book one by one, and then paint them individually.

#### The Common Mistake

JavaScript

```JavaScript
// This will NOT work and will cause an error!
const allItems = document.querySelectorAll('.list-item');
allItems.style.color = 'red'; // Fails because the collection itself has no .style property
```

#### The Correct Solution

You must loop through the collection and apply your changes to each individual node inside it. The modern `querySelectorAll` returns a `NodeList`, which lets us use the convenient `.forEach()` method.

JavaScript

```JavaScript
// 1. Get the collection of all matching elements
const allItems = document.querySelectorAll('.list-item');

// 2. Loop through each item in the collection
allItems.forEach(item => {
  // 3. Inside the loop, apply the change to the individual item
  item.style.color = 'red';
  item.classList.add('highlight');
});
```

This is the fundamental pattern for working with multiple elements in the DOM.
