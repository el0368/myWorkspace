He was explaining **`getElementsByTagName()`**, another method for finding elements in the DOM.

His main point is that this method is very similar to `getElementsByClassName()`, but it's even **broader and less specific**.

---

## The Core Concept: Finding by Tag Type

Simply put, `getElementsByTagName()` finds every element on your page that has a specific HTML tag, like `<p>`, `<li>`, or `<div>`.

Let's use our library analogy 📚:

- `getElementById()` is finding one book by its unique ID.
    
- `getElementsByClassName()` is finding all the books in a specific genre (e.g., "Science Fiction").
    
- `getElementsByTagName()` is finding **all books of a certain type**, like "all hardcover books" in the entire library, regardless of their genre.
    

---

## Key Takeaways from His Lecture

1. **It Can Be Inefficient:** The lecturer warned that this method can be "performance heavy." Because it has to search through every node on the page for a matching tag, it can be slower than more specific methods. His advice was to use it carefully.
    
2. **It's Not Specific:** It will grab **every single matching tag** on the entire document. If you ask for all `<p>` tags, it will find all of them, not just the ones in a particular section you might be interested in.
    
3. **It Returns an `HTMLCollection`:** Just like `getElementsByClassName()`, this method does **not** return a single element. It returns a live, array-like list called an `HTMLCollection`.
    
4. **The Solution is to Loop:** Because it returns a collection (a "shelf of books"), you cannot apply a style directly to the collection itself. You **must use a `for` loop** to access each element in the collection one by one.
    

### The Simple Step-by-Step Process He Showed

This is the exact same process used for `getElementsByClassName()`.

JavaScript

```
// 1. Get the collection of all paragraph elements on the page.
const paragraphs = document.getElementsByTagName('p');

// 2. Loop through the entire collection from the first item to the last.
for (let i = 0; i < paragraphs.length; i++) {

  // 3. Inside the loop, access the individual paragraph at the current position...
  const singleParagraph = paragraphs[i];
  
  // ...and apply a style to it.
  singleParagraph.style.border = '2px solid red';
}
```
