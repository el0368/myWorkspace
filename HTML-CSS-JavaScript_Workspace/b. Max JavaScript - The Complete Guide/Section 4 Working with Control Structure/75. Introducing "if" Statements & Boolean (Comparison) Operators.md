**I. Conditional Code Execution - The "If Statement"**

- **Purpose:** To run specific blocks of code only if certain conditions are met. Essential for creating dynamic and responsive applications.
    
- **Core Concept:** Code execution is based on a **boolean value** (true or false).
    
- **Syntax (General Idea):** `if (condition) { // code to execute if condition is true }`
    
- **Conditions:**
    
    - Must ultimately evaluate to `true` or `false`.
        
    - Can directly use a boolean variable.
        
    - More commonly, dynamically derived using **boolean (comparison) operators**.
        

**II. Boolean (Comparison) Operators**

These operators compare values and **return a boolean result** (`true` or `false`).

- **Equality Operator (`==`) - Loose Equality:**
    
    - Compares **only the value** of two operands.
        
    - **Ignores data types**.
        
    - Example: `2 == "2"` yields `true`.
        
    - **Caution:** Can lead to unexpected behavior due to type coercion.
        
- **Strict Equality Operator (`===`) - Strict Equality:**
    
    - Compares **both the value AND the data type** of two operands.
        
    - Recommended for clearer and more predictable code.
        
    - Example:
        
        - `2 === 2` yields `true`.
            
        - `2 === "2"` yields `false`.
            
- **Inequality Operator (`!=`) - Loose Inequality:**
    
    - Checks if two values are **not equal** (value only, ignores type).
        
    - Syntax: Exclamation mark followed by a single equals sign.
        
    - Example: `2 != "3"` yields `true`.
        
- **Strict Inequality Operator (`!==`) - Strict Inequality:**
    
    - Checks if two values are **not equal** (value and type).
        
    - Recommended over `!=`.
        
    - Example:
        
        - `2 !== 3` yields `true`.
            
        - `2 !== "2"` yields `true`.
            
- **Greater Than (`>`)**
    
    - Checks if the left operand is greater than the right operand.
        
    - Applicable to numbers and strings (lexicographical comparison for strings, e.g., 'c' > 'a' is true).
        
- **Less Than (`<`)**
    
    - Checks if the left operand is less than the right operand.
        
    - Applicable to numbers and strings.
        
- **Greater Than or Equal To (`>=`)**
    
    - Checks if the left operand is greater than or equal to the right operand.
        
- **Less Than or Equal To (`<=`)**
    
    - Checks if the left operand is less than or equal to the right operand.
        
- **Logical NOT Operator (`!`) - Negation:**
    
    - Used to **invert a boolean value**.
        
    - If a boolean is `true`, `!` makes it `false`, and vice-versa.
        
    - Can be used on existing boolean variables or in conjunction with other operators (e.g., `!==`, `!=`).
        

**III. Best Practices**

- **Prefer `===` and `!==`:** Always use the strict equality/inequality operators (`===`, `!==`) unless you have a very specific reason not to. They force you to be explicit about data types, leading to more robust and less error-prone code.
    
- **Type Conversion:** If comparing user input (often strings) to numbers, convert the user input to a number _before_ performing the comparison with strict equality. This makes your intentions clear and helps handle non-numeric input gracefully.

**I. Conditional Code Execution - The "If Statement"**

- **Purpose:** To run specific blocks of code only if certain conditions are met. Essential for creating dynamic and responsive applications.
    
- **Core Concept:** Code execution is based on a **boolean value** (`true` or `false`).
    
- **Syntax (General Idea):**
    
    JavaScript
    
    ```JavaScript
    if (condition) {
        // code to execute if condition is true
    } else {
        // (Optional) code to execute if condition is false
    }
    ```
    
- **Conditions:**
    
    - Must ultimately evaluate to `true` or `false`.
        
    - Can directly use a boolean variable.
        
        JavaScript
        
        ```JavaScript
        const isActive = true;
        if (isActive) {
            console.log("User is active.");
        }
        ```
        
    - More commonly, dynamically derived using **boolean (comparison) operators**.
        

**II. Boolean (Comparison) Operators**

These operators compare values and **return a boolean result** (`true` or `false`).

- **Equality Operator (`==`) - Loose Equality:**
    
    - Compares **only the value** of two operands.
        
    - **Ignores data types**.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(2 == 2);        // true (number vs number)
        console.log(2 == "2");      // true (number vs string - type coercion occurs)
        console.log(true == 1);     // true (boolean vs number)
        ```
        
    - **Caution:** Can lead to unexpected behavior due to type coercion.
        
- **Strict Equality Operator (`===`) - Strict Equality:**
    
    - Compares **both the value AND the data type** of two operands.
        
    - Recommended for clearer and more predictable code.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(2 === 2);       // true (same value and type)
        console.log(2 === "2");     // false (same value, but different types - number vs string)
        console.log(true === 1);    // false (different types - boolean vs number)
        ```
        
- **Inequality Operator (`!=`) - Loose Inequality:**
    
    - Checks if two values are **not equal** (value only, ignores type).
        
    - Syntax: Exclamation mark followed by a single equals sign.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(2 != 3);        // true
        console.log(2 != "2");      // false (values are equal, type ignored)
        ```
        
- **Strict Inequality Operator (`!==`) - Strict Inequality:**
    
    - Checks if two values are **not equal** (value and type).
        
    - Recommended over `!=`.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(2 !== 3);       // true (different values)
        console.log(2 !== "2");     // true (same value, but different types)
        ```
        
- **Greater Than (`>`)**
    
    - Checks if the left operand is greater than the right operand.
        
    - Applicable to numbers and strings (lexicographical comparison for strings).
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(10 > 5);        // true
        console.log(5 > 10);        // false
        console.log("c" > "a");     // true (lexicographical comparison)
        console.log("apple" > "banana"); // false
        ```
        
- **Less Than (`<`)**
    
    - Checks if the left operand is less than the right operand.
        
    - Applicable to numbers and strings.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(5 < 10);        // true
        console.log(10 < 5);        // false
        console.log("a" < "c");     // true
        ```
        
- **Greater Than or Equal To (`>=`)**
    
    - Checks if the left operand is greater than or equal to the right operand.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(10 >= 10);      // true
        console.log(10 >= 5);       // true
        console.log(5 >= 10);       // false
        ```
        
- **Less Than or Equal To (`<=`)**
    
    - Checks if the left operand is less than or equal to the right operand.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        console.log(5 <= 5);        // true
        console.log(5 <= 10);       // true
        console.log(10 <= 5);       // false
        ```
        
- **Logical NOT Operator (`!`) - Negation:**
    
    - Used to **invert a boolean value**.
        
    - If a boolean is `true`, `!` makes it `false`, and vice-versa.
        
    - Can be used on existing boolean variables or in conjunction with other operators.
        
    - Example:
        
        JavaScript
        
        ```JavaScript
        const isLoggedIn = false;
        if (!isLoggedIn) {
            console.log("Please log in to continue."); // This will execute
        }
        
        const isAdmin = true;
        if (!isAdmin) {
            console.log("Access denied."); // This will NOT execute
        }
        
        console.log(!true);         // false
        console.log(!false);        // true
        console.log(!(5 > 10));     // true (because 5 > 10 is false, !false is true)
        ```
        

**III. Best Practices**

- **Prefer `===` and `!==`:** Always use the strict equality/inequality operators (`===`, `!==`) unless you have a very specific reason not to. They force you to be explicit about data types, leading to more robust and less error-prone code.
    
    JavaScript
    
    ```JavaScript
    let userInput = "123";
    let requiredValue = 123;
    
    // Bad practice (loose equality):
    if (userInput == requiredValue) {
        console.log("Values match (loose)."); // This will log
    }
    
    // Good practice (strict equality):
    if (userInput === requiredValue) {
        console.log("Values match (strict)."); // This will NOT log
    } else {
        console.log("Values do not match (strict) - different types."); // This will log
    }
    ```
    
- **Type Conversion:** If comparing user input (often strings) to numbers, convert the user input to a number _before_ performing the comparison with strict equality. This makes your intentions clear and helps handle non-numeric input gracefully.
    
    JavaScript
    
    ```JavaScript
    let ageInput = prompt("Enter your age:"); // User enters "30"
    
    // Without conversion, strict comparison fails:
    if (ageInput === 30) {
        console.log("Age is 30."); // Will not log
    }
    
    // With conversion, strict comparison works:
    const age = Number(ageInput); // Convert "30" to 30
    if (age === 30) {
        console.log("Age is exactly 30."); // Will log
    }
    
    // Handling invalid input with conversion
    let priceInput = prompt("Enter the price:"); // User enters "abc"
    const price = Number(priceInput);
    
    if (isNaN(price)) { // isNaN checks if a value is Not-a-Number
        console.log("Invalid price entered. Please enter a number.");
    } else if (price > 100) {
        console.log("Price is expensive.");
    } else {
        console.log("Price is reasonable.");
    }
    ```
