## Simplified Study Guide: Using `if-else` for Code Optimization

**I. The Problem: Code Duplication**

- Imagine you have several functions that do almost the same thing, like `add()`, `subtract()`, `multiply()`, and `divide()`.
    
- They often share common steps (e.g., getting user input, showing the result, logging data).
    
- The only real difference is the _specific mathematical operation_ (`+`, `-`, `*`, `/`).
    
- **Issue:** This "copied and pasted" code is hard to manage. If you need to change a common step, you have to change it in multiple places, increasing the chance of errors.
    

**II. The Solution: A "Driver" Function with `if-else`**

- **Main Idea:** Create one central function (let's call it a "driver" function) that can perform _all_ the similar operations.
    
- **How it Works:**
    
    1. This driver function accepts an input (e.g., a string like `"ADD"`, `"SUBTRACT"`) that tells it which operation to perform.
        
    2. Inside the driver function, you use an `if-else if-else` structure.
        
    3. `if` the input is `"ADD"`, perform addition.
        
    4. `else if` the input is `"SUBTRACT"`, perform subtraction.
        
    5. And so on for other operations.
        
    6. The parts of the code that _are_ common (like getting input or logging) are written only once in this driver function.
        
- **Benefit:** Now, your original `add()` function just needs to call this driver function and tell it to "ADD". The `subtract()` function tells it to "SUBTRACT", etc.
    

**III. Core Concepts of `if-else`**

- **Condition:** The `if` statement checks a `condition` that must be either `true` or `false`.
    
    - Example: `if (calculationType === 'ADD')` checks if the `calculationType` variable is exactly the string "ADD".
        
- **`if` Block:** The code inside the `{}` immediately after `if (condition)` runs _only if_ the condition is `true`.
    
- **`else` Block:** The code inside the `{}` after `else` runs _only if_ the `if` condition (and any preceding `else if` conditions) are `false`.
    
- **Styling (Best Practice):** Always use curly braces `{}` for your `if` and `else` blocks, even if there's only one line of code inside. This makes your code much easier to read and less prone to errors.
    

**IV. Why this is Important**

- **Cleaner Code:** Less repetition, making your code shorter and easier to understand.
    
- **Easier to Maintain:** If you need to change how the calculator gets input, you change it in _one place_ (the driver function), not four.
    
- **More Flexible:** The same function can now handle multiple actions just by receiving a different instruction.
    

**In essence, `if-else` allows you to create smart functions that behave differently based on specific situations, reducing duplicated code and making your programs more efficient and organized.**

// Assume these are defined elsewhere in your project (e.g., vendor.js or HTML)

// Mocking these for a standalone example if not running in a browser environment
const usrInput = { value: '0' }; // Simulates input field
const currentResultOutput = { textContent: '0' }; // Simulates result display
const currentCalculationOutput = { textContent: '0' }; // Simulates calculation display

let currentResult = 0; // The current total
let logEntries = []; // To store calculation history

// Helper function to update the display
function outputResult(result, text) {
  currentResultOutput.textContent = result;
  currentCalculationOutput.textContent = text;
}

// Helper function to get number from input field
function getUserNumberInput() {
  return parseInt(usrInput.value); // Converts input string to an integer
}

// Helper function to create and display calculation string
function createAndWriteOutput(operator, resultBeforeCalc, calcNumber) {
  const calcDescription = `${resultBeforeCalc} ${operator} ${calcNumber}`;
  outputResult(currentResult, calcDescription);
}

// Helper function to log calculations
function writeToLog(operationIdentifier, prevResult, operationNumber, newResult) {
  const logEntry = {
    operation: operationIdentifier,
    prevResult: prevResult,
    number: operationNumber,
    result: newResult
  };
  logEntries.push(logEntry);
  console.log(logEntries); // For demonstration, logs the array to console
}

/**
 * Driver function to perform calculations based on type.
 * This function consolidates the logic from add, subtract, multiply, and divide.
 * @param {string} calculationType - A string indicating the type of calculation (e.g., 'ADD', 'SUBTRACT', 'MULTIPLY', 'DIVIDE').
 */
function calculateResult(calculationType) {
  const enteredNumber = getUserNumberInput(); // Common step: Get input
  const initialResult = currentResult;      // Common step: Store result before calculation
  let mathOperator;                         // To store the string symbol for display

  // Conditional execution based on calculationType
  if (calculationType === 'ADD') {
    currentResult += enteredNumber;
    mathOperator = '+';
  } else if (calculationType === 'SUBTRACT') {
    currentResult -= enteredNumber;
    mathOperator = '-';
  } else if (calculationType === 'MULTIPLY') {
    currentResult *= enteredNumber;
    mathOperator = '*';
  } else if (calculationType === 'DIVIDE') {
    // Basic division protection (could be more robust)
    if (enteredNumber === 0) {
        alert("Cannot divide by zero!");
        return; // Exit the function if division by zero is attempted
    }
    currentResult /= enteredNumber;
    mathOperator = '/';
  } else {
    // Fallback or error handling for unknown calculation types
    console.error('Invalid calculation type:', calculationType);
    return; // Stop function execution
  }

  // Common steps after calculation
  createAndWriteOutput(mathOperator, initialResult, enteredNumber);
  writeToLog(calculationType, initialResult, enteredNumber, currentResult);
}

// Event handler functions - now much simpler!
function add() {
  calculateResult('ADD'); // Simply call the driver function with the operation type
}

function subtract() {
  calculateResult('SUBTRACT');
}

function multiply() {
  calculateResult('MULTIPLY');
}

function divide() {
  calculateResult('DIVIDE');
}

console.log("Final log entries:", logEntries);
