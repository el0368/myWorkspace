

## Parameters vs. Arguments in JavaScript Functions: A Study Guide

While often used interchangeably, understanding the technical difference between **parameters** and **arguments** can bring more precision to your JavaScript vocabulary.

---

### Key Definitions:

- **Parameters:** These are the named variables listed in the parentheses when you **define** a function. They act as placeholders for the values that the function expects to receive when it's called. Think of them as the "inputs" a function is set up to handle.
    
    **Code Example (Definition):**
    
    
    
    ```JavaScript
    function greet(name, age) { // 'name' and 'age' are parameters
      console.log(`Hello, ${name}! You are ${age} years old.`);
    }
    ```
    
- **Arguments:** These are the actual, concrete **values** you pass into a function when you **call** it. They are the data that fills the placeholders defined by the parameters.
    
    **Code Example (Call):**
    
    
    
    ```JavaScript
    greet('Alice', 30); // 'Alice' and 30 are arguments
    ```
    

---

### Illustrative Example:

Let's break down the example provided:



```JavaScript
function sayHi(name) { // Function Definition
  // 'name' is a PARAMETER
  console.log(`Hi, ${name}!`);
}

sayHi('Max'); // Function Call
// 'Max' is an ARGUMENT
// It's the concrete value passed for the 'name' parameter.
```

### Why the Distinction Matters (Sometimes):

While the terms are frequently swapped in everyday coding conversations, knowing the technical difference can be helpful when:

- **Debugging:** Understanding if an issue lies with how a function expects inputs (parameters) or with the actual data being provided (arguments).
    
- **Reading Documentation:** Technical documentation often adheres strictly to these definitions.
    
- **Discussing Code Structure:** Being precise when describing how functions are designed to receive data vs. how data is actually supplied.
    

---

In essence, **parameters** are part of the function's **signature** (what it expects), and **arguments** are the **data** you supply when you **execute** that function. You'll often hear phrases like "defining the arguments a function receives," which ultimately refers to setting up its parameters.
