## JavaScript Functions & Methods: A Study Guide

### 127. Functions vs Methods

**Goal:** To understand the difference between a standalone "function" and a "method," which is a function stored inside an object.

1. **Starting Code Setup:**
    
    - We have an `index.html` file with a button:
        
        HTML
        
        ```HTML
        <!DOCTYPE html>
        <html lang="en">
        <head>
          <meta charset="UTF-8">
          <meta name="viewport" content="width=device-width, initial-scale=1.0">
          <meta http-equiv="X-UA-Compatible" content="ie=edge">
          <title>Rock, Paper, Scissors</title>
          <script src="app.js" defer></script>
        </head>
        <body>
          <button id="start-game-btn">Start Game!</button>
        </body>
        </html>
        ```
        
    - And an `app.js` file that gets the button:
        
        JavaScript
        
        ```
        const startGameBtn = document.getElementById('start-game-btn');
        // This line gets the button element and stores it in 'startGameBtn'.
        ```
        
2. **Direct Function Execution:**
    
    - We can define a function using the `function` keyword, its name, parameters (none needed here), and a body.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        function startGame() {
          console.log("Game is starting....");
        }
        ```
        
    - To run it directly, we call its name with parentheses:
        
        JavaScript
        
        ```JavaScript
        startGame();
        ```
        
    - **Result:** If this `startGame()` call is in `app.js`, "Game is starting...." appears in the console immediately when the page loads. Clicking the button does nothing because the function isn't connected to it. This is **direct execution**.
        
3. **Indirect Function Execution (Event Listener):**
    
    - We can connect our `startGame` function to the button's click event using `addEventListener`.
        
    - We pass the function's name _without_ parentheses to `addEventListener`.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        // (Assuming startGame function is defined as above)
        startGameBtn.addEventListener("click", startGame);
        ```
        
    - **Result:** No output on page load. When the button is clicked, "Game is starting...." appears. This is **indirect execution**.
        
4. **Understanding `addEventListener` and Dot Notation:**
    
    - `addEventListener` is not a function _we_ defined. It's provided by the browser.
        
    - We call it on `startGameBtn` using **dot notation** (`startGameBtn.addEventListener`). This implies `startGameBtn` is an **object**.
        
    - You've learned objects have **properties** (e.g., `person.name`). With `addEventListener`, we're not just accessing a property; we're _executing_ something.
        
    - This indicates that **functions can be stored inside objects as well.**
        
5. **Introducing "Methods":**
    
    - If we have an object, we can add a property to it, and the value of that property can be a function.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        const person = {
          greet: function greet() { // Here, 'greet' is a property whose value is a function.
            console.log("hello there!");
          },
        };
        ```
        
    - The special thing is that on the right side of the colon, instead of a simple value, we have a function.
        
    - When a function is stored in an object like this (as a property), it's called a **method**.
        
    - To execute this method, we use dot notation followed by parentheses:
        
        JavaScript
        
        ```JavaScript
        person.greet(); // Output: "hello there!"
        ```
        
    - So, a **method is nothing else than a function attached to an object.**
        
6. **`addEventListener` and `getElementById` as Methods:**
    
    - `addEventListener` is a **method** on the `startGameBtn` object.
        
    - `startGameBtn` itself is an object generated by JavaScript by calling another method: `document.getElementById()`.
        
    - `document` is a globally available variable that gives us access to our HTML document. `getElementById` is a **method** on this `document` object.
        
    - This method (`getElementById`) returns the object representing our button, which we then store in `startGameBtn`.
        
    - This `startGameBtn` object then has its own `addEventListener` method.
        

Summary of 127. Functions vs Methods:

Storing functions in objects is possible. When functions are stored in objects as properties, they are called methods. You call them using the dot notation (object.method()). addEventListener and getElementById are examples of built-in methods.
