The main point he is making is that **`getElementsByClassName()` is fundamentally different from `getElementById()` because it returns a _collection_ of items, not just one.**

You cannot treat a collection of items the same way you treat a single item.

## The Core Concept: A Shelf vs. a Single Book

Let's use a simple analogy.

- **`getElementById()`**: This is like asking for one specific book in a library using its unique ID number. The librarian hands you **one single book**. You can open it, write in it, or paint its cover directly.
    
- **`getElementsByClassName()`**: This is like asking for **all the books** in the "Science Fiction" section. The librarian doesn't hand you one book; they point you to an entire **shelf of books**.
    

This is where the confusion starts. You can't just tell the librarian to "paint the shelf blue" and expect all the books to become blue. You have to take **each book off the shelf, one by one, and paint it individually**.

---

## Key Takeaways from the Transcript

Here are the lecturer's main points, explained simply:

### 1. It Returns a Collection, Not a Single Element

`getElementsByClassName('header')` doesn't give you a single `<div>`. It gives you a live list of _all_ elements with the class "header." This list is called an **`HTMLCollection`**.

### 2. You Must Loop Through the Collection

This is why this code fails:

JavaScript

```JavaScript
// This fails because classElements is a SHELF, not a single BOOK.
classElements.style.backgroundColor = 'blue'; 
```

The error "Cannot set property 'backgroundColor' of undefined" happens because the _collection itself_ doesn't have a `.style` property. Only the individual elements _inside_ the collection do.

To solve this, you must loop through the collection and apply the style to each element one at a time.

### 3. An `HTMLCollection` is Not a True Array

The lecturer points out another tricky part: an `HTMLCollection` looks like an array, but it's not. This means some modern array methods, like `.forEach()`, will not work on it. That is why this code also fails:

JavaScript

```JavaScript
// This fails because an HTMLCollection doesn't have a forEach method.
classElements.forEach(function(element) {
  // ...
});
```

However, a classic `for` loop **does** work, which is the method he uses to solve the problem.

---

## The Simple Step-by-Step Solution

Here is the simple rule to follow, which is what the lecturer demonstrated at the end:

1. **Select the collection** of elements and store it in a variable.
    
    JavaScript
    
    ```JavaScript
    const elements = document.getElementsByClassName('header');
    ```
    
2. **Use a `for` loop** to go through each item in that collection.
    
    JavaScript
    
    ```JavaScript
    for (let i = 0; i < elements.length; i++) {
        // ... code to run on each element ...
    }
    ```
    
3. **Inside the loop**, access the _individual element_ using its index (`elements[i]`) and apply your changes to it.
    
    JavaScript
    
    ```JavaScript
    for (let i = 0; i < elements.length; i++) {
      // Access the book at the current position on the shelf
      const individualElement = elements[i];
    
      // Now "paint" that individual book
      individualElement.style.backgroundColor = 'blue';
    }
    ```
    

This loop successfully "paints" each book on the shelf blue, one by one.
