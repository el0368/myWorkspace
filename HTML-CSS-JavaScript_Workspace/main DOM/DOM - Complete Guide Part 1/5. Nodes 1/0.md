## Module 1: Core Concepts - What is the DOM?

This module establishes the foundational mental model.

1. **What a Node Is: The DOM's Building Block:** The core idea that the DOM is a tree and a "Node" is the generic name for any single item in it.
    
2. **The "Everything is a Node" Rule:** Explaining that elements, text, comments, and even whitespace are all represented as nodes.
    
3. **The 4 Most Common Node Types:** Focusing on the essential types: **Element**, **Text**, **Comment**, and **Document**.
    

---

## Module 2: The Node Family - Structure & Identification

This module explains how nodes are organized and how we can identify them.

4. **Node Relationships: Parent, Child, & Siblings:** Using the "family tree" analogy to understand the DOM's hierarchy.
    
5. **Identifying Nodes (`.nodeType`, `.nodeName`):** Learning how to use these properties to check what kind of node you are working with.
    
6. **Seeing the Full Picture with `.childNodes`:** A practical lesson on how to reveal all nodes, including the "invisible" text nodes for whitespace.
    

---

## Module 3: Working with Groups of Nodes

This module covers the practicalities of handling multiple nodes at once.

7. **Introduction to Collections (`HTMLCollection` & `NodeList`):** Explaining that selecting multiple nodes returns a special collection, not a standard array.
    
8. **The Rule of Collections: You Must Loop:** The crucial concept that you cannot apply changes directly to a collection and must iterate through it to affect the individual nodes inside.
    

---

## Module 4: Advanced Concepts - Live vs. Static

This module covers the single most important "gotcha" when working with collections.

9. **Live vs. Static Collections: The Key Difference:** Explaining that an `HTMLCollection` is a live, self-updating view of the DOM, while a `NodeList` from `querySelectorAll` is a static snapshot.
    
10. **Practical Demonstration of Live vs. Static Behavior:** Showing with code how a live collection changes automatically when the DOM is modified, while a static one does not.
