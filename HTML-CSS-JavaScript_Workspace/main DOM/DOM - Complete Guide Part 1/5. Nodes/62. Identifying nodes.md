### The `$0` Shortcut in DevTools

His first point was about the `== $0` you see in the **Elements** panel.

This is a built-in browser shortcut. When you click on any node in the Elements panel, the browser temporarily assigns it to the variable `$0`. You can then go to the **Console** and type `$0` to directly access and manipulate that specific node without having to write `document.getElementById()` first. It's a quick way to debug the currently selected item.

### The Three "ID Card" Properties

He then used this `$0` shortcut to demonstrate the three properties every node has to help you identify it:

1. **`.nodeType`**: This gives you a **number code** representing the type of node. As he showed, a comment node returns `8`. An element node (`<div>`, `<h1>`) would return `1`.
    
2. **`.nodeName`**: This gives you a **human-readable string** for the node's name. For a comment, it returns `'#comment'`. For a `<div>`, it would return `'DIV'`. This is often more intuitive than remembering the number codes.
    
3. **`.nodeValue`**: This gives you the **actual text content** of a Text Node or a Comment Node. For the comment he selected, this would return the string inside ``.
