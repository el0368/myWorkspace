In Part 1, you learned the foundational concepts of the Document Object Model (DOM) and the primary methods for selecting and basic manipulation of existing elements on a web page.

Here's a breakdown of what you covered in Part 1:

1. **Introduction to the DOM (Conceptual):**
    
    - What the DOM is (a structured representation of HTML).1
        
    - Its purpose (allowing JavaScript to interact with web page content).2
        
    - The basic hierarchy: `window` -> `document` -> `html` -> `head`/`body` -> other elements.
        
2. **Examining the `document` Object:**
    
    - How to inspect the entire `document` object using `console.dir(document)` to see its properties and methods.3
        
    - Key `document` properties: `domain`, `URL`, `title` (and how to change it dynamically), `doctype`, `head`, `body`, `all`, `forms`, `links`, `images`. You learned how to access these to get information about the page.
        
3. **Core DOM Element Selection Methods:** You learned how to get references to specific HTML elements from the document using various methods:
    
    - document.getElementById(): For selecting a single element by its unique id.
        
    - **`document.getElementsByClassName()`:** For selecting _multiple_ elements by a common `class` name.4 You learned that this returns an `HTMLCollection` and requires iteration (e.g., a `for` loop) to apply changes to all elements.5
        
    - **`document.getElementsByTagName()`:** For selecting _multiple_ elements by their HTML tag name (e.g., `div`, `li`).6 This also returns an `HTMLCollection` and requires iteration.7
        
    - **`document.querySelector()`:** A powerful, modern method for selecting the _first_ element that matches a CSS selector (ID, class, tag, attribute, pseudo-classes like `:last-child`, `:nth-child`).8
        
    - **`document.querySelectorAll()`:** Another powerful, modern method for selecting _all_ elements that match a CSS selector.9 You learned that this returns a `NodeList`, which is similar to an `HTMLCollection` but can be iterated using methods like `forEach` (though a `for` loop was used in the example). You also saw how to use pseudo-classes (`:nth-child(odd)`, `:nth-child(even)`) to style alternating elements.10
        
4. **Basic Element Manipulation:** Once you've selected an element, you learned how to modify its content and style:
    
    - **Changing Text Content:**
        
        - `element.textContent`: Sets or gets the textual content, ignoring HTML tags.11
            
        - `element.innerText`: Similar to `textContent` but is aware of styling (e.g., won't show text if `display: none`).12
            
    - **Changing HTML Content:**
        
        - `element.innerHTML`: Sets or gets the HTML content _inside_ an element.13 (Important note about potential security risks with untrusted input).
            
    - **Changing Inline Styles:**
        
        - `element.style.propertyName = "value"`: How to apply CSS styles directly to an element, remembering to use camelCase for CSS properties with hyphens (e.g., `borderBottom` instead of `border-bottom`).
            

In summary, Part 1 laid the groundwork for interacting with the DOM by teaching you how to **find** elements and then perform basic **modifications** to their text, HTML, and visual appearance.
