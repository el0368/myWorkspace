### 5. Traversing the DOM

Traversing the DOM means moving from one element to another within the document's hierarchical structure (up to parents, down to children, or across to siblings).

#### 5.1. Parent Elements

- **`element.parentNode`** (01:52)
    
    - **Purpose:** Returns the parent **node** of a specified element.
        
    - **Behavior:** Includes text nodes (like whitespace/line breaks) as potential parent nodes if they are direct parents.
        
    - **Example:**
        
        JavaScript
        
        ```        JavaScript
        var itemList = document.querySelector("#items");
        console.log(itemList.parentNode); // Will log the div with id="main"
        itemList.parentNode.style.backgroundColor = "#f4f4f4"; // Applies style to the parent
        console.log(itemList.parentNode.parentNode); // Chains to get the grandparent (the container div)
        ```
        
- **`element.parentElement`** (04:05)
    
    - **Purpose:** Returns the parent **element** of a specified element.
        
    - **Behavior:** **Preferred over `parentNode`** for most cases as it _only_ returns element nodes, ignoring text nodes (whitespace). It's essentially the same as `parentNode` if the parent is an element, but more predictable.
        
    - **Example:**
        
        JavaScript
        
        ```        JavaScript
        console.log(itemList.parentElement); // Will also log the div with id="main"
        itemList.parentElement.style.backgroundColor = "#f4f4f4";
        console.log(itemList.parentElement.parentElement); // Chains to get the grandparent
        ```
        
- **Interchangeability:** For HTML elements, `parentNode` and `parentElement` often return the same result. However, `parentElement` is generally safer when you specifically want an element and not a text node.
    

#### 5.2. Child Elements

- **`element.childNodes`** (04:51)
    
    - **Purpose:** Returns a **NodeList** of all child **nodes** (including element nodes, text nodes, and comment nodes).
        
    - **Behavior:** Often includes "text nodes" for whitespace (line breaks, indentation) between elements in your HTML source. This can be problematic if you only want element children. (05:20)
        
    - **Example:**
        
        JavaScript
        
        ```        JavaScript
        console.log(itemList.childNodes); // Will likely include text nodes
        ```
        
- **`element.children`** (06:36)
    
    - **Purpose:** Returns an **HTMLCollection** of only the child **element nodes**.
        
    - **Behavior:** **Preferred over `childNodes`** when you want to access only the actual HTML element children, as it ignores whitespace text nodes.
        
    - **Example:**
        
        JavaScript
        
        ```        JavaScript
        console.log(itemList.children); // Returns only the <li> elements
        console.log(itemList.children[1]); // Accesses the second <li>
        itemList.children[1].style.backgroundColor = "yellow"; // Styles the second <li>
        ```
        
- **`element.firstChild`** (08:05)
    
    - **Purpose:** Returns the first child **node** (can be a text node, comment, or element).
        
    - **Behavior:** Similar to `childNodes`, it will return a text node if there's whitespace before the first actual element. (08:22)
        
    - **Example:**
        
        JavaScript
        
        ```        JavaScript
        console.log(itemList.firstChild); // Might return a Text Node
        ```
        
- **`element.firstElementChild`** (08:58)
    
    - **Purpose:** Returns the first child **element**.
        
    - **Behavior:** **Preferred over `firstChild`** when you want the actual first HTML element child.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.firstElementChild); // Returns the first <li> element
        itemList.firstElementChild.textContent = "hello 1";
        ```
        
- **`element.lastChild`** (09:39)
    
    - **Purpose:** Returns the last child **node** (can be a text node, comment, or element).
        
    - **Behavior:** Similar to `firstChild`, it can return a text node if there's whitespace after the last element.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.lastChild); // Might return a Text Node
        ```
        
- **`element.lastElementChild`** (09:56)
    
    - **Purpose:** Returns the last child **element**.
        
    - **Behavior:** **Preferred over `lastChild`** when you want the actual last HTML element child.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.lastElementChild); // Returns the last <li> element
        itemList.lastElementChild.textContent = "hello 4";
        ```
        

#### 5.3. Sibling Elements

- **`element.nextSibling`** (10:46)
    
    - **Purpose:** Returns the next sibling **node** (can be a text node, comment, or element).
        
    - **Behavior:** Will return a text node if there is whitespace between the current element and the next.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.nextSibling); // Might return a Text Node
        ```
        
- **`element.nextElementSibling`** (11:15)
    
    - **Purpose:** Returns the next sibling **element**.
        
    - **Behavior:** **Preferred over `nextSibling`** when you want the actual next HTML element sibling.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.nextElementSibling); // If itemList is a UL, and there's a SPAN after it, it might return that SPAN.
        ```
        
- **`element.previousSibling`** (12:06)
    
    - **Purpose:** Returns the previous sibling **node** (can be a text node, comment, or element).
        
    - **Behavior:** Will return a text node if there is whitespace between the current element and the previous.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.previousSibling); // Might return a Text Node
        ```
        
- **`element.previousElementSibling`** (12:31)
    
    - **Purpose:** Returns the previous sibling **element**.
        
    - **Behavior:** **Preferred over `previousSibling`** when you want the actual previous HTML element sibling.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        console.log(itemList.previousElementSibling); // Returns the H2 element before the UL
        itemList.previousElementSibling.style.color = "green"; // Changes the color of the H2
        ```
        

### 6. Creating and Inserting Elements

You can dynamically build new HTML elements entirely with JavaScript and then place them into the existing DOM.

#### 6.1. Creating Elements

- **`document.createElement('tagName')`** (14:31)
    
    - **Purpose:** Creates a new HTML element of the specified tag name. The element is _not yet_ in the DOM; it's just a JavaScript object in memory.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        var newDiv = document.createElement("div"); // Creates an empty <div> element
        ```
        
- **Adding Attributes and Properties to the New Element:**
    
    - **`element.className = 'class-name'`:** Sets the `class` attribute. (15:26)
        
        JavaScript
        
        ```JavaScript
        newDiv.className = "helloClassName";
        ```
        
    - **`element.id = 'id-name'`:** Sets the `id` attribute. (15:57)
        
        JavaScript
        
        ```JavaScript
        newDiv.id = "HelloID";
        ```
        
    - **`element.setAttribute('attributeName', 'value')`:** A more general method to set any attribute. (16:23)
        
        JavaScript
        
        ```JavaScript
        newDiv.setAttribute("title", "hello div");
        ```
        
    - **`element.style.propertyName = 'value'`:** Sets inline CSS styles. (20:01)
        
        JavaScript
        
        ```JavaScript
        newDiv.style.fontSize = "20px";
        ```
        

#### 6.2. Creating Text Nodes

- **`document.createTextNode('text content')`** (16:59)
    
    - **Purpose:** Creates a new text node with the specified string content.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        var newDivText = document.createTextNode("Hello World!");
        ```
        

#### 6.3. Appending and Inserting Elements

- **`parentElement.appendChild(childElement)`** (17:36)
    
    - **Purpose:** Appends a child element to the _end_ of the `parentElement`'s children.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        newDiv.appendChild(newDivText); // Puts the "Hello World!" text node inside the newDiv
        ```
        
- **`parentElement.insertBefore(newElement, referenceElement)`** (19:22)
    
    - **Purpose:** Inserts `newElement` immediately _before_ the `referenceElement` within the `parentElement`.
        
    - **Key:** You need to identify the `parentElement` where the insertion will occur, the `newElement` to insert, and the `referenceElement` that the `newElement` should appear before.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        var container = document.querySelector("header .container"); // The parent
        var h1 = document.querySelector("header h1"); // The reference element (insert before this)
        container.insertBefore(newDiv, h1); // Inserts newDiv before h1 within the container
        ```
        
    - **Result:** The `newDiv` element, complete with its class, ID, title, and "Hello World!" text, is now visible on the page, positioned before the `h1` within the header container.
