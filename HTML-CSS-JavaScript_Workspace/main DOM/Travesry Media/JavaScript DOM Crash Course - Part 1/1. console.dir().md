`console.dir()` is a browser console method that displays an interactive list of the properties of a specified JavaScript object. It allows you to see the object's contents as a hierarchical, expandable directory.

---

## What does ".dir" stand for?

`.dir()` stands for **directory**. Think of it as showing you a file directory listing for an object, where you can see all its properties (files) and nested objects (folders) 📂.

---

## console.dir() vs. console.log()

The main difference is how they display objects, especially DOM elements.

- **`console.log()`**: Gives you a simple, often string-based, representation. For a DOM element, it usually just shows the HTML tag.
    
- **`console.dir()`**: Gives you an interactive, property-first view. For a DOM element, it shows the **element object** itself, allowing you to expand and inspect all its properties like `.style`, `.classList`, and `.children`.
    

### Example

JavaScript

```
// Grab a DOM element
const myHeading = document.querySelector('h1');

// This will likely show the HTML tag in the console: <h1>My Title</h1>
console.log(myHeading);

// This will show an interactive object that you can expand to see all its properties
console.dir(myHeading);
```
