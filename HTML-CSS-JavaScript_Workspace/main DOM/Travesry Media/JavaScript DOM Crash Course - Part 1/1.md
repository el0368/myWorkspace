## JavaScript DOM Manipulation Study Guide

This guide covers fundamental concepts and practical examples of interacting with the Document Object Model (DOM) using vanilla JavaScript.

### 1. Understanding the DOM

- **What is the DOM?** (02:45)
    
    - Stands for **Document Object Model**.
        
    - A structured representation (tree of nodes/elements) of an HTML document created by the browser.
        
    - Allows JavaScript to manipulate the structure, content, and style of a web page.
        
    - Object-oriented: Each node has properties and methods.
        
- **DOM Structure (Tree Analogy):** (03:27)
    
    - `window` object: Represents the browser window itself (top-level object).
        
    - `document` object: The core of the DOM, contained within the `window`.
        
    - `html` tag (root element): Parent of `head` and `body`.
        
    - `head` and `body` tags: Children of `html`, containing their own children (e.g., `title`, `meta`, `h1`, `a`, `ul`, `li`, `form`, `input`).
        
    - Text nodes: Text content within elements (e.g., "My Header" inside an `h1`).
        
    - Attributes: Properties of elements (e.g., `href` on an `a` tag, `id`, `class`).
        

### 2. Examining the `document` Object

- The `document` object is your entry point to the DOM.
    
- **`console.dir(document)`:** (07:38)
    
    - Use this to explore all the properties and methods available on the `document` object. It provides a detailed, interactive view in the browser's console.
        
- **Useful `document` Properties:**
    
    - `document.domain`: (09:05) Returns the domain of the current document (e.g., `127.0.0.1` for localhost).
        
    - `document.URL`: (09:36) Returns the full URL of the current document.
        
    - `document.title`: (09:55) Returns or sets the title of the document (visible in the browser tab). Can be changed dynamically (e.g., `document.title = "New Title";`).
        
    - `document.doctype`: (10:39) Returns the document's doctype (e.g., `<!DOCTYPE html>`).
        
    - `document.head`: (10:53) Returns the `<head>` element of the document.
        
    - `document.body`: (11:06) Returns the `<body>` element of the document.
        
    - `document.all`: (11:19) Returns an HTML collection of _all_ elements in the document. **Avoid using for specific selection** as element indices can change (13:11).
        
    - `document.forms`: (13:57) Returns an HTML collection of all `<form>` elements.
        
    - `document.links`: (14:24) Returns an HTML collection of all `<a>` (link) elements.
        
    - `document.images`: (15:17) Returns an HTML collection of all `<img>` elements.
        

### 3. Selecting Elements from the DOM

These methods allow you to pinpoint specific elements or groups of elements on your page.

#### 3.1. `document.getElementById()`

- **Purpose:** Selects a single element by its unique `id` attribute. (15:53)
    
- **Syntax:** `document.getElementById('your-id-name')`
    
- **Example:**
    
    
    
    ```JavaScript
    var headerTitle = document.getElementById("header-title");
    console.log(headerTitle); // Logs the h1 element with id="header-title"
    var mainHeader = document.getElementById("main-header");
    ```
    
- **Returns:** A single element object or `null` if not found.
    

#### 3.2. `document.getElementsByClassName()`

- **Purpose:** Selects all elements that have a specific class name. (22:29)
    
- **Syntax:** `document.getElementsByClassName('your-class-name')`
    
- **Example:**
    
    
    
    ```JavaScript
    var items = document.getElementsByClassName("list-group-item");
    console.log(items); // Logs an HTMLCollection
    console.log(items[0]); // Accesses the first element in the collection
    ```
    
- **Returns:** An **HTMLCollection** (array-like object).
    
- **Important:** You **must iterate** over an HTMLCollection if you want to apply changes to all elements (e.g., with a `for` loop) (25:22).
    
    
    
    ```JavaScript
    for (var i = 0; i < items.length; i++) {
        items[i].style.backgroundColor = "#f4f4f4";
    }
    ```
    

#### 3.3. `document.getElementsByTagName()`

- **Purpose:** Selects all elements that have a specific HTML tag name. (27:17)
    
- **Syntax:** `document.getElementsByTagName('your-tag-name')`
    
- **Example:**
    
    
    
    ```JavaScript
    var li = document.getElementsByTagName("li");
    console.log(li); // Logs an HTMLCollection
    console.log(li[0]); // Accesses the first li element
    ```
    
- **Returns:** An **HTMLCollection**.
    
- **Important:** Similar to `getElementsByClassName()`, you **must iterate** to apply changes to all elements.
    

#### 3.4. `document.querySelector()`

- **Purpose:** Selects the _first_ element that matches a specified CSS selector. (29:14)
    
- **Syntax:** `document.querySelector('css-selector')`
    
- **CSS Selectors You Can Use:**
    
    - **ID:** `$('#your-id')` becomes `document.querySelector('#your-id')`
        
    - **Class:** `$('.your-class')` becomes `document.querySelector('.your-class')`
        
    - **Tag:** `$('your-tag')` becomes `document.querySelector('your-tag')`
        
    - **Attribute:** `$('input[type="submit"]')` becomes `document.querySelector('input[type="submit"]')`
        
    - **Pseudo-classes:**
        
        - `:last-child`: `document.querySelector('.list-group-item:last-child')` (33:20)
            
        - `:nth-child(n)`: `document.querySelector('.list-group-item:nth-child(2)')` (34:08)
            
- **Example:**
    
    
    
    ```JavaScript
    var header = document.querySelector("#main-header");
    header.style.borderBottom = "solid 4px #ccc";
    
    var input = document.querySelector("input"); // Selects the first input
    input.value = "hello world";
    
    var submitBtn = document.querySelector('input[type="submit"]');
    submitBtn.value = "SEND";
    ```
    
- **Returns:** A single element object or `null` if no match is found.
    

#### 3.5. `document.querySelectorAll()`

- **Purpose:** Selects _all_ elements that match a specified CSS selector. (35:02)
    
- **Syntax:** `document.querySelectorAll('css-selector')`
    
- **Example:**
    
    
    
    ```JavaScript
    var titles = document.querySelectorAll(".title");
    console.log(titles); // Logs a NodeList
    titles[0].textContent = "Add Items, Now!";
    
    var oddItems = document.querySelectorAll("li:nth-child(odd)");
    var evenItems = document.querySelectorAll("li:nth-child(even)");
    
    for (var i = 0; i < oddItems.length; i++) {
        oddItems[i].style.backgroundColor = "#f4f4f4";
        evenItems[i].style.backgroundColor = "#ccc";
    }
    ```
    
- **Returns:** A **NodeList** (array-like object).
    
- **Key Difference from HTMLCollection:** A NodeList **can** have array methods (like `forEach`) applied directly, unlike an HTMLCollection. While the provided code uses a `for` loop, `forEach` is also a common choice for NodeLists.
    

### 4. Manipulating Element Content and Styles

Once you've selected an element, you can modify its properties. This applies to elements selected by any of the above methods.

- **Changing Text Content:**
    
    - **`element.textContent`:** Gets or sets the text content of an element, ignoring any HTML tags within it. (17:12)
        
        
        
        ```JavaScript
        headerTitle.textContent = "Hello";
        ```
        
    - **`element.innerText`:** Similar to `textContent`, but is aware of the element's rendered styling (e.g., if content is hidden by `display: none`, `innerText` won't include it). (17:24)
        
        
        
        ```JavaScript
        headerTitle.innerText = "Goodbye";
        ```
        
- **Changing HTML Content:**
    
    - **`element.innerHTML`:** Gets or sets the HTML content within an element. Be cautious as this can introduce security vulnerabilities if used with untrusted input. (19:14)
        
        
        
        ```JavaScript
        headerTitle.innerHTML = "<h3>Hi</h3>"; // Replaces content with an h3
        ```
        
- **Changing CSS Styles:**
    
    - Access the `style` property of an element, then the specific CSS property.
        
    - **Use camelCase for CSS properties** that contain hyphens (e.g., `border-bottom` becomes `borderBottom`). (20:55)
        
    - **Example:**
        
        
        
        ```JavaScript
        header.style.borderBottom = "solid 10px #000";
        items[1].style.fontWeight = "bold";
        items[1].style.backgroundColor = "yellow";
        ```
