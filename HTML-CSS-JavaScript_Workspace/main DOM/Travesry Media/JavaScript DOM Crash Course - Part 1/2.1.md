From Part 2 (both the code and the transcript), you primarily learn about two major aspects of DOM manipulation:

1. **Traversing the DOM:** This is about navigating the existing structure of your HTML document.1 Instead of always selecting elements directly by ID or class, you learn how to move relative to an element you've already selected.
    
    - **Moving Up (Parents):**
        
        - `parentNode`: Gets the parent node (can include text nodes like whitespace).2
            
        - `parentElement`: Gets the parent element (ignores text nodes, generally preferred).
            
    - **Moving Down (Children):**
        
        - `childNodes`: Gets all child nodes (includes text nodes).3
            
        - `children`: Gets only child _elements_ (generally preferred).4
            
        - `firstChild` / `lastChild`: Gets the first/last child node (can be text nodes).5
            
        - `firstElementChild` / `lastElementChild`: Gets the first/last child _element_ (generally preferred).6
            
    - **Moving Sideways (Siblings):**
        
        - `nextSibling` / `previousSibling`: Gets the next/previous sibling node (can be text nodes).7
            
        - `nextElementSibling` / `previousElementSibling`: Gets the next/previous sibling _element_ (generally preferred).8
            
    - **Key takeaway regarding "Node" vs. "Element":** You learn the crucial distinction between "nodes" (which include elements, text, comments, etc.) and "elements" (which are only HTML tags). For most practical DOM manipulation, you'll want to use the "Element" versions of the properties to avoid dealing with unwanted text nodes created by whitespace in your HTML.
        
2. **Creating and Inserting New DOM Elements:** This involves dynamically building HTML elements from scratch using JavaScript and then placing them into the live document.9
    
    - **`document.createElement('tagName')`**: How to create a brand new HTML element (e.g., `div`, `li`, `p`).10
        
    - **Setting Element Properties/Attributes**: How to add classes (`className`), IDs (`id`), and other attributes (`setAttribute`) to your newly created elements.
        
    - **`document.createTextNode('text content')`**: How to create a text node that can be appended to an element.11
        
    - **`element.appendChild(child)`**: How to add a child element or text node to the end of another element.12
        
    - **`parentElement.insertBefore(newElement, referenceElement)`**: How to insert a new element at a specific position _before_ an existing reference element.13
        

In essence, Part 2 moves beyond just _selecting_ and _modifying_ existing content to giving you the power to _navigate_ the DOM programmatically and _generate_ entirely new content, integrating it into the page at precise locations.
