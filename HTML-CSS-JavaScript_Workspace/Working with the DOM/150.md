### ## Selecting DOM Elements

To interact with content on your web page, you first need to select the specific elements. You can do this using methods available on the global `document` object. These methods can be grouped into two categories: those that select a single element and those that select multiple elements.

### ## Selecting a Single Element

These methods return a direct reference to the first DOM element that matches the query.

- **`document.querySelector('selector')`**
    
    - This is the most flexible and modern method.
        
    - It accepts any **CSS selector** as an argument (e.g., `'#main-title'`, `'.list-item'`, `'ul > li'`).
        
    - It always returns the **first** element that matches the selector.
        
- **`document.getElementById('id')`**
    
    - This method specifically selects an element by its `id` attribute.
        
    - Since IDs should be unique on a page, it's a very reliable way to get exactly one element.
        

### ## Selecting Multiple Elements

These methods return a collection of elements that match the query. This collection is typically a **NodeList**, which is an "array-like" object (you can loop over it, but it doesn't have all array methods).

- **`document.querySelectorAll('selector')`**
    
    - Similar to `querySelector`, but it returns **all** elements that match the CSS selector, not just the first one.
        
    - **Important:** This method returns a static, non-live "snapshot" of the DOM. If you add or remove elements later, the list returned by this method will not be updated.
        
- **`document.getElementsByTagName('tag')`**
    
    - Returns all elements that have a specific HTML tag (e.g., `'li'`, `'p'`).
        
    - **Important:** Unlike `querySelectorAll`, this method returns a **live collection**. If elements with that tag are added or removed from the DOM, this collection will automatically update to reflect the changes.

### ## Nodes vs. Elements

It's important to understand the distinction between "nodes" and "elements."

- **Node:** Everything in the DOM is a **node**. This includes HTML tags, the text inside those tags, comments, etc.
    
- **Element:** An **element** is a specific _type_ of node—one created from an HTML tag (like `<p>`, `<div>`, or `<h1>`). These are the nodes we interact with most often.
    

We focus on elements because they have special properties and methods that allow us to change their style, content, and attributes. While text is also a node (a "text node"), we typically manipulate it by accessing the element that contains it.
