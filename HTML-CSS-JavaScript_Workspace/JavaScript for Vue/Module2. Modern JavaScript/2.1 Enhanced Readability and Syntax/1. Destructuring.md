Destructuring is a JavaScript feature that lets you extract values from arrays or properties from objects and assign them to distinct variables in a clean, concise way.

---

### Object Destructuring `{}`

Object destructuring allows you to unpack properties from an object by their **key names**.

- **Basic Unpacking**:
    
    JavaScript
    
    ```JavaScript
    const user = {
      name: 'Alice',
      role: 'Admin',
      theme: 'dark'
    };
    
    // Extract 'name' and 'role' into variables with the same names.
    const { name, role } = user;
    
    console.log(name); // 'Alice'
    console.log(role); // 'Admin'
    ```
    
- Assigning to New Variable Names:
    
    You can rename the variables using a colon (:).
    
    JavaScript
    
    ```JavaScript
    const { name: userName, role: userRole } = user;
    
    console.log(userName); // 'Alice'
    ```
    
- Setting Default Values:
    
    You can provide a default value for a property that might not exist on the object.
    
    JavaScript
    
    ```JavaScript
    const { theme = 'light', name } = user;
    
    console.log(theme); // 'dark' (since it exists on the object)
    ```
    

---

### Array Destructuring `[]`

Array destructuring allows you to unpack values from an array by their **position (index)**.

- **Basic Unpacking**:
    
    JavaScript
    
    ```JavaScript
    const scores = [100, 95, 88];
    
    // Extract values based on their position.
    const [first, second] = scores;
    
    console.log(first); // 100
    console.log(second); // 95
    ```
    
- Skipping Elements:
    
    You can use a comma to skip an element you don't need.
    
    JavaScript
    
    ```JavaScript
    const [topScore, , thirdScore] = scores;
    
    console.log(thirdScore); // 88
    ```
    
- The Rest Pattern (...):
    
    You can gather all remaining elements into a new array.
    
    JavaScript
    
    ```JavaScript
    const [winner, ...losers] = ['Alice', 'Bob', 'Charlie'];
    
    console.log(winner); // 'Alice'
    console.log(losers); // ['Bob', 'Charlie']
    ```
    

Destructuring is incredibly useful in Vue for cleanly handling component `props` and for pulling specific state or getters from state management libraries like Pinia or Vuex.
