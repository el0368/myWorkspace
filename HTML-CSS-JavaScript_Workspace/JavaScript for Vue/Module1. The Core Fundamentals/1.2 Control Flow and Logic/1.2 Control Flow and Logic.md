Control flow and logic are the fundamental tools that allow your JavaScript code to make decisions, repeat actions, and handle different scenarios. Mastering these is essential before learning Vue, as Vue's directives like `v-if` and `v-for` are simply declarative ways of applying these same core principles.

---

### Conditional Statements: Making Decisions 🤔

Conditional statements execute different blocks of code based on whether a condition is true or false.

- **`if / else`**: This is the most common conditional statement. The `if` block runs if a condition is true; otherwise, the `else` block runs.
    
    JavaScript
    
    ```JavaScript
    const userRole = 'admin';
    
    if (userRole === 'admin') {
      console.log('Access Granted.');
    } else {
      console.log('Access Denied.');
    }
    ```
    
- **`switch`**: Useful when you have multiple conditions to check against a single value. It's often cleaner than a long chain of `if/else if` statements.
    
    JavaScript
    
    ```JavaScript
    const userStatus = 'active';
    
    switch (userStatus) {
      case 'active':
        console.log('User is active.');
        break;
      case 'inactive':
        console.log('User is inactive.');
        break;
      default:
        console.log('User status unknown.');
    }
    ```
    
- **Ternary Operator (`? :`)**: A compact, one-line shortcut for a simple `if/else` statement. It's heavily used for inline conditionals in Vue templates.
    
    JavaScript
    
    ```JavaScript
    const isLoggedIn = true;
    const message = isLoggedIn ? 'Welcome back!' : 'Please log in.';
    // message is 'Welcome back!'
    ```

### Loops: Repeating Actions 🔁

Loops allow you to execute a block of code repeatedly, which is crucial for processing lists of data.

- **`for` loop**: The classic loop. You define a counter, a condition to continue, and an incrementor. It's ideal when you know how many times you need to loop.
    
    JavaScript
    
    ```JavaScript
    for (let i = 0; i < 3; i++) {
      console.log(`Iteration number ${i}`);
    }
    ```
    
- **`while` loop**: This loop continues as long as its condition remains true. It's useful when the number of iterations isn't known beforehand.
    
    JavaScript
    
    ```JavaScript
    let stock = 3;
    while (stock > 0) {
      console.log(`Selling one item. Stock remaining: ${stock - 1}`);
      stock--;
    }
    ```
    
- **`do...while` loop**: Similar to a `while` loop, but it guarantees that the code block will be executed at least once before the condition is checked.
    
    JavaScript
    
    ```JavaScript
    let password;
    do {
      // This block will run at least once.
      password = prompt('Enter your password:');
    } while (password.length < 8);
    ```

### Logical Operators: Combining Conditions 🚦

Logical operators are used to combine or invert boolean (`true`/`false`) values.

- **`&&` (AND)**: Returns `true` only if **both** conditions are true.
    
    JavaScript
    
    ```JavaScript
    const hasKey = true;
    const isDoorUnlocked = false;
    // (hasKey && isDoorUnlocked) is false
    ```
    
- **`||` (OR)**: Returns `true` if **at least one** of the conditions is true.
    
    JavaScript
    
    ```JavaScript
    const hasCoupon = false;
    const isMember = true;
    // (hasCoupon || isMember) is true
    ```
    
- **`!` (NOT)**: Inverts a boolean value.
    
    JavaScript
    
    ```JavaScript
    const isEditing = false;
    // !isEditing is true
    ```
