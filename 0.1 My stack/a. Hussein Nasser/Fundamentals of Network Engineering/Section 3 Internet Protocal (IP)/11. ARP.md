### What is ARP (Address Resolution Protocol)?

**ARP** stands for **Address Resolution Protocol**. It's a fundamental network protocol used to find the **MAC address** of a device when only its **IP address** is known.

||**IP Address**|**MAC Address**|
|---|---|---|
|**Purpose**|Used to route data across different networks.|Used to identify a specific device on a local network.|
|**Example**|192.168.1.100|00:1A:2B:3C:4D:5E|
|**Known By**|We almost always know this (from DNS lookup).|We almost never know this.|

### How does ARP work?

When a computer (let's call it Host A) wants to send data to another computer (Host B) on the same local network, it follows these steps:

1. **Check IP Address:** Host A first checks if Host B is on the same local network using the **subnet mask**.
    
2. **Check ARP Table:** If Host B is on the same network, Host A checks its **ARP table**, which is a local cache of IP-to-MAC address mappings. If it finds Host B's MAC address, it can immediately send the data.
    
3. **Broadcast ARP Request:** If Host A doesn't find Host B's MAC address in its table, it sends an **ARP request broadcast** to every device on the local network. The request asks, "Who has the IP address 10.0.0.5? Please reply with your MAC address."
    
4. **Send ARP Reply:** All devices on the network receive the broadcast, but only Host B recognizes its own IP address. It replies to Host A with a message stating, "I have that IP address, and my MAC address is [MAC address of Host B]."
    
5. **Update ARP Table:** Host A receives the reply, updates its ARP table with the new mapping, and can now send the data directly to Host B's MAC address.
    

### What about communicating with devices on a different network?

If Host A wants to talk to a device on a different network, it uses the same process but with a different target. Since it can't send data directly to the remote device, it needs to send the data to its **default gateway** (router).

1. Host A checks its ARP table for the MAC address of its default gateway.
    
2. If it doesn't have it, it sends an ARP request asking for the MAC address of the gateway's IP address.
    
3. The gateway replies with its MAC address, and Host A can then send the data frame to the gateway.
    
4. The gateway takes the packet and handles the routing to the correct external network.
    

### What is ARP Poisoning?

**ARP poisoning** is a type of attack where a malicious actor intercepts network traffic by faking an ARP reply. The attacker sends a fake ARP message to the network, claiming that their MAC address belongs to the IP address of the default gateway.

When Host A sends an ARP request for its gateway, the attacker can respond first with this false information. Host A will then update its ARP table with the attacker's MAC address, and all its traffic intended for the internet will be sent to the attacker's computer instead of the real router. The attacker can then read all the data before forwarding it to the real gateway. This is a common way to perform a **man-in-the-middle attack** on a local network.
