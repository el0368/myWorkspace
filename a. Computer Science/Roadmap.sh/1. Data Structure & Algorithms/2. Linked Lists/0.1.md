### Examples for General Concepts

These examples show the general programming ideas using Rust syntax.

#### 1. Core Programming Fundamentals (structs, functions, control flow)

This shows how to define a custom data type (`struct`), create functions that operate on it (`impl`), and use `if/else` logic.

Rust

```Rust
// A custom data type for a User
struct User {
    username: String,
    active: bool,
}

// An implementation block with functions for the User struct
impl User {
    // A function to create a new user
    fn new(username: String) -> User {
        User {
            username: username,
            active: true,
        }
    }

    // A function to get a status message
    fn get_status(&self) -> String {
        // Using if/else for control flow
        if self.active {
            format!("{} is active.", self.username)
        } else {
            format!("{} is inactive.", self.username)
        }
    }
}
```

#### 2. Pointers vs. References

This demonstrates the "address vs. house" analogy. A reference (`&`) points to the memory location of another variable.

Rust

```Rust
fn main() {
    // The "house": the actual data `5` stored in the variable `x`.
    let x = 5;

    // The "address": `y` is a reference that stores the memory location of `x`.
    let y = &x;

    println!("The value of x is: {}", x);
    println!("The value that y points to is: {}", *y); // Use `*` to get the value
    println!("The memory address stored in y is: {:p}", y);
}
```

#### 3. Dynamic Memory Allocation (Heap vs. Stack)

Here, `on_stack` is allocated directly on the fast, automatic stack. `on_heap` is allocated on the flexible heap using `Box::new()`, which is necessary for data structures like linked lists.

Rust

```Rust
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    // This `Point` is created on the stack. Its memory is automatically cleaned up.
    let on_stack = Point { x: 10, y: 20 };

    // This `Point` is created on the heap. The `Box` smart pointer manages its memory.
    let on_heap = Box::new(Point { x: 30, y: 40 });

    println!("Stack point x: {}", on_stack.x);
    println!("Heap point x: {}", on_heap.x);
}
```

### Examples for Rust-Specific Concepts

These examples show the specific tools Rust provides.

#### 1. Ownership & `Box<T>`

`Box<T>` is a smart pointer that takes ownership of the data it points to and allocates it on the heap.

Rust

```Rust
fn main() {
    // `my_string` is a String allocated on the heap.
    let my_string = String::from("hello");

    // `my_box` is a smart pointer that now OWNS `my_string`.
    // The data is moved from `my_string` into the box.
    let my_box = Box::new(my_string);

    // This line would cause a compile error because `my_string`'s value was moved.
    // You can't use it anymore because `my_box` is the new owner.
    // println!("{}", my_string);

    // We can still use the data through the box.
    println!("The box contains: {}", my_box);
}
```

#### 2. `Option<T>` for Nullability

Rust uses the `Option` enum to handle cases where a value might be absent. This is how you create "nullable" pointers for the end of a linked list.

Rust

```Rust
// This function might find a user, or it might not.
fn find_user(name: &str) -> Option<String> {
    if name == "Alice" {
        Some(String::from("Alice")) // Return the user if found
    } else {
        None // Return `None` if not found
    }
}

fn main() {
    // We use `match` to safely handle both possibilities from the function.
    match find_user("Alice") {
        Some(user) => println!("Found user: {}", user),
        None => println!("User not found."),
    }

    match find_user("Bob") {
        Some(user) => println!("Found user: {}", user),
        None => println!("User not found."),
    }
}
```
