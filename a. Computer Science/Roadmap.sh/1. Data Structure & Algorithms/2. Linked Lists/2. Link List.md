### 1. The Core Definition and Structure (Singly Linked List)

This example shows the basic `struct`s used to create a singly linked list. Notice how the `Node` contains the data (`elem`) and a link to the `next` node. The `List` itself just needs to know where the `head` is.

Rust

```Rust
// The List itself just holds a link to the first node.
pub struct List<T> {
    head: Link<T>,
}

// A "Link" is a type alias for an optional, heap-allocated Node.
// `Option` is used because the link might be `None` (the end of the list).
// `Box` is used to store the node on the heap.
type Link<T> = Option<Box<Node<T>>>;

// A Node contains the data element and a link to the next node.
struct Node<T> {
    elem: T,
    next: Link<T>,
}
```

### 2. Essential Operations (Singly Linked List)

Here's how some of the essential operations are implemented.

#### Inserting at the Beginning (push): Very Fast (O(1))

This is the primary advantage of a linked list. We only need to create a new node and update a couple of pointers; we don't have to shift any data.

Rust

```Rust
// Implementation block for our List
impl<T> List<T> {
    // Creates a new, empty list
    pub fn new() -> Self {
        List { head: None }
    }

    // Adds an element to the front of the list. This is O(1).
    pub fn push(&mut self, elem: T) {
        let new_node = Box::new(Node {
            elem: elem,
            // The new node's `next` points to the old head
            next: self.head.take(),
        });

        // The list's head now points to our new node
        self.head = Some(new_node);
    }
}
```

#### Searching (and Sequential Access): Slow (O(n))

To find an element, you must start at the `head` and walk through the list one node at a time. This demonstrates the **sequential access** property.

Rust

```Rust
// (Continuing the impl block...)
    // Simple search to see if an element exists. This is O(n).
    // We must use `PartialEq` to be able to compare elements with `==`.
    pub fn search(&self, target: &T) -> bool where T: PartialEq {
        let mut current = &self.head;

        // Loop while `current` is not `None`
        while let Some(node) = current {
            if node.elem == *target {
                return true; // Found it!
            }
            // Move to the next node in the list
            current = &node.next;
        }
        false // Reached the end without finding it
    }
```

### 3. The Structure of a Doubly Linked List

Implementing a full, safe doubly linked list in Rust is an advanced topic because of Rust's ownership rules. However, you can understand the basic structure of its node.

Notice that a node has a pointer to the `next` element _and_ the `prev` (previous) element.

Rust

```Rust
// This code just shows the structure of the node.
// A full, safe implementation in Rust requires advanced concepts like `Rc<RefCell<T>>`.

struct DoublyLinkedNode<T> {
    elem: T,
    // A link to the next node
    next: Option</* Pointer to a node */ T>,
    // A link to the previous node
    prev: Option</* Pointer to a node */ T>,
}
```
