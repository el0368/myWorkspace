### 1. Basic Syntax and Declaration

This example shows how to declare an array, let the compiler infer its type, initialize it with a default value, and access its elements.

Rust

```Rust
fn main() {
    // 1. Declare an array with explicit type and size: [type; size]
    let numbers: [i32; 5] = [10, 20, 30, 40, 50];

    // 2. Let the compiler infer the type and size
    let fruits = ["apple", "banana", "orange"]; // Type is [&str; 3]

    // 3. Initialize an array with the same value for all elements: [value; size]
    let zeros = [0; 8]; // An array of eight zeros: [0, 0, 0, 0, 0, 0, 0, 0]

    // 4. Access elements using an index (starting from 0)
    let first_number = numbers[0]; // Gets 10
    let second_fruit = fruits[1]; // Gets "banana"

    println!("The first number is: {}", first_number);
    println!("The second fruit is: {}", second_fruit);
    println!("The zeros array looks like: {:?}", zeros);
}
```

### 2. The Static Type System in Action

This example demonstrates that an array's size is part of its type, which is checked at compile time.

Rust

```Rust
// This function ONLY accepts an array of exactly 3 floating-point numbers.
fn process_rgb_color(color: [f32; 3]) {
    println!("Processing color: R={}, G={}, B={}", color[0], color[1], color[2]);
}

fn main() {
    let red: [f32; 3] = [1.0, 0.0, 0.0];
    let blue_with_alpha: [f32; 4] = [0.0, 0.0, 1.0, 1.0];

    // This works perfectly because `red` matches the type [f32; 3]
    process_rgb_color(red);

    // This line will cause a COMPILE ERROR!
    // process_rgb_color(blue_with_alpha);
    //
    // The compiler will stop you with an error like:
    // "mismatched types: expected array `[f32; 3]`, found array `[f32; 4]`"
}
```

This compile-time check prevents bugs by ensuring you can't accidentally pass an array of the wrong size to a function.

### 3. Stack Memory Use Case

Because arrays have a known, fixed size, they are stored on the stack, making them very fast for data that doesn't need to change size. A classic example is coordinates.

Rust

```Rust
fn main() {
    // An array is perfect for a 2D point. It's a fixed size and very fast.
    // This `point` variable lives entirely on the stack.
    let point: [i32; 2] = [120, 250];

    println!("The x-coordinate is: {}", point[0]);

    // In contrast, a Vec<T> is for when you need a list that can grow.
    // Its data is stored on the slower, but more flexible, heap.
    let mut dynamic_points: Vec<[i32; 2]> = Vec::new();
    dynamic_points.push([10, 20]);
    dynamic_points.push([30, 40]);
    dynamic_points.push(point); // We can add our stack-allocated point to the Vec

    println!("Dynamic points: {:?}", dynamic_points);
}
```
