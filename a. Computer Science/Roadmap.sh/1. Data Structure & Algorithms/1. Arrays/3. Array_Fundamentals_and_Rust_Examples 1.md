### 1. Core Definition and Key Properties

This example demonstrates the **fixed size**, **homogeneous elements** (same type), and **index-based** nature of an array.

Rust

```Rust
fn main() {
    // This array is declared with a fixed size of 5.
    // It can ONLY hold `u32` (unsigned 32-bit integer) elements.
    let daily_high_temps: [u32; 5] = [28, 31, 33, 29, 30];

    // We access the element at index 2 (the third day's temperature).
    // This is the index-based property in action.
    let temp_on_day_3 = daily_high_temps[2]; // Accesses the value 33

    println!("The high temperature on day 3 was: {}°C", temp_on_day_3);

    // This line would cause a compile error because all elements must be the same type.
    // let mixed_data: [i32; 3] = [10, 20, "thirty"];

    // This line would cause the program to panic at runtime because the index is out of bounds.
    // let invalid_access = daily_high_temps[10];
}
```

### 2. Essential Operations and Their Runtimes

These examples show the performance characteristics of common array operations.

#### Accessing (Reading/Writing): Very Fast (O(1))

Accessing an element by its index is a **constant time** operation. The computer can calculate the memory location directly, so it's incredibly fast, regardless of the array's size.

Rust

```Rust
fn main() {
    let grades = [85, 92, 78, 99, 88];

    // This access is instantaneous (O(1)).
    let fourth_grade = grades[3];

    println!("The fourth grade is: {}", fourth_grade);
}
```

#### Searching: Slow (O(n) - Linear Search)

To find a value, you often have to look at each item one by one. This is a **linear time** operation because the time it takes is directly proportional to the number of elements (`n`).

Rust

```Rust
fn main() {
    let product_ids = [101, 204, 230, 311, 452];
    let target_id = 311;
    let mut found = false;

    // We have to loop through the array to find our target.
    // In the worst case, we might check every single element.
    for id in product_ids.iter() {
        if *id == target_id {
            found = true;
            break; // Exit the loop as soon as we find it
        }
    }

    if found {
        println!("Product with ID {} was found.", target_id);
    } else {
        println!("Product not found.");
    }
}
```

#### Inserting/Deleting: Can be very slow (O(n))

**Note:** Rust's core arrays have a fixed size, so you can't actually add or remove elements to change their length. To demonstrate the performance concept of inserting/deleting (which requires shifting elements), we'll use a `Vec<T>`, which is a growable, "dynamic" array. The performance cost is the same.

Rust

```Rust
fn main() {
    let mut scores: Vec<i32> = vec![100, 90, 85, 70];
    println!("Before insert: {:?}", scores);

    // We want to insert the value 95 at index 2.
    // To do this, the elements `85` and `70` must be shifted to the right.
    // This is an O(n) operation because the number of shifts depends on the list's size.
    scores.insert(2, 95);

    println!("After insert:  {:?}", scores); // The output is [100, 90, 95, 85, 70]
}
```
