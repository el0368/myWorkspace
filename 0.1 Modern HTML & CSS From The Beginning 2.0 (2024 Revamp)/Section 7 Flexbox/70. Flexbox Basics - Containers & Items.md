Based on the transcript, here are the foundational properties used to create and control a Flexbox container.

---

### Creating a Flex Container (`display: flex`)

To activate Flexbox, you apply **`display: flex;`** to a parent element, which is then known as the **flex container**.

Once this is done, all of its **direct children** automatically become **flex items**. By default, they will immediately align themselves side-by-side in a horizontal row, and they will shrink to fit within the container if necessary. It's important to note that only direct children are affected; elements nested deeper inside a flex item are not part of the flex layout.

---

### Controlling Direction (`flex-direction`)

This property defines the direction of the main axis, which determines how the flex items are placed within the container.

- **`row`** (Default): Items are arranged in a row from left to right.
    
- **`row-reverse`**: Items are arranged in a row from right to left.
    
- **`column`**: Items are stacked in a column from top to bottom.
    
- **`column-reverse`**: Items are stacked in a column from bottom to top.
    

---

### Handling Overflow (`flex-wrap`)

By default, flex items will try to fit onto one line, even if it means shrinking or overflowing. The `flex-wrap` property controls this behavior.

- **`nowrap`** (Default): All items are forced onto a single line.
    
- **`wrap`**: Items will wrap onto additional lines if there isn't enough space on the current line. This is a key feature for creating responsive layouts that adapt to different screen sizes.
    
- **`wrap-reverse`**: Items wrap onto additional lines in the reverse order.
    

---

### Spacing Items (`gap`)

The `gap` property is the modern and preferred way to create space _between_ flex items, without having to add margins to the items themselves.

- **`gap: 10px;`**: Adds a 10px gap between both rows and columns.
    
- **`row-gap: 10px;`**: Adds a gap only between the rows (horizontal spacing).
    
- **`column-gap: 10px;`**: Adds a gap only between the columns (vertical spacing).
