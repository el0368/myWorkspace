The CSS Flexbox model provides specific properties to control how flex items grow and shrink to fit their container.

---

### `flex-shrink`

This property defines the ability of a flex item to shrink if necessary.

- **Default value:** `1`. This means all items will shrink equally when the container becomes too small.
    
- **`flex-shrink: 0;`**: This prevents the item from shrinking at all. It will maintain its size even if it overflows the container.
    
- **Higher values**: An item with `flex-shrink: 2;` will shrink twice as much as items with the default value of `1`.
    

---

### `flex-grow`

This property defines the ability of a flex item to grow to fill available space.

- **Default value:** `0`. This means items will not grow to fill extra space in the container.
    
- **`flex-grow: 1;`**: This allows an item to grow and take up any remaining space. If multiple items are set to `1`, they will share the available space equally.
    
- **Higher values**: An item with `flex-grow: 2;` will take up twice as much available space as an item with `flex-grow: 1`.
    

---

### `flex-basis`

This property defines the default size of an element before the remaining space is distributed. You can think of it as the initial starting size for a flex item. It accepts size values like pixels (`200px`) or percentages.

---

### `flex` (Shorthand)

This property is a shorthand that combines `flex-grow`, `flex-shrink`, and `flex-basis` into a single declaration, in that order.

`flex: [grow] [shrink] [basis];`

In real-world use, you will often use a simplified version of this shorthand to create common layouts:

- **`flex: 1;`**: This is a very common and powerful declaration. When applied to all flex items, it makes them all grow and shrink equally to fill the container, creating a flexible and evenly distributed layout (e.g., three equal-width columns).
    
- **`flex: 2;`**, **`flex: 3;`**, etc.: By giving one item a higher flex value, you can make it proportionally larger than the others, which is perfect for creating layouts like a main content area with smaller sidebars.
