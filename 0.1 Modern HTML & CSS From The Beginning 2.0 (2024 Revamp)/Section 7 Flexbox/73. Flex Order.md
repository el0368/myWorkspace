The CSS `order` property allows you to change the visual order of flex items inside their container without altering the HTML source code.

---

### How It Works

The `order` property is applied to **individual flex items**, not the flex container.

- By default, all flex items have an `order` value of **`0`**. This causes them to be laid out in the order they appear in the HTML.
    
- You can assign any integer value (positive or negative) to the `order` property.
    
- Flex items are then re-arranged in ascending order based on their `order` value. Items with a lower `order` value (e.g., `1`) will appear before items with a higher `order` value (e.g., `2`).
    

---

### Common Use Case

The primary benefit of the `order` property is that it separates the visual presentation from the document's source order. This is incredibly useful for responsive design.

For example, you might want an image to appear before the text on a desktop view but have the text appear before the image on a mobile view for better readability. The `order` property lets you make this change with CSS alone, keeping your HTML clean and semantically correct.
