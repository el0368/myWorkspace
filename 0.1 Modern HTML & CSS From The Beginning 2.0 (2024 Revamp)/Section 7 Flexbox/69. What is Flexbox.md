Flexbox, short for Flexible Box Layout, is a modern CSS layout model designed to efficiently arrange, align, and distribute elements within a container, even when their size is unknown or dynamic. It's a one-dimensional model, meaning it handles layout in either a row or a column at a time.

---

### The Core Concept: Container and Items

The foundation of Flexbox is the relationship between a **flex container** and its **flex items**.

- **Flex Container**: This is a parent element that you designate as a flexible box. You activate it simply by setting its CSS property to **`display: flex;`**.
    
- **Flex Items**: These are the **direct children** of the flex container. Once their parent becomes a flex container, they automatically become flex items and are arranged according to the flexbox rules.
    

By default, applying `display: flex;` to a container will immediately arrange its items side-by-side in a horizontal row.

---

### The Two Axes: Main and Cross

To understand how to align and distribute items, you must understand the two axes of a flex container.

- **Main Axis**: This is the primary axis along which the flex items are laid out.
    
- **Cross Axis**: This axis is perpendicular to the main axis.
    

The direction of these axes is determined by the **`flex-direction`** property:

#### When `flex-direction` is `row` (Default)

If you don't specify a direction, it defaults to `row`.

- The **Main Axis** runs **horizontally** (left-to-right).
    
- The **Cross Axis** runs **vertically** (top-to-bottom).
    

#### When `flex-direction` is `column`

If you set `flex-direction: column;`, the axes swap.

- The **Main Axis** runs **vertically** (top-to-bottom).
    
- The **Cross Axis** runs **horizontally** (left-to-right).
    

Understanding which axis is "main" is crucial because alignment properties like `justify-content` operate on the main axis, while properties like `align-items` operate on the cross axis.
