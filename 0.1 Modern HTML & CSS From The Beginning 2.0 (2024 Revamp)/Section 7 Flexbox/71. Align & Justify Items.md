### Revised Explanation

In CSS Flexbox, alignment is controlled by two main properties: **`justify-content`** for the main axis and **`align-items`** for the cross axis.

#### The #1 Rule: Main Axis vs. Cross Axis

The behavior of these properties depends entirely on **`flex-direction`**.

- **`justify-content`** always aligns items along the **main axis**.
    
- **`align-items`** always aligns items along the **cross axis**.
    

By default (`flex-direction: row`), the main axis is horizontal and the cross axis is vertical. If you set `flex-direction: column`, they swap.

---

#### `justify-content` (Main Axis)

This property distributes space between items along the main axis.

- **Analogy:** Think of arranging books on a shelf—`justify-content` is how you slide them to the left, right, center, or space them out evenly.

---

#### `align-items` (Cross Axis)

This property aligns items along the cross axis.

- **Analogy:** This is like moving all the books to the top of the shelf, the bottom of the shelf, or aligning them in the middle vertically.
    

**Key Values:**

- **`stretch`** (Default): Stretches items to fill the container's height (in a row).
    
- **`flex-start`**: Aligns items to the top.
    
- **`center`**: Aligns items to the vertical center.
    
- **`flex-end`**: Aligns items to the bottom.
    

---

#### `align-self` (Single Item)

While the properties above are set on the container to align all items, **`align-self`** is set on a single flex item to override the container's `align-items` value.

It accepts the same values as `align-items` (e.g., `flex-start`, `center`, `stretch`).
