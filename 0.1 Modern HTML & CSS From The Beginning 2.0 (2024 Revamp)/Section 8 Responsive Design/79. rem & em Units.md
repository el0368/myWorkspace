We will now explore **fluid typography** using **`em`** and **`rem`** units, which are essential for creating accessible and responsive websites. Unlike fixed units, such as pixels, these units scale relative to other elements, providing a more flexible approach to styling.

---

## Understanding Absolute vs. Relative Units

In CSS, units can be categorized into two main types:

- **Absolute Units:** These units are fixed and do not change based on other elements or screen sizes. The most common absolute unit is the **pixel (`px`)**. Others include inches (`in`), centimeters (`cm`), and points (`pt`), which are primarily used for print media.
    
- **Relative Units:** These units are calculated based on another value. This makes them ideal for responsive design. Examples include percentages (`%`), **`em`**, and **`rem`**. Other relative units include **viewport width (`vw`)** and **viewport height (`vh`)**, which we will discuss later.
    

---

## Introducing `rem` (Root `em`) Units

The `rem` unit stands for "root `em`." It is a relative unit that is always based on the **font size of the root element (`<html>`)**. By default, most browsers set the root font size to **16 pixels**.

A value of `1rem` is equivalent to the root font size. So, `1rem` is typically `16px`. If you set an element's font size to `2rem`, it will be `2 * 16px = 32px`.

### Code Example: `rem` Unit

This example shows how to use `rem` units for font sizes and margins. The sizes will scale predictably based on the root font size.

CSS

```CSS
/* By default, the root font size is 16px. */
/* We can explicitly set it for clarity or to change the base. */
html {
  font-size: 16px; /* This is the default, 1rem = 16px */
}

.container {
  max-width: 900px;
  margin: 20px auto;
  padding: 20px;
  border: 1px solid black;
}

h1 {
  /* 2rem = 2 * 16px = 32px */
  font-size: 2rem;
}

p {
  /* 1.2rem = 1.2 * 16px = 19.2px */
  font-size: 1.2rem;
  /* 1rem top and bottom margin, 0 left and right */
  margin: 1rem 0;
}
```

A common practice is to set the root font size to `62.5%` or `10px`. This makes calculations easier since `1rem` would then equal `10px`. For example, `1.8rem` would be `18px`, and `3rem` would be `30px`. This approach simplifies development but may not be ideal for accessibility, as we'll see below.

---

## Introducing `em` Units

The `em` unit is also a relative unit, but it's based on the **font size of the parent element**. This can make it a powerful but sometimes unpredictable tool. A value of `1em` is equal to the parent element's font size.

### Code Example: `em` Unit

In this example, the paragraph's font size is `1.2em`. Since its parent (`.container`) has no explicit font size, the `p` element's font size is calculated from the root element (`<html>`), which is `16px` by default. So, `1.2em` here is `1.2 * 16px = 19.2px`.

CSS

```CSS
.container {
  max-width: 900px;
  margin: 20px auto;
  padding: 20px;
  border: 1px solid black;
}

p {
  /* 1.2em is based on the parent's font size. */
  /* Since the parent has no font size, it inherits from the root (16px). */
  /* Therefore, 1.2em = 1.2 * 16px = 19.2px. */
  font-size: 1.2em;
}
```

The issue with `em` units arises with **nested elements**. Because the size is always relative to the _immediate parent_, the font size can get progressively larger or smaller with each level of nesting.

### Code Example: Nested `em` Units

CSS

```CSS
.list {
  /* Font size of the outer list is 1.5em relative to the root (16px), so it becomes 24px. */
  font-size: 1.5em; 
}

.list li ul {
  /* Font size of the nested list is 1.5em relative to its parent (the <li>), which inherits a font size of 24px. */
  /* Therefore, this nested list's font size becomes 1.5 * 24px = 36px. */
  font-size: 1.5em;
}
```

This behavior can be hard to predict and control, which is why **`rem` is often preferred for font sizes** because it provides a consistent, predictable scaling factor.

---

## The Role of `rem` for Accessibility

One of the most significant benefits of using `rem` units is **accessibility**. Many users with visual impairments increase their browser's default font size in their settings.

- If you use **pixels** for font sizes, your text will remain fixed and will not scale with the user's browser settings.
    
- If you use **`rem`** units, your text will automatically adjust based on the user's root font size setting, ensuring your content remains readable for everyone.
    

**`em` units also respect user settings**, but because their size is based on the parent, they can become more difficult to manage and predict. For this reason, `rem` is a safer and more consistent choice for building accessible layouts.

---

## When to Use Which Unit

- **`rem`:** Use `rem` for most of your font sizes, margins, and padding. It provides consistent scaling and is great for accessibility.
    
- **`em`:** Use `em` for elements that need to scale relative to their direct parent. For example, you might use `em` for the padding or margin of a button where you want the spacing to be proportional to the button's font size.
    
- **`px`:** Use `px` for elements that need a precise, fixed size, such as thin borders (`1px solid`) or certain icons.
