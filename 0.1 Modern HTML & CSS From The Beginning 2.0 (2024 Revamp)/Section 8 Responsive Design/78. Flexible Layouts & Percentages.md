A **flexible layout** in web development uses relative units, such as percentages, to create designs that adapt to different screen sizes. This approach ensures content remains readable and accessible, preventing it from being cut off on smaller screens. Using percentages for properties like `width`, `margin`, and `padding` allows elements to scale proportionally to their parent container or the viewport.

Here's how to create a flexible layout using percentages and best practices for responsive design.

### The Problem with Fixed Widths

Using a fixed width, like `width: 1100px;`, can cause content to be cut off on screens smaller than the specified width. This forces users to scroll horizontally, which is a poor user experience.

#### Example: Fixed Width

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body {
      margin: 0;
      padding: 0;
    }
    .container {
      /* Fixed width causes issues on small screens */
      width: 1100px;
      margin: 50px auto;
      padding: 20px;
      background-color: #f0f0f0;
    }
  </style>
</head>
<body>
  <div class="container">
    <h1>Fixed Layout</h1>
    <p>This text will be cut off on screens smaller than 1100px.</p>
  </div>
</body>
</html>
```

---

### The Solution: `max-width`

The most common and effective solution is to use `max-width` instead of `width`. This allows the container to shrink on smaller screens while preventing it from growing beyond the specified size on larger screens.

#### Example: `max-width`

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body {
      margin: 0;
      padding: 0;
    }
    .container {
      /* max-width allows the container to be smaller than 1100px */
      max-width: 1100px;
      margin: 50px auto;
      padding: 20px;
      background-color: #f0f0f0;
    }
  </style>
</head>
<body>
  <div class="container">
    <h1>Responsive with Max-Width</h1>
    <p>This text will fit on any screen size, up to a maximum width of 1100px.</p>
  </div>
</body>
</html>
```

---

### Using Percentages for Flexible Widths

You can also use percentages to define the width of a container, making it always a certain percentage of its parent element (which is often the viewport or the `body` in this case). A common approach is to set a `width` with a percentage and then use `max-width` to prevent it from getting too large on very wide screens.

#### Example: `width` and `max-width` with Percentages

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body {
      margin: 0;
      padding: 0;
    }
    .container {
      /* 80% width relative to its parent (the viewport) */
      width: 80%;
      /* max-width prevents it from getting too wide on large screens */
      max-width: 1100px;
      margin: 50px auto;
      padding: 20px;
      background-color: #f0f0f0;
    }
  </style>
</head>
<body>
  <div class="container">
    <h1>Flexible Width with Percentage</h1>
    <p>The container is always 80% of the viewport width, but never larger than 1100px.</p>
  </div>
</body>
</html>
```

---

### Flexible Images with `max-width`

A crucial part of responsive design is ensuring images don't overflow their containers. If an image has a fixed size larger than its parent, it will break the layout. The solution is to set `max-width: 100%;` for all images. This ensures an image will never be wider than its parent container, but it can still be smaller if its natural size is less than 100%.

#### Example: Responsive Image

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <style>
    body {
      margin: 0;
      padding: 0;
    }
    .container {
      max-width: 1100px;
      margin: 50px auto;
      padding: 20px;
      background-color: #f0f0f0;
    }
    /* This is the key to flexible images! */
    img {
      max-width: 100%;
      height: auto; /* Maintains the image's aspect ratio */
    }
  </style>
</head>
<body>
  <div class="container">
    <h1>Flexible Image</h1>
    <p>Below is a responsive image that will shrink to fit its container.</p>
    <img src="https://picsum.photos/1200/400" alt="A random placeholder image">
  </div>
</body>
</html>
```

### When Not to Use Percentages

While percentages are great for flexible layouts, there are times when other units are more appropriate:

- **Fixed-Size Elements**: For elements that must have an exact size, like a logo or a small icon, use `px`.
    
- **Font Sizes**: While technically possible, using percentages for font size is not ideal. Instead, use **relative units** like `em` or `rem`, which scale based on the user's browser settings or the root font size. We will cover this in more detail later.
    
- **Pixel-Perfect Layouts**: In some design-heavy projects where every element must be in a precise location (often dictated by a designer's file), `px` or other fixed units might be necessary.
    
- **Nested Structures**: Be cautious when using percentages on deeply nested elements, as the percentage is always relative to the immediate parent. This can lead to unexpected and confusing results.
