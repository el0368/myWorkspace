### **Flashcard 1**

Front:

What is a flexible layout in web development?

Back:

A layout that uses relative units, like percentages, to create designs that adapt to different screen sizes. It allows properties like width, margin, and padding to scale proportionally with their container.

---

### **Flashcard 2**

Front:

What is the main problem with using a fixed width (e.g., width: 1100px;) for a layout?

Back:

On screens smaller than the fixed width, the content gets cut off. This forces users to scroll horizontally, which creates a poor user experience. 👎

---

### **Flashcard 3**

Front:

What is the most common CSS solution to the fixed-width problem?

Back:

Use the max-width property instead of width. For example, max-width: 1100px; allows the container to shrink on smaller screens while preventing it from growing too large on wider screens.

---

### **Flashcard 4**

Front:

How can you make a container take up a certain percentage of the screen while also preventing it from becoming too wide?

Back:

Combine a percentage width with a pixel-based max-width.

Example:

width: 80%;

max-width: 1100px;

This makes the container flexible but stops it from becoming excessively wide on large monitors.

---

### **Flashcard 5**

Front:

How do you make an image flexible or responsive so it never overflows its container? 🖼️

Back:

Set its CSS properties to:

max-width: 100%;

height: auto;

This ensures the image will scale down to fit its container while maintaining its original aspect ratio.

---

### **Flashcard 6**

Front:

When is it not ideal to use percentages for sizing?

Back:

You should avoid using percentages for:

- **Fixed-size elements** like logos or icons (use `px`).
    
- **Font sizes** (use relative units like `em` or `rem` instead).
    
- **Deeply nested elements**, where the cascading percentages can become hard to manage.
