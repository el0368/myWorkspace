A **media query** is a CSS technique that applies specific styles to a webpage only when certain conditions are met, such as the device's screen size, orientation, or resolution. It is a fundamental tool for creating responsive web designs that adapt to different devices, from desktops to smartphones.

## Media Query Syntax

The basic syntax for a media query uses the `@media` rule, followed by the type of media and a media feature (or condition) enclosed in parentheses. The styles to be applied are then placed within curly braces.

CSS

```CSS
@media <media-type> and (<media-feature>) {
  /* CSS rules to apply */
}
```

- **`<media-type>`**: This specifies the type of device. Common types include `screen`, `print`, and `speech`. You can omit it to target all devices.
    
- **`<media-feature>`**: This is the condition that must be true for the styles to be applied. Common features include:
    
    - **`max-width`**: Applies styles when the viewport is equal to or narrower than a specified width.
        
    - **`min-width`**: Applies styles when the viewport is equal to or wider than a specified width.
        
    - **`orientation`**: Applies styles based on the viewport's orientation (e.g., `portrait` or `landscape`).
        

---

## Common Breakpoints

A **breakpoint** is the point at which a layout changes. While these are not strict rules, here are some common breakpoints used in responsive design:

- **Smartphones**: `576px`
    
- **Tablets**: `768px`
    
- **Laptops/Desktops**: `992px`
    
- **Large Desktops**: `1200px`
    

By using these breakpoints, you can create a layout that works well on most devices.

---

## Creating a Desktop-First Layout with `max-width`

A **desktop-first** approach involves designing for larger screens first and then using media queries with `max-width` to apply adjustments for smaller screens. This is a common and effective strategy.

### Code Example: `max-width`

This example demonstrates how to apply a background color to different elements based on the screen size, simulating a desktop-first approach.

CSS

```CSS
/* Styles for screens up to 1200px */
@media screen and (max-width: 1200px) {
  .wide-screen {
    background: coral;
  }
}

/* Styles for screens up to 992px */
@media (max-width: 992px) {
  .normal-screen {
    background: lightblue;
  }
}

/* Styles for screens up to 768px (tablets) */
@media (max-width: 768px) {
  .tablet-screen {
    background: lightgreen;
  }
}

/* Styles for screens up to 576px (smartphones) */
@media (max-width: 576px) {
  .smartphone-screen {
    background: lightcoral;
  }
}
```

In this example, the `wide-screen` div will have a coral background on all screens up to 1200px. The `normal-screen` div's background will turn light blue on screens up to 992px, and so on.

## Using `min-width` for a Mobile-First Approach

The **mobile-first** approach involves designing for the smallest screen size first, and then using `min-width` to add styles for larger screens. This method is often recommended for performance because it starts with the most basic styles and progressively enhances them.

### Code Example: `min-width`

CSS

```CSS
/* Base styles for all devices (mobile-first) */
body {
  font-size: 1rem;
}

/* Styles for screens 768px and wider (tablets and up) */
@media (min-width: 768px) {
  .container {
    width: 80%;
  }
}

/* Styles for screens 1200px and wider (desktops and up) */
@media (min-width: 1200px) {
  .container {
    width: 60%;
  }
}
```

In this case, the `container` starts with a full width on mobile, then becomes 80% wide on tablets, and 60% wide on desktops.

## Other Media Features

You can also use media queries to target other features, such as orientation and height:

- **Orientation**: The `orientation` feature allows you to apply styles based on whether the viewport is in `portrait` or `landscape` mode.
    
    CSS
    
    ```CSS
    @media (orientation: landscape) {
      .landscape {
        background: goldenrod;
      }
    }
    ```
    
- **Height**: You can also use `max-height` and `min-height` to apply styles based on the viewport's vertical size.
    
    CSS
    
    ```CSS
    @media (max-height: 500px) {
      .height-div {
        background: lightseagreen;
      }
    }
    ```
    

---

## Combining Media Features with `and`

You can use the `and` keyword to combine multiple media features in a single query, which allows you to target a very specific range of screen sizes.

### Code Example: Combining `min-width` and `max-width`

CSS

```CSS
/* This rule applies only to screens between 768px and 991px */
@media (min-width: 768px) and (max-width: 991px) {
  body {
    background: darkgray;
  }
}
```

This is useful for creating styles that are specific to a certain device type, like a tablet, without affecting mobile or desktop views.
