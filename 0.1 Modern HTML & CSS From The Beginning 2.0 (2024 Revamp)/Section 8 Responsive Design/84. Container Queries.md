A **container query** is a CSS feature that lets you apply styles to an element based on the size of its parent container, rather than the viewport. This provides more flexibility than traditional media queries, which are only based on the viewport's size. Container queries are a powerful tool for building modular and reusable components.

---

## The Basics of Container Queries

To use a container query, you must first define a container. This is done by adding the `container-type` property to a parent element.

### Defining a Container

The `container-type` property can take one of two values:

- **`inline-size`**: The container's size is based on its horizontal (inline) dimension, which is typically its width. This is the most common use case.
    
- **`size`**: The container's size is based on both its width and height.
    

By default, the container's name is anonymous. However, you can give it a specific name using the `container-name` property. This allows you to target a specific container from a nested structure.

CSS

```CSS
/* Declaring the 'main' element as a container */
main {
  container-type: inline-size;
  container-name: main;
}
```

---

## Using the `@container` Rule

Once a container is defined, you can use the `@container` rule to apply conditional styles. This rule works similarly to a media query but checks the container's dimensions instead of the viewport's.

### Example: Basic Container Query

In this example, we'll change the background color of a paragraph inside the `main` container when the container's width is less than `992px`.

#### HTML Structure

HTML

```HTML
<main>
  <p>This is a paragraph inside the main container.</p>
</main>
```

#### CSS

CSS

```CSS
/* Base styles for the main container */
main {
  max-width: 1100px;
  margin: 30px auto;
  padding: 20px;
  background: #eee;
  container-type: inline-size;
}

/* Default paragraph styles */
main p {
  padding: 2rem;
  background-color: lightgreen;
}

/* This rule applies when the 'main' container's width is 992px or less */
@container (max-width: 992px) {
  main p {
    background-color: lightblue;
  }
}
```

When you resize the browser window, the `main` container will shrink, and when its width drops below `992px`, the paragraph's background color will change to light blue.

## Naming Containers for Specificity

When you have multiple containers, naming them is crucial for applying styles to a specific one. You can use the `@container` rule with a container's name to target it directly.

### Example: Named Container

Here's an example with a main content area and a sidebar, each acting as its own container.

#### HTML Structure

HTML

```HTML
<body>
  <main>
    <p>Main content area.</p>
  </main>
  <aside>
    <p>Sidebar content.</p>
  </aside>
</body>
```

#### CSS

CSS

```CSS
/* Define the sidebar as a named container */
aside {
  flex-basis: 30%;
  background: lightgray;
  padding: 20px;
  container-type: inline-size;
  container-name: sidebar; /* Naming the container */
}

/* Define styles for the sidebar's paragraph */
aside p {
  background: lightyellow;
  padding: 1rem;
}

/* This rule targets the 'sidebar' container specifically */
@container sidebar (max-width: 300px) {
  aside p {
    background: lightgreen;
  }
}
```

In this setup, the `aside` container's paragraph will turn light green only when the `aside` element itself is `300px` or less. The `main` container's styles remain unaffected, demonstrating the power of isolated, component-based responsiveness.
