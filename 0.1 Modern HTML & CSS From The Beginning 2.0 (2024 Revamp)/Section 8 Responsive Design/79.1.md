<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Fluid Typography with em and rem</title>

  <div class="container">
    <h1>Understanding Fluid Typography</h1>
    <p>In web design, fluid typography is key to creating accessible and responsive layouts. By using relative units like <code>em</code> and <code>rem</code>, we can ensure that our text scales gracefully with different screen sizes and user preferences.</p>
    
    <h2>The REM Unit</h2>
    <p>The <code>rem</code> unit is based on the font size of the root HTML element. This makes it predictable and easy to manage, as its size is consistent regardless of where it's used in the document.</p>

    <h2>The EM Unit</h2>
    <p>The <code>em</code> unit, on the other hand, is relative to the font size of its parent element. This can lead to some interesting and sometimes unintended results, especially with nested elements.</p>

    <h3>Example of Nested EM Units</h3>
    <ul class="list">
      <li>This is a list item using <code>em</code> units.
        <ul>
          <li>This is a nested list item.
            <ul>
              <li>This is another nested list item.</li>
            </ul>
          </li>
        </ul>
      </li>
    </ul>

  </div>

</body>
</html>
