Building upon our discussion of flexible layouts and fluid typography, we'll now explore **container units**, a modern and powerful CSS feature that enables us to create components that are responsive to their parent container, not just the viewport.

---

## What Are Container Units?

**Container units** are a set of relative units that, like viewport units (`vw`, `vh`), are based on a measurement of a container. However, instead of the viewport, they are relative to the size of a specific parent element that has been declared as a container.

The primary container units are:

- **`cqi`** (Container Query Inline Size): Represents 1% of the container's inline (horizontal) size. In most cases, this is the same as `cqw`.
    
- **`cqw`** (Container Query Width): Represents 1% of the container's width.
    
- **`cqb`** (Container Query Block Size): Represents 1% of the container's block (vertical) size. In most cases, this is the same as `cqh`.
    
- **`cqh`** (Container Query Height): Represents 1% of the container's height.
    

To use these units, you first need to explicitly declare a parent element as a container using the `container-type` property.

---

## Setting up a Container

First, we need to create an HTML structure with a parent element that will act as our container and child elements (cards) that will respond to it.

### HTML Structure

HTML

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container Units</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>

  <main class="container-main">
    <div class="card card-1">
      <h2>My First Card</h2>
      <p>Lorem ipsum dolor sit amet consectetur adipisicing elit. Adipisci fuga sint, consectetur rerum nobis id?</p>
    </div>
    <div class="card card-2">
      <h2>My Second Card</h2>
      <p>Lorem ipsum dolor sit amet consectetur, adipisicing elit. Molestiae sit, officia aut exercitationem minus vitae?</p>
    </div>
  </main>

</body>
</html>
```

In this HTML, the `<main>` element will serve as our container. The two `div`s with the class `card` are the child elements whose properties we want to make responsive to the `<main>` element's size.

---

## Using Container Units in CSS

Now, let's add the necessary CSS to enable and use container units. The first step is to define the `container-main` as a container using the `container-type` property. We'll use `inline-size` to make it a container for width-based queries.

### Initial CSS Setup

CSS

```CSS
/* General reset and base styles */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: sans-serif;
  font-size: 18px;
  line-height: 1.6;
  padding: 2rem;
}

p {
  margin-bottom: 1rem;
}

/* Make the main element a container */
.container-main {
  max-width: 1100px;
  margin: 0 auto;
  padding: 20px;
  background-color: lightgray;
  /* This is the key declaration for container queries */
  container-type: inline-size;
}

/* Card styles */
.card {
  background-color: white;
  padding: 2rem;
  margin: 1rem 0;
  box-shadow: 0 0 10px rgba(0, 0, 0, 0.1);
}

.card h2 {
  font-size: 1.5rem;
  margin-bottom: 0.5rem;
}
```

---

## Applying `cqw` and `cqh` Units

With the container defined, we can now use container units on the child elements. Let's make the cards' width and height relative to the container.

### Code Example: `cqw` and `cqh`

The following CSS uses `cqw` and `cqh` to set the width and height of the cards.

CSS

```CSS
/* Card widths are now relative to the container-main width */
.card-1 {
  /* This card will take up 50% of the container's width. */
  width: 50cqw;
}

.card-2 {
  /* This card will take up 70% of the container's width. */
  width: 70cqw;
  /* We can also set the height relative to the container's height. */
  /* For this to work, the container-main needs a defined height. */
  /* height: 50cqh; */
}
```

## Combining with `@container` Rules

The true power of container units comes from combining them with **container queries**. This allows you to apply different styles to elements based on the size of their parent container. This is a more flexible and component-driven approach than traditional media queries, which are based on the viewport.

### Code Example: `@container` Query

Let's use a container query to change the cards' width when the parent container shrinks below a certain size.

CSS

```CSS
/* Apply this rule only when the container-main is 600px or less. */
@container (max-width: 600px) {
  /* When the container is small, both cards will take up 95% of its width. */
  .card {
    width: 95cqw;
    padding: 1rem;
  }
}
```

This container query ensures that when the `<main>` element's width is 600px or less, both cards will become wider and use less padding to fill the available space, making them more suitable for a smaller column layout. This demonstrates how container units and container queries work together to create truly responsive and modular components.
