Using `font-size: 62.5%` on the `html` element is a common practice in responsive web design, but it's not strictly necessary. It's a technique used to make `rem` unit calculations easier.

---

### Why People Use `font-size: 62.5%`

By default, most browsers set the root font size of the `html` element to `16px`. This means that `1rem` equals `16px`. If you want an element to have a font size of `18px`, you would need to calculate `18 / 16`, which is `1.125rem`.

Setting `font-size: 62.5%` on the `html` element changes the root font size from `16px` to `10px` (`16px * 0.625 = 10px`). This makes conversions between pixels and `rem` much simpler:

- `1.8rem` becomes `18px`
    
- `2.4rem` becomes `24px`
    

This method simplifies the developer's mental math, allowing them to think in a `1rem = 10px` scale.

---

### Alternative Approach

Many modern developers prefer to leave the default root font size at `16px`. They use a pre-processor or a CSS custom property to define a base font size. Alternatively, they just calculate the `rem` values directly. This approach is considered more accessible because it respects the user's default browser settings, which they may have adjusted for better readability.

### Conclusion

Whether you use `font-size: 62.5%` or stick with the default `16px` is a matter of personal or team preference. Both methods are valid ways to work with `rem` units, and the choice doesn't impact the final output on the user's screen.
