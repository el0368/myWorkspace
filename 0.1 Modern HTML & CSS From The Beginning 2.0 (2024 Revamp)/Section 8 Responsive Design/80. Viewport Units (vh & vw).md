CSS viewport units, **`vh`** (viewport height) and **`vw`** (viewport width), allow you to size elements based on the dimensions of the browser window (the viewport). This makes them incredibly useful for creating responsive layouts that adapt to different screen sizes.

---

### What are `vh` and `vw` Units?

Think of the viewport as being divided into 100 slices vertically and 100 slices horizontally.

- **`1 vh`** = 1% of the viewport's height (1 of the 100 vertical slices).
    
- **`1 vw`** = 1% of the viewport's width (1 of the 100 horizontal slices).
    

So, if you set an element's height to `50vh`, it will always take up 50% of the current height of the browser window, regardless of the size of its parent container.

---

### Key Difference: `vh`/`vw` vs. `%`

The most important distinction is what these units are relative to:

- **Percentage (`%`) units** are relative to the dimensions of the **parent container**. If you set an element's `height` to `100%`, it will only be as tall as its direct parent element. If the parent has no defined height, this `100%` value often has no effect.
    
- **Viewport (`vh`/`vw`) units** are _always_ relative to the **viewport**. An element with `height: 100vh` will fill the entire height of the browser window, no matter where it's nested in the HTML.
    

---

### Practical Uses

1. **Full-Screen "Hero" Sections:** A common use is to create a large introductory section on a webpage that fills the entire screen. This is easily achieved by setting the container's height to `100vh`. As the user scrolls, the content below comes into view.
    
    CSS
    
    ```CSS
    .hero-section {
      height: 100vh; /* Fills the full viewport height */
      background-image: url('your-image.jpg');
      background-size: cover;
    }
    ```
    
2. **Responsive Typography:** You can use `vw` units to set font sizes, particularly for large headings. This makes the text scale smoothly as the browser window is resized. For example, a `font-size: 7vw` will make a heading larger on wide screens and smaller on narrow screens. However, this should be used with caution, as text can become too large on very wide screens or unreadably small on narrow ones without media queries to control it.
