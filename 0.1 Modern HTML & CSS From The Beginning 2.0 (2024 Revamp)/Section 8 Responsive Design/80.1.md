### Full-Screen Hero Section

This code creates a section that will always fill the entire browser window's height. The text content is centered vertically and horizontally for a typical hero layout.

**HTML (`index.html`)**


```HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hero Section</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <section class="hero-section">
        <h1>Welcome to Our Site</h1>
        <p>This section fills the entire screen.</p>
    </section>

    <section class="content-section">
        <p>Other content would begin here as you scroll down.</p>
    </section>
</body>
</html>
```

**CSS (`style.css`)**


```CSS
/* Basic reset for margin and box-sizing */
body {
    margin: 0;
    font-family: sans-serif;
}

.hero-section {
    /* The key property: makes the section as tall as the viewport */
    height: 100vh; 

    /* Styling for visual appearance and text centering */
    background-color: #2c3e50;
    color: white;
    display: flex;
    flex-direction: column;
    justify-content: center;
    align-items: center;
    text-align: center;
}

.content-section {
    padding: 50px;
    text-align: center;
}
```

### Responsive Typography

This example shows how to make a heading's font size scale dynamically with the width of the browser window. Try resizing your browser to see the effect.

**HTML (`index.html`)**



```HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Text</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1 class="responsive-heading">Resize The Window</h1>
    </div>
</body>
</html>
```

**CSS (`style.css`)**



```CSS
body {
    margin: 0;
    font-family: sans-serif;
}

.container {
    padding-top: 50px;
}

.responsive-heading {
    /* The key property: font size is 7% of the viewport's width */
    font-size: 7vw; 
    
    text-align: center;
    color: #3498db;
}
```
