### **Flashcard 1**

Front:

What are the two main categories of CSS units, and what is the difference?

**Back:**

1. **Absolute Units:** Fixed-size units that do not change. Examples: `px` (pixels), `pt` (points), `cm` (centimeters).
    
2. **Relative Units:** Flexible units whose size is relative to another value. Examples: `%` (percentage), `rem`, `em`, `vw` (viewport width).
    

---

### **Flashcard 2**

Front:

What is a rem unit in CSS?

Back:

It stands for "root em." It is a relative unit where 1rem is equal to the font size of the root <html> element. By default, this is 16px in most browsers.

_Example:_ If the root font size is `16px`, then `font-size: 2rem;` will compute to `32px` (16×2).

---

### **Flashcard 3**

Front:

What is an em unit in CSS?

Back:

It is a relative unit where 1em is equal to the font size of the element's direct parent container. If no parent has a defined font size, it will eventually fall back to the root font size.

_Example:_ If a parent `<div>` has `font-size: 20px;`, a child `<p>` with `font-size: 1.5em;` will compute to `30px` (20×1.5).

---

### **Flashcard 4**

Front:

What is the key accessibility benefit of using rem or em over px for font size? ♿

Back:

Text sized with rem or em units will scale according to the user's browser font-size settings. Text sized with px is fixed and will ignore these settings, making it harder for users with visual impairments to increase text size for readability.

---

### **Flashcard 5**

Front:

Why can using em units become a problem in nested elements (e.g., a list inside another list)?

Back:

The font size can compound unexpectedly. Each nested element calculates its size based on its parent, which may have already been scaled by an em unit. This causes the font size to grow (or shrink) with each level of nesting.

`rem` units avoid this by _always_ being relative to the single root `<html>` element.

---

### **Flashcard 6**

Front:

What is the "62.5% font-size trick"?

Back:

A technique where developers set html { font-size: 62.5%; }.

Since the default browser font size is `16px`, this trick sets the root font size to `10px` (16×0.625). This makes `rem` calculations simpler (e.g., `1.8rem` is exactly `18px`).

---

### **Flashcard 7**

Front:

Can rem and em units be used for properties other than font-size?

Back:

Yes. They are commonly used for properties like margin, padding, and border-width to create layouts where spacing scales proportionally with the font size.
