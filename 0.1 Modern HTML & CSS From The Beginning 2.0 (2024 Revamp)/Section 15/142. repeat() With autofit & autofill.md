When building dynamic and responsive layouts with CSS Grid, the `repeat()` function's `auto-fill` and `auto-fit` keywords are incredibly useful. They allow the browser to automatically create columns without you having to specify a fixed number, which is essential for grids with a variable number of items.

### The Core Difference

- **`auto-fill`**: This keyword fills the row with as many columns as will fit. If there aren't enough items to fill the row, the extra space is left as empty grid tracks. It essentially creates "ghost" columns to fill the space.
    
- **`auto-fit`**: This keyword works similarly to `auto-fill`, but it collapses any empty grid tracks. If there aren't enough items to fill the row, the existing items will stretch to take up the available space.
    

In most cases where you want a responsive, gap-free layout, you'll find yourself using `auto-fit`.

---

### Progressive Code Example

Let's look at how to build a dynamic grid with a minimum column size using these keywords, and then demonstrate the subtle difference between them.

#### 1. HTML Structure

First, we'll create a container for our grid and add a few child items.

HTML

```HTML
<div class="item-grid">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

#### 2. Initial CSS with a Fixed Grid

We'll start by styling a container with a fixed number of columns to show the problem these keywords solve.

CSS

```CSS
.item-grid {
  display: grid;
  max-width: 800px;
  margin: 30px auto;
  background: lightgray;
  gap: 1rem;
}

.item {
  background-color: coral;
  border: 1px solid darkgrey;
  padding: 1rem;
  text-align: center;
}

/* Problem: The number of columns is fixed and doesn't respond to the content or container size */
.item-grid {
  grid-template-columns: repeat(6, 1fr);
}
```

This works well if you always have six items, but if you have fewer, the grid will leave empty spaces.

#### 3. Using `auto-fill` and `minmax()`

To create a grid that dynamically adjusts the number of columns, we use `repeat()` with a keyword and the `minmax()` function. The `minmax()` function sets a minimum and maximum size for a grid track.

CSS

```CSS
/* Using auto-fill */
.item-grid {
  display: grid;
  max-width: 800px;
  margin: 30px auto;
  background: lightgray;
  gap: 1rem;
  /* This creates as many columns as possible with a min size of 100px. */
  grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));
}
```

Now, if you resize the browser or change the number of items, the grid will adjust. With `auto-fill`, if there's an empty space at the end of a row (e.g., if the container is wide enough for five columns but you only have four items), it will leave that space as an empty grid track.

#### 4. Using `auto-fit` for Flexible Layouts

To create a fluid layout where items stretch to fill any extra space, we simply change the keyword to `auto-fit`.

CSS

```CSS
/* Using auto-fit */
.item-grid {
  display: grid;
  max-width: 800px;
  margin: 30px auto;
  background: lightgray;
  gap: 1rem;
  /* This will stretch the items to fill any empty space. */
  grid-template-columns: repeat(auto-fit, minmax(100px, 1fr));
}
```

Now, if the container is wide enough for five columns but only has four items, the four items will each take up 25% of the width, stretching to fill the entire row. This is the key difference and makes `auto-fit` a popular choice for responsive grids.
