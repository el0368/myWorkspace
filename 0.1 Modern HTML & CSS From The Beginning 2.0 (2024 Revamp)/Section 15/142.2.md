### Dynamic Grids with `auto-fill` and `auto-fit`

The `repeat()` function in CSS Grid can be used with special keywords, `auto-fill` and `auto-fit`, to create responsive layouts with a dynamic number of columns. This is ideal for layouts where the number of items isn't fixed, such as image galleries or product lists.

---

### `auto-fill` vs. `auto-fit`

Both keywords tell the browser to create as many columns as will fit within the container. The key difference lies in how they handle empty space when there are fewer items than the maximum number of columns.

- **`auto-fill`**: This keyword creates as many columns as possible based on the specified size, leaving empty grid tracks if there aren't enough items to fill them. It's like the browser is reserving space for potential future items.
    
- **`auto-fit`**: This keyword collapses any empty grid tracks. If a row has extra space, the existing items will stretch to occupy that space, ensuring no gaps appear. This behavior is usually preferred for cleaner, more responsive layouts.
    

CSS

```CSS
/* Example of auto-fill leaving empty space */
.grid-auto-fill {
  grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));
  /* With 3 items in a 500px container, this leaves empty columns. */
}

/* Example of auto-fit stretching items */
.grid-auto-fit {
  grid-template-columns: repeat(auto-fit, minmax(100px, 1fr));
  /* With 3 items in a 500px container, the items stretch to fill the row. */
}
```

---

### The `minmax()` Function

To make `auto-fill` and `auto-fit` work effectively, you must use the `minmax()` function. This function defines a range of sizes for each track, ensuring the columns are flexible but don't shrink too small. The syntax is `minmax(minimum_size, maximum_size)`. A common pattern is `minmax(100px, 1fr)`.

- **`100px` (minimum size):** This ensures that no column will ever shrink below 100 pixels, preventing content from becoming unreadable on narrow screens.
    
- **`1fr` (maximum size):** This allows the columns to expand and take up any available space. The `1fr` unit ensures that all items grow at an equal rate.
    

---

### In-depth Code Example

This example demonstrates how to build a responsive, dynamic grid that uses `auto-fit` and `minmax()` to create a fluid layout.

#### HTML

HTML

```HTML
<div class="container">
  <div class="item-grid">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
    <div class="item">Item 4</div>
  </div>
</div>
```

#### CSS

CSS

```CSS
/* General container for centering and padding */
.container {
  max-width: 800px;
  margin: 30px auto;
  padding: 10px;
  background-color: #f4f4f4;
}

/* Styles for the grid items */
.item {
  background-color: coral;
  border: 1px solid #333;
  padding: 1rem;
  text-align: center;
  color: white;
  font-size: 1.5rem;
}

/* The core grid definition */
.item-grid {
  display: grid;
  gap: 1rem; /* Creates space between items */

  /* This is the key line for the dynamic grid */
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
}
```

In this code, the `grid-template-columns` property instructs the browser to create as many columns as possible. Each column will have a minimum width of `200px` and a flexible maximum width of `1fr`. If the container can fit three `200px` columns, it will. If a fourth column can't fit, the existing three columns will stretch to fill the remaining space.
