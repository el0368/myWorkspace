The `box-shadow` property in CSS allows you to add a drop shadow effect to an element's frame.

---

### `box-shadow` Syntax and Values

The property accepts several values to define the shadow's appearance. The horizontal offset, vertical offset, and color are required.

`box-shadow: [horizontal-offset] [vertical-offset] [blur-radius] [spread-radius] [color];`

- **Horizontal Offset**: Controls the shadow's position on the x-axis. A positive value moves it to the right, and a negative value moves it to the left.
    
- **Vertical Offset**: Controls the shadow's position on the y-axis. A positive value moves it down, and a negative value moves it up.
    
- **Blur Radius** (Optional): Sets how blurry or soft the shadow appears. A larger value creates a more blurred effect. Without a blur, the shadow will have sharp edges.
    
- **Spread Radius** (Optional): Causes the shadow to expand or shrink. A positive value makes it larger, and a negative value makes it smaller.
    
- **Color**: Defines the color of the shadow. Using an **`rgba()`** color value is recommended for creating transparent shadows, which often look more subtle and modern.
    

---

### Advanced Techniques

- **Transparent Shadows**: Instead of a solid color like `black`, you can use `rgba(0, 0, 0, 0.2)` to create a black shadow with 20% opacity. This produces a softer, more realistic shadow.
    
- **Multiple Shadows**: You can apply multiple, layered shadows to a single element by separating each shadow's set of values with a comma. This allows for more complex and creative depth effects.
