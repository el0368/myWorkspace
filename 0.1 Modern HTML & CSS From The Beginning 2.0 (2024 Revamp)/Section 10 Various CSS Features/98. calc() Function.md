The CSS `calc()` function allows you to perform basic arithmetic operations (addition, subtraction, multiplication, and division) to determine a property's value. It can be used anywhere a length, frequency, angle, time, percentage, number, or integer is expected. The `calc()` function is particularly useful for creating dynamic layouts and responsive designs, as it allows you to combine different units of measurement.

---

### Syntax and Operations

The syntax is straightforward: `property: calc(expression)`. You must include a space around the `+`, `-`, `*`, and `/` operators.

CSS

```CSS
.element {
  /* This will set the width to 400px (500px - 100px) */
  width: calc(500px - 100px);
  
  /* This will set the width to 60% of the parent, plus an additional 50px */
  width: calc(60% + 50px);
}
```

One of the most powerful features of `calc()` is its ability to mix and match different units within the same expression, such as combining `px`, `em`, `rem`, and `%`.

---

### Progressive Code Example: A Real-World Use Case

A common and practical use for `calc()` is to create a responsive grid where the items have a fixed margin. Without `calc()`, the items would break out of their container once the margins are added. With `calc()`, we can subtract the margin from the total width, ensuring all items fit perfectly.

#### 1. Initial HTML Structure

Let's create a container with five items inside.

HTML

```HTML
<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
  <div class="item">Item 4</div>
  <div class="item">Item 5</div>
</div>
```

#### 2. Initial CSS (without `calc()`)

Here, we set up a Flexbox container and define the size of the items.

CSS

```CSS
.container {
  max-width: 1000px;
  height: 200px;
  display: flex;
  background-color: black;
}

.item {
  width: 200px; /* 5 items * 200px = 1000px */
  height: 200px;
  background-color: coral;
  margin: 10px; /* This will cause the items to break out of the container */
}
```

In this example, the total width of the five items is 1000px, which fits the container. However, once a `10px` margin is added to each item, the total width becomes `(5 * 200px) + (5 * 20px of total margin)`, which is `1100px`. This will cause the items to overflow.

#### 3. Using `calc()` to Fix the Layout

Now, let's use `calc()` to dynamically calculate the width and height of each item, accounting for the margin.

CSS

```CSS
.container {
  max-width: 1000px;
  height: 200px;
  display: flex;
  background-color: black;
}

.item {
  /* (100% of container / 5 items) - (margin on both sides of each item) */
  width: calc(100% / 5 - 20px);
  
  /* (100% of container height) - (margin on both sides of each item) */
  height: calc(100% - 20px); 
  
  background-color: coral;
  margin: 10px;
}
```

Now, the width of each item is dynamically calculated to be `(1000px / 5) - 20px = 180px`, which, when combined with the `20px` of total margin per item, adds up to a perfect 1000px. This ensures the items fit perfectly inside the container regardless of its size.

You can also nest `calc()` functions for more complex calculations and use CSS custom properties (variables) within `calc()` to make your styles even more flexible.
