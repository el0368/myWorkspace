### Smooth Scrolling

Smooth scrolling is a web design technique that creates a smooth animation when a user clicks an anchor link, guiding them to a specific section on the same page. This provides a more fluid and user-friendly experience than an abrupt jump. Previously, this effect required JavaScript, but now it can be achieved with a single CSS property: `scroll-behavior`.

To make the scroll-behavior work for the entire page, it should be applied to the **`<html>`** element, which represents the root of the document.

---

### Building the Layout

We'll create a single-page layout with a navigation bar that links to different sections. This will demonstrate how the `scroll-behavior` property works in a real-world scenario.

#### 1. HTML Structure

We'll set up a header with a navigation menu, followed by a series of sections. Each section will have an `id` that corresponds to a link in the menu. This is the foundation for the smooth scrolling to work.

HTML

```HTML
<header class="header">
  <nav class="menu">
    <ul>
      <li><a href="#home">Home</a></li>
      <li><a href="#project-1">Project 1</a></li>
      <li><a href="#project-2">Project 2</a></li>
      <li><a href="#project-3">Project 3</a></li>
      <li><a href="#project-4">Project 4</a></li>
    </ul>
  </nav>
</header>
<main class="container">
  <section class="section" id="home">
    <h2>Welcome</h2>
    <p>Lorem ipsum dolor sit amet consectetur...</p>
  </section>
  <section class="section" id="project-1">
    <h2>Project 1</h2>
    <img src="project-1.jpg" alt="Project 1 Image">
    <p>Lorem ipsum dolor sit amet consectetur...</p>
  </section>
  </main>
```

#### 2. Base and Layout Styles

The CSS will style the main components, including the header, navigation, and sections. This ensures the page is visually appealing before we apply the smooth scrolling effect. Key styles include using Flexbox to align the menu items and setting a `max-width` on images to prevent overflow.

CSS

```CSS
/* Base Styles */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
html, body {
  /* This is where the magic happens for smooth scrolling */
  scroll-behavior: smooth; 
  font-family: sans-serif;
  font-size: 18px;
  line-height: 1.6;
}
p { margin-bottom: 20px; }
img { max-width: 100%; }

/* Header & Navigation Styles */
.header {
  background: linear-gradient(45deg, #f00, #00f);
  padding: 10px;
  margin-bottom: 80px;
}
.menu ul {
  display: flex;
  justify-content: center;
  list-style: none;
  gap: 3rem;
}
.menu a {
  color: white;
  text-decoration: none;
}
.menu a:hover {
  color: #f00;
}

/* Container & Sections */
.container {
  max-width: 700px;
  margin: 0 auto;
}
.section {
  margin-bottom: 30px;
}
.section h2 {
  font-size: 40px;
  text-align: center;
  background: linear-gradient(45deg, #f00, #00f);
  color: white;
  padding: 10px 0;
  margin-bottom: 20px;
}
```

#### 3. Implementing Smooth Scrolling

The final step is to add the `scroll-behavior` property. To make it affect the entire page, we apply it to the `html` element. The value should be set to `smooth`.

CSS

```CSS
/* Place this style on the html element to enable smooth scrolling for the entire document */
html {
  scroll-behavior: smooth;
}
```

Now, when a user clicks on a navigation link, the page will scroll smoothly to the corresponding section instead of jumping instantly.
