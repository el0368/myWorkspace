To apply visual effects to elements and images, you can use the CSS **`filter` property**. This property allows you to adjust a variety of visual effects, such as color, contrast, and blur.

---

### Common Filter Functions

The `filter` property takes one or more filter functions as its value. Each function modifies the element's appearance in a specific way. Here are some of the most common ones:

- **`grayscale()`**: Converts the image to grayscale. It takes a percentage value, where `100%` is completely black and white, and `0%` is the original image.
    
- **`blur()`**: Applies a blur effect. It takes a pixel value to define the blur radius. For example, `blur(5px)`.
    
- **`brightness()`**: Adjusts the image's brightness. It takes a percentage, with `100%` being the default brightness. Values less than `100%` darken the image, while values greater than `100%` brighten it.
    
- **`contrast()`**: Modifies the contrast. It also uses a percentage, with `100%` as the default.
    
- **`drop-shadow()`**: Creates a shadow effect similar to `box-shadow`, but it follows the shape of the image's content. It takes values for horizontal offset, vertical offset, blur radius, and color.
    
- **`hue-rotate()`**: Rotates the colors of the image. It takes a degree value (e.g., `90deg`) to shift the colors.
    
- **`invert()`**: Inverts the colors of the image. A value of `100%` completely inverts the colors.
    
- **`opacity()`**: Adjusts the transparency. A value of `50%` makes the image semi-transparent.
    
- **`saturate()`**: Controls the color saturation. `100%` is the default, while `200%` doubles the saturation.
    
- **`sepia()`**: Applies a sepia tone effect. A value of `100%` gives a full sepia look.
    

---

### Chaining Multiple Filters

You can apply multiple filter functions to a single element by simply listing them with a space in between.

Example:

To make an image both grayscale and blurred, you would write:

CSS

```
.image {
  filter: grayscale(100%) blur(5px);
}
```

This is how you "chain" or stack filters. Using separate `filter` properties for each function will not work, as the last one will overwrite the previous ones.

---

### Vendor Prefixes

While vendor prefixes like `-webkit-` and `-moz-` are less common for modern CSS properties, some experimental or newer features, including `filter`, may still require them for wider browser compatibility. It's a good practice to use a tool like Autoprefixer to automatically add these prefixes for you.

**Example with vendor prefix:**

CSS

```
.image {
  -webkit-filter: grayscale(100%);
  filter: grayscale(100%);
}
```
