Okay, let's talk about **CSS custom properties**, also known as **CSS variables**. They are a powerful feature that allows you to define reusable values in one place and reference them throughout your stylesheet. This makes your CSS more maintainable, scalable, and easier to customize.

---

### Why Use Custom Properties?

- **Centralized Values:** Instead of repeating the same value (like a specific color, font size, or spacing) multiple times in your code, you can store it in a custom property.
    
- **Easy Maintenance:** If you need to change a value, you only have to update it in one location. This is much more efficient than searching for and replacing every instance.
    
- **Theming and Consistency:** Custom properties are perfect for defining design tokens like a color palette, font stacks, and spacing units, ensuring a consistent design across your entire project.
    

---

### The Syntax

The syntax for using custom properties involves two main parts:

1. **Defining a custom property:** You create a variable name that starts with a double hyphen (`--`). The variable is defined within a CSS selector, which determines its scope.
    
2. **Using the custom property:** You reference the variable using the `var()` function.
    

### Defining Scope

The scope of a custom property determines where it can be used.

- **Global Scope:** To make a custom property available everywhere in your CSS, you define it on the `:root` pseudo-class. This is the most common and recommended approach for general-purpose variables.
    
- **Local Scope:** You can define a custom property on a specific selector (e.g., `.container`), and it will only be accessible to that selector and its child elements.
    

### Progressive Code Example: From Hardcoded Values to Custom Properties

Let's start with a simple layout using hardcoded values and then refactor it using custom properties.

#### Initial HTML

HTML

```HTML
<header>
  <h1>Custom Properties</h1>
</header>
<div class="container">
  <div class="box box-1">
    <h3>Box One</h3>
    <p>Lorem ipsum dolor sit amet...</p>
  </div>
  <div class="box box-2">
    <h3>Box Two</h3>
    <p>Lorem ipsum dolor sit amet...</p>
  </div>
  <div class="box box-3">
    <h3>Box Three</h3>
    <p>Lorem ipsum dolor sit amet...</p>
  </div>
</div>
```

#### Step 1: Hardcoded CSS

First, we'll write the CSS with hardcoded values. Notice how the `lightcoral` color and `0.1` shadow opacity are repeated.

CSS

```CSS
/* Hardcoded CSS */
.header {
  background-color: lightcoral; /* Hardcoded color */
  padding: 20px;
  text-align: center;
  margin-bottom: 20px;
}

.container {
  display: flex;
  max-width: 900px;
  margin: 30px auto;
  gap: 20px;
}

.box {
  flex: 1;
  padding: 20px;
  border-radius: 10px;
  box-shadow: 0 0 10px rgba(0, 0, 0, 0.1); /* Hardcoded opacity */
}

.box-1 {
  background-color: lightcoral;
}
.box-2 {
  background-color: lightblue;
}
.box-3 {
  background-color: lightgreen;
}
```

#### Step 2: Refactoring with Custom Properties on `:root`

Now, let's create a global scope for our custom properties on the `:root` element. This makes them available to our entire document. We'll define a few colors and a variable for our box shadow opacity.

CSS

```CSS
:root {
  --primary-color: lightcoral;
  --secondary-color: lightblue;
  --tertiary-color: lightgreen;
  --box-shadow-opacity: 0.2; /* A value can be just part of a property */
}

/* Now we use the var() function to reference our custom properties */
.header {
  background-color: var(--primary-color); /* Using the custom property */
  padding: 20px;
  text-align: center;
  margin-bottom: 20px;
}

.box {
  flex: 1;
  padding: 20px;
  border-radius: 10px;
  /* Using the var() function for just a part of the value */
  box-shadow: 0 0 10px rgba(0, 0, 0, var(--box-shadow-opacity));
}

.box-1 {
  background-color: var(--primary-color);
}
.box-2 {
  background-color: var(--secondary-color);
}
.box-3 {
  background-color: var(--tertiary-color);
}
```

Now, if you want to change the primary color, you only need to update the value once in the `:root` selector. This makes the code much cleaner and more manageable. You can use custom properties for any CSS value, including dimensions, fonts, and more.
