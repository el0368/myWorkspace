Here is the modern, opinionated CSS reset I would use for a new project in 2025.

This reset is built on a philosophy of being **minimal, modern, and practical**. It aggressively removes common browser-default styles to provide a clean, predictable slate, allowing you to build your design system from the ground up without fighting the user-agent stylesheet.

### My Modern CSS Reset

CSS

```CSS
/* My Modern, Opinionated CSS Reset */

*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

body {
  font-family: system-ui, -apple-system, sans-serif;
  line-height: 1.5;
  min-height: 100vh;
}

img,
picture,
video,
canvas,
svg {
  display: block;
  max-inline-size: 100%;
  block-size: auto;
}

input,
button,
textarea,
select {
  font: inherit;
}

h1,
h2,
h3,
h4,
h5,
h6 {
  font-size: inherit;
  font-weight: inherit;
}

ul,
ol {
  list-style: none;
}

a {
  text-decoration: none;
  color: inherit;
}
```

---

## The Philosophy and Breakdown

Here's a deep dive into why each rule exists and what it accomplishes.

### **1. The Universal Box Model & Reset**

CSS

```CSS
*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

- **`box-sizing: border-box;`**: This is the most crucial rule. It makes layout math intuitive by including `padding` and `border` within the element's specified `width` and `height`. It's non-negotiable for modern layout.
    
- **`margin: 0;` & `padding: 0;`**: This is an aggressive but clean approach. It removes all inconsistent, browser-default spacing from every element. You are now in 100% control of your layout's spacing, which is what a "blank slate" reset should provide.
    

### **2. Sensible Document & Body Defaults**

CSS

```CSS
html {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

body {
  font-family: system-ui, -apple-system, sans-serif;
  line-height: 1.5;
  min-height: 100vh;
}
```

- **Font Smoothing:** These non-standard properties provide crisper, more pleasant text rendering on macOS and some other systems. It's a subtle but professional touch.
    
- **`font-family: system-ui, ...`**: This is a modern font stack that defaults to the user's native operating system font. It's incredibly fast (no download required) and feels familiar to the user.
    
- **`line-height: 1.5;`**: A unitless `line-height` is the best practice for setting a readable, accessible baseline for all your text.
    
- **`min-height: 100vh;`**: This allows the `body` to fill at least the full height of the viewport, which is essential for modern layouts that might use Flexbox or Grid to position a footer at the bottom of the screen, even on pages with little content.
    

### **3. Responsive & Modern Media Defaults**

CSS

```CSS
img,
picture,
video,
canvas,
svg {
  display: block;
  max-inline-size: 100%;
  block-size: auto;
}
```

- **`display: block;`**: Fixes the classic issue where a small space appears below `<img>` tags.
    
- **`max-inline-size: 100%;`**: This is the logical property equivalent of `max-width: 100%`. It's the key to making images responsive so they never overflow their containers. Using the logical property is a forward-thinking best practice.
    
- **`block-size: auto;`**: The logical property for `height: auto;`, ensuring the media element maintains its aspect ratio as it scales.
    

### **4. De-styling Common Elements (The Opinionated Part)**

CSS

```CSS
input,
button,
textarea,
select {
  font: inherit;
}

h1, h2, h3, h4, h5, h6 {
  font-size: inherit;
  font-weight: inherit;
}

ul, ol {
  list-style: none;
}

a {
  text-decoration: none;
  color: inherit;
}
```

This is where the reset shows its philosophy. Instead of preserving browser defaults, it wipes them clean so your design system takes full control.

- **`font: inherit;`**: Normalizes form elements to use your project's typography, fixing a major source of browser inconsistency.
    
- **Headings (`h1`, `h2`, etc.)**: By resetting `font-size` and `font-weight`, headings now behave like regular text. This is for developers who want to define their typographic scale completely from scratch without fighting default values.
    
- **Lists (`ul`, `ol`):** Removes default bullet points and `padding`, as these are almost always customized for navigation menus, item lists, etc.
    
- **Links (`a`):** Removes the default underline and blue color, making links inherit text styles from their parent. This is a common first step in virtually any design.
