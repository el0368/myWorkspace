If you are building this by depending on an **AI Agent** (like an LLM or a specialized coding agent), you shouldn't start by writing code. You start by building the **"System Instructions"** so the AI understands your specific "Factory" logic.

Here is the 4-step sequence to start your project using an AI agent:

---

### 1. Step One: The "Brain Dump" (Defining the DNA)

The AI needs to know the **Rules of the World**. Feed it a prompt that defines your hierarchy and tech stack exactly as we discussed.

**Use this prompt for your AI Agent:**

> "I am building a math curriculum factory using the SPELP-Z stack (Svelte 5, Phoenix/Elixir, Python, Zig).
> 
> Hierarchy: Chapter > Unit > Topic > Exercise (Square Box).
> 
> Logic: Prerequisite-driven. One box unlocks the next.
> 
> Navigation: A vertical 'Ladder' of boxes.
> 
> Tagging: Multi-level (Chapter Domain, Unit Theme, Exercise Style).
> 
> Your Role: You are the Lead Architect. Help me scaffold the database and the Svelte 5 components to match the 'Khan Academy' box grid."

---

### 2. Step Two: The "Database Migration" (The Foundation)

Tell the AI to create the tables. This is the "Unbreakable" part. If the database is wrong, the boxes won't link.

**Ask the AI:**

- "Generate an **Elixir Ecto Migration** for `chapters`, `units`, and `exercises`."
    
- "Ensure the `exercises` table has a `position` (integer), `status` (enum: locked, available, completed), and a `parent_id` linking to the `unit`."
    
- "Add a `tags` column (array of strings) to every table."
    

---

### 3. Step Three: The "Unit Row" Component (The Visuals)

Once the database is set, ask the AI to build the UI for the **Lab (Front Stage)**.

**Ask the AI:**

- "Create a **Svelte 5 component** called `UnitRow.svelte`."
    
- "It should receive a list of exercise objects from Phoenix."
    
- "Render them as a horizontal grid of **Square Boxes**. Use Tailwind CSS."
    
- "Include logic where if `exercise.status == 'locked'`, the box is greyed out. If 'completed', show a checkmark."
    

---

### 4. Step Four: The "AI Generator" (The Python Forge)

Finally, start the **Python** part. This is where the AI actually creates the content.

**Ask the AI:**

- "Write a Python script that uses an LLM to generate 10 math exercises for a Unit titled 'Intro to Fractions'."
    
- "For each exercise, provide a title, a LaTeX math problem, and suggest 3 **Tags** (e.g., #visual, #intro, #fractions)."
    
- "Output this as a JSON list so I can import it into my Elixir database."
