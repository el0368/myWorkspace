In data structures and algorithms, the "Contains Duplicate" problem is a classic question where you need to determine if any element appears more than once in a collection, like an array or list. The goal is to return true if a duplicate exists and false if all elements are unique.
Common Approaches and Rust Examples
Here are two simple and common ways to solve this problem in Rust.
1. Using a Hash Set (Optimal Solution) ✨
The most efficient approach uses a hash set to keep track of the numbers you've already seen. You iterate through the input array, and for each number, you try to add it to the set. If the number is already in the set, you've found a duplicate.
 * Time Complexity: O(n) - You only need to iterate through the array once.
 * Space Complexity: O(n) - In the worst case, you store all unique elements in the hash set.

use std::collections::HashSet;

// Function to check for duplicates using a HashSet
fn contains_duplicate_hashset(nums: &[i32]) -> bool {
    let mut seen = HashSet::new();
    for &num in nums {
        // The `insert` method returns `false` if the value was already present.
        if !seen.insert(num) {
            return true; // Found a duplicate!
        }
    }
    false // No duplicates found
}

fn main() {
    let list1 = vec![1, 2, 3, 1];
    let list2 = vec![1, 2, 3, 4];
    
    println!("List 1 contains duplicate: {}", contains_duplicate_hashset(&list1)); // true
    println!("List 2 contains duplicate: {}", contains_duplicate_hashset(&list2)); // false
}

2. Using Sorting
Another common method is to sort the array first. If there are any duplicates, they will be next to each other after sorting. You can then iterate through the sorted array and check if any adjacent elements are the same.
 * Time Complexity: O(n \\log n) - This is dominated by the sorting algorithm's performance.
 * Space Complexity: O(1) or O(n) - Depends on the sorting algorithm. Rust's sort is an in-place sort, but we create a mutable copy here, so it's O(n).

// Function to check for duplicates by sorting
fn contains_duplicate_sorting(nums: &[i32]) -> bool {
    // Return false early if the list is empty or has one element
    if nums.len() < 2 {
        return false;
    }
    
    // Create a mutable copy to sort
    let mut sorted_nums = nums.to_vec();
    sorted_nums.sort_unstable(); // Use sort_unstable for potentially better performance

    // Check for adjacent duplicates
    for i in 0..(sorted_nums.len() - 1) {
        if sorted_nums[i] == sorted_nums[i + 1] {
            return true; // Found a duplicate
        }
    }
    
    false // No duplicates found
}

fn main() {
    let list1 = vec![1, 2, 3, 1];
    let list2 = vec![1, 2, 3, 4];

    println!("List 1 contains duplicate: {}", contains_duplicate_sorting(&list1)); // true
    println!("List 2 contains duplicate: {}", contains_duplicate_sorting(&list2)); // false
}
