The goal of LeetCode 1920 "Build Array from Permutation" is to create a new array `ans` from an input array `nums` using the rule: `ans[i] = nums[nums[i]]`.

---

### The Approach ➡️

This problem is a straightforward exercise in using an array's values as indices for a lookup. For each position `i` in the new array, you find the value at that position in the original array (`nums[i]`) and then use that value as a _new index_ to look up the final value.

#### Algorithm

1. Create a new result array, `ans`, of the same size as `nums`.
    
2. Loop from `i = 0` to the end of the `nums` array.
    
3. For each index `i`, perform the double lookup: first get `nums[i]`, then use that result to get `nums[nums[i]]`.
    
4. Place this final value into `ans[i]`.
    
5. Return `ans`.
    

For example, if `nums = [0, 2, 1]`:

- `ans[0] = nums[nums[0]] = nums[0] = 0`
    
- `ans[1] = nums[nums[1]] = nums[2] = 1`
    
- ans[2] = nums[nums[2]] = nums[1] = 2
    
    The result is [0, 1, 2].
    

---

### Rust Solution

#### Idiomatic (Functional) Version

This version is concise and leverages Rust's iterators.

Rust

```Rust
impl Solution {
    pub fn build_array(nums: Vec<i32>) -> Vec<i32> {
        (0..nums.len())
            .map(|i| nums[nums[i] as usize])
            .collect()
    }
}
```

#### Manual Loop Version

This version follows the step-by-step algorithm more explicitly.

Rust

```Rust
impl Solution {
    pub fn build_array_manual(nums: Vec<i32>) -> Vec<i32> {
        let n = nums.len();
        let mut ans = vec![0; n];

        for i in 0..n {
            ans[i] = nums[nums[i] as usize];
        }

        ans
    }
}
```

---

### Complexity

- **Time Complexity:** O(n)
    
    - We iterate through the `n` elements of the array exactly once.
        
- **Space Complexity:** O(n)
    
    - We create a new array `ans` that has the same size `n` as the input array. (The problem has a follow-up that asks for an O(1) space solution, which is a more advanced trick).
