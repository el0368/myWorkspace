The goal of LeetCode 242 "Valid Anagram" is to determine if two strings are anagrams of each other. An anagram is a word formed by rearranging the letters of another, meaning they must contain the exact same characters with the exact same frequencies. For example, "anagram" and "nagaram" are anagrams.

---

### Approach 1: Sorting

The simplest conceptual approach is to sort the characters of both strings. If the strings are anagrams, their sorted versions will be identical.

#### Algorithm

1. Check if the strings have different lengths. If so, they can't be anagrams, so return `false`.
    
2. Convert both strings into character vectors.
    
3. Sort both vectors.
    
4. Compare the sorted vectors. If they are equal, return `true`; otherwise, return `false`.
    

#### Rust Solution

Rust

```Rust
impl Solution {
    pub fn is_anagram_sorting(s: String, t: String) -> bool {
        if s.len() != t.len() {
            return false;
        }

        let mut s_chars: Vec<char> = s.chars().collect();
        let mut t_chars: Vec<char> = t.chars().collect();

        s_chars.sort_unstable();
        t_chars.sort_unstable();

        s_chars == t_chars
    }
}
```

---

### Approach 2: Frequency Map (Character Counter)

A more efficient approach is to count the frequency of each character.

#### Algorithm

1. Check if the strings have different lengths. If they do, return `false`.
    
2. Create a frequency map (an array of size 26 is perfect since the problem states the input is lowercase English letters).
    
3. Iterate through the first string (`s`) and **increment** the count for each character.
    
4. Iterate through the second string (`t`) and **decrement** the count for each character.
    
5. If the strings are anagrams, the frequency map should contain all zeros at the end.
    

#### Rust Solution

Rust

```Rust
impl Solution {
    pub fn is_anagram(s: String, t: String) -> bool {
        if s.len() != t.len() {
            return false;
        }

        // Create a frequency map for 26 lowercase letters.
        let mut counts = [0; 26];
        let a_val = 'a' as usize;

        // Count characters for string s
        for byte in s.as_bytes() {
            counts[*byte as usize - a_val] += 1;
        }

        // Decrement counts for string t
        for byte in t.as_bytes() {
            counts[*byte as usize - a_val] -= 1;
        }

        // If the array is all zeros, they are anagrams.
        counts.iter().all(|&count| count == 0)
    }
}
```

---

### Complexity Comparison

|Approach|Time Complexity|Space Complexity|Notes|
|---|---|---|---|
|**Sorting**|O(nlogn)|O(n)|Easy to understand, but slower due to the sorting step. Space is needed to create mutable character vectors.|
|**Frequency Map**|O(n)|O(1)|More efficient. The space is constant because the array size (26) doesn't change with input length `n`.|

Because of its better time complexity, the **Frequency Map** approach is generally the preferred solution.
