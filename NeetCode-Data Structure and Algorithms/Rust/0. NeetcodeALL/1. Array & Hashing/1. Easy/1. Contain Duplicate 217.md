The goal of LeetCode 217 "Contains Duplicate" is to determine if any number appears more than once in an array. If a duplicate exists, you return `true`; otherwise, you return `false`.

---

### The Approach ✅

The most common and efficient way to solve this is by using a **HashSet**. A HashSet is a data structure that only stores unique elements and allows for very fast lookups.

The algorithm is simple:

1. Create an empty HashSet.
    
2. Iterate through each number in the input array.
    
3. For each number, check if it's already in the HashSet.
    
    - If it is, you've found a duplicate, and you can immediately return `true`.
        
    - If it's not, add the number to the HashSet and continue.
        
4. If you finish the entire loop without finding a duplicate, it means all elements are unique, so you return `false`.
    

---

### Rust Solution

Rust

```Rust
use std::collections::HashSet;

impl Solution {
    pub fn contains_duplicate(nums: Vec<i32>) -> bool {
        // 1. Create an empty HashSet.
        let mut seen = HashSet::new();

        // 2. Iterate through each number.
        for num in nums {
            // 3. If the number is already in the set, we found a duplicate.
            if seen.contains(&num) {
                return true;
            }
            // Otherwise, add it to the set.
            seen.insert(num);
        }

        // 4. If the loop finishes, no duplicates were found.
        false
    }
}
```

---

### Complexity

- **Time Complexity:** O(n)
    
    - We iterate through the array of `n` elements once. Each HashSet operation (insert and contains) takes, on average, constant time, O(1).
        
- **Space Complexity:** O(n)
    
    - In the worst-case scenario (where all elements are unique), the HashSet will store all `n` elements from the input array.
