The goal of LeetCode 220 "Contains Duplicate III" is to find if there are two "almost duplicate" numbers in an array. This means their **values** are at most `t` apart (`abs(nums[i] - nums[j]) <= t`) and their **indices** are at most `k` apart (`abs(i - j) <= k`).

---

### The Approach 🥉

This problem is significantly harder than the first two and its "Easy" label is often considered misleading. A simple check is too slow. The efficient solution uses a technique called **bucketing**.

The core idea is to group numbers into "buckets" of a certain size. If two numbers fall into the same bucket, they are guaranteed to be close enough in value. We only need to check the buckets immediately next to a number's own bucket for potential matches.

The algorithm works like this:

1. **Bucket Size:** Define a bucket size of `t + 1`. Any two numbers in the same bucket will have a difference of at most `t`.
    
2. **Sliding Window:** Use a HashMap to store bucket IDs and the numbers within them. This map will only hold numbers that are within the index window of size `k`.
    
3. **Iteration:** Loop through the array. For each number:
    
    - Calculate its bucket ID.
        
    - Check for a match in the current bucket or the two adjacent buckets. If a valid number is found (its value is within `t` of the current number), return `true`.
        
    - Add the current number and its bucket ID to the map.
        
    - If the window size exceeds `k`, remove the oldest number's bucket from the map to maintain the window.
        
4. If the loop finishes, no such pair was found, so return `false`.
    

---

### Rust Solution

Rust

```Rust
use std::collections::HashMap;

impl Solution {
    pub fn contains_nearby_almost_duplicate(nums: Vec<i32>, k: i32, t: i32) -> bool {
        if k <= 0 || t < 0 {
            return false;
        }

        // The HashMap stores: bucket_id -> number
        let mut buckets = HashMap::new();
        let bucket_size = t as i64 + 1;

        for (i, &num) in nums.iter().enumerate() {
            let num = num as i64;
            
            // Determine the bucket ID for the current number
            let bucket_id = num.div_euclid(bucket_size);

            // 1. Check if the current bucket contains a valid number
            if buckets.contains_key(&bucket_id) {
                return true;
            }

            // 2. Check the previous bucket
            if let Some(&prev_val) = buckets.get(&(bucket_id - 1)) {
                if (num - prev_val).abs() <= t as i64 {
                    return true;
                }
            }

            // 3. Check the next bucket
            if let Some(&next_val) = buckets.get(&(bucket_id + 1)) {
                if (num - next_val).abs() <= t as i64 {
                    return true;
                }
            }
            
            // Add the current number to its bucket
            buckets.insert(bucket_id, num);

            // Maintain the sliding window of size k
            if i >= k as usize {
                let old_num = nums[i - k as usize] as i64;
                let old_bucket_id = old_num.div_euclid(bucket_size);
                buckets.remove(&old_bucket_id);
            }
        }

        false
    }
}
```

---

### Complexity

- **Time Complexity:** O(n)
    
    - We iterate through the array once. All operations inside the loop (HashMap access, arithmetic) take, on average, constant time, O(1).
        
- **Space Complexity:** O(k)
    
    - The `buckets` HashMap stores at most `k` elements, corresponding to the size of the sliding window.
