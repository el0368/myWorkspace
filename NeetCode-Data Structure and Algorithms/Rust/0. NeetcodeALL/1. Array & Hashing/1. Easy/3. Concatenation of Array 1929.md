The goal of LeetCode 1929 "Concatenation of Array" is to create a new array that is a copy of the original array, `nums`, followed by another copy of `nums`.

For example, if `nums` is `[1, 2, 3]`, the result should be `[1, 2, 3, 1, 2, 3]`.

---

### The Approach 🔗

The task is to build an array of length `2 * n` from an input array of length `n`. 1There are a few ways to do this, but the core logic is the same: the first half of the new array is a copy of the original, and the second half is also a copy of the original.

#### Algorithm

1. Get the length of the input array `nums`, let's call it `n`.
    
2. Create a new result array, `ans`, of size `2 * n`.
    
3. Loop from `i = 0` to `n - 1`.
    
4. In each step of the loop, set `ans[i] = nums[i]` and `ans[i + n] = nums[i]`.
    
5. Return the `ans` array.
    

---

### Rust Solution

Rust's powerful vector and slice operations make this very concise.

#### Idiomatic Version

This is the simplest way to write it in Rust.

Rust

```Rust
impl Solution {
    pub fn get_concatenation(nums: Vec<i32>) -> Vec<i32> {
        // Create a new vector by concatenating two clones of the input vector.
        [nums.clone(), nums.clone()].concat()
    }
}
```

#### Manual Loop Version

This version follows the step-by-step algorithm and can be easier to understand for beginners.

Rust

```Rust
impl Solution {
    pub fn get_concatenation_manual(nums: Vec<i32>) -> Vec<i32> {
        let n = nums.len();
        // 1. Create a new vector of size 2*n, initialized with zeros.
        let mut ans = vec![0; 2 * n];

        // 2. Loop through the original vector.
        for i in 0..n {
            // 3. Place the element at its two positions.
            ans[i] = nums[i];
            ans[i + n] = nums[i];
        }

        ans
    }
}
```

---

### Complexity

- **Time Complexity:** O(n)
    
    - We must read all `n` elements of the input array to create the new array of size `2n`. The work is directly proportional to the size of the input.
        
- **Space Complexity:** O(n)
    
    - We are required to create a new array of size `2n`. The space needed for this output array scales linearly with the input size `n`.
