### Tracing Example 2: Action in the "Descending" Phase 🔽

The instructor presents a second example that is very similar to the first, but with a "minor difference." He notes, "here it is printing and then calling itself. But here **first it is calling itself then printing.**" This small change completely reverses the output.

**Go Code Example:**

```go
package main

import "fmt"

// This function calls itself with n-1, THEN prints the value of n.
func fun2(n int) {
    // The base condition remains the same.
	if n > 0 {
		// Step 1: Make the recursive call first.
		fun2(n - 1)
		
		// Step 2: Perform the action (print) AFTER the call returns.
		fmt.Println(n)
	}
}

func main() {
	x := 3
	fun2(x)
}
```

The instructor traces this function, highlighting how the print statements are deferred until the recursive calls have returned. The trace happens in two distinct phases.

#### The Calling Phase

1.  **Call: `fun2(3)`**

      * The condition `3 > 0` is true.
      * **First statement:** It immediately calls **`fun2(2)`**. The instructor notes, "what about the next statement printing? **it will not be done first. This call has to finish, then only it will print.**" The `Println(3)` statement is now pending.

2.  **Call: `fun2(2)`**

      * The condition `2 > 0` is true.
      * **First statement:** It calls **`fun2(1)`**. The `Println(2)` statement is pending.

3.  **Call: `fun2(1)`**

      * The condition `1 > 0` is true.
      * **First statement:** It calls **`fun2(0)`**. The `Println(1)` statement is pending.

4.  **Call: `fun2(0)` — The Base Case**

      * The condition `0 > 0` is **false**.
      * The function does nothing and returns immediately.

#### The Returning Phase

Now that the deepest call has finished, the stack begins to unwind, and the pending operations are executed.

1.  **Return to `fun2(1)`:**

      * The call to `fun2(0)` has finished.
      * The next statement is executed: "print n." In the context of this function call, `n` is `1`. The program prints **`1`**.

2.  **Return to `fun2(2)`:**

      * The call to `fun2(1)` has now completed.
      * The next statement is executed: "print n." The value of `n` here is `2`. The program prints **`2`**.

3.  **Return to `fun2(3)`:**

      * The call to `fun2(2)` is complete.
      * The final pending statement is executed: "print n." The value of `n` is `3`. The program prints **`3`**.

This process, where the work is done after the recursive call, leads the instructor to conclude that "**printing is done at returning time.** When the function is returning to the previous call...printing is done."

The final output generated is **`1, 2, 3`**.
