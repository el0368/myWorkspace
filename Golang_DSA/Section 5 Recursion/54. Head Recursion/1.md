### What is Head Recursion? 🤔

Head recursion is a type of recursion where the recursive call is the **very first statement** within the function. This means there are no other operations or processing steps that occur before the function calls itself again.

#### The Defining Rule

As the instructor states, if "the first statement inside the function is recursive call...Then we can say this is a Head recursion." He clarifies that if there is any operation performed _before_ the recursive call, then it is just a standard recursion, not specifically head recursion.

The consequence of this structure is that the function performs no work on its way "down" into the recursive calls. All of its actions are postponed until the recursive calls have hit their base case and begin to return. In the instructor's words, **"the function doesn't have to process or perform any operation at the time of calling. It has to do everything only at the time of returning."**

#### Go Example

This function is a perfect example of head recursion. The call to `headRecursionExample(n - 1)` happens immediately, and the `Println` action is saved for later.

Go

```Go
package main

import "fmt"

func headRecursionExample(n int) {
	if n > 0 {
		// 1. The recursive call is the first action inside the block.
		headRecursionExample(n - 1)

		// 2. All work, like this print statement, happens AFTER the call returns.
		fmt.Printf("Processing on the way back: %d\n", n)
	}
}

func main() {
	headRecursionExample(3)
}
// Output:
// Processing on the way back: 1
// Processing on the way back: 2
// Processing on the way back: 3
```

Because all the work is postponed until the calls are returning, this type of function is defined by the principle that **"all the processing is done at returning time."**
