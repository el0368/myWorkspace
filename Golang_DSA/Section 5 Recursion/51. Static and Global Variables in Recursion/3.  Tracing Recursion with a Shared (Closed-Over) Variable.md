### Tracing Recursion with a Shared Variable (Closure) ⛓️

This section provides a detailed trace of the modified recursive function to show how using a single, shared variable dramatically changes the outcome.

**Go Code Example (for reference):**

Go

```Go
// This is the function we are tracing. 'x' is the shared variable.
func makeSumFunc() func(int) int {
	x := 0 // 'x' is initialized only once.
	var f func(int) int
	f = func(n int) int {
		if n == 0 {
			return 0
		}
		x++
		result := f(n - 1)
		return result + x
	}
	return f
}

// In main:
// fun := makeSumFunc()
// result := fun(5) -> This is what we are tracing.
```

Following the instructor's method, we track the **single copy of `x`** separately from the recursive calls.

**Initial State:**

- `x = 0`
    

---

### The Calling Phase (Modifying `x`)

During the "calling" or "ascending" phase, the function calls itself repeatedly, and the `x++` operation modifies the single shared `x` at each step.

1. **`fun(5)` is called:** `x` is incremented. `x` is now `1`. The function then calls `fun(4)`.
    
2. **`fun(4)` is called:** `x` is incremented. `x` is now `2`. The function calls `fun(3)`.
    
3. **`fun(3)` is called:** `x` is incremented. `x` is now `3`. The function calls `fun(2)`.
    
4. **`fun(2)` is called:** `x` is incremented. `x` is now `4`. The function calls `fun(1)`.
    
5. **`fun(1)` is called:** `x` is incremented. `x` is now `5`. The function calls `fun(0)`.
    
6. **`fun(0)` is called:** This is the base case. It immediately returns `0`.
    

At the end of the calling phase, the final value of our single, shared `x` is **`5`**.

---

### The Returning Phase (Using `x`)

Now the stack unwinds. In the "returning" or "descending" phase, the `return result + x` line is executed. Crucially, every single step will use the **current and final value of `x`**, which is `5`.

1. **`fun(1)` resumes:** It receives the `result` (`0`) from `fun(0)`. It calculates `$0 + x$`. Since `x` is `5`, it returns `$0 + 5 = 5$`.
    
2. **`fun(2)` resumes:** It receives the `result` (`5`) from `fun(1)`. It calculates `$5 + x$`. Since `x` is `5`, it returns `$5 + 5 = 10$`.
    
3. **`fun(3)` resumes:** It receives `10`. It calculates `$10 + x$`. It returns `$10 + 5 = 15$`.
    
4. **`fun(4)` resumes:** It receives `15`. It calculates `$15 + x$`. It returns `$15 + 5 = 20$`.
    
5. **`fun(5)` resumes:** It receives `20`. It calculates `$20 + x$`. It returns `$20 + 5 = 25$`.
    

The final result returned to `main` is **`25`**.

As the instructor points out, this is different from the first example where each call used its own local copy of `n`. Here, "**there is only one single copy of x, so each call will use that same copy.**"
