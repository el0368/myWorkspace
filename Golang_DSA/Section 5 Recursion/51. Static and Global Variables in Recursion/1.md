### Baseline: Recursion with Local Variables 🔢

This first example establishes the standard behavior of a recursive function using normal **local variables**. The key principle is that each time a function calls itself, a new, separate workspace (**activation record**) is created on the stack for that call.

Go Code Example:

This function recursively calculates the sum of all integers from 1 up to n.

Go

```Go
package main

import "fmt"

// sum recursively calculates the sum of numbers up to n.
func sum(n int) int {
	// Base case: the sum of numbers up to 0 is 0.
	if n == 0 {
		return 0
	}
	
	// Recursive step: the sum of n is the sum of (n-1) plus the current n.
	return sum(n-1) + n
}

func main() {
	result := sum(5)
	fmt.Println(result) // Output: 15
}
```

---

### How It Works: The Tracing Tree and Stack

The instructor traces this function to show how the final result of `15` is achieved.

1. **The Calling Phase:** The function calls itself repeatedly until it hits the base case. Each call pauses and waits for the result of the next call.
    
    - `sum(5)` calls `sum(4)` and waits.
        
    - `sum(4)` calls `sum(3)` and waits.
        
    - `sum(3)` calls `sum(2)` and waits.
        
    - `sum(2)` calls `sum(1)` and waits.
        
    - `sum(1)` calls `sum(0)`.
        
2. **The Base Case:** `sum(0)` immediately returns `0`.
    
3. **The Returning Phase:** Now, the chain of calls unwinds, and the addition operation is performed at each step. This works because each call has its **own independent copy of `n`** stored in its activation record on the stack.
    
    - `sum(1)` receives `0` from `sum(0)` and adds its _own_ `n` (which is `1`). It returns `$0 + 1 = 1$`.
        
    - `sum(2)` receives `1` from `sum(1)` and adds its _own_ `n` (which is `2`). It returns `$1 + 2 = 3$`.
        
    - `sum(3)` receives `3` from `sum(2)` and adds its _own_ `n` (which is `3`). It returns `$3 + 3 = 6$`.
        
    - `sum(4)` receives `6` from `sum(3)` and adds its _own_ `n` (which is `4`). It returns `$6 + 4 = 10$`.
        
    - `sum(5)` receives `10` from `sum(4)` and adds its _own_ `n` (which is `5`). It returns `$10 + 5 = 15$`.
        

This behavior is the foundation of recursion. The stack preserves the unique state of each function call, allowing computations to be performed correctly during the returning phase.
