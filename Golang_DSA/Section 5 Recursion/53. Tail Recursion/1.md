### What is Tail Recursion? 🤔

Tail recursion is a specific form of recursion where the recursive call is the **absolute last action** performed by the function. Once the recursive call is made, there is no other computation or operation left to do in the current function's scope.

#### The Defining Rule

As the instructor states, "if a recursive function is calling itself and that recursive call...is the **last statement in a function then it is called as tail recursion.**" This means that all necessary work, such as printing, calculations, or modifications, is done _before_ the function calls itself again.

Because all operations are completed upfront, the function does not need to perform any work during the "returning time." Its job is finished as soon as it makes the final call.

#### Go Example

This function is a perfect example of tail recursion because after the `tailRecursionExample(n - 1)` call is made, there are no more lines of code to execute within that `if` block.

Go

```Go
package main

import "fmt"

func tailRecursionExample(n int) {
	if n > 0 {
		// 1. All work, like this print statement, is done first.
		fmt.Printf("Processing on the way down: %d\n", n)

		// 2. The recursive call is the final action. Nothing follows it.
		tailRecursionExample(n - 1)
	}
}

func main() {
	tailRecursionExample(3)
}

```

---

### The Critical Distinction: No Work at Returning Time

The key to identifying tail recursion is to check if any operation depends on the result of the recursive call.

- **Tail Recursion:** In our example, the function simply calls `tailRecursionExample(n - 1)`. It doesn't need to wait for a value to come back.
    
- **NOT Tail Recursion:** Consider this modification: `return fun(n-1) + n`.
    
    - In this case, the addition (`+ n`) cannot be performed until the `fun(n-1)` call has finished and returned a value.
        
    - As the instructor explains, "this operation can be performed only at returning time." Because there is pending work to do after the recursive call finishes, this is **not** tail recursion.
