### Introduction to Space Complexity 💾

After discussing time complexity, the instructor briefly introduces the concept of space complexity. He defines it simply as the answer to the question: **"how much space is consumed in main memory during the execution of a program?"**

He clarifies that the goal is not to calculate the exact number of bytes. Instead, the focus is on understanding how the memory usage scales with the input size. In his words, "**we want to know, the space is dependent on what? n. If the value of n is more, the space will be more, that's what the idea is.**"

He then applies this concept to the data structures discussed previously:

* **Array or Slice:** An array or slice containing 'n' elements requires space proportional to 'n'. Therefore, the space complexity is **`Order(n)`**.

* **Linked List:** For a list with 'n' nodes, you need space for the 'n' elements plus additional space for the pointer in each node that links to the next. Even if this means the total space is `2n`, the complexity is still simplified to **`Order(n)`** because it scales linearly with 'n'.

* **Matrix (Slice of Slices in Go):** An `n x n` matrix contains `n²` elements, so its space complexity is **`Order(n²)`**.

* **Composite Structure:** For the example of a structure with 'm' outer elements and 'n' inner elements, the space complexity is **`m+n`**.

* **Binary Tree:** A tree with 'n' nodes requires space for each of those 'n' nodes, making its space complexity **`Order(n)`**.
