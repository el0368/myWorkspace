### **Getting Started with Node.js: Installation & First Script**

This guide covers installing Node.js, setting up a code editor, and writing and running your first two simple Node.js applications.

---

### **1. Installation & Verification 💻**

1. **Download:** Go to **nodejs.org** and download the latest version (the speaker used 14.11, but any newer version is fine).
    
2. **Install:** Run the downloaded installer, accepting all the default settings. The process is similar for both Windows and Mac.
    
3. **Verify:** Open your system's terminal (or Command Prompt/PowerShell on Windows) and run the command:
    
    Bash
    
    ```
    node -v
    ```
    
    If it successfully shows a version number, Node.js is installed correctly.
    

---

### **2. Setting Up Your Editor (VS Code) 📝**

- **Create a Project Folder:** Make a new, empty folder on your computer for your project.
    
- **Install a Code Editor:** The guide recommends **Visual Studio Code (VS Code)**, which is free and available at **code.visualstudio.com**.
    
- **Open Your Project:** In VS Code, go to `File > Open` and select the project folder you created.
    
- **(Optional) Match the Look:**
    
    - **Theme:** `Preferences > Color Theme` and select `Dark+`.
        
    - **Icons:** `View > Extensions` and install the `Material Icon Theme`.
        

---

### **3. Writing & Running Your First Scripts ▶️**

#### **A. "Hello World" to the Console**

1. **Create a File:** In VS Code, create a new file named `first-app.js`.
    
2. **Write Code:** Add the following JavaScript to the file:
    
    JavaScript
    
    ```
    console.log('Hello from Node.js');
    ```
    
3. **Run the Script:**
    
    - Open the integrated terminal in VS Code (`Terminal > New Terminal`).
        
    - Run the file using the `node` command followed by the filename:
        
    
    Bash
    
    ```
    node first-app.js
    ```
    
    - You will see "Hello from Node.js" printed in the terminal.
        

#### **B. Writing to a File with the `fs` Module**

This demonstrates a core Node.js feature: interacting with the file system.

1. **Modify the File:** Replace the content of `first-app.js` with the following:
    
    JavaScript
    
    ```
    // 1. Import the built-in 'File System' module
    const fs = require('fs');
    
    // 2. Use a method from the module to write a file
    // This creates 'hello.txt' with the specified content.
    fs.writeFileSync('hello.txt', 'Hello from Node.js');
    ```
    
2. **Run the Script Again:** In the terminal, run the same command as before:
    
    Bash
    
    ```
    node first-app.js
    ```
    
3. **Check the Result:** A new file named `hello.txt` will appear in your project folder containing the text "Hello from Node.js".
    

---

### **Quick Tip: The REPL (Interactive Mode) ⚡**

- You can enter an interactive Node.js session directly in your terminal by just typing `node` and hitting Enter.
    
- This mode, called the REPL, is useful for quick tests and calculations.
    
- To exit, press `Ctrl + C` twice.
