## What is Node.js? 🚀

**Node.js** is a **JavaScript runtime**, which is a program that allows you to execute JavaScript code **outside of a web browser**.1 It effectively turns JavaScript into a general-purpose language that can run on any computer or server, making it a great choice for building back-end web applications.

> The core takeaway: **Node.js lets you run JavaScript on your computer.2**

---

## How It Works: The V8 Engine

Node.js is built on **Google's V8 JavaScript engine**, the same powerful engine used in Google Chrome.

- **What is an engine?** A JavaScript engine like V8 takes your JS code and compiles it into low-level **machine code** that your computer's processor can execute directly and efficiently.
    
- **Node.js's Extension:** Node.js takes the core V8 engine (which is written in C++) and adds new features and modules to it.
    

---

## Key Differences: Node.js vs. Browser JavaScript 💻

While both use JavaScript, their environments give them different capabilities.

### What Node.js ADDS:

- **Server-Side Functionality:** It adds features impossible in a browser for security reasons.
    
- **File System Access:** You can create, read, and delete files on the local machine.
    
- **Networking:** You can create servers, handle HTTP requests, and more.
    

### What Node.js REMOVES:

- **DOM Manipulation:** Since Node.js doesn't run in a browser, there is no webpage or HTML to interact with. You **cannot** use browser-specific APIs like `document.getElementById()` or `window.alert()`.
    

In essence, Node.js swaps the browser's functionalities (like interacting with a webpage) for server-side functionalities (like interacting with the computer's file system).
