### Rust Shortening Code for Competitive Programming

In competitive programming, writing concise code is crucial for speed and clarity. Rust provides several mechanisms to shorten code, including type aliases for simplifying type names and macros for reducing repetitive patterns. These tools help streamline code without sacrificing readability or performance. Below is a detailed explanation of shortening code in Rust for competitive programming, covering type aliases and macros, structured to match the style of previous responses.

#### 1. Type Aliases

Rust’s `type` keyword allows you to define shorter names for existing types, making code more concise and easier to read. This is particularly useful for complex or frequently used types in competitive programming.

Example: Defining a type alias for `i64`:

```rust
use std::io::{self, Write};

type LL = i64;

fn main() {
    let a: LL = 123_456_789;
    let b: LL = 987_654_321;
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "{}", a * b).expect("Failed to write");
}
```

- **Explanation**: The `type LL = i64;` line defines `LL` as an alias for `i64`, a 64-bit signed integer. This allows `LL` to be used instead of `i64` throughout the code, reducing verbosity while maintaining clarity. The program multiplies two `LL` values and outputs the result.

Type aliases are also useful for complex types, such as collections or tuples. For example:

```rust
use std::io::{self, Write};
use std::collections::VecDeque;

type VI = Vec<i32>;
type PI = (i32, i32);

fn main() {
    let mut v: VI = vec![];
    v.push(1);
    v.push(2);
    let p: PI = (3, 4);
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "{} {}", v[0], p.0 + p.1).expect("Failed to write");
}
```

- **Explanation**: `type VI = Vec<i32>;` creates an alias for a vector of 32-bit integers, and `type PI = (i32, i32);` defines an alias for a tuple of two 32-bit integers. These aliases simplify declarations and improve code readability.

#### 2. Macros

Rust’s macro system allows you to define reusable code patterns that are expanded at compile time, reducing repetitive code. Macros are defined using the `macro_rules!` construct and are particularly useful in competitive programming for shortening common operations, such as method calls, loops, or data structure manipulations.

Example: Defining macros for common operations:

```rust
use std::io::{self, Write};
use std::collections::VecDeque;

macro_rules! pb {
    ($v:expr, $x:expr) => {
        $v.push_back($x);
    };
}

macro_rules! mp {
    ($x:expr, $y:expr) => {
        ($x, $y)
    };
}

fn main() {
    let mut v: VecDeque<(i32, i32)> = VecDeque::new();
    let y1 = 3;
    let x1 = 4;
    let y2 = 5;
    let x2 = 6;
    pb!(v, mp!(y1, x1));
    pb!(v, mp!(y2, x2));
    let d = v[0].0 + v[0].1;
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "{}", d).expect("Failed to write"); // Outputs 7
}
```

- **Explanation**: The `pb!` macro simplifies `push_back` for a `VecDeque`, and the `mp!` macro creates a tuple from two values. These macros reduce the verbosity of `v.push_back((y1, x1))` to `pb!(v, mp!(y1, x1))`, making the code more concise.

Macros can also have parameters to shorten repetitive structures like loops. For example:

```rust
use std::io::{self, Write};

macro_rules! rep {
    ($i:ident, $a:expr, $b:expr, $block:block) => {
        for $i in $a..=($b) {
            $block
        }
    };
}

fn search(i: i32) {
    // Example function
}

fn main() {
    let n = 5;
    rep!(i, 1, n, {
        search(i);
    });
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "Done").expect("Failed to write");
}
```

- **Explanation**: The `rep!` macro expands to a `for` loop iterating from `a` to `b` (inclusive), with the loop variable `i` and body `block`. This shortens `for i in 1..=n { search(i); }` to `rep!(i, 1, n, { search(i); })`, saving keystrokes and improving readability.

#### 3. Additional Notes

- **Type Aliases**: Use `type` for any type, including primitives (`i64`), collections (`Vec<i32>`), or custom structs. Aliases don’t create new types; they are purely for convenience.
- **Macro Flexibility**: Rust’s `macro_rules!` supports complex patterns, including multiple arguments and nested expansions. Use them for repetitive tasks like input parsing, output formatting, or data structure operations.
- **Performance**: Type aliases and macros have no runtime overhead, as they are resolved at compile time. This makes them ideal for competitive programming, where efficiency is critical.
- **Readability**: Balance brevity with clarity. Overusing macros can make code harder to understand, so reserve them for common patterns.

#### Example: Complete Template with Aliases and Macros

A template for a problem using type aliases and macros:

```rust
use std::io::{self, BufRead, BufWriter, Write};
use std::collections::VecDeque;

type LL = i64;
type PI = (i32, i32);

macro_rules! pb {
    ($v:expr, $x:expr) => {
        $v.push_back($x);
    };
}

macro_rules! rep {
    ($i:ident, $a:expr, $b:expr, $block:block) => {
        for $i in $a..=($b) {
            $block
        }
    };
}

fn main() {
    let mut stdin = io::stdin().lock();
    let stdout = io::stdout();
    let mut stdout = BufWriter::new(stdout.lock());

    // Read input
    let mut line = String::new();
    stdin.read_line(&mut line).expect("Failed to read line");
    let mut iter = line.trim().split_whitespace();
    let n: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let x: LL = iter.next().unwrap().parse().expect("Expected an integer");

    // Use macros and aliases
    let mut v: VecDeque<PI> = VecDeque::new();
    rep!(i, 1, n, {
        pb!(v, (i, i * 2));
    });

    // Compute and output
    let sum: LL = v.iter().map(|p| (p.0 as LL) + (p.1 as LL)).sum();
    writeln!(stdout, "{}", sum + x).expect("Failed to write");
}
```

- **Explanation**: Uses `LL` for `i64` and `PI` for `(i32, i32)`. The `pb!` macro simplifies pushing to a `VecDeque`, and `rep!` shortens a loop. The program reads `n` and `x`, creates `n` pairs, computes their sum, adds `x`, and outputs the result.
