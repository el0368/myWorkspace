#### Rust Code Template

A standard Rust template for competitive programming looks like this:

```rust
use std::io::{self, BufRead, Write};

fn main() {
    // solution comes here
}
```

#### Explanation of the Template

1. **Imports with `use`**:
   - The `use std::io::{self, BufRead, Write};` line imports essential input/output functionality from Rust’s standard library. The `std::io` module provides tools for reading from standard input (`stdin`) and writing to standard output (`stdout`). Specifically:
     - `self` imports the `io` module itself for accessing `io::stdin` and `io::stdout`.
     - `BufRead` is a trait for buffered reading, useful for efficient line-by-line input processing.
     - `Write` is a trait for writing to output streams, enabling formatted output.
   - In competitive programming, this import is sufficient for most I/O tasks, but additional modules like `std::collections` (for `Vec`, `HashMap`, etc.) or `std::cmp` (for comparison utilities) can be added as needed for specific problems.
   - Rust’s module system requires explicit imports, ensuring only necessary components are included, which keeps the code clear and efficient.

2. **Main Function**:
   - The `fn main() {}` block is the entry point of the program, where the competitive programming solution is implemented.
   - In Rust, `main` can be a simple function with no return value (as shown) or return a `Result` for error handling. For competitive programming, the simple `fn main()` is typically used, as error handling is often minimal due to guaranteed input formats.

#### Compiling Rust Code

To compile the Rust code, you can use the `rustc` compiler for single-file programs, which is common in competitive programming. The command is:

```bash
rustc -O main.rs -o main
```

- **`-O`**: Enables optimizations, producing efficient machine code suitable for competitive programming’s performance requirements.
- **`main.rs`**: The source file containing the Rust code.
- **`-o main`**: Specifies the output binary name, creating an executable file named `main`.

For most Rust development, including competitive programming, the `cargo` build tool is preferred for its project management features. To compile with `cargo`, you first create a project:

```bash
cargo new contest
cd contest
```

Then, place your code in `src/main.rs`. To compile with optimizations, run:

```bash
cargo build --release
```

- **`--release`**: Builds the program with optimizations, placing the binary in `target/release/contest`.
- Rust’s editions (e.g., 2021, 2024) define the language version. The edition is typically specified in the `Cargo.toml` file (e.g., `edition = "2021"`). For `rustc`, you can specify it with `--edition=2021`, but the default is usually sufficient for competitive programming.
- Rust’s compiler provides warnings by default, catching issues like unused variables or potential logic errors. For stricter checks, you can add `#![warn(all)]` at the top of your code or use `cargo build --release --verbose`.

#### Example: Basic Competitive Programming Setup

Here’s an expanded template showing how to use the imported modules for a typical problem (e.g., reading two integers and printing their sum):

```rust
use std::io::{self, BufRead, Write};

fn main() {
    let mut input = String::new();
    io::stdin()
        .lock()
        .read_line(&mut input)
        .expect("Failed to read line");
    let numbers: Vec<i32> = input
        .trim()
        .split_whitespace()
        .map(|s| s.parse().expect("Expected an integer"))
        .collect();
    let sum = numbers[0] + numbers[1];
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "{}", sum).expect("Failed to write");
}
```

- **Input**: Reads a line (e.g., `123 456`) into a `String`, splits it into tokens, and parses them as `i32`.
- **Output**: Writes the sum to standard output with a newline.
- **Efficiency**: Uses `lock()` for buffered I/O to minimize system calls.

#### Additional Features

- **Standard Library Access**: Rust’s standard library (`std`) includes modules like:

  - `std::collections` for data structures like `Vec`, `HashMap`, and `BTreeSet`.
  - `std::cmp` for utilities like `max` and `min`.
  - These are accessible via explicit `use` statements, tailored to the problem’s needs.
- **Memory Safety**: Rust’s ownership model ensures safe memory management without a garbage collector, which is ideal for competitive programming where performance is critical.
- **Performance**: The `-O` flag or `cargo build --release` produces highly optimized binaries, leveraging Rust’s LLVM backend for performance comparable to or better than other systems languages.
