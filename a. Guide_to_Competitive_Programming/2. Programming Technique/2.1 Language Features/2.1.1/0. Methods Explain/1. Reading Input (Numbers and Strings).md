### Part 1: Reading Input (Numbers and Strings) - Explanation of Methods

The "Reading Input (Numbers and Strings)" section of the Rust Input and Output for Competitive Programming document demonstrates how to read input data, typically consisting of numbers and strings separated by spaces or newlines, using the `std::io` module. This part employs several methods to handle input efficiently and safely. Below is a detailed explanation of each method that appears in the provided code, along with examples to illustrate their usage in a competitive programming context.

#### Methods Explained

1. **`io::stdin`**
   - **Purpose**: Returns a handle to the standard input stream.
   - **Signature**: `pub fn stdin() -> Stdin`
   - **Explanation**: This static method creates a `Stdin` object, representing the input stream (e.g., keyboard or redirected file). It serves as the entry point for reading from standard input in Rust.
   - **Example**:
     ```rust
     use std::io;

     fn main() {
         let stdin = io::stdin(); // Creates a Stdin handle
         println!("Stdin handle created");
     }
     ```
     - This basic example shows how `io::stdin()` initializes the input handle, though it’s typically followed by `lock()` for practical use.

2. **`Stdin::lock`**
   - **Purpose**: Locks the standard input stream and returns a locked reference implementing the `BufRead` trait.
   - **Signature**: `pub fn lock(&self) -> StdinLock<'_>`
   - **Explanation**: This method provides a `StdinLock`, which implements `BufRead`, enabling buffered reading. Locking prevents concurrent access and optimizes performance by reducing system calls, making it ideal for competitive programming.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock(); // Locks input for buffered reading
         let mut buffer = String::new();
         stdin.read_line(&mut buffer).expect("Failed to read");
         println!("Read: {}", buffer);
     }
     ```
     - Input: `Hello\n`
     - Output: `Read: Hello\n`
     - The lock ensures efficient reading into the `buffer`.

3. **`BufRead::read_line`**
   - **Purpose**: Reads a line of text into a string buffer until a newline (`\n`) or EOF is encountered.
   - **Signature**: `fn read_line(&mut self, buf: &mut String) -> Result<usize, Error>`
   - **Explanation**: This method appends data to the provided mutable `String` buffer and returns the number of bytes read as a `Result`. It includes the newline unless EOF is reached. The `expect` method unwraps the `Result`, assuming no I/O errors in a contest setting.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         println!("Input: {}", input);
     }
     ```
     - Input: `123 456\n`
     - Output: `Input: 123 456\n`
     - Reads the entire line, including the newline.

4. **`String::trim`**
   - **Purpose**: Removes leading and trailing whitespace from a string, including newlines.
   - **Signature**: `pub fn trim(&self) -> &str`
   - **Explanation**: This method returns a slice of the string with whitespace (spaces, tabs, newlines) removed from both ends. It’s used after `read_line` to clean up input for parsing, especially to remove the trailing newline.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         let trimmed = input.trim();
         println!("Trimmed: {}", trimmed);
     }
     ```
     - Input: `123 456\n`
     - Output: `Trimmed: 123 456`
     - Removes the newline, leaving only the tokens.

5. **`str::split_whitespace`**
   - **Purpose**: Splits a string into an iterator of substrings separated by whitespace.
   - **Signature**: `pub fn split_whitespace(&self) -> SplitWhitespace<'_>`
   - **Explanation**: This method returns an iterator over the string’s words, where words are sequences of non-whitespace characters separated by spaces, tabs, or newlines. It’s perfect for parsing space-separated input in competitive programming.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         let tokens: Vec<&str> = input.trim().split_whitespace().collect();
         for token in tokens {
             println!("Token: {}", token);
         }
     }
     ```
     - Input: `123 456 monkey\n`
     - Output:
       ```
       Token: 123
       Token: 456
       Token: monkey
       ```
     - Splits the trimmed input into individual tokens.

6. **`Iterator::next`**
   - **Purpose**: Advances the iterator and returns the next item.
   - **Signature**: `fn next(&mut self) -> Option<Self::Item>`
   - **Explanation**: This method, from the `Iterator` trait, returns `Some(item)` for the next element or `None` if the iterator is exhausted. The `unwrap()` call assumes an item exists, which is valid for expected input formats in contests.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         let mut iter = input.trim().split_whitespace();
         let first = iter.next().unwrap();
         let second = iter.next().unwrap();
         println!("First: {}, Second: {}", first, second);
     }
     ```
     - Input: `123 456\n`
     - Output: `First: 123, Second: 456`
     - Advances the iterator to retrieve the first two tokens.

7. **`str::parse`**
   - **Purpose**: Parses a string slice into a specified type (e.g., `i32`, `String`).
   - **Signature**: `fn parse<F: FromStr>(&self) -> Result<F, F::Err>`
   - **Explanation**: This method attempts to convert a string slice into a target type and returns a `Result`. The `expect` call unwraps the `Result`, panicking if parsing fails, which is acceptable in contests with guaranteed input.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         let mut iter = input.trim().split_whitespace();
         let num: i32 = iter.next().unwrap().parse().expect("Expected an integer");
         println!("Number: {}", num);
     }
     ```
     - Input: `123\n`
     - Output: `Number: 123`
     - Parses the token `123` into an `i32`.

8. **`String::to_string`**
   - **Purpose**: Converts a string slice or other type into a `String`.
   - **Signature**: `pub fn to_string(&self) -> String` (for `&str`)
   - **Explanation**: This method creates a new `String` from a string slice (e.g., from `split_whitespace`), useful when the token should remain a string rather than being parsed into a number.
   - **Example**:
     ```rust
     use std::io::{self, BufRead};

     fn main() {
         let mut stdin = io::stdin().lock();
         let mut input = String::new();
         stdin.read_line(&mut input).expect("Failed to read line");
         let mut iter = input.trim().split_whitespace();
         let word: String = iter.next().unwrap().to_string();
         println!("Word: {}", word);
     }
     ```
     - Input: `hello\n`
     - Output: `Word: hello`
     - Converts the token `hello` into a `String`.

#### Comprehensive Example Combining All Methods
```rust
use std::io::{self, BufRead};

fn main() {
    let mut stdin = io::stdin().lock();
    let mut input = String::new();
    stdin.read_line(&mut input).expect("Failed to read line");
    let mut iter = input.trim().split_whitespace();
    let a: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let b: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let x: String = iter.next().unwrap().to_string();
    println!("a: {}, b: {}, x: {}", a, b, x);
}
```
- **Input**: `123 456 monkey\n`
- **Output**: `a: 123, b: 456, x: monkey`
- **Explanation**: This example integrates all methods:
  - `io::stdin().lock()` sets up buffered input.
  - `read_line` reads the line.
  - `trim().split_whitespace()` prepares tokens.
  - `next().parse()` converts `123` and `456` to `i32`.
  - `next().to_string()` keeps `monkey` as a `String`.
  - `println!` displays the results.

#### Multi-Line Input Example
```rust
use std::io::{self, BufRead};

fn main() {
    let mut lines = io::stdin().lock().lines();
    let first_line = lines.next().unwrap().expect("Failed to read line");
    let mut iter = first_line.trim().split_whitespace();
    let a: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let b: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let second_line = lines.next().unwrap().expect("Failed to read line");
    let x: String = second_line.trim().to_string();
    println!("a: {}, b: {}, x: {}", a, b, x);
}
```
- **Input**:
  ```
  123 456
  monkey
  ```
- **Output**: `a: 123, b: 456, x: monkey`
- **Explanation**: Uses `lines()` to iterate over lines, processing `123 456` and `monkey` separately with the same methods.
