### Methods in "Writing Output"

#### 1. **`io::stdout`**
- **Purpose**: Returns a handle to the standard output stream.
- **Signature**: `pub fn stdout() -> Stdout`
- **Explanation**: This static method creates a `Stdout` object, representing the output stream (e.g., console or redirected file). It serves as the entry point for writing to standard output in Rust.
- **Usage in Code**:
  ```rust
  let mut stdout = io::stdout().lock();
  ```
  - Called to initiate output handling, typically followed by `lock()` to enable efficient writing.

#### 2. **`Stdout::lock`**
- **Purpose**: Locks the standard output stream and returns a locked reference implementing the `Write` trait.
- **Signature**: `pub fn lock(&self) -> StdoutLock<'_>`
- **Explanation**: This method provides a `StdoutLock`, which implements the `Write` trait, allowing buffered writing. Locking ensures thread safety and reduces system call overhead, making it suitable for competitive programming where performance is key.
- **Usage in Code**:
  ```rust
  let mut stdout = io::stdout().lock();
  ```
  - Applied to the `Stdout` handle to prepare it for writing with macros like `write!` or `writeln!`, with `mut` allowing modifications.

#### 3. **`Write::write` (via `write!` macro)**
- **Purpose**: Writes a formatted string to the output stream without a newline.
- **Signature**: `fn write(&mut self, buf: &[u8]) -> Result<usize, Error>` (underlying trait method)
- **Explanation**: The `write!` macro leverages the `Write` trait to format and write data to the stream as a byte slice. It returns a `Result` indicating the number of bytes written. This macro allows custom output formatting without automatically adding a newline, offering fine-grained control.
- **Usage in Code**:
  ```rust
  write!(stdout, "{} {} {}", a, b, x).expect("Failed to write");
  ```
  - Formats `a`, `b`, and `x` with spaces (using `{}` placeholders) and writes them to `stdout`, with `expect` handling potential errors.

#### 4. **`Write::writeln` (via `writeln!` macro)**
- **Purpose**: Writes a formatted string to the output stream with a newline.
- **Signature**: `fn writeln(&mut self, buf: &[u8]) -> Result<(), Error>` (underlying trait method)
- **Explanation**: The `writeln!` macro extends `write!` by appending a newline (`\n`) after the formatted string. It returns a `Result`, and `expect` unwraps it, assuming success in a contest environment. This is the preferred method for contest output where each result typically ends with a newline.
- **Usage in Code**:
  ```rust
  writeln!(stdout, "{} {} {}", a, b, x).expect("Failed to write");
  ```
  - Formats `a`, `b`, and `x` with spaces and adds a newline, producing output like `123 456 monkey\n`.
  - Also used standalone:
    ```rust
    writeln!(stdout).expect("Failed to write newline");
    ```
    - Adds a newline without additional data.

#### 5. **`Result::expect`**
- **Purpose**: Unwraps a `Result`, panicking with a custom message if it’s `Err`.
- **Signature**: `pub fn expect(self, msg: &str) -> Self::T`
- **Explanation**: This method extracts the `Ok` value from a `Result`, providing a message for debugging if an error occurs. It’s used here to handle the `Result` returned by `write!` and `writeln!`, ensuring the operation succeeds or panics with a meaningful message.
- **Usage in Code**:
  ```rust
  writeln!(stdout, "{} {} {}", a, b, x).expect("Failed to write");
  ```
  - Ensures the write operation succeeds, panicking with `"Failed to write"` if it fails.
