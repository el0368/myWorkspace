### 2.1.1 Input and Output

In most contests, standard streams are used for reading input and writing output. In Rust, standard input is accessed through `io::stdin()` and standard output through `io::stdout()` or the `println!` macro.

The input for the program usually consists of numbers and strings separated with spaces and newlines. They can be read as follows:

```rust
let mut input = String::new();
io::stdin().read_line(&mut input).unwrap();
let mut parts = input.split_whitespace();
let a: i32 = parts.next().unwrap().parse().unwrap();
let b: i32 = parts.next().unwrap().parse().unwrap();
let x: String = parts.next().unwrap().to_string();
```

This kind of code always works, assuming that there is at least one space or newline between each element in the input. For example, the above code can read both the following inputs:

```
123 456 monkey
```

```
123
456
monkey
```

Output is typically handled using the `println!` macro:

```rust
let a = 123;
let b = 456;
let x = "monkey";
println!("{} {} {}", a, b, x);
```

Input and output is sometimes a bottleneck in the program. For more efficient I/O operations, you can use buffered readers and writers:

```rust
use std::io::{self, BufRead, BufWriter, Write};

let stdin = io::stdin();
let mut reader = stdin.lock();
let stdout = io::stdout();
let mut writer = BufWriter::new(stdout.lock());
```

Note that `println!` automatically adds a newline and flushes, while `write!` and `writeln!` with a buffered writer can be more efficient for multiple outputs.

For faster input parsing, especially with large datasets, you can read all input at once:

```rust
let mut input = String::new();
io::stdin().read_to_string(&mut input).unwrap();
let mut tokens = input.split_whitespace();
let a: i32 = tokens.next().unwrap().parse().unwrap();
let b: i32 = tokens.next().unwrap().parse().unwrap();
```

Sometimes the program should read a whole input line, possibly containing spaces. This can be accomplished using:

```rust
let mut s = String::new();
io::stdin().read_line(&mut s).unwrap();
let s = s.trim(); // Remove the trailing newline
```

If the amount of data is unknown, the following loop is useful:

```rust
let stdin = io::stdin();
for line in stdin.lock().lines() {
    let line = line.unwrap();
    let tokens: Vec<&str> = line.split_whitespace().collect();
    // process tokens
}
```

This loop reads lines from the input one after another, until there is no more data available in the input.

In some contest systems, files are used for input and output. An easy solution for this is to redirect the streams at the beginning of the program:

```rust
use std::fs::File;
use std::io::{self, BufRead, BufReader, Write};

let input_file = File::open("input.txt").unwrap();
let reader = BufReader::new(input_file);
let mut output_file = File::create("output.txt").unwrap();

for line in reader.lines() {
    let line = line.unwrap();
    // process input from file
    writeln!(output_file, "output").unwrap();
}
```

After this setup, the program reads the input from the file "input.txt" and writes the output to the file "output.txt".
