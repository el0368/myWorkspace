### 2.1.1 Input and Output

In most competitive programming contests, standard streams are utilized for reading input and writing output. Rust employs the `std::io` module to manage these operations, providing efficient and safe methods for handling input and output. The input for a program typically consists of numbers and strings separated by spaces and newlines, which can be read and processed using Rust's I/O tools. Output is formatted and written using similar mechanisms, ensuring compatibility with contest requirements.

#### Reading Input (Numbers and Strings)

Rust uses `std::io::stdin` to read from standard input, often with buffered reading via the `BufRead` trait for efficiency. Here's how to read two integers and a string from a single line:

```rust
use std::io::{self, BufRead};

fn main() {
    let mut stdin = io::stdin().lock();
    let mut input = String::new();
    stdin.read_line(&mut input).expect("Failed to read line");
    let mut iter = input.trim().split_whitespace();
    let a: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let b: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let x: String = iter.next().unwrap().to_string();
    println!("a: {}, b: {}, x: {}", a, b, x);
}
```

- **Terminal Interaction**:
  1. Run the program (e.g., `cargo run --quiet` after setting up a Rust project).
  2. Type `123 456 monkey` and press Enter.
- **Input**:
  ```
  123 456 monkey
  ```
- **Output**:
  ```
  a: 123, b: 456, x: monkey
  ```
- **Explanation**: The program locks `stdin` for buffered reading, reads a line into `input`, trims the newline, splits it into tokens, and parses `a` and `b` as integers and `x` as a string. This works for inputs like `123 456 monkey` or multi-line inputs (e.g., `123 456` on one line, `monkey` on the next) if adjusted to read multiple lines.

For multi-line input, you can use the following approach:

```rust
use std::io::{self, BufRead};

fn main() {
    let mut lines = io::stdin().lock().lines();
    let first_line = lines.next().unwrap().expect("Failed to read line");
    let mut iter = first_line.trim().split_whitespace();
    let a: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let b: i32 = iter.next().unwrap().parse().expect("Expected an integer");
    let second_line = lines.next().unwrap().expect("Failed to read line");
    let x: String = second_line.trim().to_string();
    println!("a: {}, b: {}, x: {}", a, b, x);
}
```

- **Terminal Interaction**:
  1. Run the program.
  2. Type `123 456` and press Enter.
  3. Type `monkey` and press Enter.
- **Input**:
  ```
  123 456
  monkey
  ```
- **Output**:
  ```
  a: 123, b: 456, x: monkey
  ```
- **Explanation**: The `lines()` iterator reads each line separately, allowing `a` and `b` to be parsed from the first line and `x` from the second.

#### Writing Output

Rust uses `std::io::stdout` for output, with macros like `println!` or `write!` for formatting. Here's how to output two integers and a string:

```rust
use std::io::{self, Write};

fn main() {
    let a = 123;
    let b = 456;
    let x = "monkey";
    let mut stdout = io::stdout().lock();
    writeln!(stdout, "{} {} {}", a, b, x).expect("Failed to write");
}
```

- **Terminal Interaction**:
  1. Run the program.
  2. The output appears immediately.
- **Input**: None (this is output-only).
- **Output**:
  ```
  123 456 monkey
  ```
- **Explanation**: `io::stdout().lock()` provides a buffered output handle, and `writeln!` formats the values with spaces and a newline. For finer control without a newline:

```rust
use std::io::{self, Write};

fn main() {
    let a = 123;
    let b = 456;
    let x = "monkey";
    let mut stdout = io::stdout().lock();
    write!(stdout, "{} {} {}", a, b, x).expect("Failed to write");
    writeln!(stdout).expect("Failed to write newline");
}
```

- **Terminal Interaction**: Run the program.
- **Input**: None.
- **Output**:
  ```
  123 456 monkey
  ```
- **Explanation**: `write!` outputs without a newline, and `writeln!` adds it separately, offering manual control.

#### Optimizing Input and Output

Input and output can be bottlenecks in competitive programming. Rust optimizes this with buffered I/O and reusable buffers. Here's an example:

```rust
use std::io::{self, BufRead, BufWriter, Write};

fn main() {
    let mut stdin = io::stdin().lock();
    let stdout = io::stdout();
    let mut stdout = BufWriter::new(stdout.lock());
    let mut input = String::new();
    stdin.read_line(&mut input).expect("Failed to read line");
    let numbers: Vec<i32> = input
        .trim()
        .split_whitespace()
        .map(|s| s.parse().expect("Expected an integer"))
        .collect();
    for num in numbers {
        write!(stdout, "{} ", num).expect("Failed to write");
    }
    writeln!(stdout).expect("Failed to write newline");
}
```

- **Terminal Interaction**:
  1. Run the program.
  2. Type `1 2 3` and press Enter.
- **Input**:
  ```
  1 2 3
  ```
- **Output**:
  ```
  1 2 3
  ```
- **Explanation**: `BufWriter` buffers output, reducing system calls, while `stdin.lock()` and a reusable `input` buffer optimize input. This is faster for large datasets.

#### Reading a Whole Input Line (Including Spaces)

To read a line that may contain spaces, use `read_line`:

```rust
use std::io::{self, BufRead};

fn main() {
    let mut stdin = io::stdin().lock();
    let mut s = String::new();
    stdin.read_line(&mut s).expect("Failed to read line");
    let s = s.trim();
    println!("Line: {}", s);
}
```

- **Terminal Interaction**:
  1. Run the program.
  2. Type `hello world` and press Enter.
- **Input**:
  ```
  hello world
  ```
- **Output**:
  ```
  Line: hello world
  ```
- **Explanation**: `read_line` captures the entire line, including spaces, and `trim()` removes the newline.

#### Reading Unknown Amounts of Data

For inputs with an unknown number of elements, use a loop with `lines()`:

```rust
use std::io::{self, BufRead};

fn main() {
    let stdin = io::stdin().lock();
    for line in stdin.lines() {
        let line = line.expect("Failed to read line");
        for x in line.trim().split_whitespace() {
            let num: i32 = x.parse().expect("Expected an integer");
            print!("{} ", num);
        }
        println!();
    }
}
```

- **Terminal Interaction**:
  1. Run the program.
  2. Type `1 2 3` and press Enter.
  3. Type `4 5` and press Enter.
  4. Press Ctrl+D (Unix) or Ctrl+Z (Windows) and Enter.
- **Input**:
  ```
  1 2 3
  4 5
  [Ctrl+D or Ctrl+Z]
  ```
- **Output**:
  ```
  1 2 3
  4 5
  ```
- **Explanation**: `lines()` iterates until EOF, processing each line’s tokens.

#### File-Based Input and Output

Some contest systems use files. Rust supports this with `std::fs::File` and redirection:

```rust
use std::fs::File;
use std::io::{self, BufRead, BufWriter, Write};

fn main() {
    let input_file = File::open("input.txt").expect("Failed to open input.txt");
    let mut input = BufReader::new(input_file);
    let output_file = File::create("output.txt").expect("Failed to create output.txt");
    let mut output = BufWriter::new(output_file);
    let mut line = String::new();
    input.read_line(&mut line).expect("Failed to read line");
    let numbers: Vec<i32> = line
        .trim()
        .split_whitespace()
        .map(|s| s.parse().expect("Expected an integer"))
        .collect();
    for num in numbers {
        write!(output, "{} ", num).expect("Failed to write");
    }
    writeln!(output).expect("Failed to write newline");
}
```

- **Terminal Interaction**:
  1. Create `input.txt` with `1 2 3\n`.
  2. Run `cargo run --quiet` (ensure `input.txt` is in the project directory).
- **Input File (`input.txt`)**:
  ```
  1 2 3
  ```
- **Output File (`output.txt`)**:
  ```
  1 2 3
  ```
- **Explanation**: `BufReader` reads from `input.txt`, and `BufWriter` writes to `output.txt`. Alternatively, redirect with `cargo run --quiet < input.txt > output.txt`.

#### Conclusion

Rust’s `std::io` module provides a robust framework for competitive programming I/O, using buffered streams (`lock`, `BufReader`, `BufWriter`) for efficiency, `read_line` for whole lines, and file support for contest systems. These methods ensure fast, safe handling of all common input/output patterns.
