The most critical concept to understand is that a slice does not contain any data itself. Instead, a slice is a **lightweight view** or a **window** into a section of an underlying array.

---

### No Data Copying

When you create a slice from an array, the data from the array is **not copied**. The slice is a small data structure that simply holds a pointer to the start of its view, along with its length and capacity. This means creating a slice is extremely fast and memory-efficient, as you are not duplicating potentially large amounts of data.

---

### Shared Memory and Modification

Because a slice is just a view into an array, both the slice and the array share the same underlying memory. This has one very important implication: if you modify an element in the slice, the change will be visible in the original array.

This demonstrates that the slice is not a separate copy but is directly linked to the array's data.

Go

```Go
package main

import "fmt"

func main() {
    // 1. The original array
    prices := [4]float64{10.99, 9.99, 45.99, 20.0}
    fmt.Println("Original Array:", prices)

    // 2. Create a slice (a view) of the middle two elements
    featuredPrices := prices[1:3] // This slice views [9.99, 45.99]
    fmt.Println("Slice before change:", featuredPrices)

    // 3. Modify the first element of the SLICE
    featuredPrices[0] = 199.99 // This changes the element at index 0 of the slice

    // 4. Observe the change in the ORIGINAL ARRAY
    // The element at index 1 of the 'prices' array has been changed.
    fmt.Println("Original Array after change:", prices)
    fmt.Println("Slice after change:", featuredPrices)
}
```

**Output:**

```Go
Original Array: [10.99 9.99 45.99 20]
Slice before change: [9.99 45.99]
Original Array after change: [10.99 199.99 45.99 20]
Slice after change: [199.99 45.99]
```
