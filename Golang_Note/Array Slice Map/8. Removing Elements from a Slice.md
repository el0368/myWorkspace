Go does not have a built-in `remove` or `delete` function for slices. Instead, you remove elements by using slicing and the `append` function to create a **new slice** that contains only the elements you want to keep.

---

### The Technique: Slicing and Appending

The most common and versatile way to remove an element from any position in a slice is to combine two slices: one containing everything _before_ the element you want to remove, and one containing everything _after_ it.

The general pattern to remove the element at index `i` is:

Go

```Go
slice = append(slice[:i], slice[i+1:]...)
```

Let's break down how this works:

- **`slice[:i]`**: This creates a new slice containing all elements from the beginning up to (but not including) index `i`.
    
- **`slice[i+1:]`**: This creates another new slice containing all elements from index `i+1` all the way to the end.
    
- **`append(...)`**: This function takes the first slice (`slice[:i]`) and appends all the elements from the second slice (`slice[i+1:]`) to it.
    
- **The `...` operator**: This is crucial. It "unpacks" the second slice, feeding its elements individually to `append`. Without it, you'd be trying to append a slice to a slice, which would cause a type error.
    

---

### Example

Let's remove the element "C" (at index 2) from a slice of strings.

Go

```Go
package main

import "fmt"

func main() {
    letters := []string{"A", "B", "C", "D", "E"}
    fmt.Println("Original slice:", letters)

    // Remove the element at index 2 ("C")
    letters = append(letters[:2], letters[3:]...)

    fmt.Println("Modified slice:", letters)
}
```

**Output:**

```Go
Original slice: [A B C D E]
Modified slice: [A B D E]
```

### Simpler Cases

Removing the first or last element is much simpler, as you only need to create one slice.

- **To remove the first element:** `slice = slice[1:]`
    
- **To remove the last element:** `slice = slice[:len(slice)-1]`
