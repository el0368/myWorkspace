In programming language design, the term **first-class citizen** refers to any entity that supports all the operations generally available to other entities, such as being passed as an argument, returned from a function, and assigned to a variable.1 In Go, functions are first-class citizens, a feature that provides significant flexibility and enables powerful programming paradigms.2

This document provides an in-depth exploration of this concept, covering function types, the use of functions as values, and the declaration of anonymous functions.

---

### Function Types

Just as `int` is the type for integers and `string` is the type for text, a function also has a type. A function's type is defined by its signature: the sequence of its parameter types and the sequence of its return types.

The syntax for a function type is `func(parameter_types) return_types`.

Consider the following example. We can declare a custom type named `calculatorFunc` that represents any function taking two integers as input and returning a single integer.

Go

```Go
package main

import "fmt"

// Declaring a function type
type calculatorFunc func(int, int) int

// 'add' is a function that matches the calculatorFunc type
func add(a, b int) int {
	return a + b
}

// 'subtract' is another function that matches the same type
func subtract(a, b int) int {
	return a - b
}

func main() {
    // Here we declare a variable 'op' of our new function type
	var op calculatorFunc

    // Assign the 'add' function to our variable
	op = add
	fmt.Printf("Result of 'add': %d\n", op(10, 5)) // Result of 'add': 15

    // Reassign the 'subtract' function to the same variable
	op = subtract
	fmt.Printf("Result of 'subtract': %d\n", op(10, 5)) // Result of 'subtract': 5
}
```

In this demonstration, `op` is a variable that acts as a placeholder for a function. Its ability to hold different functions of the same type is the first indication of functions being treated as values.

### Passing Functions to Other Functions

A significant consequence of functions being first-class citizens is the ability to pass them as arguments to other functions.3 This pattern is fundamental to creating flexible and reusable code, often employed for implementing strategies, filters, or callbacks.4 A function that accepts another function as an argument is known as a **higher-order function**.

Let's design a higher-order function `compute` that accepts two integers and a `calculatorFunc` to perform an operation.

Go

```Go
package main

import "fmt"

type calculatorFunc func(int, int) int

func add(a, b int) int {
	return a + b
}

func multiply(a, b int) int {
    return a * b
}

// 'compute' is a higher-order function
func compute(a, b int, op calculatorFunc) int {
	fmt.Printf("Executing operation on %d and %d...\n", a, b)
	return op(a, b)
}

func main() {
	result1 := compute(8, 4, add)
	fmt.Printf("Result: %d\n\n", result1) // Result: 12

	result2 := compute(8, 4, multiply)
	fmt.Printf("Result: %d\n", result2)   // Result: 32
}
```

By passing different functions (`add`, `multiply`) into `compute`, we can alter its behavior without modifying its core logic.

### Returning Functions from Other Functions

Complementary to passing functions as arguments, Go allows functions to be returned as values.5 This enables the creation of "function factories"—functions that generate and configure other functions.

The following example shows a function `createMultiplier` that returns a new function. The returned function "remembers" the `factor` it was created with, a concept known as a closure (which will be detailed in a subsequent lesson).

Go

```Go
package main

import "fmt"

// This function returns another function
func createMultiplier(factor int) func(int) int {
    // This is the function we are returning
	return func(n int) int {
		return n * factor
	}
}

func main() {
    // Create a function that doubles a number
	double := createMultiplier(2)

    // Create a function that triples a number
	triple := createMultiplier(3)

	fmt.Println("Result of doubling 5:", double(5))    // Result of doubling 5: 10
	fmt.Println("Result of tripling 5:", triple(5))    // Result of tripling 5: 15
}
```

### Anonymous Functions

Go supports **anonymous functions**, which are functions defined inline without a name.6 They are particularly useful when you need a short, one-off function to pass as an argument to a higher-order function, thus avoiding the need to declare a separate, named function.

Let's revisit our `compute` example, this time using an anonymous function for a division operation.

Go

```Go
package main

import "fmt"

type calculatorFunc func(int, int) int

func compute(a, b int, op calculatorFunc) int {
	return op(a, b)
}

func main() {
	// We define the division logic directly where it's needed
	divisionResult := compute(100, 25, func(a, b int) int {
		if b == 0 {
			return 0 // Avoid division by zero
		}
		return a / b
	})

	fmt.Printf("Result of division: %d\n", divisionResult) // Result of division: 4
}
```

In essence, the treatment of functions as first-class citizens is a cornerstone of expressive, modular programming in Go. It allows developers to write abstract, adaptable code by manipulating functions as values, which is fundamental to many advanced software patterns.
