Of course. Here is a demonstration of building a composite interface from smaller ones.

Our goal is to create a contract for a resource that can be read from, written to, and closed.

---

### 1. The Simple, Single-Action Interfaces

First, we define three small interfaces, each with only one job.



```Go
package main

import "fmt"

// A contract for things that can be read.
type Reader interface {
	Read()
}

// A contract for things that can be written to.
type Writer interface {
	Write()
}

// A contract for things that can be closed.
type Closer interface {
	Close()
}
```

### 2. The Composite Interface

Now, we create a more complex interface, `ReadWriteCloser`, by embedding the three smaller interfaces. This new interface now requires a type to have all three methods (`Read`, `Write`, and `Close`).



```Go
// This interface is composed of the other three.
type ReadWriteCloser interface {
	Reader
	Writer
	Closer
}
```

### 3. The Concrete Type

Next, we create a type that will fulfill this composite contract by implementing all the necessary methods.



```Go
// A File can be read, written, and closed.
type File struct {
	name string
}

func (f File) Read() {
	fmt.Printf("Reading from file %s...\n", f.name)
}

func (f File) Write() {
	fmt.Printf("Writing to file %s...\n", f.name)
}

func (f File) Close() {
	fmt.Printf("Closing file %s...\n", f.name)
}
```

### 4. Using the Composite Interface

Finally, we can write a function that accepts our composite interface. It can confidently call any of the embedded interface methods on any type that satisfies the contract.



```Go
// This function can work with any resource that satisfies
// the ReadWriteCloser contract.
func manageResource(rwc ReadWriteCloser) {
	fmt.Println("--- Managing Resource ---")
	rwc.Read()
	rwc.Write()
	rwc.Close()
}

func main() {
	// Create our concrete File type.
	myFile := File{name: "document.txt"}

	// Pass our File to the function. It works because File
	// has all the methods required by the ReadWriteCloser interface.
	manageResource(myFile)
}
```

**Output:**

```
--- Managing Resource ---
Reading from file document.txt...
Writing to file document.txt...
Closing file document.txt...
```
