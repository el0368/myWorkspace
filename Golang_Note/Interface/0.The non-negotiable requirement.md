  a type to satisfy an interface is that it must implement **all the methods** defined in that interface.

---

### The Strict Contract

An interface is an "all or nothing" contract. It's not enough to implement some of the methods; you must implement every single one listed in the interface definition.

Furthermore, the implementation's method signature (the method name, parameter types, and return types) must **exactly** match the signature in the interface.

This is not a suggestion; it's a strict rule enforced by the Go compiler. If a type is missing even one required method or has a slight mismatch in its signature, your code will not compile.
