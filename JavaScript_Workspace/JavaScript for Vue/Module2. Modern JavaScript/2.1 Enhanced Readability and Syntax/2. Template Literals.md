Template literals are a modern way to create strings in JavaScript, allowing you to easily embed expressions and create multi-line strings. They are defined using backticks (`` ` ``) instead of single or double quotes.

---

### Embedding Expressions 🚀

The most powerful feature of template literals is the ability to embed JavaScript expressions directly into a string using the `${...}` syntax. The expression inside the curly braces is evaluated, and its result is included in the final string.

This is much cleaner and more readable than traditional string concatenation with the `+` operator.

- **Traditional String Concatenation:**
    
    JavaScript
    
    ```JavaScript
    const user = { name: 'Alice', role: 'Admin' };
    const welcomeMessage = 'Welcome, ' + user.name + '! Your role is ' + user.role + '.';
    ```
    
- **With Template Literals:**
    
    JavaScript
    
    ```JavaScript
    const user = { name: 'Alice', role: 'Admin' };
    const welcomeMessage = `Welcome, ${user.name}! Your role is ${user.role}.`;
    ```
    

You can embed any valid JavaScript expression, not just variables.

JavaScript

```JavaScript
const item = { price: 50, tax: 0.07 };
const totalCostMessage = `The total cost is $${item.price * (1 + item.tax)}.`;
// totalCostMessage is "The total cost is $53.5."
```

---

### Multi-line Strings 📄

Template literals also make creating strings that span multiple lines incredibly simple. You just press Enter to create a new line, and the line breaks are preserved in the string. This was cumbersome with traditional strings, which required concatenation or escape characters.

- **Traditional Multi-line String:**
    
    JavaScript
    
    ```JavaScript
    const htmlBlockOld = '<div class="profile">\n' +
                       '  <h2>Alice</h2>\n' +
                       '</div>';
    ```
    
- **With Template Literals:**
    
    JavaScript
    
    ```JavaScript
    const htmlBlockNew = `<div class="profile">
                          <h2>Alice</h2>
                        </div>`;
    ```
    

Understanding template literals is excellent preparation for Vue, as Vue's own template syntax uses a similar concept of embedding data and expressions directly into your HTML markup to create dynamic user interfaces.
