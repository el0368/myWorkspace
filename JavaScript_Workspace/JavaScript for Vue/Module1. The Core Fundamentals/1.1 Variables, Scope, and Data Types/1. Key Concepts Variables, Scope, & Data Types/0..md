### **Key Concepts: Variables, Scope, & Data Types**

- **Variables**: Think of variables as labeled containers for storing data. In modern JavaScript, you have three keywords to declare them:
    
    - `let`: Use this for variables whose values **will change**. It's block-scoped, meaning it's only accessible within the code block (`{}`) it's defined in.
        
    - `const`: Use this for variables whose values **will not change**. It's also block-scoped and must be given a value when declared. This is the preferred choice for most variables to prevent accidental reassignment.
        
    - `var`: The older way to declare variables. It's function-scoped, not block-scoped, which can lead to unexpected behavior. It's best to avoid `var` in modern code.
        

---

- **Scope**: Scope determines the accessibility or visibility of variables. It's the answer to the question, "Where can I see this variable?"
    
    - **Global Scope**: A variable declared outside any function or block is available everywhere in your code.
        
    - **Function Scope**: A variable declared inside a function (with `var`, `let`, or `const`) is only accessible within that function.
        
    - **Block Scope**: A variable declared inside a block, like an `if` statement or a `for` loop (with `let` or `const`), is only accessible within that specific block. This is a key advantage of `let` and `const`.
        

---

- **Data Types**: This describes the type of data a variable can hold.
    
    - **Primitive Types**: These are the most basic data types.
        
        - **String**: Text, like `"hello world"`.
            
        - **Number**: Numeric values, both integers (`10`) and decimals (`3.14`).
            
        - **Boolean**: Represents `true` or `false`.
            
        - **Undefined**: A variable that has been declared but not assigned a value.
            
        - **Null**: Represents the intentional absence of any object value. It means "nothing."
            
        - **Symbol** & **BigInt**: More specialized types you'll encounter less frequently at the start.
            
    - **Object Type**: A more complex data type that can store a collection of key-value pairs. Arrays, functions, and dates are also technically types of objects in JavaScript.
