### ## Querying and Selecting DOM Elements

You can select elements from the DOM using various methods, most of which are available on the global **`document`** object. These methods allow you to get references to DOM nodes, store them in variables, and manipulate them.

### ## Selecting a Single Element

- **`document.getElementById('id-name')`**
    
    - Selects one element by its unique `id`.
        
    - You pass the ID string as an argument **without** the leading `#` symbol.
        
    - This is the preferred and most efficient way to select a unique element.
        
- **`document.querySelector('css-selector')`**
    
    - A powerful and flexible method that selects the **first** element matching a given CSS selector.
        
    - The selector can be simple (`.my-class`, `#my-id`) or complex (`ul > li:first-of-type`).
        

### ## Selecting Multiple Elements

- **`document.querySelectorAll('css-selector')`**
    
    - The multi-element version of `querySelector`.
        
    - It returns a **NodeList** (an array-like object) containing **all** elements that match the CSS selector.
        
- **Older Methods (Still Supported)**
    
    - `document.getElementsByClassName('class-name')`
        
    - `document.getElementsByTagName('tag-name')`
        
    - These return live HTMLCollections but `querySelectorAll` is generally more common and flexible today.
        

### ## Scoped Queries

Once you have selected an element and stored it in a variable, you can run query methods **on that element** to search only within its children. This is useful for narrowing down your search.

JavaScript

```
const list = document.querySelector('ul');
// This searches for an <li> only inside the <ul> we already found.
const firstItem = list.querySelector('li');
```

---

### ## Important Note on Script Placement

Your JavaScript file must be executed **after** the HTML document has been fully parsed. Otherwise, your queries for DOM elements will fail because the elements won't exist yet. Ensure this by:

1. Placing your `<script>` tag at the very end of the `<body>`, OR
    
2. Placing it in the `<head>` with the **`defer`** attribute (`<script src="app.js" defer></script>`).
