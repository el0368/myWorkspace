## JavaScript Functions & Methods: A Study Guide

### 128. Functions Are Objects

**Core Idea:** Despite having their own `typeof` result, functions in JavaScript are fundamentally a special type of **object**.

1. **Proof with `typeof`:**
    
    - We can use the `typeof` operator to check the type of our `startGame` function.
        
    - **Important:** Do _not_ add parentheses `()` after the function name when using `typeof` if you want to know the type of the function itself.
        
        - `typeof startGame()` would execute the function, and since `startGame` returns nothing, it'd give `typeof undefined`, which is `"undefined"`.
            
    - If you just log `typeof startGame` (the name without `()`), you get:
        
        JavaScript
        
        ```JavaScript
        function startGame() {
          console.log("Game is staring....");
        }
        console.log(typeof startGame); // Output: "function"
        ```
        
    - **Conclusion:** While it explicitly logs "function," this distinct type is actually _based on object_.
        
2. **Deeper Proof with `console.dir()`:**
    
    - To see the object nature more clearly, we can use `console.dir()`. This displays an interactive listing of an object's properties.
        
    - If you use `console.dir()` on a function, you'll see it has many properties (key-value pairs) just like any other object.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        function startGame() {
          console.log("Game is staring....");
        }
        console.dir(startGame);
        ```
        
    - **Observation:** In the console, you can expand `startGame` and see properties like `name`, `arguments`, `length`, `prototype`, and `[[Scopes]]`. These are all properties of the function object itself.
        
    - **Conclusion:** This confirms that a function, while having its own specific "function" type, is ultimately an **object**. It's a special type of object with pre-configured properties.
        
3. **Implications of Functions Being Objects:**
    
    - Since functions are objects, they are typically stored in the **heap** (memory).
        
    - Anything that applies to objects, such as being **reference types**, also applies to functions. This means when you pass a function, you're passing a reference to that object in memory.
        
    - While this might not always directly affect your daily coding, it's important to be aware of this fundamental characteristic of JavaScript.
        

Summary of 128. Functions Are Objects:

Functions are a special type of object in JavaScript. This is evidenced by typeof returning "function" (a type based on object) and console.dir() showing that functions possess properties like other objects. This implies functions are reference types and stored in the heap.
