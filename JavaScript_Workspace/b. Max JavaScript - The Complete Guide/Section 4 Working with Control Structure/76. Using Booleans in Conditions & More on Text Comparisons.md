**I. Understanding the "Condition" in `if` Statements**

- **Core Principle:** The expression inside the parentheses of an `if` statement, `if (condition)`, _must always evaluate to a boolean value_ (`true` or `false`).
    
- **Generating Booleans:**
    
    - Most commonly, you'll **generate** a boolean value using comparison operators:
        
        - Strict Equality (`===`)
            
        - Strict Inequality (`!==`)
            
        - Greater Than (`>`)
            
        - Less Than (`<`)
            
        - Greater Than or Equal To (`>=`)
            
        - Less Than or Equal To (`<=`)
            
    - These operators **yield (return) boolean values** without modifying the original variables or values involved in the comparison.
        
- **Using Existing Booleans:**
    
    - If you already have a variable that directly holds a boolean value, you can use it as the condition _without any additional operator_.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        const isLoggedIn = true; // isLoggedIn already holds a boolean
        if (isLoggedIn) {
            console.log("Welcome back!"); // This code executes because isLoggedIn is true
        }
        ```
        
    - **Redundancy:** Writing `if (isLoggedIn === true)` is redundant because `isLoggedIn` itself is already a boolean. You're unnecessarily creating a new boolean value (`isLoggedIn === true`) when you already have one.
        
- **Negating Booleans with `!` (Logical NOT):**
    
    - The `!` operator (Logical NOT) **inverts** a boolean value (turns `true` into `false`, and `false` into `true`).
        
    - You can use `!` directly on a boolean variable within a condition.
        
    - **Example:**
        
        JavaScript
        
        ```JavaScript
        const userIsAdmin = false;
        if (!userIsAdmin) {
            console.log("You do not have administrative access."); // This code executes because !false is true
        } else {
            console.log("Welcome, Administrator.");
        }
        ```
        
    - **Redundancy:** Writing `if (userIsAdmin !== true)` is redundant when `if (!userIsAdmin)` achieves the same, clearer result.
        

**II. More on Text (String) Comparisons**

- **Comparisons with `>`, `<`, `>=`, `<=`:** Strings can be compared using these operators, not just for equality.
    
- **Lexicographical Ordering (Alphabetical Order):**
    
    - JavaScript compares strings based on **standard lexicographical (dictionary) ordering**.
        
    - This comparison uses **Unicode values** of the characters.
        
- **Comparison Rules:**
    
    1. **First Character:** JavaScript primarily compares the _first character_ of each string.
        
        - If the first characters are different, the comparison result is determined by their Unicode values.
            
    2. **Subsequent Characters (if first characters are similar/same):** Only if the first characters are identical (or equal in Unicode value) does JavaScript move on to compare the second characters, and so on.
        
    3. **Case Sensitivity:** **Capital letters are considered "smaller" (have lower Unicode values) than lowercase letters.** This is a crucial detail.
        
- **Examples:**
    
    - `'ab' > 'aa'` // `true` (because 'b' comes after 'a' in the second position)
        
    - `'a' > 'B'` // `true` (because lowercase 'a' has a higher Unicode value than uppercase 'B')
        
    - `'a' > 'b'` // `false` (because lowercase 'a' comes before lowercase 'b')
        
    - `'Z' > 'a'` // `false` (because uppercase 'Z' has a lower Unicode value than lowercase 'a')
        
    - `'apple' < 'banana'` // `true` (lexicographically, 'a' comes before 'b')
        
    - `'cat' >= 'Car'` // `true` (because lowercase 'c' is greater than uppercase 'C')
