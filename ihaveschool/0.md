# Project Setup Log

Here is the step-by-step account of how we set up the "Khan Academy Lite" project.

## 1. Environment Preparation

- **Bun Installation**: Identified `bun` was missing. Installed key-value runtime (`v1.3.4`) using formatting compatible with Git Bash on Windows.
- **Workspace Selection**:
    - Initially attempted setup in a scratch folder.
    - Relocated to **`E:\GitHub\ihaveschool`** (External Hard Drive) per your request.

## 2. Project Initialization

- **Scaffolding**: Used `bun create vite . --template vue-ts` to generate a Vue 3 + TypeScript base.
- **Dependency Installation**:
    - Installed the "High Performance" stack:
        - **Backend/Fullstack**: `elysia`, `drizzle-orm`
        - **State/Utils**: `pinia`, `@vueuse/core`
        - **Styling**: `tailwindcss`, `@tailwindcss/vite`
        - **Math**: `katex` (Rendering), `mathlive` (Input)
        - **Dev Tools**: `@biomejs/biome` (Linting)
    - _Note_: Encountered `EINVAL` lockfile errors due to the external drive file system, but verified all packages were successfully installed.

## 3. Strict Architecture Implementation (Feature-Sliced)

- **Clean Up**: Removed default `HelloWorld.vue` and `style.css`.
- **Restructuring**:
    - Created `src/modules/` for business logic (Math, English).
    - Created `src/shared/` for reusable UI and utils.
    - Created `src/app/` for app configuration.
    - Moved `App.vue` and `main.ts` into `src/app/`.

## 4. Configuration Updates

- **Vite (`vite.config.ts`)**:
    - Configured path aliases (`@app`, `@modules`, `@shared`) for clean imports.
    - Added custom element support for `math-field` (MathLive).
- **TypeScript (`tsconfig.app.json`)**:
    - Mapped the same aliases so VS Code understands the imports.
- **Entry Point (`index.html`)**:
    - Updated script source to `/src/app/main.ts`.

## 5. Feature Implementation (Math Module)

- **`EquationRenderer.vue`**: Created a component that takes a LaTeX string and renders it using **KaTeX**.
- **`MathInput.vue`**: Created a wrapper around **MathLive** web component to allow interactive equation typing.
- **Integration**: Updated `App.vue` to display a quadratic formula demo and a live input tester.

## 6. Final Verification

- Ran `bun run build`.
- Confirmed successful compilation despite earlier file locking warnings.
