**What is SQL?**

- **Definition:** SQL (Structured Query Language, pronounced "sequel" or "S.Q.L.") is a language used for working with structured data, especially data organized into tables.
    
- **Purpose:**
    
    - **Querying Data:** Selecting, filtering, and merging data from different tables (most prominent use).
        
    - **Data Manipulation (CRUD Operations):** Inserting, updating, and deleting data.
        
    - **Database and Table Creation:** Creating databases and defining the structure of tables (columns, data types).
        

**Key Concepts:**

1. **Tabular Data:**
    
    - SQL works with data stored in **tables**.
        
    - Each table has **multiple columns (fields)** and **different rows (records/entries)**.
        
    - **Columns define the structure:** When creating a table, you define its columns and the _data type_ each column can hold (e.g., number, text). All data in a given column must adhere to this defined type.
        
    - **Rows represent individual entities:** Each row contains a complete record for an entity (e.g., one employee, one department).
        
2. **Relational Database Management Systems (RDBMS):**
    
    - SQL is the language for interacting with these systems.
        
    - RDBMS are the _software tools_ that actually store, organize, and manage data in tables.
        
    - **Examples:** MySQL (or MySQL), PostgreSQL, Microsoft SQL Server, Oracle.
        
    - **Key Feature:** Data is stored in a **normalized form**, meaning data entities are split into different, related tables instead of one large table.
        
3. **Relationships Between Tables:**
    
    - Data is often split across multiple tables (e.g., "employees" and "departments").
        
    - These tables are connected through **logical relations**.
        
    - SQL provides tools to **connect and merge data** from related tables into a single result set.
        

**Core Characteristics (of SQL/RDBMS):**

- Data stored in **table format**.
    
- Typically involves **multiple tables**.
    
- Data stored in a **normalized form** (individual data entities extracted into separate, linked tables).
    
- **Clear structure:** Columns are clearly defined with specific data types, and all data inserted must adhere to this structure.
    

**Important Note on Terminology:**

- Both "SQL" and "sequel" are acceptable and commonly used. "SQL" is more official, while "sequel" often flows better in conversation.
