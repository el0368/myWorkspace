## How to Reset a Lost MySQL 8.0 Root Password on Windows

This guide outlines the successful procedure for resetting the `root` user password when it has been lost. The core of this method is to start the MySQL server in a special mode that bypasses the existing password check, allowing you to set a new one.

### **Step 1: Stop the MySQL Service**

Before making any changes, you must ensure the main MySQL server is not running.

1. Press **Windows Key + R**, type **`services.msc`**, and press Enter.
    
2. Find the service named **MySQL80** (or similar) in the list.
    
3. Right-click on it and select **Stop**.
    

### **Step 2: Create a Password Reset File**

Next, you will create a simple text file that contains the SQL commands to reset the password. This method sets the password to be blank initially for reliability.

1. Create a folder on your `C:\` drive (e.g., `C:\GitHub`).
    
2. Inside that folder, create a new text file named **`mysql-init.txt`**.
    
3. Open the file and paste the following two lines into it. This command clears the root password.
    
    SQL
    
    ```SQL
    UPDATE mysql.user SET authentication_string = '' WHERE User = 'root' AND Host = 'localhost';
    FLUSH PRIVILEGES;
    ```
    
4. Save and close the file.
    

### **Step 3: Manually Start the MySQL Server**

You will now start the server from the command prompt, telling it to use your reset file.

1. Open Command Prompt **as Administrator**.
    
2. Navigate to your MySQL `bin` directory by running this command:
    
    DOS
    
    ```SQL
    cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"
    ```
    
3. Run the following command to start the server with your reset file. It is normal for the cursor to just sit there as if it's "stuck"—this means the server is running and waiting.
    
    DOS
    
    ```SQL
    mysqld --defaults-file="C:\ProgramData\MySQL\MySQL Server 8.0\my.ini" --init-file="C:\GitHub\mysql-init.txt"
    ```
    
    > **Leave this command prompt window open.**
    

### **Step 4: Set the New Password**

With the temporary server running, you can now log in without a password and set your new one.

1. Open a **new, second** command prompt window.
    
2. In this new window, navigate to the `bin` directory again:
    
    DOS
    
    ```SQL
    cd "C:\Program Files\MySQL\MySQL Server 8.0\bin"
    ```
    
3. Log in to MySQL as root. When it prompts for a password, **do not type anything**—just press **Enter**.
    
    DOS
    
    ```SQL
    mysql -u root -p
    ```
    
4. You should now be at the `mysql>` prompt. Run the final command to set your desired password. Replace `YourNewPasswordHere` with the password you want.
    
    SQL
    
    ```SQL
    ALTER USER 'root'@'localhost' IDENTIFIED BY 'YourNewPasswordHere';
    ```
    
5. If you see `Query OK`, it was successful. Type `exit` and press Enter.
    

### **Step 5: Final Cleanup**

Your password is now reset. The last step is to return your system to its normal state.

1. Close **both** command prompt windows.
    
2. For security, **delete** the `C:\GitHub\mysql-init.txt` file.
    
3. Go back to the **Services** window and **Start** the MySQL80 service.
    

You can now connect to your MySQL database normally using your new password.
