**Course Outline: What You Will Learn in This SQL Course**

This course is structured into two main parts: **Basics** and **Advanced** topics.

**Part 1: Basics (Fundamentals)**

- **Getting Started (Current Module):** Completed - Understanding what SQL is and its relationship with RDBMS.
    
- **Module 2: SQL's Core Syntax (Theory-driven)**
    
    - Learning how to write correct SQL statements.
        
    - Understanding the general structure and appearance of the SQL language.
        
- **Module 3: Setup (Hands-on, Interactive)**
    
    - Setting up your development environment.
        
    - Learning how to run SQL queries on your own machine.
        
    - Concepts applicable to future projects.
        

**Part 2: Advanced Topics (Mastering SQL)**

- **Module 4: CRUD Operations (Create, Read, Update, Delete)**
    
    - **C (Create/Insert):** Adding new data into the database.
        
    - **R (Read/Access):** Retrieving existing information.
        
    - **U (Update):** Modifying data already stored in the database.
        
    - **D (Delete):** Removing information from databases.
        
    - _Importance:_ These are core commands essential for working with SQL.
        
- **Module 5: Data Relations and Joins**
    
    - Understanding that data is often split across multiple, related tables (e.g., `products`, `customers`).
        
    - How to establish relationships between tables.
        
    - Using **Joins** to combine and access information from related tables.
        
- **Module 6: Aggregate Functions**
    
    - Introduction to functions in SQL.
        
    - Focus on functions that perform mathematical calculations (e.g., `SUM`, `AVG`).
        
- **Module 7: Built-in Utility Functions**
    
    - Building on aggregate functions.
        
    - Learning helpful SQL functions for working with different data types:
        
        - Text manipulation.
            
        - Number operations (e.g., rounding decimals).
            
        - Date functions.
            
- **Module 8: Transactions**
    
    - A more advanced concept.
        
    - Bundling multiple SQL steps into a single, atomic operation (all or nothing).
        
    - _Note:_ More helpful later in the course.
        
- **Module 9: Indexes**
    
    - Focus on **performance improvement**.
        
    - Learning how to make data retrieval from the database faster and more efficient for SQL.
        

**Course Completion:**

- Upon finishing the "Indexes" module, you will have completed the core/advanced part of the course and be ready to work with SQL in your own projects.
    

**Alternative Learning Path:**

- The course also offers an "Essentials Summary approach," which will be explained further.
