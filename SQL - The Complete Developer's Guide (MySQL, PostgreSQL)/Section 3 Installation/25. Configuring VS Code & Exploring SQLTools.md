The lecturer is explaining how to use the **SQLTools extension in Visual Studio Code** for interacting with MySQL and PostgreSQL databases throughout the course.

Here are the key takeaways:

---

## Managing Database Connections

- **Persistent Connections:** The SQLTools extension allows you to manage database connections conveniently. You don't need to re-enter connection commands every time you resume work. Simply click the **green connection button** in the extension to re-establish a connection.
    
- **Switching Connections:** You can easily switch between connected databases (e.g., MySQL and PostgreSQL) by clicking on their respective tabs at the top of the SQL file window. This changes the active connection against which commands will be executed.
    
- **Closing Connections:** When you're done for the day, you can close active connections.
    

---

## Key Features of SQLTools for the Course

- **Cross-Database Testing:** A primary reason for using this extension in the course is its ability to easily run SQL commands against both MySQL and PostgreSQL. This facilitates **highlighting differences** between these database servers, as SQL has minor variations despite being largely standardized.
    
- **Query History:** The **Query History** feature records all executed commands. You can easily select an entry from the history to paste the command into your active SQL file or re-execute it directly.
    
- **Result Window Features:**
    
    - **Re-run Query:** A button in the result window allows for quick re-execution of the last query.
        
    - **Export Results:** You can export query results to **CSV or JSON files**, which is useful for external analysis or sharing.
        
    - **Console Log:** The "console" tab provides log messages about command execution (e.g., successful execution).
        
    - **Window Organization:** The results tab can be dragged to the bottom of the screen to create a split-pane view, allowing you to see both the command and its results simultaneously. This layout will be used frequently in the course.
        
- **Database and Schema Exploration:** The left-hand panel for connections allows you to expand a connected database (e.g., `postgres`'s `public` schema) to view its tables and other objects. This will become crucial later in the course when working with created tables.
    

---

## Fixing the MySQL Connection Issue

- **Problem:** The initial connection attempt to MySQL failed because a default database was not present, unlike with PostgreSQL where one was created during setup.
    
- **Solution:**
    
    1. Open **MySQL Workbench**.
        
    2. Go to the **Schemas tab**.
        
    3. **Right-click** within the schema area and choose "Create Schema."
        
    4. Name the new schema **`default`** (or the name you're trying to connect to in VS Code) and click "Apply" to create the database.
        
    5. After creation, close and **reconnect to MySQL** in the SQLTools extension in VS Code.
        
    6. The `default` database should now appear, and you can successfully run SQL commands against your MySQL connection.
        

---

## Storing Commands in Files

- **Moving Beyond "On-the-Fly" Execution:** While immediate command execution in the active connection window is useful, the course will emphasize storing commands in **`.sql` files** within a project folder.
    
- **Benefits of File Storage:**
    
    - **Persistence:** Commands are saved on your hard drive, allowing you to easily revisit and re-execute them later without retyping.
        
    - **Course Material Distribution:** The instructors (Max and Emmanuel) will provide course commands in these files.
        
- **How to Set Up:**
    
    1. Close any open, unsaved SQL windows in VS Code.
        
    2. Go to the **Explorer view** (left sidebar).
        
    3. Click "Open Folder" and select a dedicated folder (e.g., `SQL complete guide`).
        
    4. Create new files within this folder (e.g., `test.sql`). The `.sql` extension ensures the SQLTools extension recognizes and can execute the file's content.
        
    5. Type your SQL commands in these files and save them. You can then connect to a database via SQLTools and use the "Run on active connection" button to execute the commands from the file.
