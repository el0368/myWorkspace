The lecturer is explaining the initial setup of **Visual Studio Code (VS Code)** and the **SQLTools extension** to serve as the primary database client for the course, replacing dedicated database clients like MySQL Workbench or the PostgreSQL shell.

---

## Why Visual Studio Code and SQLTools?

- **Convenience:** Easier to save and share SQL commands with students.
    
- **Centralized Tool:** Acts as a single client for both MySQL and PostgreSQL.
    
- **Enhanced Features:** Provides autocomplete, syntax highlighting, and easy switching between database connections, which are beneficial for learning and development.
    

---

## Step-by-Step Setup Guide

### 1. Install Visual Studio Code

- **Download:** Visit [code.visualstudio.com](https://code.visualstudio.com/) to download the free code editor for your operating system.
    
- **Installation:** Follow the installer's instructions.
    
- **Initial Setup:** You can close the welcome page and customize the appearance (e.g., hide the sidebar, change color theme under **View > Appearance** and **Preferences > Color Theme**). The lecturer uses the "Dark+" theme.
    

### 2. Install the SQLTools Extension

- **Access Extensions:** Go to **View > Extensions** in VS Code.
    
- **Search and Install:** Search for "SQLTools" (no space) and install the extension by clicking the "Install" button.
    

### 3. Install Database Drivers

- **Access SQLTools Tab:** Go to **View > Appearance > Activity Bar** to show the activity bar on the left. You should now see the SQLTools icon (a database symbol). Click it.
    
- **Add New Connection:** Click "Add New Connection."
    
- **Search Marketplace:** Since no drivers are initially installed, click "Search VSCode Marketplace."
    
- **Install Drivers:**
    
    - Search for and install **"SQLTools MySQL/MariaDB driver."**
        
    - Search for and install **"SQLTools PostgreSQL driver."**
        
- **Close Marketplace:** Once installed, close the marketplace tab and return to the SQLTools tab.
    

### 4. Connect to MySQL

- **Select MySQL:** Click "Add New Connection" again and choose "MySQL."
    
- **Connection Details:**
    
    - **Connection Name:** `mysql1` (or any descriptive name).
        
    - **Server/Port:** Keep `localhost` and the default port unless you've changed them.
        
    - **Database:** Enter `default` (this database doesn't exist yet, but the connection attempt will confirm connectivity).
        
    - **Username:** `root`.
        
    - **Password:** Select "Ask on connect" (recommended for security).
        
- **Test Connection:** Click "Test Connection," enter your password, and verify it works.
    
- **Save Connection:** Click "Save Connection."
    
- **Connect Now:** Click "Connect Now" and enter your password again to establish the connection.
    

### 5. Fix MySQL Authentication Issue

- **Problem:** The default "strong authentication method" used by MySQL during installation prevents SQLTools from connecting, even though a basic `SELECT 'hello world'` might appear to fail due to a missing database, the underlying connection is still problematic. This is fine for local development.
    
- **Solution (Using MySQL Workbench):**
    
    1. Open **MySQL Workbench**.
        
    2. Connect to your MySQL server.
        
    3. Open a **new query tab**.
        
    4. Execute the following command (replace `your_password` with your MySQL root password):
        
        SQL
        
        ```
        ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'your_password';
        ```
        
    5. Execute this command (it's also provided as a file with the lecture).
        
- **Reconnect in VS Code:**
    
    1. Go back to the SQLTools tab in VS Code.
        
    2. **Close the existing MySQL connection** by clicking the "disconnect" icon (red X).
        
    3. **Reconnect** by clicking the "connect" icon (green arrow). Enter your password if prompted.
        
    4. Now, running `SELECT 'hello world';` will still show an error, but it will be because the `default` database doesn't exist yet (which is expected), not due to an authentication failure. This confirms the connection itself is successful.
        

### 6. Connect to PostgreSQL

- **Select PostgreSQL:** Click "Add New Connection" and choose "PostgreSQL."
    
- **Connection Details:**
    
    - **Connection Name:** `postgresql1` (or any descriptive name).
        
    - **Server/Port:** Keep `localhost` and the default port.
        
    - **Database:** `postgres` (this database should already exist from the PostgreSQL installation).
        
    - **Username:** `postgres`.
        
    - **Password:** Select "Ask on connect."
        
- **Test Connection:** Click "Test Connection," enter your password, and verify it works.
    
- **Save and Connect:** Click "Save Connection" and then "Connect Now."
    
- **Run Query:** You can now run `SELECT 'hello world';` against PostgreSQL, and it should succeed as the `postgres` database already exists.
