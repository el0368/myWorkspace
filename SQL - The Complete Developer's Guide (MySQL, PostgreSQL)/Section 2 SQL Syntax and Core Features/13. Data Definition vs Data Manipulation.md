## Data Definition vs. Data Manipulation in SQL

To truly master SQL, it's essential to understand that SQL commands are broadly categorized into two main types: **Data Definition Language (DDL)** and **Data Manipulation Language (DML)**. These two categories serve distinct purposes related to the structure and content of your database.

### 1. Data Definition Language (DDL)

- **Purpose:** DDL commands are used to **define the structure** or schema of your database. They deal with the overall organization of data, rather than the individual values within the data itself.
    
- **What it defines:**
    
    - **Databases:** Creating new databases.
        
    - **Tables:** Creating new tables within a database.
        
    - **Table Structures:** Defining the columns within a table, including their names, data types, and other properties.
        
    - **Relationships:** Establishing how different tables are logically connected to each other (e.g., through primary and foreign keys, which define how data in one table relates to data in another).
        
- **Key Operations (Examples of DDL Commands):**
    
    - **Creating:**
        
        - Creating databases.
            
        - Creating tables (e.g., specifying column names and their data types).
            
    - **Changing/Modifying:**
        
        - Modifying existing table structures (e.g., adding, dropping, or altering columns).
            
    - **Deleting (Dropping):**
        
        - Deleting entire tables or databases.
            
- **Logical Priority:** Data definition commands **logically come first**. You must define the structure (create tables) before you can add, retrieve, or modify data within that structure.
    
- **Course Relevance:** You will learn about these statements in **Section 4 and other sections** of this course.
    

### 2. Data Manipulation Language (DML)

- **Purpose:** DML commands are used to **interact with and manage the actual data** stored _within_ the defined database structures (tables). They deal with individual values, rows, and columns of data.
    
- **Commonly Referred to as CRUD:** DML operations are often summarized by the acronym **CRUD**:
    
    - **C** - **Create (Insert):** Adding _new data_ (rows) into an existing table.
        
    - **R** - **Read (Select):** Accessing and retrieving _existing data_ from tables. This includes filtering and sorting data.
        
    - **U** - **Update:** Modifying _existing data_ (values in rows/columns) within a table.
        
    - **D** - **Delete:** Removing _existing data_ (rows) from a table.
        
- **Key Operations (Examples of DML Commands):**
    
    - **Inserting Data:** Adding new rows to a table.
        
    - **Updating Data:** Changing values in existing rows.
        
    - **Deleting Data:** Removing specific rows from a table.
        
    - **Filtering Data:** Selecting only the rows that meet certain conditions (e.g., using a `WHERE` clause).
        
    - **Sorting Data:** Arranging retrieved data in a specific order.
        
    - **Joining Data:** Combining information from multiple, related tables into a single result set. This leverages the relationships previously defined by DDL.
        
- **Logical Dependency:** DML operations **depend on** the existence of structures created by DDL. You can't manipulate data if there's no table to hold it.
    
- **Course Relevance:** You will dive into DML topics starting in **Section 5 and other sections** of this course.
    

### Summary of Distinction:

|Feature|Data Definition Language (DDL)|Data Manipulation Language (DML)|
|---|---|---|
|**Focus**|**Structure** (Databases, Tables, Columns, Relationships)|**Content** (Individual data values within tables)|
|**Commands**|`CREATE`, `ALTER`, `DROP` (for databases/tables)|`INSERT`, `SELECT`, `UPDATE`, `DELETE` (CRUD operations)|
|**What it does**|Defines, changes, or removes the schema/framework of the database|Adds, retrieves, modifies, or removes actual data within that framework|
|**Logical Order**|Comes first (you build the house)|Comes second (you furnish and live in the house)|
